# 搶救鴻海與記憶體——費半重挫下台股脫鉤的真相與均線操作實戰

> 費半連續重挫但台股開低走高脫鉤，老王解析資金翹翹板效應與缺口壓力，鴻海從310跌回240外資連12天賣超，記憶體族群靠美光走勢定生死

## 核心觀點

**1. 費半重挫是漲多回檔，資金沒離開只是翹翹板**

道瓊大漲創新高同時費半連續重挫，從美股熱力圖看AI半導體供應鏈（左上方紅色）是唯一重災區，其他傳產、防禦型類股、蘋果等科技龍頭都是綠色上漲。這是資金從高基期流向低基期的翹翹板效應，並非資金撤離市場。後續關鍵在流向低基期的錢會不會回流費半——如果費半區域轉綠代表資金回籠，如果全部變紅才是真正危險信號。

**2. 台股短期脫鉤是假象，長期連動不可避免**

台股連續兩天開低走高看似跟費半脫鉤，但老王強調長期趨勢絕對高度連動。費半有未封閉的空方缺口、台股也有未封閉的空方缺口，型態完全連動。費半目前還沒跌破季線（長線支撐），一旦跌破季線加前波低點的雙重支撐，台股不可能獨強。

**3. 台股三陽開胎形成但缺中洞，缺口未封閉是關鍵**

7月1日大盤站上三條短期均線形成三陽開胎短線翻多，但上方空方缺口（中洞）始終未封閉。連漲三天碰到缺口壓力就過不去然後回落，技術分析在此展現精準度。下週功課：守住三條短期均線 + 封閉中洞缺口才能挑戰前高壓力突破。櫃買市場出現多方缺口，守住缺口反彈持續，封閉缺口才轉弱。

**4. 鴻海從310跌回240，外資連12天賣超是元兇**

鴻海一個月內從310跌回不到240，回到半山腰以下，關鍵在外資連續12天賣超「賣鴻海像在賣垃圾」。大漲時外資連8週大買推升股價，散戶連8週丟出籌碼；現在反過來，散戶連3週增加持股接走外資賣單，100張以下散戶持股比例飆高成為反向指標。鴻海要止跌需等外資回頭 + 散戶持股比例下降。

**5. 記憶體族群「看大做小」，美光跌破5日10日均線台廠必跟跌**

美光連跌兩天（跌10% + 跌5%），華邦電、南亞科高度連動同步跌破5日、10日甚至月均線。老王在6月23日盤中就建議會員在美光財報前先賣一半記憶體持股，精準賣在歷史高點隔天。操作邏輯：跌破5日均線減碼一半，跌破10日均線出場，等重新站回5日10日均線再買回（先賣再買策略）。

## 實戰重點

- **道瓊觀察**：用10日均線判斷強弱，跌破轉弱站上轉強；兩個三烏日結算大量低點都未跌破，趨勢仍向上
- **納斯達克觀察**：三烏日結算大量低點未站回 = 做空贏家；站回大量低點 = 四海游龍三陽開胎多方反彈
- **費半觀察**：空方缺口未封閉 = 空方趨勢不變；前波低點 + 季線雙重支撐不能跌破
- **台股大盤**：三條短期均線（5日、10日、月線）站上 = 三陽開胎短線翻多；跌破 = 三生無奈短線翻空；守住三條均線不需砍股票
- **鴻海操作**：大型權值股看月均線（20日均線），站上買進（約200元）、跌破賣出（約270元），一條線賺70元；目前四條短期均線全跌破 = 四面楚歌長線翻空，等站回所有均線才能買
- **記憶體操作**：5日均線跌破減碼一半，10日均線跌破出場；跌破大量低點直接先賣半不用等5日均線；先賣再買比撐月均線風險小
- **台化（1326）**：四海游龍型態 + 突破長期前高壓力 + 多方缺口，連兩天漲停；守住多方缺口 = 突破成功持續有高點，封閉缺口 = 假突破要小心

## 注意事項

- 台股短期脫鉤費半可能撐1-3天，但長期連動不會改變，不要因為短期脫鉤就忽視費半走勢
- 鴻海散戶持股比例上升是反向指標，散戶越多股價越難漲
- 先賣再買策略比撐月均線風險小，但可能殺在地板要承受買回的成本價差
- 7月1日職場霸凌法上路，不能對同事說「神經病」會被罰錢（老王幽默提醒）
- 旺宏已跌破季線 = 四面楚歌長線翻空，同族群要買最強的不要買最弱的
