# EP320 SPCX跌破發行價、Grok 4.5出包與Intel 18A良率85%

> SpaceX從高點211跌到135塊跌破發行價但M觀點估值合理價84塊仍偏貴；Grok 4.5模型成功但Grok CLI工具偷偷上傳整個程式庫引發資安風暴，馬斯克緊急公開原始碼滅火；Mira Murati新創Thinking Machine Lab推出開源模型Inkling 41分打敗Nemotron 3 Ultra；GPT-5.6 Soul版本口碑佳但日常使用感受不到與GPT-5.5差異；Intel 18A良率從65%提升到85%，Nova Lake 80-90%轉回18A生產，五大客戶蘋果AMD亞馬遜微軟加SpaceX

## 核心觀點

**1. SpaceX跌破發行價135塊——M觀點估值84塊仍偏貴但長線看好**

SpaceX從IPO高點211塊跌到135塊（發行價），跌了三分之一。M觀點估算合理價值約1.05兆美元（每股84塊），即使135塊仍偏貴。目前已買入約1.5%部位，目標4%。若跌到120-110會加買，跌到90左右買滿，跌到60-70會非常開心。Grok 4.5成功是利多（Token用量預估5-10倍成長），中國長征10號火箭網網回收不是威脅（Falcon 9十年前就能精準著陸，Starship若成功成本再低10倍）。Starship第13飛行即將發射將攜帶真V3衛星。

**2. Grok 4.5出包——CLI工具偷偷上傳整個程式庫**

Grok 4.5模型本身很成功，但搭配的CLI開發工具Grok Bill被資安研究者seroblab發現會在背景把整個程式庫打包上傳到Google Cloud（SpaceX的）。問題在於：(1)上傳範圍遠超所需，(2)未告知使用者。馬斯克解釋是第一版設定不當，已修正並承諾100%清除歷史上傳數據，更全面公開Grok Bill原始碼。M觀點認為滅火大致成功，因為Grok 4.5在GPT-5.5等級中是最快又最便宜的，開發者會繼續用。

**3. Mira Murati新創推出開源模型Inkling——美國終於有能打的開源模型**

OpenAI前任CTO Mira Murati的Thinking Machine Lab推出開源MoE模型Inkling，總參數975億、推理啟動410億。AAII得分41分，打敗GLM 5.1、DeepSeek v4 Flash、NVIDIA Nemotron 3 Ultra，成為美國最強開源模型。但仍輸給中國最強開源模型GLM 5.2和DeepSeek v4 Pro一小截。川普政府正討論簡化美國開源模型審查措施以追趕中國。

**4. GPT-5.6 vs GPT-5.5——日常使用感受不到差異但口碑分化**

GPT-5.6 Soul版本AAII得分更高但M觀點實際使用感受不到與GPT-5.5的差異，原因是處理問題難度不夠高（聯考效應：題目太簡單就沒有鑑別力）。口碑觀察：GPT-5.6 Luna評價意外好，AAII coding agent index打敗Opus 4.8；Grok 4.5實際使用體驗被部分使用者認為比Fable 5和GPT-5.6 Soul更好用；Fable 5雖然最聰明但被抱怨token太多、太慢、太貴。OpenAI Codex（已改名Chain GPT）使用人數兩週暴增，疑似從Anthropic Claude跳槽。

**5. Intel 18A良率85%——Nova Lake 80-90%轉回自產**

KBCN通路研究報告顯示Intel 18A良率從Q1的65%提升到Q2結束的85%，Intel下一代Nova Lake CPU原本80%計畫用台積電2奈米，現在反轉為80-90%用自家18A。18A已有五大傳聞客戶：蘋果、AMD、亞馬遜、微軟、 plus SpaceX/特斯拉TerraFab（14A但可能先用18A少量生產）。客戶下單Intel的原因：(1)台積電產能有限排不進去，(2)培養第二供應鏈殺價策略，(3)即使對手也要在供不應求時下單。對台積電影響不大：AI GPU未來幾年仍嚴重供不應求，且需求下降時客戶更容易拿到台積電產能反而減少下單Intel。Pat Gelsinger有功：上任後拍板定案擁抱EUV，董事會換他是錯的。

## 實戰重點

- **SpaceX操作策略**：合理價84塊，135仍偏貴，已買1.5%目標4%，跌到120-110加買，跌到90買滿，跌到60-70開心買滿
- **Grok 4.5 Token用量**：預估比Grok 4.3成長5-10倍，xAI若已是AI公司光Grok 4.5成功股價就該翻倍
- **開源模型競爭格局**：中國最強GLM 5.2/DeepSeek v4 Pro > 美國Inkling > NVIDIA Nemotron 3 Ultra > GLM 5.1
- **Fable 5弱點**：token消耗太多、反應慢、成本高，Anthropic面臨小逆風，Claude Code延長免費方案不敢取消
- **Intel 18A良率85%可量產**：60-65%是Break Even，85%成本漂亮可代工；Nova Lake轉回18A代表產能擴大

## 注意事項

- SpaceX股價預測僅供參考，每股沒有漲跌幅限制，每個人心理素質不同無法給投資建議
- Grok Bill原始碼雖已公開但是否還有問題需自行審查
- Intel 18A客戶消息仍為供應鏈調查傳聞，隨時可能改變
