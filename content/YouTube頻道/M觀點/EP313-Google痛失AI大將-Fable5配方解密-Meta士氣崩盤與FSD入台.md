# EP313 Google痛失AI大將、Fable 5配方解密、Meta士氣崩盤與FSD入台

> Google兩名AI頂尖研究員跳槽對手、Fable 5用12萬字System Prompt把Agent Harness直接塞進聊天機器人、Meta Applied AI部門是裁員後的暫存區，FSD正式遞件台灣審查。

## 核心觀點

### Google連失兩名AI大將

Google Gemini共同負責人 Noam Shazeer（Transformer論文共同作者）合約期滿後跳槽 OpenAI，負責 AI 架構研究；Google DeepMind VP、諾貝爾化學獎得主 John Jumper 跳槽 Anthropic，預期負責科學領域AI研究。Google當初花27億美元併購 Character.AI 才把 Noam Shazeer 買回來，兩年綁約一到就走，對士氣打擊不小。

Miula 認為 Google 不會因此被打趴——算力、資金、資料、人才儲量仍是第一線玩家。但 Gemini 3.5 Pro 據傳可能不如預期，若無法打敗 GPT-5.5 和 OPPOS 4.8，聲勢下滑趨勢會延續。Google 在消費者端（chatbot 市佔 27.7%）表現不錯，但企業端 Agentic Workflow 顯著落後 OpenAI。

### Fable 5 的秘密：12萬字 System Prompt 做出內嵌 Agent Harness

研究者在 X 上公開 Fable 5 在 Claude.ai 的 12萬字元 System Prompt，揭露 Anthropic 將完整的 Agent Harness（多 subagent、多工具、沙盒運算）直接寫進系統提示詞。使用者問問題時，Fable 5 背後不是單一模型回答，而是在雲端開沙盒跑 Agent Workflow——分成多個 subagent 各自操作工具、做 review、查資料庫，最後整合答案回傳。

這解釋了 Fable 5 為什麼強但回應較慢。傳統上 Agent Harness 在 Claude Code 等軟體端才能用，Anthropic 把它直接內嵌到 web 聊天機器人服務中，讓一般使用者也能享有約七八成的 Harness 能力。2026年 AI 顯學就是 Harness——最終實力 = 模型實力 × Harness 實力。

### Fable 5 出口管制與國安爭議

Fable 5 仍被川普政府出口管制。川普在 G7 AI 會議上跟 Anthropic CEO Dario Amodei 聊過後態度軟化，但國會議員 Mark Warner 引述 NSA 說法：MISOS 可在數小時內破解高度機密系統，且 Fable 5 的 Guardrail 已被破解可繞過。Miula 認為 NSA 測試是給模型看原始碼的內部測試場景，外部駭客難度更高，但 Anthropic 至少應修補已知漏洞，預期2-4週內 Fable 5 有機會重新上線。

### Meta 士氣崩盤：Applied AI 是裁員後的暫存區

Meta CTO Andrew Bosworth 承認目前士氣是20年來最差前三名。裁員8000人後，另有7000人被調到 Applied AI 部門，負責出題訓練AI、評估AI回答、做資料標記等重複性工作——對年薪30萬美元的天之驕子來說毫無成就感。Miula 認為 Applied AI 是「Placeholder 部門」：Meta 不確定未來要不要再大舉招人，先放7000人暫存，不爽的自然離職，想留的轉調新任務，認命的就留下。這也預示了未來高熵值資料創造工作可能讓大部分人失去意義感。

## 實戰重點

- **AI投資看人才流動**：Google人才流失是短期士氣問題非致命傷，但若 Gemini 3.5 Pro 無法追上競爭對手，Google AI 估值壓力會加大
- **Fable 5 監管鬆綁時間點**：Anthropic 若配合修補已知漏洞，2-4週內可能解禁，對 AI 概念股有短線催化效果
- **FSD進台灣時間**：已向車安中心遞件，預估最快8月、最慢9月通過，Level 2 supervised 版本，需要 AI4 硬體
- **特斯拉今年銷量回升**：FSD 全球陸續通過將帶動銷量，台灣若通過會進一步刺激需求；台灣買斷FSD 22.2萬元，Miula建議用月費制即可

## 注意事項

- Fable 5 的國安爭議涉及政治博弈，解禁時程可能延後
- Meta Applied AI 部門的問題是過渡期現象，半年後不爽的會走、認命的會留
- FSD 在台灣的通過時間受法規流程影響，且台灣法規常參考歐洲而非美國
- 台美對等貿易協定尚未在立法院通過，特斯拉關稅降價時間不確定，即使過了也要再跑行政程序
