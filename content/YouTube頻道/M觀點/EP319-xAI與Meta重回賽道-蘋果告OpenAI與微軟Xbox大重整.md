# EP319 xAI與Meta重回賽道、蘋果告OpenAI與微軟Xbox大重整

> AI超級黃金週：GPT-5.6全面上線匹敵Fable 5但成本僅四成，Grok 4.5用不到10%成本提供GPT-5.5能力，Meta Muse Spark 1.1從排名50跳到前段班，蘋果告OpenAI偷商業機密，微軟砍Xbox 20%人力

## 核心觀點

### 1. AI超級黃金週——四大模型密集發表

7月第二週成為AI模型的超級黃金週。Anthropic的Fable 5和Mythos 5在7月第一週重新上架後，隔週所有競爭對手全部推出對應動作：OpenAI全面發布GPT-5.6系列（Soul/Terra/Luna三版本），xAI發表Grok 4.5（1.5兆參數），Meta發表Muse Spark 1.1。Miula用Artificial Analysis Intelligence Index（AAII）和Coding Agent Index（AACAI）兩個評測機構的分數來比較各模型實力。

### 2. GPT-5.6 Soul——同等能力半價成本

GPT-5.6 Soul在AAII拿到59分，僅落後Fable 5的60分一分，屬於同等級模型。但成本僅Fable 5的四成左右。在寫程式能力AACAI中，GPT-5.6 Soul甚至打敗Fable 5，GPT-5.6 Terra追平Fable 5，連最弱的GPT-5.6 Luna也打敗Claude Opus 4.8。這代表OpenAI正在搶回Anthropic的市佔率，因為Fable 5又貴又慢，而GPT-5.6能力相當但成本大幅降低。

### 3. Grok 4.5——成本效率的帕雷托前緣王者

Grok 4.5是xAI的1.5兆參數基礎模型，加上Cursor團隊的後訓練能力，實力等同GPT-5.5和Claude Opus 4.8（AAII 54分 vs GPT-5.5的55分、Opus 4.8的56分）。關鍵優勢在成本：API價格比GPT-5.6 Terra更低（input token約八成，output token僅四成），加上Token使用效率極高——執行同樣任務消耗的Token只有GPT-5.6 Terra的三成。等於用不到10%的成本提供GPT-5.5的能力，速度還更快。這在市場上引發巨大震撼。

### 4. Meta Muse Spark 1.1——從排名50跳到前段班

Meta的Muse Spark 1.1在AAII拿到51分（與中國開源模型GLM 5.2同分），AACAI拿69分。實力介於GPT-5.4和GPT-5.5之間，比GLM 5.2更強但輸給GPT-5.5和Grok 4.5。雖然Meta落後xAI一點，但從Llama 4大失敗後已過兩三年，等於從排名50名一口氣進步到前段班。Alexander Wong雖然不是會發明新理論的AI科學家，但作為Tech Lead能引進各家最新技術，做出前沿模型97-98%能力的模型對Meta來說已經足夠。

### 5. 蘋果告OpenAI偷商業機密

蘋果在加州北區聯邦地方法院起訴OpenAI，指控違反聯邦商業秘密防禦法。核心是OpenAI硬體長Tan Tan（前蘋果產品設計副總裁）系統性挖角蘋果員工，並在面試時直接詢問蘋果內部機密。這場訴訟讓OpenAI很難安全下莊。

## 實戰重點

- **AI模型競爭格局**：Anthropic領先OpenAI約1個月，OpenAI領先xAI約2個月，Meta再落後1-2個月。第一到最後差距僅5個月，競爭非常激烈
- **成本效率是AI模型新戰場**：GPT-5.6 Soul成本是Fable 5的四成，Grok 4.5用不到10%成本提供GPT-5.5能力，Token使用效率成為差異化關鍵
- **賣算力不是放棄AI**：XAI和Meta賣算力被市場誤讀為退出AI，實際上是資產彈性運用。研發模型三大條件（算力、資料、人才）兩家都具備
- **Meta認真發展算力業務**：Zuckerberg不只是釋出閒置算力，而是要買更多GPU認真做算力雲端業務
- **微軟Xbox大重整**：砍掉20%人力，調整整個Xbox策略
- **Gemini 3.5 Pro預測**：Miula預期能力約等於GPT-5.5和Grok 4.5，不會超過Fable 5或GPT-5.6 Soul。Google的大招可能在年底Gemini 4.0

## 注意事項

- AI模型Benchmark分數變動快速，各機構評測方法不同，分數僅供參考
- Token使用效率的實測樣本有限，不同任務類型可能差異很大
- 蘋果告OpenAI案件結果尚不確定，但已影響OpenAI硬體佈局
- 成本比較基於API定價，實際企業使用成本可能因合約條件而異
