# 擺動指數與累積擺動指數 Swing Index & ASI

> **J. Welles Wilder Jr.** 於 1978 年《New Concepts in Technical Trading Systems》提出的突破分析工具，用單日價格關係量化「真正的」市場擺動，ASI 將每日 Swing Index 累加成連續線，是辨識真假突破與趨勢確認的經典輔助指標。

## 核心概念

**Swing Index (SI)** 是一個單日的擺動強度指標，將今日與昨日的 Open / High / Low / Close 四個價格代入公式，計算出一個 0~100（或 -100~+100）的值。

**Accumulative Swing Index (ASI)** 就是把每天的 SI 逐日累加，形成一條連續的擺動線，類似 OBV 之於成交量、MACD 之於價格——把短期的擺動能量可視化為長期的趨勢線。

Wilder 的核心洞察是：傳統的 K 線只看收盤價，忽略了開盤價與高低價之間的關係。Swing Index 把「今天開盤在哪、最高衝到哪、最低探到哪、最後收在哪」全部濃縮成一個數字，捕捉 K 線圖看不到的擺動力道。

## 計算公式

### Swing Index (SI)

$$
SI = \frac{50 \times \left[ (C_y - C_t) + \frac{1}{2}(C_t - O_t) + \frac{1}{4}(C_y - O_y) \right]}{R} \times \frac{K}{T}
$$

其中：
- **C_t / C_y**：今日 / 昨日收盤價
- **O_t / O_y**：今日 / 昨日開盤價
- **R**：真實波幅（True Range）的近似值，取以下三者的最大值：
  - |H_t - L_t|（今日高低差）
  - |H_t - C_y|（今日高 - 昨日收）
  - |L_t - C_y|（今日低 - 昨日收）
- **K**：取 max(|H_t - C_y|, |L_t - C_y|) 的較大值
- **T**：限制係數（Limit Move Value），通常設為 3（或商品每日漲跌幅限制的 0.5 倍）

SI 值範圍在 **-100 到 +100** 之間（T 設定影響極值）。

### Accumulative Swing Index (ASI)

$$
ASI_t = ASI_{t-1} + SI_t
$$

ASI 就是 SI 的累加值，起點通常設為 0。

## 判讀方法

### Swing Index 單日判讀

- **SI > 0**：今日多方擺動，收盤高於開盤代表買方主導
- **SI < 0**：今日空方擺動，收盤低於開盤代表賣方主導
- **SI 接近極值（±80~100）**：單日擺動力道極強，可能是突破日或反轉日
- **SI 接近 0**：今日價格幾乎沒有實質擺動，盤整訊號

### ASI 趨勢判讀

- **ASI 上升**：累積擺動能量偏多，趨勢向上
- **ASI 下降**：累積擺動能量偏空，趨勢向下
- **ASI 橫盤**：多空力量均衡，市場在盤整

### 突破確認（Wilder 的核心用法）

Wilder 設計 ASI 的最大目的是**確認突破的真實性**：

- **真突破**：價格突破震盪區間上緣，ASI 同步創新高 → 多方擺動確認，有效突破
- **假突破**：價格突破區間上緣，但 ASI 未創新高 → 擺動能量不足，突破可能是誘多
- **同樣適用於向下突破**：價格跌破支撐但 ASI 未創新低 → 空方力道不足，可能是假跌破

### ASI 背離

- **頂背離**：價格創新高但 ASI 未創新高 → 多方擺動力道衰竭，趨勢即將反轉
- **底背離**：價格創新低但 ASI 未創新低 → 空方擺動力道衰竭，底部將近

## 實戰操作策略

### 策略一：突破確認交易

1. 價格突破近期高點（或阻力線）
2. 確認 ASI 是否同步突破前高
3. ASI 確認 → 進場做多，停損設在突破點下方
4. ASI 未確認 → 觀望或減碼，可能是假突破

### 策略二：背離反轉交易

1. 價格在高位震盪
2. ASI 出現頂背離（價格新高、ASI 未新高）
3. 等待價格跌破短期均線確認
4. 進場做空或減碼多頭部位

### 策略三：ASI 趨勢線突破

ASI 本身也可以畫趨勢線：
- ASI 長期上升趨勢線被跌破 → 中期趨勢可能反轉
- ASI 長期下降趨勢線被突破 → 中期底部可能確認
- Wilder 認為 ASI 的趨勢線突破比價格趨勢線突破更可靠

## 與其他指標的關係

- **與 ATR 的關係**：Swing Index 的計算使用了類似 True Range 的概念，Wilder 同時期開發了 ATR。ATR 衡量波動大小，SI 衡量擺動方向，兩者互補
- **與 RSI 的關係**：RSI 也是 Wilder 開發，但 RSI 純看收盤價變動幅度，SI 加入開盤價與高低價，訊息量更大但更複雜
- **與 OBV 的關係**：OBV 累加成交量方向，ASI 累加價格擺動方向，兩者都是累加型趨勢指標但底層邏輯不同
- **與 [[技術分析/MACD指標實戰判讀|MACD]] 的關係**：MACD 看均線收斂發散，ASI 看擺動能量累積，背離訊號互為驗證

## 優缺點

### 優點
- 同時考慮 OHLC 四個價格，訊息量比只看收盤的指標更豐富
- 對突破確認有獨特價值，Wilder 設計的核心目的就是辨識真假突破
- 累積型指標，ASI 的趨勢線判讀有獨特視角

### 缺點
- 計算公式較複雜，需要四個價格數據
- T 值（限制係數）的設定影響結果，不同市場需要調整
- 在極端跳空時 SI 可能失真
- 單獨使用訊號有限，通常需要搭配趨勢指標或成交量確認
- 在台股因漲跌幅 10% 限制，T 值設定需調整

## 台股實戰注意事項

- **T 值設定**：台股漲跌幅 10%，建議 T 設為漲停幅度的 0.5 倍左右，通常設 3~5
- **跳空缺口影響**：台股經常因美股跳空開盤，跳空日的 SI 值可能失真，需結合成交量判斷
- **搭配使用**：ASI 在台股最適合作為突破確認的輔助指標，不建議單獨使用
- **與 [[技術分析/ADX趨勢強度過濾盤整|ADX]] 搭配**：ADX 判趨勢強度，ASI 確認突破方向，雙重確認提升勝率

## 參數設定

- **預設參數**：T = 3（Wilder 原始設定），適用大部分日線
- **短線交易**：T 可降低至 1.5~2，增加靈敏度
- **長線分析**：T 可提高至 5~10，過濾短期噪音
- **週線**：T 值可放寬，因週線擺動幅度更大

## 來源

- Wilder, J. W. (1978). *New Concepts in Technical Trading Systems*
- Wilder 原文強調 ASI 最適合用於「趨勢線突破確認」，而非作為主指標
- SI 公式中的 T 值在期貨市場通常設為合約每日漲跌限制的一半
