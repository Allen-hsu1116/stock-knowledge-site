# NVI負成交量指標 Negative Volume Index

> NVI 只在成交量低於前一期時更新，假設低量日更能反映聰明錢動作；實戰重點是 NVI 與 255 日 EMA 的相對位置，用來判斷長期多空機率與資金是否在安靜累積。

## 核心概念

NVI（Negative Volume Index）最早由 Paul Dysart 在 1930 年代提出，後來 Norman Fosback 改良為以價格百分比變動計算。它的核心假設很直白：

- 放量日常是大眾追逐消息、情緒交易
- 低量日反而可能是聰明錢安靜布局
- 因此 NVI 只在成交量低於前一期時跟著價格變動更新
- 成交量增加時，NVI 保持不變

常見計算流程：

1. NVI 從 1000 開始。
2. 若今日成交量低於昨日成交量，NVI 依今日價格漲跌百分比更新。
3. 若今日成交量高於昨日成交量，NVI 不更新。
4. 以 255 日 EMA 作為長期多空判斷線。

## 實戰應用

### 一、NVI 與 255 日 EMA 判斷長期環境

StockCharts 整理的傳統用法是：

- NVI 高於 255 日 EMA：偏多環境，長期牛市機率較高
- NVI 低於 255 日 EMA：偏弱環境，風險升高
- NVI 重新站回 255 日 EMA：低量日資金開始改善
- NVI 跌破 255 日 EMA：安靜買盤結構破壞

這適合用在大盤、ETF、權值股，不是拿來做 5 分鐘線的玩具。硬要短線亂套，市場會負責教育你。

### 二、辨識「低量上漲」是否健康

低量上漲不一定是壞事。若價格上漲、量縮、NVI 也持續墊高，代表低量日仍有資金推動，可能是籌碼穩定、賣壓輕。

可搭配 [[技術分析/量縮上漲與量價背離區分實戰]] 判斷：

- 價格上漲 + NVI 上升 + 回檔量縮：偏健康
- 價格上漲 + NVI 不跟 + OBV 轉弱：量價背離風險升高
- 價格突破 + NVI 高於 255 EMA：突破可信度提高

### 三、與 OBV 分工使用

[[技術分析/OBV能量潮指標量價趨勢判讀]] 每天都會依價格漲跌更新成交量累計，NVI 只看低量日，兩者可分工：

- OBV：看整體量價累積方向
- NVI：看低量日是否有安靜資金進場
- OBV 與 NVI 同步走強：量價結構健康
- OBV 走弱但 NVI 持穩：表面賣壓增加，但低量日資金未明顯撤退
- OBV 與 NVI 同步走弱：資金結構轉差，降低曝險

### 四、台股應用場景

NVI 對台股可用於：

- 指數 ETF：判斷大盤長期多空環境
- 權值股：確認低量盤整是否仍有資金承接
- 波段股：觀察主升段中量縮回檔是否健康
- 族群輪動：比較同族群個股誰在低量日仍能維持 NVI 上升

## 注意事項

- **假設不一定永遠成立**：低量日不一定都是聰明錢，有時只是沒人想玩。
- **訊號偏長線**：255 日 EMA 是年線概念，反應不會快。
- **不適合冷門股**：成交量太低的股票，NVI 容易被零星交易扭曲。
- **不能單獨當買賣點**：NVI 是環境與資金結構指標，進場仍需價格型態、支撐壓力與成交量確認。
- **放量突破仍重要**：NVI 重視低量日，但真正突破關鍵位置時，仍需要 [[技術分析/成交量確認原則Volume-Confirmation]] 支持。
