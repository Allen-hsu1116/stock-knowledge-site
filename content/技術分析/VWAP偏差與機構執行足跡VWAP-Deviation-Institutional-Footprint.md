# VWAP偏差與機構執行足跡 VWAP Deviation & Institutional Footprint

> VWAP不只是當日均價線——價格與VWAP的偏差程度、偏差方向、偏差持續時間，三者構成解讀機構執行意圖的三維座標系。持續站在VWAP上方不代表「強勢」，也可能是機構在執行TWAP賣單時刻意維持股價不跌以降低衝擊成本。

## 核心概念

### VWAP偏差的三層含義

[[技術分析/VWAP成交量加權均價|VWAP]]是當日成交量加權均價，代表所有參與者的平均成本。價格偏離VWAP的行為本身蘊含豐富資訊：

**第一層：偏差方向**
- **價格持續在VWAP上方**：買方意願強於賣方，但若伴隨成交量遞減，可能是機構被動掛賣單讓散戶追價
- **價格持續在VWAP下方**：賣方意願強於買方，但若量縮在下方，可能是機構刻意壓價吸籌
- **價格反覆穿越VWAP**：多空均衡，機構可能正在分批進出

**第二層：偏差幅度**
- 偏差<0.5%：正常交易噪音
- 偏差0.5-1.5%：有方向性偏好但不強烈
- 偏差1.5-3%：機構執行中，值得追蹤方向
- 偏差>3%：強方向性執行，可能伴隨消息面或重大事件

**第三層：偏差持續時間**
- 30分鐘以內：短線情緒脈動
- 30分鐘至2小時：機構執行週期
- 全天維持單一方向偏差：機構全天候執行大單，趨勢可能延續到次日

### 機構執行演算法與VWAP足跡

機構大單執行主要依賴三種演算法，每種都會在VWAP上留下不同足跡：

**1. VWAP演算法**
- 目標：讓執行均價盡量接近當日VWAP
- 足跡特徵：價格在VWAP上下小幅擺動，成交量分佈與歷史VWAP分佈相似（U型或W型）
- 判讀：看到價格持續緊貼VWAP但量能不自然地集中於開盤和收盤，機構可能在執行VWAP演算法

**2. TWAP演算法**
- 目標：將大單均勻切割到全天每個時間段
- 足跡特徵：成交量均勻分佈但價格出現持續性偏差（機構方向性壓力均勻釋放）
- 判讀：看到量能沒有明顯集中但價格持續單向偏離VWAP，可能是TWAP執行中

**3. 執行缺衝擊演算法（IS）**
- 目標：最小化對市場價格的衝擊
- 足跡特徵：成交量與流動性成正比，價格偏差極小但方向穩定
- 判讀：看到量能隨盤中流動性起伏但價格持續單向走，可能是IS演算法在隱蔽執行

### Anchored VWAP追蹤事件後機構成本

Anchored VWAP是從特定時間點（如法說會、重大消息公告、突破日）開始計算的VWAP，代表事件後進場者的平均成本。

**實戰用法**：
- 法說會後的Anchored VWAP是機構新增部位的成本線
- 股價回測Anchored VWAP是機構的「加碼線」或「防守線」
- 若股價跌破法說會後Anchored VWAP且持續3天，代表機構可能已轉為淨賣出

## 與其他指標的系統整合

VWAP偏差最大的價值在於與其他指標形成共振確認：

- **VWAP偏差 + [[技術分析/RSI相對強弱指標|RSI]]背離**：VWAP持續在上方但RSI出現頂背離，機構可能在高位分批出貨
- **VWAP偏差 + [[技術分析/MACD指標實戰判讀|MACD]]零軸**：VWAP上穿配合MACD零軸上穿，確認多方主導
- **VWAP偏差 + [[技術分析/ATR平均真實波幅-Average-True-Range|ATR]]**：ATR擴大時VWAP偏差更可信，ATR收縮時VWAP偏差噪音更大

## 實戰應用

### VWAP偏差三維判讀框架

**步驟一：看偏差方向**
- 14:30仍站在VWAP上方+量能遞增 → 尾盤機構可能加碼做多
- 14:30跌破VWAP+量能放大 → 尾盤機構可能在出貨

**步驟二：看偏差幅度變化**
- 偏差從3%收斂到1% → 機構執行接近尾聲
- 偏差從0.5%擴大到2% → 機構執行加速
- 偏差長期維持在1-2% → 機構可能在分批執行大單

**步驟三：看成交量分佈形態**
- 量能集中於開盤30分鐘和收盤30分鐘 → 典型VWAP演算法執行
- 量能均勻分佈 → TWAP執行
- 量能隨流動性起伏 → IS演算法

### 結合Volume Profile提升判讀精度

[[技術分析/Volume-Profile成交量分佈分析|Volume Profile]]提供價格軸上的成交量分佈，與VWAP的時間軸互補：

- VWAP在POC（Point of Control）上方 → 多方控制盤面
- VWAP在POC下方 → 空方控制盤面
- VWAP穿越POC → 多空平衡轉折點

### 結合訂單流足跡圖

[[技術分析/訂單流足跡圖Footprint-Chart|訂單流足跡圖]]提供每個價位的買賣量，與VWAP偏差搭配可以判斷：

- 價格在VWAP上方+足跡圖顯示主動買單多於賣單 → 真實多方主導
- 價格在VWAP上方+足跡圖顯示主動賣單多於買單 → 機構掛賣單讓散戶追價（虛假強勢）
- 價格在VWAP下方+足跡圖顯示主動買單多於賣單 → 機構主動買入但刻意壓壓價（隱蔽吸籌）

## 注意事項

### 台股VWAP判讀的特殊性

1. **開盤搓合機制**：台股9:00開盤為集合競價，前5分鐘的VWAP可能極度偏離，建議從9:05後開始計算盤中VWAP
2. **尾盤13:25-13:30搓合**：收盤前5分鐘集合競價可能造成VWAP突然跳動，不應將尾盤VWAP跳動視為趨勢訊號
3. **零股交易**：13:40-14:30的零股交易量雖小但可能影響小型股VWAP
4. **外資Rebalance**：每季底外資Rebalance可能造成收盤前VWAP大幅偏離日內趨勢，屬於一次性事件而非趨勢訊號

### 三大常見誤判

**誤判一：把VWAP當支撐壓力線用**
- VWAP是成本線不是支撐壓力線，價格穿越VWAP不代表方向反轉
- 正解：看穿越VWAP時的量能變化和偏差是否擴大

**誤判二：VWAP上方=做多、VWAP下方=做空**
- 這是最常見的錯誤簡化，忽略了機構可能利用VWAP心理掩護執行
- 正解：結合[[技術分析/相對成交量RVOL-Relative-Volume|RVOL]]和足跡圖交叉驗證

**誤判三：忽略VWAP的日間斷層**
- 每日VWAP獨立計算，昨日的VWAP與今日的VWAP之間存在斷層
- 正解：使用Anchored VWAP跨日追蹤，或觀察多日VWAP的趨勢變化
