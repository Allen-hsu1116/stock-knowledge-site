# DPO去趨勢價格震盪指標 Detrended Price Oscillator

> William Blau 於 1991 年開發的震盪指標，透過位移移動平均線消除長期趨勢，讓價格的短期超買超賣循環一目了然——不看方向，只看週期的高低點。

## 核心概念

**DPO（Detrended Price Oscillator，去趨勢價格震盪指標）** 的核心思想是：**把趨勢拿掉，只看循環**。

傳統的震盪指標如 [[RSI相對強弱指標|RSI]]、[[KD指標隨機指標|KD]] 在強趨勢中會嚴重鈍化（參見 [[技術指標鈍化與對策]]），因為它們的計算包含了最近期的價格，而趨勢會把整個指標推到極端區間不回來。DPO 的解法很暴力也很聰明——**不使用最近期的價格**。

### 與其他價格震盪指標的差異

- **MACD**（[[MACD指標實戰判讀]]）：用兩條 EMA 差值判斷趨勢動能方向
- **PPO**（[[技術分析/PPO百分比價格震盪指標|PPO]]）：MACD 的百分比版本，可跨標的比較
- **DPO**：刻意消除趨勢，只關注價格偏離循環均值的程度

DPO 不告訴你方向，它告訴你**價格在當前循環中的相對位置**——偏高還是偏低。

### 為什麼要「去趨勢」？

想像一條從 100 漲到 200 的股票。如果你用傳統震盪指標，全程可能都顯示「超買」，但這不代表該賣——趨勢就是這樣。DPO 把這個 100→200 的斜率抽掉，剩下的就是價格圍繞循環均值的上下波動。這樣你才能判斷：在這個上升趨勢中，目前是循環的高點還是低點？

## 計算公式

### DPO 計算步驟

**Step 1：設定週期 n**

n 應為你想要捕捉的循環週期的一半。例如想捕捉 20 日循環，n = 10。

**Step 2：計算 SMA**

$$SMA_n = \frac{\sum_{i=0}^{n-1} Close_i}{n}$$

**Step 3：位移 SMA**

把 SMA 往前位移 $\frac{n}{2} + 1$ 天。這是關鍵——DPO 使用的是**過去的 SMA**，不包含當前價格。

**Step 4：計算 DPO**

$$DPO = Close_{\frac{n}{2}+1} - SMA_n(\text{shifted})$$

或者更直觀的理解：

$$DPO = \text{價格}_{(n/2+1)\text{天前}} - \text{SMA}_n$$

### 參數說明

- **n（週期）**：預設 20，但應根據標的的實際循環長度調整
- **位移量**：$\frac{n}{2} + 1$，確保 SMA 完全不包含最近期價格
- **結果**：DPO 在零軸上下波動，沒有上下限

### 為什麼要位移？

位移 $(n/2 + 1)$ 天的核心原因：
1. **消除當前價格的影響**：SMA 不反應最新價格動作
2. **對齊循環中心**：位移後的 SMA 相當於循環的「中心線」
3. **避免趨勢污染**：趨勢的斜率被減掉，剩下純粹的循環波動

## 判讀方法

### 1. 零軸上下循環

DPO 在零軸上下反覆波動是常態：
- **DPO > 0**：價格高於循環均值，處於循環偏高位
- **DPO < 0**：價格低於循環均值，處於循環偏低位
- **DPO = 0**：價格等於循環均值，處於循環中點

### 2. 尋找循環高低點

DPO 最大的用途是**辨識價格循環的轉折點**：
- DPO 從正值轉負值 → 循環高點已過，短期可能回檔
- DPO 從負值轉正值 → 循環低點已過，短期可能反彈

### 3. 衡量循環週期

觀察 DPO 兩個高點（或兩個低點）之間的距離，可以估算標的的循環週期長度。這是 DPO 獨特的功能——其他指標很少能直接幫你量循環長度。

### 4. 背離訊號

雖然 DPO 不是動量指標，但仍可觀察背離：
- 價格創新高但 DPO 高點下移 → 上升動能在循環層面減弱
- 價格創新低但 DPO 低點上移 → 下跌動能在循環層面減弱

## 實戰用法

### 用法一：循環定位

在上升趨勢中：
- DPO 在零軸上方見頂回落 → 不是賣點，而是**等待回檔後的買點即將出現**
- DPO 跌到零軸下方見底回升 → 循環低點，配合趨勢方向進場做多

在下降趨勢中：
- DPO 反彈到零軸上方 → 不是買點，而是**反彈結束的訊號**
- DPO 回到零軸下方 → 空方循環恢復

### 用法二：週期測量 → 參數優化

1. 先用預設 n=20 畫 DPO
2. 觀察 DPO 波峰到波峰的距離（例如 28 天）
3. 把 n 設為 28/2 = 14，重新計算
4. 迭代直到 DPO 波形最平滑對稱

### 用法三：搭配趨勢指標

DPO 本身不判斷趨勢方向，必須搭配趨勢指標：
- **DPO + [[均線判斷|均線]]**：均線判方向，DPO 找循環進出場時機
- **DPO + [[MACD指標實戰判讀|MACD]]**：MACD 判趨勢動能，DPO 找短期循環極值
- **DPO + [[ADX趨勢強度過濾盤整|ADX]]**：ADX 確認趨勢存在，DPO 在趨勢中找回檔買點

### 用法四：搭配成交量

- DPO 從低點轉正 + [[成交量確認原則Volume-Confirmation|帶量確認]] → 循環低點反轉更有力
- DPO 從高點轉負 + 量縮 → 正常回檔，循環高點確認

## 優缺點

### 優點

- **消除趨勢干擾**：在強趨勢中不會鈍化，這是最大優勢
- **循環週期測量**：唯一能直接幫你量循環長度的指標
- **直觀易懂**：零軸上下，沒有複雜的計算邏輯
- **不受絕對價格影響**：DPO 值只反映偏離循環均值的程度

### 缺點

- **不反應最新價格**：位移 $(n/2+1)$ 天意味著 DPO 永遠落後，這是設計上的取捨
- **不判斷趨勢方向**：必須搭配其他指標，單獨使用會在趨勢中逆勢操作
- **循環不規則時失效**：如果標的沒有明顯的固定循週期，DPO 的訊號會很混亂
- **參數敏感**：n 的設定直接影響結果，錯誤的 n 會得到錯誤的循環判斷

## 與其他指標的組合策略

### DPO + 均線 + ADX 循環交易系統

1. **方向**：[[均線多頭排列與空頭排列|均線多頭排列]]確認上升趨勢
2. **強度**：ADX > 25 確認趨勢夠強
3. **時機**：DPO 從負值轉正值（循環低點反轉）
4. **確認**：帶量突破近期高點
5. **出場**：DPO 從正值轉負值，或均線排列破壞

### DPO + 布林通道

- [[布林通道Bollinger-Bands三軌八型態|布林通道]]的 Squeeze 壓縮 + DPO 接近零軸 → 循環正在收斂，大行情即將啟動
- 布林通道擴張 + DPO 遠離零軸 → 循環進入極端區

## 台股實戰注意事項

- **台股除權息影響**：除權息造成的價格跳空會扭曲 DPO，建議使用還原股價計算
- **週期因標的而異**：權值股（如台積電）的循環可能 30-40 天，小型股可能 10-15 天，不要用固定參數
- **搭配法人籌碼**：DPO 循環低點 + 外資/投信買超 → 更高勝率的進場點
