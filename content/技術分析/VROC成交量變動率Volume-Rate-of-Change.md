# VROC 成交量變動率 (Volume Rate of Change)

## 概述

Volume Rate of Change（VROC）是一個衡量成交量動量的技術指標。它的計算邏輯與 [[技術分析/ROC變動率指標Rate-of-Change|價格變動率 ROC]] 完全對應，只是把分子從「價格變化」換成「成交量變化」。

核心思路：**價格的趨勢需要量的支撐，而量的變化本身也有動量。當成交量在短期內急劇放大或萎縮，往往領先於價格的轉折。**

VROC 就是在量化「量能的加速度」——不是看量是多是空，而是看量的變化速率。

## 計算公式

**VROC = [(當前成交量 - N 期前成交量) / N 期前成交量] × 100**

- 常見參數：N = 12 或 14（短期），N = 20 或 25（中期）
- 值域：理論上 -100% ~ +∞（因為成交量不能為負，但可以從某水準暴增數倍）
- 正值：當前成交量 > N 期前成交量（量能擴增）
- 負值：當前成交量 < N 期前成交量（量能萎縮）
- 零軸：量能與 N 期前持平

也有另一種計算方式（不除以基期，純看差值）：
**VROC = 當前成交量 - N 期前成交量**

但百分比版本更常用，因為不同個股的成交量基數差異大，用百分比才能跨標的比較。

## 判讀方式

### 1. 零軸穿越
- **VROC 向上突破 0**：量能開始擴增，如果伴隨價格上漲 → 多方動能增強
- **VROC 向下跌破 0**：量能開始萎縮，趨勢可能失去動能
- 零軸穿越是量能動量轉折的基本訊號

### 2. 背離判讀
- **量價頂背離**：股價創新高但 VROC 未創新高（甚至下降）→ 量能跟不上價格上漲，多頭力道減弱
- **量價底背離**：股價創新低但 VROC 由負轉正或上升 → 量能開始擴增（可能在低檔有承接），底部訊號
- 背離是 VROC 最核心的用法——量的背離往往領先於價的背離

### 3. 極值判讀
- **VROC 暴衝正值**（如 > 200%）：成交量突然暴增數倍，可能是：
  - 利多消息引發搶買
  - 主力大舉進場（需搭配 [[籌碼面分析/分點進出追蹤關鍵分點|分點進出]] 確認方向）
  - 也可以是恐慌性拋售的承接
- **VROC 深度負值**（如 < -50%）：量能急劇萎縮，可能是：
  - 觀望氣氛濃厚
  - 趨勢即將進入盤整
  - 也可能是暴量後的正常回落

### 4. 趨勢確認
- **多頭趨勢中 VROC 持續為正**：量能持續擴增，健康的多頭
- **多頭趨勢中 VROC 轉負**：量能萎縮，漲勢可能後繼無力
- **空頭趨勢中 VROC 暴衝正值**：可能是恐慌性賣出暴量，反而接近底部
- **空頭趨勢中 VROC 持續為負**：陰跌縮量，空頭仍主導

## 與其他量能指標的關係

- **[[技術分析/OBV能量潮指標量價趨勢判讀|OBV 能量潮]]**：OBV 是累積型指標（量加減的累計），VROC 是動量型指標（量的變化率）。OBV 看長期累積方向，VROC 看短期量能加速
- **[[技術分析/成交量確認原則Volume-Confirmation|成交量確認原則]]**：VROC 是量化版的量價確認，把「量有沒有跟上来」變成具體數字
- **[[技術分析/ROC變動率指標Rate-of-Change|價格 ROC]]**：價格 ROC 看價格動量，VROC 看量能動量，兩者搭配可以形成「價的動量 + 量的動量」雙確認
- **[[技術分析/MFI資金流量指標Money-Flow-Index|MFI 資金流量指標]]**：MFI 結合了價格和成交量，VROC 只看量，MFI 更全面但計算複雜
- **[[技術分析/相對成交量RVOL-Relative-Volume|RVOL 相對成交量]]**：RVOL 看今日量相對於平均量的倍數，VROC 看量相對於 N 期前的變化率。RVOL 是「靜態比較」，VROC 是「動態趨勢」

## 實戰用法

### 策略一：量價雙 ROC 共振
1. 計算價格 ROC（12 期）和 VROC（12 期）
2. 兩者同時為正 → 價漲量增，健康多頭，偏多操作
3. 兩者同時為負 → 價跌量縮，空頭但可能接近底部（陰跌末端）
4. 價格 ROC 為正但 VROC 為負 → 價漲量縮，[[技術分析/量縮上漲與量價背離區分實戰|量價背離]]，警訊
5. 價格 ROC 為負但 VROC 暴衝正值 → 價跌量暴增，可能是恐慌底部

### 策略二：VROC 背離交易
1. 股價創新高但 VROC 出現頂背離
2. 等待價格確認反轉（跌破短期均線或 [[技術分析/支撐壓力|支撐線]]）
3. 進場做空或減碼多頭
4. 停損設在股價新高上方

### 策略三：暴量偵測 + 籌碼確認
1. VROC 超過 +150%（量能暴增 2.5 倍以上）
2. 檢查 [[籌碼面分析/三大法人買賣超實戰判讀|三大法人買賣超]]方向
3. 檢查 [[籌碼面分析/分點進出追蹤關鍵分點|分點進出]]是否有主力進場
4. 法人買超 + 主力進場 + VROC 暴衝 → 高可信度的多方訊號
5. 法人賣超 + 主力出場 + VROC 暴衝 → 高可信度的空方訊號

### 策略四：底部量縮確認
1. 股價在低檔區整理
2. VROC 持續為負（量能持續萎縮）
3. 當 VROC 開始由負轉正，且股價突破整理區間
4. 這是「量先價行」的底部反轉訊號

## VROC 的優缺點

**優點：**
- 計算簡單，概念直觀
- 與價格 ROC 對稱，容易理解和組合使用
- 背離訊號領先於價格轉折的機率較高
- 跨標的可比性好（百分比計算）

**缺點：**
- 成交量本身波動極大，VROC 噪音嚴重，需要平滑
- 不區分主動買盤和主動賣盤——同樣的量增，搶買和搶賣的意義完全相反
- 在低量基期時容易產生失真（例如某日成交量 100 張，隔日 300 張，VROC = +200%，但其實絕對量很小）
- 不含價格資訊，必須搭配價格指標使用

## 台股實戰注意事項

1. **除權息量大失真**：除權息當日成交量往往暴增（因為 zero-cost basis 交易），VROC 會給出極端值，需排除或使用還原數據
2. **當沖比重的影響**：台股 [[籌碼面分析/當沖成交比重與市場過熱判讀Day-Trading-Ratio-and-Market-Overheating|當沖比重高]]，當沖造成的量增不代表真實投資人進場，VROC 解讀需扣除此因素
3. **個股流動性差異**：小型股的成交量波動天然就大，VROC 容易出現極端值，建議搭配 [[技術分析/換手率與週轉率實戰判讀Turnover-Rate|換手率]]一起看
4. **月線級別更穩定**：日線 VROC 噪音大，週線或月線的 VROC 更能反映真實的量能趨勢變化
5. **法人對敲**：[[籌碼面分析/主力作線與控盤手法|主力作線]]可能透過對敲製造假量，VROC 會被欺騙，需搭配分點進出確認

## 總結

VROC 是一個用「量的變化率」來衡量市場動能的輔助指標。它的最大價值在於：

- 與價格 ROC 搭配形成量價雙確認系統
- 背離訊號能領先預警趨勢衰竭
- 暴量偵測配合籌碼分析，能捕捉主力進出場時機

但它不適合單獨使用——成交量不區分多空方向，同樣的量增可能是搶買也可能是搶賣。最佳用法是搭配價格指標、法人籌碼和分點進出，形成「量的動量 + 價的方向 + 籌碼的確認」三維判讀體系。
