# TSI真實強度指標 True Strength Index

> TSI 是把價格變動做雙重 EMA 平滑後再標準化的動能震盪指標，比一般動能線更平順，可用零軸、信號線、趨勢線與背離判斷趨勢強弱與轉折。

## 核心概念

TSI（True Strength Index）由 William Blau 開發，核心是先計算價格變動，再做兩層 EMA 平滑，最後除以「絕對價格變動」的雙重平滑值：

- 先算本期價格變動：今天收盤 - 昨天收盤
- 對價格變動做 25 期 EMA，再做 13 期 EMA
- 對絕對價格變動也做同樣的雙重 EMA
- TSI = 雙重平滑價格變動 ÷ 雙重平滑絕對價格變動 × 100

這樣做的效果是：保留動能方向，同時把雜訊壓下去。TSI 為正代表上漲動能占優，TSI 為負代表下跌動能占優。

## 實戰應用

### 一、零軸穿越判斷趨勢方向

- TSI > 0：多方動能較強
- TSI < 0：空方動能較強
- TSI 由下往上穿越零軸：動能轉多
- TSI 由上往下跌破零軸：動能轉空

零軸穿越適合用於中期趨勢確認。如果價格已突破壓力、TSI 同步翻正，訊號比單純價格突破更可信。

### 二、信號線交叉抓進出場節奏

常見做法是替 TSI 加上一條短期 EMA 當信號線：

- TSI 向上穿越信號線：短期動能改善
- TSI 向下跌破信號線：短期動能轉弱
- 零軸上方的多頭交叉：偏續漲訊號
- 零軸下方的空頭交叉：偏續跌訊號

如果 TSI 在零軸附近頻繁交叉，代表市場可能處於盤整，這時候硬做會被雙巴，沒必要跟市場比誰比較蠢。

### 三、趨勢線應用

TSI 本身也能畫趨勢線：

- TSI 低點持續墊高：動能結構改善
- TSI 高點持續降低：動能結構轉弱
- TSI 跌破上升趨勢線：多方動能破壞
- TSI 突破下降趨勢線：空方壓力減弱

這個用法適合搭配 [[技術分析/趨勢線與通道線]]，用價格趨勢線與 TSI 趨勢線交叉驗證。

### 四、背離判斷反轉預警

- 價格創新低、TSI 未創新低：底背離，空方動能衰退
- 價格創新高、TSI 未創新高：頂背離，多方動能衰退
- 背離後 TSI 突破信號線或零軸：訊號確認度提升

TSI 背離可與 [[技術分析/背離Divergence進階實戰]] 的確認規則合併使用：背離只是預警，價格突破關鍵 K 線或壓力位才是進場依據。

## 注意事項

- **平滑換來延遲**：TSI 比原始動能線更穩，但代價是反應較慢。
- **沒有固定超買超賣標準**：TSI 雖可判斷極端區，但不同標的區間差異大，應用歷史區間校準。
- **盤整盤仍會失真**：動能指標在無趨勢市場都會變成洗臉機。
- **需搭配量價確認**：TSI 轉強但成交量沒有跟上，容易只是弱反彈。
- **參數要符合週期**：短線交易縮短參數會更敏感，波段交易放大參數可降低雜訊，但別調到只會解釋過去。
