# 訂單流失衡 OFI (Order Flow Imbalance)

> 量是市場的心跳，訂單流是市場的心電圖——OFI 把逐筆訂單拆成買方力量與賣方力量，失衡的那一刻就是方向即將改變的瞬間

## 核心概念

### 什麼是訂單流失衡（OFI）？

Order Flow Imbalance（OFI）是市場微結構研究中最核心的概念之一，由 Cont, Kukanov & Stoikov（2014）在學術論文中正式提出。它量化了**買方力量與賣方力量在每一個價位層級的不平衡程度**。

簡單說，OFI 回答一個問題：**此刻市場上，急著買的人多還是急著賣的人多？**

### OFI 的計算

**最基礎的 OFI 公式**：
```
OFI_t = 令買力量_t - 令賣力量_t
```

**令買力量（Buy Pressure）**：
- 當成交價在最佳買價或以上 → 買方主動吃賣單
- 計算：最佳買價深度的變化 + 成交在買價以上的量

**令賣力量（Sell Pressure）**：
- 當成交價在最佳賣價或以下 → 賣方主動吃買單
- 計算：最佳賣價深度的變化 + 成交在賣價以下的量

**進階版：多層級 OFI（Multi-Level OFI）**：
- 不只看最佳五檔，看第 1 到第 5 檔的失衡
- 越深的層級反映越長期的機構意向
- 最佳五檔 OFI 預測短期（毫秒到秒級），深層 OFI 預測中短期（分鐘到小時級）

### OFI 與傳統量價指標的差異

| 比較 | 傳統量價指標 | OFI |
|------|------------|-----|
| 資料頻率 | 分鐘/日K | 逐筆 Tick |
| 看什麼 | 成交量方向 | 主動買賣力量 |
| 預測力 | 中長期趨勢 | 極短期到短期 |
| 核心邏輯 | 量先價行 | 訂單先量先行 |
| 適用 | 波段交易 | 當沖、極短線 |

## 實戰應用

### 1. 極短期價格預測

**學術研究結論**：
- OFI 對下一秒到下一分鐘的價格變動有顯著預測力
- R² 約 0.3-0.7（視市場流動性而定），是已知最強的極短期價格預測變數之一
- 失衡越大，下一期價格移動方向越明確

**實戰含義**：
- OFI 持續為正（買方力量>賣方力量）→ 極短期偏多
- OFI 持續為負 → 極短期偏空
- OFI 從正轉負或從負轉正 → 方向可能在轉變

### 2. 識別主力進場

**大單 OFI 判讀**：
- 剔除小單（<50萬），只看中實戶以上的大單流向
- 大單 OFI 持續為正且股價未明顯上漲 → 主力默默吸籌
- 大單 OFI 持續為負且股價未明顯下跌 → 主力悄悄出貨

**搭配 [[籌碼面分析/主力買賣超定義與計算方式|主力買賣超]]**：
- OFI 是即時版本的主力動向（逐筆可看）
- 主力買賣超是盤後版本（日頻率）
- 兩者方向一致時確認度最高

### 3. 五檔委託簿失衡判讀

**委託簿失衡比率（Order Book Imbalance Ratio）**：
```
OBI = (Best Bid Volume) / (Best Bid Volume + Best Ask Volume)
```
- OBI > 0.6 → 買方力量明顯大於賣方，短期偏多
- OBI < 0.4 → 賣方力量明顯大於買方，短期偏空
- OBI 0.4-0.6 → 多空均衡，方向不明

**實戰用法**：
- 開盤前 5 分鐘觀察委託簿失衡方向 → 判斷開盤方向
- 關鍵價位（支撐/壓力）附近的委託簿失衡 → 判斷突破真偽
- 搭配 [[技術分析/內外盤比與五檔報價判讀InOut-Disk-Ratio-and-Order-Book|內外盤比]] 交叉確認

### 4. 吸收行為識別（Absorption）

**吸收 = 訂單流失衡但價格不動**：
- 大量賣單被買方吃掉，但價格不下跌 → 買方吸收了賣壓，偏多訊號
- 大量買單被賣方滿足，但價格不上漲 → 賣方吸收了買盤，偏空訊號

**搭配 [[技術分析/訂單流足跡圖Footprint-Chart|訂單流足跡圖]]** 交叉確認吸收行為是最佳實戰方式。

### 5. 當沖與極短線應用

**開盤15分鐘 OFI 判讀**：
- 開盤 OFI 持續偏正 → 早盤偏多，考慮做多
- 開盤 OFI 持續偏負 → 早盤偏空，考慮做空
- OFI 方向與價格方向背離 → 注意反轉

**搭配 [[操作策略/開盤八法-開盤15分鐘判盤勢|開盤八法]]** 使用效果更佳。

## 注意事項

### 1. 資料取得門檻高
OFI 需要逐筆委託和成交資料（Tick Data），台股可從證交所即時資訊或 TEJ 取得，但需要付費。免費看盤軟體通常看不到完整的委託簿和逐筆成交。

### 2. 高頻交易者的領域
OFI 的預測力在毫秒到秒級最強，散戶的手速和分析能力很難利用極短期失衡。建議將時間框架拉到 1-5 分鐘，用 OFI 累積值（而不是逐筆值）來判斷短期方向。

### 3. 暗池和大宗交易不在委託簿上
OFI 只能看到交易所內的委託簿，場外大宗交易和暗池的訂單不在其中。大機構可能先在場外完成交易再揭露，OFI 會滯後。

### 4. 假委託（Spoofing）
委託簿上看到的掛單不一定都是真的——有人掛大單但不打算成交，目的是操縱委託簿失衡比例。這就是所謂的 Spoofing，是違法行為但並不罕見。

**防範方式**：
- 只看成交後的 OFI，不看未成交掛單
- 大單突然消失是 Spoofing 的特徵
- 搭配成交明細驗證，不要只看委託簿靜態畫面

### 5. 流動性不足的股票不適用
OFI 在高流動性標的（台積電、大盤期貨）效果最好。低流動性標的的委託簿稀疏，OFI 訊號雜訊比高，容易誤判。
