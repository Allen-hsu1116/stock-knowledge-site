# 盤後分析與隔日預測框架

> 盤後分析的品質決定隔天盤中決策的品質，系統化盤後分析是穩定獲利的基石。

## 核心概念

### 為什麼需要盤後分析

盤中決策容易被情緒和盤面波動影響，盤後分析讓你在冷靜、客觀的狀態下：
- 檢視今日操作是否符合計畫
- 判斷今日走勢對明日方向的意義
- 調整明日策略和進出場條件
- 追蹤觀察股是否符合進場條件

**盤後分析的底層邏輯**：今天的收盤是明天開盤的基礎。收盤價代表了所有參與者在今日交易結束後的最終共識，這個共識是明日開盤和盤中走勢的起點。

### 盤後分析 vs 盤中分析

| 面向 | 盤後分析 | 盤中分析 |
|------|---------|---------|
| 目的 | 確認方向、設定條件 | 確認進場時機 |
| 情緒 | 冷靜客觀 | 容易被波動影響 |
| 時間 | 充足 | 有限 |
| 決策 | 策略層面 | 戰術層面 |
| 執行 | 寫下計畫 | 依計畫執行 |

## 盤後分析框架

### 第一步：大盤環境確認（5分鐘）

**三大確認**：
1. **趨勢方向**：看日K線和大盤均線排列（5/10/20/60MA）
2. **位置判斷**：大盤處於上漲趨勢、盤整、還是下跌趨勢？距離壓力和支撐多遠？
3. **量能狀態**：今日成交量vs 20日均量，量增或量縮？

**大盤環境分類**：
- **多頭環境**：均線多頭排列，價格站穩20MA之上 → 積極操作
- **盤整環境**：均線糾結，價格在5-20MA之間震盪 → 選股操作、減少頻率
- **空頭環境**：均線空頭排列，價格在20MA之下 → 防禦為主、空手或減碼

### 第二步：今日K線判讀（5分鐘）

**五維判讀**：
1. **K線型態**：長紅、長黑、十字線、鎚子線、上影線、下影線？
2. **量價關係**：價漲量增？價漲量縮？價跌量增？價跌量縮？
3. **均線關係**：站上或跌破哪些均線？均線交叉訊號？
4. **支撐壓力**：測試了哪些支撐壓力？突破或跌破？
5. **技術指標**：KD/RSI/MACD位置和方向？

**K線判讀速查表**：

| 今日K線 | 多空意義 | 隔日預估 |
|---------|---------|---------|
| 帶量長紅 | 多方強勢 | 續漲機率高 |
| 帶量長黑 | 空方強勢 | 續跌機率高 |
| 量縮小紅 | 多方觀望 | 盤整或轉弱 |
| 量縮小黑 | 空方觀望 | 盤整或轉強 |
| 帶上影線長紅 | 多方受阻 | 可能回測 |
| 帶下影線長紅 | 多方支撐強 | 續漲機率高 |
| 十字線 | 多空膠著 | 等待方向 |
| 缺口長紅 | 多方爆發 | 續漲或填缺口 |

### 第三步：籌碼面確認（5分鐘）

**四大觀察**：
1. **三大法人買賣超**：外資、投信、自營商方向是否一致？
2. **融資融券變化**：融資增減？融資維持率水準？
3. **主力買賣超**：前15大買賣超方向？
4. **期貨未平倉**：外資期貨OI變化？

**籌碼共振判讀**：
- **正面組合**：外資+投信同時買超 + 融資不增 + 借券穩定 → 偏多
- **負面組合**：外資+投信同時賣超 + 融資暴增 + 借券增加 → 偏空
- **分歧組合**：法人方向不一致 → 觀望或依技術面判斷

### 第四步：觀察股追蹤（10分鐘）

對每檔觀察股執行三步檢查：
1. **是否觸發進場條件？** — 價格、量能、籌碼是否達到計畫中的進場標準
2. **是否需要調整停損停利？** — 移動停利點、調整停損位置
3. **是否有新的觀察股加入？** — 今日出現符合選股條件的新標的

### 第五步：明日策略制定（5分鐘）

**策略三要素**：
1. **方向**：明日做多、做空、或觀望？
2. **條件**：什麼條件下進場？（具體價位、量能條件、時間條件）
3. **防護**：停損設在哪？停利目標是什麼？

**策略模板**：
```
日期：2026-XX-XX
大盤環境：[多頭/盤整/空頭]
今日重點：[1-2句話描述今天走勢的意義]
明日方向：[看多/看空/觀望]
進場條件：
  - 做多條件：如果大盤站上XXXX且量能>XX日均量
  - 做空條件：如果大盤跌破XXXX且帶量長黑
停損點：XXXX
停利目標：XXXX
觀察重點：[明日需要特別留意的事件或數據]
```

## 隔日預測方法

### K線預測法

根據今日K線型態推估明日走勢：

**看漲K線組合**：
- 帶量長紅 + 站上壓力 → 明日續漲機率高
- 下影線長紅 + 支撐確認 → 明日反彈機率高
- 量縮十字線 + 下跌趨勢末段 → 可能反轉向上

**看跌K線組合**：
- 帶量長黑 + 跌破支撐 → 明日續跌機率高
- 上影線長黑 + 壓力確認 → 明日回跌機率高
- 量縮十字線 + 上漲趨勢末段 → 可能反轉向下

**中性K線組合**：
- 盤整區內的十字線 → 方向不明，等突破
- 量縮小紅小黑在均線之間 → 續盤

### 均線扣抵預測法

利用均線扣抵值預判明日均線方向：

- 5MA扣抵值高於今日收盤 → 5MA明日下彎（偏空）
- 5MA扣抵值低於今日收盤 → 5MA明日上揚（偏多）
- 20MA扣抵值趨勢 → 判斷中期均線方向
- 60MA扣抵值趨勢 → 判斷長期方向是否改變

### 量能預測法

明日預估量 = 開盤15分鐘成交量 × 8（大致預估）

- 預估量 > 20日均量1.5倍 → 明日可能有大行情
- 預估量 < 20日均量0.8倍 → 明日可能盤整
- 連續3日量縮 → 注意變盤

### 夜盤預測法（台指期）

- 夜盤漲跌方向 → 明日開盤方向參考
- 夜盤成交量 → 外資參與程度
- 夜盤波動幅度 → 預估明日震盪幅度

## 實戰應用

實戰使用時需搭配進出場規則、部位控制與市場情境確認，不可單靠單一概念硬上。

## 注意事項

1. **盤後分析不能取代交易計畫**：盤後分析是計畫的輸入，不是計畫本身。你的交易系統才是核心，盤後分析只是提供情境判斷

2. **避免主觀偏好**：分析要客觀，不能因為自己持有多頭部位就只看多頭訊號。建議同時列出多空兩面的訊號

3. **記錄是關鍵**：不寫下來的等於沒分析。盤後分析日誌是交易日誌的重要組成部分，也是日後覆盤的依據

4. **隔日預測是機率不是確定**：任何預測都有失敗的可能，必須設定停損保護。預測方向錯了，停損讓你活下來

5. **不要過度分析**：每天15-30分鐘就夠了，超過1小時通常是分析癱瘓（analysis paralysis）

6. **簡單有效勝過複雜花俏**：3-5個指標交叉確認，勝過20個指標互相矛盾

7. **歷史回顧**：每週回顧上週的盤後分析準確度，找出系統性偏差並修正
