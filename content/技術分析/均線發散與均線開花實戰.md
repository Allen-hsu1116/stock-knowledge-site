# 均線發散與均線開花實戰

> 均線糾結後的發散是多空方向確認的開槍訊號，均線開花是最強的趨勢啟動型態。

## 核心概念

### 什麼是均線發散

均線發散（Moving Average Divergence / Expansion）是多條均線從糾結走向分離的過程。當短期均線、中期均線、長期均線由密集交纏逐漸拉開距離，代表市場從多空膠著走向明確方向。

**均線發散的底層邏輯**：
- 均線是市場平均成本的集合，多條均線糾結代表不同期間的買者成本趨於一致
- 發散代表新的趨勢力道足以讓不同期間的成本出現顯著差異
- 發散的方向決定多空，發散的角度決定趨勢強度

### 什麼是均線開花

均線開花（Moving Average Blossoming）是均線發散中最強烈的型態。名稱來自均線像花朵綻放一樣從糾結點向外展開的視覺效果。

**均線開花的定義**：
- 多條均線（通常5MA、10MA、20MA、60MA）從密集交纏狀態
- 短期均線迅速穿越中期均線，中期均線穿越長期均線
- 均線間距離持續擴大，呈現放射狀排列
- 伴隨明顯的成交量放大

## 均線發散的判讀方式

### 發散方向判斷

**多頭發散（看漲）**：
- 5MA > 10MA > 20MA > 60MA，由上而下排列
- 均線間距離持續擴大
- 價格站上所有均線之上
- 5MA斜率最陡、60MA斜率最緩

**空頭發散（看跌）**：
- 5MA < 10MA < 20MA < 60MA，由下而上排列
- 均線間距離持續擴大
- 價格跌破所有均線之下
- 5MA斜率最陡向下

### 發散角度判斷趨勢強度

| 發散角度 | 趨勢強度 | 特徵 |
|---------|---------|------|
| 緩慢發散（< 15度） | 弱趨勢 | 容易回測均線，可能失敗 |
| 中等發散（15-30度） | 中等趨勢 | 標準波段行情 |
| 急速發散（> 30度） | 強趨勢 | 可能是噴出行情，但需防過度乖離 |

### 發散過程中的均線排列演變

**多頭發散五階段**：

1. **糾結期**：均線密集交纏，5/10/20MA幾乎重疊
2. **啟動期**：5MA率先轉向突破10MA，小黃金交叉出現
3. **確認期**：10MA突破20MA，中期均線加入多頭排列
4. **加速期**：均線間距離持續擴大，開始出現明顯的多頭排列
5. **擴散期**：5MA遠離60MA，均線完全發散，趨勢最強階段

**空頭發散五階段**：反之，從糾結到死亡交叉再全面發散。

## 均線開花型態判讀

### 多頭開花（玫瑰開花）

**型態特徵**：
- 前期：5/10/20MA在60MA附近密集糾結
- 觸發：價格帶量長紅突破均線糾結區
- 展開：5MA急速上揚 → 10MA跟上 → 20MA緩步上揚 → 60MA持平或微揚
- 均線排列：5MA在最上方，依序向下展開

**確認條件**：
1. 必須有帶量長紅K線啟動
2. 均線從糾結到發散過程中不能回測10MA以下
3. 5MA與20MA距離至少大於5MA與10MA距離的1.5倍
4. 成交量必須大於20日均量1.5倍以上

### 空頭開花（倒花）

**型態特徵**：
- 前期：均線糾結在60MA附近
- 觸發：價格帶量長黑跌破均線糾結區
- 展開：5MA急速下彎 → 10MA跟下 → 20MA緩步下彎 → 60MA持平或微下
- 均線排列：5MA在最下方，依序向上展開

**確認條件**：
1. 必須有帶量長黑K線啟動
2. 反彈不過10MA
3. 5MA與20MA距離持續擴大

### 部分開花與假開花

**部分開花**：均線發散到一半就停止，5MA穿越10MA後20MA未能跟上，趨勢失敗回到盤整。

**假開花特徵**：
- 啟動時量能不足（未達20日均量1.3倍）
- 5MA穿過10MA但3天內又回落
- 價格迅速回到均線糾結區內
- 通常出現在長期均線（60MA）仍向下時

## 實戰應用

### 進場時機：均線開花啟動點

**策略一：糾結突破進場**
- 篩選條件：5/10/20MA在60MA附近糾結（距離< 3%）
- 進場訊號：帶量長紅突破糾結區上緣
- 停損設在：糾結區下緣或5MA下方
- 停利目標：等距測量或追蹤停利

**策略二：二次金叉進場**
- 第一次金叉（5MA穿10MA）：觀察不進場
- 第二次金叉：若5MA未跌破20MA且量能放大，進場
- 此時均線排列更有利，假訊號過濾效果更好

**策略三：60MA支撐確認進場**
- 等待價格回測60MA獲得支撐
- 5MA向上穿越10MA確認多頭排列
- 60MA必須持平或上揚

### 持股期間判斷

**持續持股條件**：
- 均線持續發散，間距擴大或穩定
- 價格站穩5MA或10MA之上
- 5MA斜率維持正向且未減緩

**減碼訊號**：
- 均線發散速度減緩，間距開始收斂
- 價格跌破5MA
- 5MA斜率由陡轉平

**出場訊號**：
- 均線開始收斂，5MA與10MA距離縮小
- 價格跌破10MA且5MA下彎
- 5MA死亡交叉10MA

### 均線發散與乖離率的搭配

均線發散代表趨勢啟動，但過度發散（正乖離過大）意味短線過熱：

- **5MA與20MA距離 > 歷史均值 + 2標準差**：短線過熱，可能回測5MA
- **價格與5MA乖離 > 5%**：短線追高風險大
- **5MA與60MA距離 > 歷史均值 + 2標準差**：中期趨勢過熱，注意回檔

### 均線開花選股實戰

**選股條件（多頭開花）**：
1. 5/10/20MA在20天內至少有10天處於糾結狀態（最大距離 < 3%）
2. 今日5MA向上穿越10MA（黃金交叉）
3. 成交量 > 20日均量 1.5倍
4. 60MA持平或上揚
5. 價格站上所有均線

**選股條件（空頭開花做空）**：
1. 5/10/20MA在20天內至少有10天處於糾結狀態
2. 今日5MA向下穿越10MA（死亡交叉）
3. 成交量 > 20日均量 1.3倍
4. 60MA持平或下彎
5. 價格跌破所有均線

## 注意事項

1. **均線發散必須從糾結開始**：沒有經歷糾結的發散通常是趨勢延續，而非新趨勢啟動，訊號可靠度降低

2. **量能是開花確認的關鍵**：沒有成交量配合的均線發散，大概率是假訊號或弱趨勢

3. **60MA方向是根本方向**：多頭開花時60MA必須持平或上揚；60MA下彎時的均線發散，大概率只是反彈而非趨勢反轉

4. **時間框架決定有效性**：日線均線開花影響5-20天，週線均線開花影響5-20週。日線開花配合週線方向，勝率最高

5. **過度發散是逆勢訊號**：均線間距離超過歷史均值2個標準差時，不是追趨勢的好時機，反而要注意回測風險

6. **均線開花≠趨勢一直持續**：開花後的發散可以持續很久，也可以很快就收斂。必須持續追蹤均線斜率和價格與均線的關係

7. **大盤環境優先**：大盤多頭時做多頭開花個股勝率高；大盤空頭時個股多頭開花可能是假開花
