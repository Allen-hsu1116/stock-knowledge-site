# Hayashi-Yoshida非同步共變異估計

> HY用報酬區間是否真正重疊來累加交叉乘積，不必先把兩檔股票硬塞進共同K線；但它不是雜訊、領先落後與投資組合矩陣問題的萬靈丹。

## 核心概念

### 1. 它解決的問題

兩檔股票成交時間不同，把較慢股票的最近一筆成交價向前填滿固定網格，可能將原本共同的價格反應分散到不同格子。HY不先插值或同步化，而保留各自報酬的原始起訖區間。

本篇採2005年Hayashi與Yoshida估計量的基本形式，公式依本次取得的Chang等人2019年v1第2.2節核對。2005年原始論文全文未取得，不聲稱已逐頁研讀其證明。

### 2. 定義與區間端點

X、Y是對數價格，在共同觀察窗[0,T]各有嚴格遞增的時間戳。令：

$$
I_i=(t_{i-1},t_i],\quad J_j=(s_{j-1},s_j],\quad
\Delta X_i=X_{t_i}-X_{t_{i-1}},\quad
\Delta Y_j=Y_{s_j}-Y_{s_{j-1}}
$$

$$
\widehat C_{HY}=\sum_i\sum_j\Delta X_i\Delta Y_j\,\mathbf 1\{I_i\cap J_j\ne\varnothing\}
$$

- **重疊判定**：`max(t[i-1], s[j-1]) < min(t[i], s[j])`，使用嚴格小於；(0,1]與(1,2]只碰到端點，沒有交集。
- **權重是0或1**：不是按重疊長度比例加權，也不把大區間報酬再除以重疊對數。
- **一個報酬可貢獻多次**：只要它與另一檔多個區間重疊，就有多個乘積；這是定義，不是程式重複列資料。
- **同步退化**：兩檔使用完全相同分割時，只剩同一格相乘，HY等於未去均值的已實現共變異RC。
- **單位**：對數報酬平方。它是觀察窗累積的共變異，不是每格除以樣本數的樣本共變異，也不是已年化數值。

### 3. 估計目標與成立條件

在無微結構雜訊的連續擴散模型下，目標為整段的積分共變異：

$$
C_T=\int_0^T\sigma_X(u)\sigma_Y(u)\rho(u)\,du
$$

基本一致性依賴適當的價格過程、觀察時點條件及最大區間長度趨近零；不能將原始外生／獨立取樣設定，任意推廣成「任何內生成交時間都沒問題」。本次只整理估計式與假設意涵，未重證漸近結果。

它不是預測明天的相關，更不是「今天所有價差一定回歸」。若資料帶買賣價差雜訊、跳躍或領先落後，必須另確認所用擴充估計量和定理，不能自動沿用這個無雜訊連續模型結論。

### 4. 三個重疊乘積的例子

**假設對數價格相對起點已減去常數，不是實際股價。**

- X時間戳：0、1、3；對數價格：0、0.01、0.02，兩段增量各0.01。
- Y時間戳：0、2、3；對數價格：0、0.02、0.01，兩段增量為0.02、−0.01。
- X的(0,1]與Y的(0,2]重疊，貢獻0.0002。
- X的(1,3]與Y的(0,2]重疊，貢獻0.0002。
- X的(1,3]與Y的(2,3]重疊，貢獻−0.0001。
- **HY = 0.0003**；X、Y各自RV為0.0002、0.0005，標準化比值約0.948683。

如果改用0、1、2、3的previous-tick網格，X增量為0.01、0、0.01，Y增量為0、0.02、−0.01；**RC = −0.0001**，以該網格RV標準化約−0.316228。

同一組觀察值可以得到不同正負號，說明同步化有影響；**這不表示HY的0.948683已是真實相關**，因為這條假設路徑沒有提供未觀察價格，也沒有統計推論。標準化方式均未去均值，不是Pearson相關。

### 5. 有限樣本可能超出相關範圍

保留前述兩套時間戳，但把X、Y對數價格都設成0、0.01、0.02。HY有三個0.0001乘積，合計0.0003；個別RV都為0.0002。因此HY / √(RV_X RV_Y) = **1.5**。

若將兩個RV放對角、HY放非對角，所得二乘二矩陣的特徵值為0.0005、−0.0001，**不是正半定矩陣**。這是有限樣本反例，不是「真實相關可以超過1」。

- 逐對估計再拼成矩陣，不保證可安全送進投資組合最佳化。
- 把1.5裁成1，只是後處理，沒有修復觀察模型或證明估計無偏；多資產逐元素裁切也不保證矩陣正半定。
- 必要時採有正半定保證的聯合估計、收縮或矩陣投影，並揭露修正幅度；不要把大幅修正藏起來。

## 實戰應用

### 用於跨股風險量測的工作流程

1. **先留原始時間戳**：兩檔都要有可信的盤中觀察與一致價格口徑；只有日K或已填滿的一分鐘K，無法回推出原始重疊結構。
2. **做資料稽核**：排序、處理同時戳多筆資料的固定規則、去掉無效價格，記錄停牌與長時間無更新；不應盲目把缺值當零報酬。
3. **統一觀察窗**：此教學程式要求共同起點與終點，不靠未來成交補端點；真實不同邊界需先定義共同可觀察區間與邊界處理。
4. **計算並對照**：同時列HY、previous-tick RC、不同間隔診斷、兩檔RV、重疊對數與最長觀察間隔。
5. **遇到差異先診斷**：流動性不對稱、領先落後和雜訊可能同時存在；HY高於固定網格估計不是立刻加大避險口數的理由。
6. **區分量測與交易**：完整區間報酬必須到右端點才能知道；盤中策略若用尚未結束的Y區間，就偷看未來。

台股可用在產業龍頭與供應鏈、ETF與成分股的相關性資料檢查，但這只是待測研究用途，不是本次已驗證的台股交易策略。

### 最小可重跑的核心

以下輸入為已清理、嚴格递增且共同觀察窗的時間戳與對數價格；回傳累積共變異。簡單雙迴圈適合教學，大規模逐筆資料應另做效率設計與測試。

```python
from math import isclose

def hy(tx, x, ty, y):
    assert len(tx) == len(x) >= 2 and len(ty) == len(y) >= 2
    assert tx[0] == ty[0] and tx[-1] == ty[-1]
    assert all(a < b for a, b in zip(tx, tx[1:]))
    assert all(a < b for a, b in zip(ty, ty[1:]))
    return sum(
        (x[i] - x[i - 1]) * (y[j] - y[j - 1])
        for i in range(1, len(tx))
        for j in range(1, len(ty))
        if max(tx[i - 1], ty[j - 1]) < min(tx[i], ty[j])
    )

assert isclose(hy([0, 1, 3], [0, .01, .02],
                  [0, 2, 3], [0, .02, .01]), .0003)
# Endpoint-only contact does not count.
assert hy([0, 1, 2], [0, 1, 1], [0, 1, 2], [0, 0, 1]) == 0
print("HY overlap examples passed")
```

## 注意事項

- **基本HY不等於雜訊穩健HY**：單檔TSRV處理的微結構雜訊，不會因使用重疊區間而自動消失；兩個工具解決的問題不同。
- **領先落後另行建模**：當相關反應跨越不重疊區間時，基本HY沒有「把所有延遲相關找回來」的保證；搜尋最佳時間位移本身也有多重測試風險。
- **多次貢獻不等於多份獨立資訊**：很長的稀疏區間與很多短區間重疊，不代表有效樣本數就很大。
- **共變異估計與Pearson相關勿混用**：本文的RV標準化在有限樣本可超界；真正模型相關仍在−1到1之間。
- **研究解讀有邊界**：2019年來源對事件時間與MM的偏好不代表HY理論失效；要先問估計的是潛在連續價格共變異，還是特定交易時鐘下的事件共同變動。
