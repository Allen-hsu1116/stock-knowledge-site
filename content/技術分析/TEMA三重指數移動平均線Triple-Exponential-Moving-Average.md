# TEMA 三重指數移動平均線 (Triple Exponential Moving Average)

> TEMA（Triple Exponential Moving Average，三重指數移動平均線）由 Patrick Mulloy 於 1994 年提出。核心思路是：**對 EMA 做 EMA 再做 EMA，然後用代數組合消除延遲**——讓均線既有平滑度又大幅降低遲滯性。

## 核心概念

TEMA（Triple Exponential Moving Average，三重指數移動平均線）由 Patrick Mulloy 於 1994 年提出。核心思路是：**對 EMA 做 EMA 再做 EMA，然後用代數組合消除延遲**——讓均線既有平滑度又大幅降低遲滯性。

TEMA 屬於「零延遲」均線家族的一員，與 [[技術分析/TRIX三重指數平滑移動平均指標|TRIX]] 同源但用途不同：TRIX 把 TEMA 的概念做成震盪指標（看動量轉折），TEMA 則保留為均線形式（看趨勢方向與支撐壓力）。

**一句話理解**：TEMA = EMA + EMA(EMA) + EMA(EMA(EMA)) 的線性組合，用三層 EMA 互相抵消延遲。

## 計算公式

### 三步推導

1. **EMA₁** = 對價格做 N 期 EMA
2. **EMA₂** = 對 EMA₁ 做 N 期 EMA
3. **EMA₃** = 對 EMA₂ 做 N 期 EMA

**TEMA = 3 × EMA₁ − 3 × EMA₂ + EMA₃**

### 為什麼這個公式有效

- EMA₁ 有延遲，EMA₂ 延遲更大，EMA₃ 延遲最大
- 用 3 × EMA₁ 加權最靈敏的值，再減去 3 × EMA₂ 移除「延遲的延遲」，最後加回 EMA₃ 做修正
- 本質上是把三條 EMA 的延遲特性做線性消組合（deconvolution），讓結果比單一 EMA 更貼近真實價格

### 常見參數
- N = 9（短線敏感型）
- N = 20 或 21（標準型，最常用）
- N = 50（中長期趨勢）

## 與其他均線的比較

- **vs [[技術分析/EMA指數平滑移動平均線|EMA]]**：TEMA 延遲更小，在趨勢反轉時比 EMA 更早轉向，但盤整時假訊號更多
- **vs [[技術分析/移動平均線種類比較SMA-EMA-WMA|SMA]]**：SMA 延遲最大最平滑，TEMA 反應最快但犧牲了平滑度
- **vs [[技術分析/赫爾移動平均線HMA-Hull-Moving-Average|HMA]]**：HMA 用加權和平方根壓縮延遲，TEMA 用三重 EMA 組合。兩者都屬零延遲均線，HMA 轉折更果斷、TEMA 更平滑
- **vs [[技術分析/考夫曼自適應移動平均線KAMA|KAMA]]**：KAMA 根據市場效率自動變速（盤整慢、趨勢快），TEMA 固定速度但延遲更小。KAMA 更聰明但計算更複雜
- **vs [[技術分析/TRIX三重指數平滑移動平均指標|TRIX]]**：TRIX = TEMA 的變化率，把 TEMA 的變化做成百分比震盪指標。TEMA 看價格線位置，TRIX 看動量轉折

## 判讀方式

### 1. 趨勢方向判斷
- **TEMA 向上**：短期趨勢偏多
- **TEMA 向下**：短期趨勢偏空
- **TEMA 走平**：趨勢停滯或即將轉折
- 因為延遲小，TEMA 的轉向比 EMA 和 SMA 更早

### 2. 價格與 TEMA 的關係
- **價格站上 TEMA**：多頭格局，TEMA 成為動態支撐
- **價格跌破 TEMA**：空頭格局，TEMA 成為動態壓力
- **價格與 TEMA 反覆纏繞**：盤整格局，TEMA 訊號失效

### 3. TEMA 交叉策略
- **TEMA 向上穿越價格**：買進訊號（等同黃金交叉概念）
- **TEMA 向下穿越價格**：賣出訊號（等同死亡交叉概念）
- 也可用兩條不同週期 TEMA 交叉（如 TEMA(9) 穿越 TEMA(21)）

### 4. 背離判讀
- **頂背離**：價格創新高但 TEMA 未創新高 → 趨勢動能減弱
- **底背離**：價格創新低但 TEMA 未創新低 → 跌勢可能收斂
- 因為 TEMA 延遲小，背離訊號比 SMA/EMA 更早出現，但也更容易產生假背離

## 實戰用法

### 策略一：TEMA + EMA 雙均線系統
1. 用 TEMA(20) 作為主趨勢線（快速反應）
2. 用 [[技術分析/EMA指數平滑移動平均線|EMA(50)]] 作為慢速確認線
3. TEMA 上穿 EMA → 偏多操作
4. TEMA 下穿 EMA → 偏空或空手
5. 兩線同向且發散 → 趨勢確立，加碼

### 策略二：TEMA 作為動態停損
1. 趨勢确立後，將停損設在 TEMA 下方（做多時）
2. TEMA 向上移動，停損跟著上移
3. 價格跌破 TEMA 即出場，比固定均線停損反應更快
4. 適合短線波段操作

### 策略三：TEMA + [[技術分析/MACD指標實戰判讀|MACD]] 共振
1. TEMA 確認趨勢方向（向上/向下）
2. MACD 柱狀圖確認動量是否同步
3. 兩者同向 → 高勝率進場
4. TEMA 轉向但 MACD 未確認 → 等待，可能是假訊號

## 優缺點

### 優點
- **延遲大幅降低**：比單一 EMA 減少約 60-70% 的延遲
- **趨勢反轉更早偵測**：在轉折點比 SMA/EMA 早 3-5 根 K 線
- **計算簡單**：只需三層 EMA 的線性組合，沒有複雜參數
- **可程式化**：所有交易平台都支援 EMA，TEMA 容易實作

### 缺點
- **盤整市假訊號多**：延遲小 = 靈敏 = 雜訊也多，盤整時反覆轉向
- **不適合極短線**：在 1 分鐘或 tick 級別，TEMA 的優勢被噪音淹沒
- **參數敏感性**：N 值選擇影響很大，太小過度靈敏、太大失去優勢
- **非自適應**：不像 [[技術分析/考夫曼自適應移動平均線KAMA|KAMA]] 能根據市場狀態自動調整

## 適用場景

- ✅ 中短線波段操作（日K線、週K線）
- ✅ 趨勢追蹤系統的快速訊號線
- ✅ 動態停損移動
- ✅ 與慢速均線組成雙均線系統
- ❌ 盤整市（需搭配 [[技術分析/ADX趨勢強度過濾盤整|ADX]] 或 [[技術分析/斬波指標Choppiness-Index|CHOP]] 過濾）
- ❌ 極短線高頻交易

## 與 TRIX 的關係

[[技術分析/TRIX三重指數平滑移動平均指標|TRIX]] 是 TEMA 的「變化率版本」：

- **TEMA** = 3EMA₁ − 3EMA₂ + EMA₃（看價格位置）
- **TRIX** = (TEMA今日 − TEMA昨日) / TEMA昨日 × 100（看動量變化）

TEMA 回答「現在趨勢往哪走」，TRIX 回答「趨勢的動能在增強還是減弱」。兩者搭配使用——TEMA 看方向、TRIX 看動量——可以形成完整的趨勢追蹤系統。

## 總結

TEMA 是零延遲均線家族中計算最直觀的一員。它用三層 EMA 的代數組合大幅消除延遲，讓你在趨勢反轉時比傳統均線更快做出反應。但代價是盤整時的假訊號更多——**這是所有零延遲均線的共同代價**。

最佳用法不是單獨依賴 TEMA，而是把它當作「快速訊號線」，搭配慢速均線或趨勢強度指標（ADX/CHOP）形成多層確認系統。記住：**靈敏不是免費的——你用延遲換來的時間優勢，會在盤整時被雜訊吃回去。**
