# 相對成交量 RVOL (Relative Volume)

> **一句話：** RVOL 告訴你今天的量是「正常」的幾倍——5倍就是全村的人突然全跑來看你家，異常到不能忽視。

## 核心概念

**相對成交量（Relative Volume, RVOL）** 是指當日（或特定時段）成交量與過去一段時間平均成交量的比值。它不是絕對數字，而是「相對強度」，用來判斷今天的量是否異常放大或萎縮。

**基本公式：**

```
RVOL = 當期成交量 / 過去N期平均成交量
```

- N 通常取 5、10、20 或 30 個交易日
- RVOL = 1.0 代表成交量與平均持平
- RVOL > 1.0 代表量能放大
- RVOL < 1.0 代表量能萎縮

## 為什麼 RVOL 有用

成交量是市場的燃料，但絕對量沒有語境——台積電日均量 5 萬張跟國巨日均量 5 萬張意義完全不同。RVOL 把每檔股票的量能放在自己的歷史脈絡裡比較，讓你一眼看出「今天是不是有什麼事正在發生」。

**RVOL 的三個核心用途：**

- **偵測異常事件：** RVOL 突然飆到 3-5 倍以上，代表有大資金進出或有消息面驅動，是你需要立刻關注的理由
- **確認突破真偽：** 價格突破關鍵位置時，RVOL > 2 才算「帶量突破」，RVOL < 1 的突破九成是假的
- **篩選日內活躍標的：** 當沖或短線交易者用盤中 RVOL 找出「今天突然活了」的股票

## 盤中 RVOL 更有威力

日線 RVOL 要等收盤才算，但盤中 RVOL 可以即時偵測「哪檔股票正在被資金盯上」。

**盤中預估 RVOL 計算：**

```
盤中預估量 = 截至目前成交量 × (全天交易時間 / 已過交易時間)
盤中 RVOL = 盤中預估量 / 過去N期平均成交量
```

例如開盤 30 分鐘成交 5000 張，全天交易時間 270 分鐘（9:00-13:30）：

```
預估量 = 5000 × (270/30) = 45000 張
若過去 10 日均量 = 15000 張
盤中 RVOL = 45000 / 15000 = 3.0
```

盤中 RVOL > 2 就值得放進觀察清單，因為代表今天有大資金在動。

## 實戰應用框架

### 1. 突破確認

價格突破關鍵位置（前高、均線糾結發散、型態頸線）時，要求 **RVOL > 1.5-2.0** 才算有效突破。

- 帶量突破（RVOL > 2）：可信度高，可以進場
- 無量突破（RVOL < 1）：假突破機率高，追進去容易被騙
- 參考 [[成交量確認原則Volume-Confirmation]] 和 [[真突破確認三原則帶量收盤3天]]

### 2. 背離偵測

- 價漲但 RVOL < 0.8 → [[量縮上漲與量價背離區分實戰|量價背離]]，追價力道不足
- 價跌但 RVOL > 3 → 恐慌性殺盤或主力出貨，要判斷位置在高檔還是低檔
- 參考 [[量價關係九種型態高低檔判讀]]

### 3. 飆股篩選

飆股啟動前通常伴隨 RVOL 暴增。可以設定篩選條件：

- **日線 RVOL > 3** 且 **價格漲幅 > 5%** → 強勢啟動訊號
- **連續 3 日 RVOL > 1.5** → 持續性量能進場
- **盤中 RVOL > 2 且突破盤整區** → 當沖候選標的
- 參考 [[飆股DNA選股策略]]

### 4. 底部判斷

底部窒息量是經典訊號：

- RVOL 長期 < 0.5 → 量能枯竭，可能是底部
- RVOL 從 0.3 突然跳到 2.0+ → 帶量長紅啟動底部反轉
- 參考 [[成交量特殊型態判讀Volume-Pattern-Analysis]] 和 [[底部訊號綜合判讀Bottom-Signal-Confluence]]

## 進階用法：RVOL + VWAP

把 RVOL 搭配 [[VWAP成交量加權均價|VWAP]] 使用效果更好：

- RVOL > 2 + 價格在 VWAP 上方 → 帶量站上當日成本線，多方主導
- RVOL > 2 + 價格在 VWAP 下方 → 帶量跌破當日成本線，空方主導
- RVOL < 0.5 + 價格在 VWAP 附近 → 量縮盤整，等待方向

## 台股實戰注意事項

- 台股可以用 [[5均量判定量價關係|5日均量]] 當短期 RVOL 基準，[[量價8大口訣與均量線三層次判讀Volume-Price-8-Rules-and-VMA|10/20/60 均量線]] 當中期基準
- 權值股 RVOL 波動較小，中小型股 RVOL 波動劇烈
- 注意融資融券標的 RVOL 異常放大可能代表多殺多或軋空
- 法人買賣超 + RVOL > 2 是最強的多方組合訊號

## 總結

RVOL 是量能分析的「標準化工具」，讓你不用記住每檔股票的絕對成交量，只需看一個數字就知道「今天的量正不正常」。它最好跟價格行為、支撐壓力和其他量價指標一起使用，單獨看 RVOL 容易過度解讀。

## 實戰應用

### RVOL 分級判讀
| RVOL 範圍 | 解讀 | 行動建議 |
|-----------|------|----------|
| < 0.5 | 極度萎縮，市場沒人理 | 觀望或注意是否醞釀大行情 |
| 0.5-0.8 | 量能偏弱 | 趨勢可能停滯 |
| 0.8-1.2 | 正常範圍 | 按原計畫操作 |
| 1.2-2.0 | 溫和放量 | 關注但不必緊張 |
| 2.0-3.0 | 明顯放量 | 確認價格方向是否同步 |
| 3.0-5.0 | 異常大量 | 立刻查明原因（消息、法人、股東會） |
| > 5.0 | 爆量 | 極端事件，可能是突破也可能是出貨 |

## 注意事項

**1. 除權息日失真**

除權息日成交量通常會放大（棄息賣壓），RVOL 可能飆到 2-3 倍，但這不代表有大利多。遇到除權息日要排除或修正基準。

**2. 月底季底做帳失真**

法人季底做帳時成交量系統性放大，RVOL 會偏高。建議用「過去 20 日排除最大最小值後的平均」當基準，降低極端值干擾。

**3. 新聞驅動的短期脈衝**

一則利多新聞可以讓 RVOL 瞬間飆到 5 倍，但如果量能無法持續（隔天 RVOL 回到 1 以下），代表只是消息面脈衝，不是趨勢性大資金進場。
