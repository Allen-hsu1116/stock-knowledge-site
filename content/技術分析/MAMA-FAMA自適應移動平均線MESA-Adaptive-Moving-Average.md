# MAMA/FAMA 自適應移動平均線 MAMA & FAMA

> 用希爾伯特轉換測量價格的「主導週期」，讓均線像變速箱一樣自動換檔——趨勢時緊貼、盤整時放慢，MAMA 與 FAMA 的交叉就是最自適應的買賣訊號

## 核心概念

MAMA（MESA Adaptive Moving Average）由技術分析工程師 John F. Ehlers 在《Rocket Science for Traders》（2001）提出。傳統均線最大的問題是**週期固定**——你選 20 日均線，不管市場在趨勢還是盤整，它都一樣慢吞吞。

MAMA 的核心創新：用**希爾伯特轉換（Hilbert Transform）**即時計算價格序列的主導週期（dominant cycle），然後根據主導週期動態調整平滑常數。市場趨勢明確時，主導週期短，MAMA 貼近價格；市場盤整時，主導週期長，MAMA 放慢腳步避免鞭子假訊號。

FAMA（Following Adaptive Moving Average）是 MAMA 的追隨線，用更慢的響應速度計算，相當於 MAMA 的「均線」。MAMA 與 FAMA 的交叉就是買賣訊號。

### 與其他自適應均線的比較

- **[[考夫曼自適應移動平均線KAMA|KAMA]]**：用效率係數（ER）調整，邏輯直觀但對突發波動反應較慢
- **[[FRAMA分形自適應移動平均線|FRAMA]]**：用分形維度調整，擅長偵測趨勢 vs 盤整的狀態切換
- **MAMA**：用希爾伯特轉換計算主導週期，是唯一真正測量「價格內含週期」的方法

## 計算原理

### Step 1：希爾伯特轉換提取相位

希爾伯特轉換將實數價格序列轉為複數，得到**瞬時相位（instantaneous phase）**：

```
InPhase = Price - Price[3]    （同相分量，約略）
Quadrature = Price[2] - Price[4]    （正交分量，約略）
```

Ehlers 使用簡化的有限脈衝響應（FIR）濾波器近似希爾伯特轉換，避免完整數學運算的複雜度。

### Step 2：計算主導週期

從相位變化率推算主導週期：

```
ΔPhase = Phase[t] - Phase[t-1]
DominantCycle = 2π / ΔPhase
```

主導週期代表目前價格序列中最強的循環成分。如果價格純隨機漫步，主導週期會趨向最大值（無明確循環）。

### Step 3：計算 α（平滑因子）

```
α = FastLimit / DominantCycle
```

- **FastLimit**（預設 0.5）：α 的上限，控制 MAMA 最快可以多快
- **SlowLimit**（預設 0.05）：α 的下限，控制 MAMA 最慢可以多慢

當主導週期短（趨勢明確），α 變大，MAMA 貼近價格。
當主導週期長（盤整），α 變小，MAMA 放慢。

### Step 4：MAMA 遞迴

```
MAMA = α × Price + (1 - α) × MAMA[1]
```

### Step 5：FAMA 計算

FAMA 用 MAMA 的 α 再做一次平滑，速度更慢：

```
α_FAMA = α² / FastLimit    （平方降速）
FAMA = α_FAMA × MAMA + (1 - α_FAMA) × FAMA[1]
```

### 參數預設值

- **FastLimit = 0.5**：MAMA 最快時等於 2 週期 EMA，非常靈敏
- **SlowLimit = 0.05**：MAMA 最慢時等於 39 週期 EMA，足夠平滑

## 實戰用法

### 1. MAMA/FAMA 交叉訊號

- **MAMA 向上突破 FAMA**：買進訊號（趨勢加速）
- **MAMA 向下突破 FAMA**：賣出訊號（趨勢減速或反轉）

交叉訊號的優勢在於**自適應性**：盤整時 MAMA 和 FAMA 都慢，交叉頻率低，天然過濾假訊號；趨勢時 MAMA 快速跟上，交叉訊號及時。

### 2. MAMA 斜率判讀

- MAMA 斜率向上 = 多方主導
- MAMA 斜率向下 = 空方主導
- MAMA 水平 = 盤整，不交易

### 3. MAMA 作為動態支撐壓力

趨勢中 MAMA 貼近價格，可作為動態停利線。價格跌破 MAMA 就出場，比固定均線更靈活。

### 4. 與其他指標組合

- **MAMA + [[ADX趨勢強度過濾盤整|ADX]]**：ADX > 25 確認趨勢存在，再用 MAMA/FAMA 交叉進場，雙重過濾
- **MAMA + [[RSI相對強弱指標|RSI]]**：MAMA/FAMA 金叉 + RSI > 50 = 多方確認；死叉 + RSI < 50 = 空方確認
- **MAMA + [[SuperTrend超級趨勢指標|SuperTrend]]**：兩者都是自適應趨勢指標，同向時訊號最強

## 優缺點

### 優點
- **真正的自適應**：不是用固定參數，而是從價格本身提取週期
- **盤整時假訊號少**：主導週期變長，MAMA/FAMA 自然放慢
- **趨勢時反應快**：主導週期縮短，MAMA 快速跟上
- **數學基礎扎實**：希爾伯特轉換是信號處理的標準工具

### 缺點
- **計算複雜**：需要希爾伯特轉換，一般交易軟體不一定內建
- ** lag 仍存在**：再自適應的均線也有 lag，劇烈反轉時仍會慢半拍
- **參數仍有影響**：FastLimit 和 SlowLimit 的選擇仍需最佳化
- **非常態分佈問題**：希爾伯特轉換假設信號接近正弦波，股價的非平穩性可能讓週期估計失真

## 台股實戰注意事項

1. **台股適用性**：MAMA 在台股權值股（如台積電、鴻海）效果較好，因為這些股票趨勢明確。小型股波動太大，主導週期估計可能不穩定。

2. **搭配量能**：MAMA/FAMA 金叉時如果成交量未放大，訊號可信度打折。可搭配 [[量價關係與背離|量價關係]] 確認。

3. **多時間框架**：日線 MAMA/FAMA 看方向，60 分鐘 MAMA/FAMA 找進場點。和 [[多時間框架分析|多時間框架分析]] 的邏輯一致。

4. **TradingView 語法**：TradingView 內建 MAMA 指標，可直接使用。XQ 全球贏家需要自行寫腳本。

## 與 KAMA 的深入比較

| 維度 | KAMA | MAMA |
|------|------|------|
| 適應機制 | 效率係數（位移/路徑） | 希爾伯特轉換（主導週期） |
| 數學基礎 | 統計學（方向效率） | 信號處理（頻域分析） |
| 盤整處理 | ER→0，SC→慢，水平線 | 週期→長，α→小，放慢 |
| 趨勢反應 | ER→1，SC→快，貼近 | 週期→短，α→大，貼近 |
| 計算複雜度 | 中等 | 高 |
| 適合市場 | 所有市場 | 趨勢明確的市場更佳 |
| 訊號方式 | 價格穿越 KAMA | MAMA/FAMA 交叉 |

兩者可以同時使用：KAMA 確認趨勢方向，MAMA/FAMA 找進出場時機。

## 總結

MAMA/FAMA 是技術分析中唯一真正從價格信號的頻域特性出發的自適應均線系統。它的核心優勢在於不需要預設週期，讓市場自己告訴你現在的循環長度。實戰上，MAMA/FAMA 交叉比傳統雙均線交叉更少假訊號，特別適合趨勢追蹤交易者。不過計算複雜度和對非平穩價格序列的敏感度是使用時需要注意的限制。
