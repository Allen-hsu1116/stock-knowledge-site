# 技術分析與市場微結構融合 Microstructure-Informed Technical Analysis

> 傳統技術分析看的是「結果」，微結構分析看的是「過程」——兩者融合，就像同時有 X 光片和斷層掃描。

## 核心概念

市場微結構（Market Microstructure）研究的是交易行為的最底層機制：訂單如何匹配、價格如何形成、流動性如何變化。將微結構洞察融入傳統技術分析，可以在傳統訊號出現之前或之後提供更深層的驗證，大幅提升訊號的可靠度。

傳統技術分析基於 OHLCV（開高低收量）數據，是交易的「壓縮摘要」。微結構分析則深入 Tick 級別和訂單簿級別的細節，是交易的「原始過程」。兩者的關係就像：

- **傳統技術分析 = 看照片**（已經壓縮處理的畫面）
- **微結構分析 = 看原始像素**（每個數據點的真實記錄）

## 兩者融合的三個層次

### 層次一：用微結構確認傳統訊號

傳統技術分析給出訊號，微結構確認訊號的真實性。這是最基礎也最實用的融合方式。

**應用場景**：
- 布林通道突破 + 訂單流確認：突破上軌時，Tick 級買方力量是否真的增強？
- RSI 背離 + 足跡圖確認：RSI 頂背離時，高價位的賣方吸收行為是否明顯？
- 均線黃金交叉 + VWAP 分布：交叉時，買方主導的成交是否集中在 VWAP 上方？

### 層次二：用微結構提前預警

微結構指標的領先性可以用來在傳統訊號出現前預警。

**應用場景**：
- OFI（訂單流失衡）轉向 → 領先 RSI/MACD 背離 1-3 根 K 線
- 大單吸收行為（Absorption）→ 領先支撐壓力測試 1-2 根 K 線
- 流動性空洞（Liquidity Gap）→ 領先跳空缺口或急速突破
- 詳見 [[訂單流失衡OFI-Order-Flow-Imbalance]]

### 層次三：用微結構改造技術指標

將微結構數據作為技術指標的輸入，產生更精確的指標。

**應用場景**：
- 用 Tick 數據計算「真實」VWAP（而非用分鐘 K 估算）
- 用訂單簿深度計算「壓力加權支撐壓力位」
- 用 OFI 替代成交量作為 OBV 的輸入
- 用買方主導成交比例替代 RSI 的漲跌天數

## 微結構核心概念與技術分析的對應

### 1. 訂單流（Order Flow）↔ 成交量

| 傳統指標 | 微結構對應 | 優勢 |
|---------|-----------|------|
| 成交量 | 訂單流（買方發動 vs 賣方發動） | 區分發動方，不只看量 |
| OBV | Cumulative Delta | 更精確衡量買賣力量 |
| 量價背離 | Delta 背離 | 更可靠的反轉訊號 |

**Cumulative Delta** 是日內累計的買方主動成交 - 賣方主動成交。當價格創新高但 Delta 沒有創新高 = Delta 背離 = 比傳統量價背離更可靠的頂部訊號。

### 2. 訂單簿（Order Book）↔ 支撐壓力

| 傳統指標 | 微結構對應 | 優勢 |
|---------|-----------|------|
| 支撐壓力線 | 訂單簿深度 | 看到真實的掛單量 |
| 整數關卡 | 大單密集區 | 精確定位防線 |
| 突破確認 | 掛單撤離速度 | 識別假掛單 |

**注意**：訂單簿的掛單可以被撤銷（Spoofing），看到的掛單不一定是真實需求。必須觀察掛單在價格接近時的反應：留在原地 = 有意義，快速撤離 = 假掛單。

### 3. 流動性（Liquidity）↔ 交易成本

| 傳統概念 | 微結構對應 | 優勢 |
|---------|-----------|------|
| 成交量 | 買賣價差（Spread） | 量化流動性成本 |
| 突破有效性 | 衝擊成本 | 大單進場的實際成本 |
| 滑價 | 市場深度 | 停損單的執行品質 |

流動性乾涸時的突破更可靠（賣方已經離場），流動性充沛時的突破更可能是假突破（太多人看到了同樣的訊號）。

### 4. 吸收行為（Absorption）↔ 支撐壓力測試

當價格到達某個價位時，大量對手方訂單湧入，使價格無法繼續推進：

- **上方吸收**：價格上漲到某價位，大量賣方掛單出現，買方攻勢被吸收 → 頂部訊號
- **下方吸收**：價格下跌到某價位，大量買方掛單出現，賣方攻勢被吸收 → 底部訊號
- 吸收行為在足跡圖（Footprint Chart）上清晰可見
- 詳見 [[訂單流足跡圖Footprint-Chart]]

吸收行為比傳統的支撐壓力測試更可靠，因為你能直接看到「誰在守」。

## 實戰融合策略

### 策略一：Delta 背離交易法

1. 在日K或 60 分K上確認 [[背離Divergence進階實戰]] 的傳統背離訊號
2. 在 5 分K的足跡圖上觀察 Delta 是否出現同方向背離
3. 傳統背離 + Delta 背離雙重確認 → 進場機率大幅提升
4. 止損設在背離點的 ATR 倍數之外

### 策略二：流動性空洞突破法

1. 用 Volume Profile 辨識低成交量區域（LVN = Low Volume Node）
2. 當價格進入 LVN 區域時，缺少流動性支撐容易快速穿越
3. 搭配 [[布林通道Bollinger-Bands三軌八型態]] 的 Squeeze 後突破
4. 進場：突破 LVN 區域後回測 LVN 邊緣時
5. 詳見 [[Volume-Profile成交量分佈分析]]

### 策略三：吸收行為反轉法

1. 價格測試重要支撐/壓力位
2. 在足跡圖上觀察是否有大單吸收行為（對手方大量成交但價格不動）
3. 吸收行為 + [[RSI相對強弱指標]] 超買/超賣 + 傳統背離 = 三重確認
4. 進場：吸收完成後價格反轉方向的第一根反轉 K 線

### 策略四：微結構增強的 VWAP 交易

1. 用 VWAP 判斷日內多空分界（See [[VWAP成交量加權均價]]）
2. 用 Cumulative Delta 確認 VWAP 上方是否真由買方主導
3. 價格在 VWAP 上方 + Delta 為正 → 多方真實控盤 → 拉回 VWAP 可買
4. 價格在 VWAP 上方但 Delta 為負 → 虛假上漲 → 不追多

## 台股微結構的特殊考慮

### 1. 集合競價 vs 逐筆交易

- 台股 2020 年起全面實施逐筆交易，但開盤和收盤仍為集合競價
- 集合競價時段的訂單流無法觀察（無即時匹配過程）
- 逐筆交易時段的微結構分析才有意義

### 2. 漲跌幅限制對微結構的影響

- 漲停/跌停時，訂單簿的一方完全消失（只剩漲停買單或跌停賣單）
- 漲停板的訂單流分析完全不同於正常交易
- 接近漲停時的吸收行為是強烈訊號

### 3. 權證避險的微結構影響

- 券商的 Delta 避險創造大量被動買賣盤
- 這些買賣盤不是基於對價格的判斷而是基於 Delta 中性義務
- 詳見 [[自營商權證避險Delta操作機制]]

### 4. 法人分點的微結構追蹤

- 台股的分點數據可以追蹤法人動態
- 大型券商特定分點的連續買超 = 法人進場
- 詳見 [[分點進出追蹤關鍵分點]]

## 所需工具與數據

### 免費工具

- **XQ 全球贏家**：提供即時委買委賣和五檔
- **證交所基本市況報導**：提供分鐘級成交量
- **券商看盤軟體**：多數提供即時內外盤比

### 付費工具

- **Tick 級數據**：如 TEJ、群益等數據商提供
- **足跡圖軟體**：如 ATI、InvestorsRT 等（台股可用 Quantatrade）
- **訂單流分析平台**：如 Bookmap、Quantower
- **期貨委買委賣口數**：期交所提供

## 注意事項

- **數據延遲**：微結構分析依賴即時數據，延遲 1 秒的分析價值大幅下降
- **成本高昂**：Tick 級數據和即時訂單簿數據的費用不低，需要交易規模足夠大才划算
- **過度分析的陷阱**：微結構細節太多，容易陷入「看到一切但什麼都看不懂」的狀態
- **Spoofing 與假掛單**：訂單簿上的掛單可能隨時撤銷，不能把掛單當作真實供需
- **數據量巨大**：Tick 級數據的量是日K的數千倍，儲存和處理需要基礎設施支持
- **回測困難**：Tick 級回測需要特殊工具和大量計算資源，傳統回測框架不適用
- **不適合所有人**：如果你不是日內交易者，微結構分析的邊際效益遞減
