# 成交量加權移動平均線 VWMA Volume-Weighted Moving Average

> 每一天的價格不再是平等的——成交量大的日子說話大聲，成交量小的日子閉嘴。VWMA 把成交量當權重揉進均線裡，讓你看到的不是「平均價格」而是「平均市場共識」。

## 核心概念

VWMA（Volume-Weighted Moving Average）是一種把成交量作為權重加權計算的移動平均線。傳統 SMA（簡單移動平均）對每一天的收盤價一視同仁，VWMA 則讓成交量大的日子權重更高、成交量小的日子權重更低。

### 計算公式

```
VWMA = Σ(Close_i × Volume_i) / Σ(Volume_i)
```

其中 i 從 1 到 N（N 為週期天數）。

對比 SMA：

```
SMA = Σ(Close_i) / N
```

SMA 每天權重都是 1/N，VWMA 每天的權重是 Volume_i / ΣVolume_i。

### 簡單例子

假設 5 天收盤價分別為 100, 102, 101, 105, 103，成交量分別為 1000, 500, 800, 3000, 1200：

- **SMA** = (100+102+101+105+103) / 5 = 102.2
- **VWMA** = (100×1000 + 102×500 + 101×800 + 105×3000 + 103×1200) / (1000+500+800+3000+1200) = (100000+51000+80800+315000+123600) / 6500 = 670400 / 6500 ≈ 103.14

第 4 天成交量 3000 是最大的，收盤 105 也是最高的。VWMA 被這一天拉高到 103.14，比 SMA 的 102.2 更貼近「大資金認同的價格」。

## VWMA vs SMA vs EMA vs VWAP

### 與 SMA 的差異
SMA 忽略成交量資訊，VWMA 把量價合一。在量價背離時（價漲量縮），VWMA 會比 SMA 更早反映上漲力道不足。

### 與 EMA 的差異
EMA 對近期價格加權，VWMA 對大量成交的日子加權。EMA 關心「最近」，VWMA 關心「大資金」。兩者加權邏輯完全不同：EMA 永遠偏重最近幾天，VWMA 偏重任何一天只要量大就說話大聲。

### 與 VWAP 的差異
- **VWAP**（Volume-Weighted Average Price）只計算當日，每個交易日從零開始累加，是日內指標
- **VWMA** 是跨日滾動的，跟 SMA 一樣有週期 N，是日線指標

## 實戰用法

### 1. 趨勢確認——VWMA 與 SMA 的發散

當 VWMA 在 SMA 上方，代表大量成交的日子偏向高價區，市場共識偏多。當 VWMA 在 SMA 下方，代表大量成交的日子偏向低價區，市場共識偏空。

**VWMA 上穿 SMA** = 近期大量買盤推升價格，趨勢轉多訊號
**VWMA 下穿 SMA** = 近期大量賣盤壓低價格，趨勢轉空訊號

這比單純看 SMA 交叉更可靠，因為 VWMA/SMA 發散本質上是量價關係的量化表達。

### 2. 支撐壓力判讀

VWMA 本身就是一條「大資金成本線」。當股價回測 VWMA 時，等於回到大資金的平均進場成本，容易形成支撐。反之突破 VWMA 站穩，代表新的大資金認同更高價位。

### 3. 突破確認濾網

價格突破前高但 VWMA 沒有同步上升 → 突破缺乏大量支撐，假突破機率高。

價格突破前高且 VWMA 同步上升甚至上穿 SMA → 大資金參與的突破，可信度高。

> 相關頁面：[[技術分析/真突破確認三原則帶量收盤3天|真突破確認三原則]]、[[技術分析/成交量確認原則Volume-Confirmation|成交量確認原則]]

### 4. 背離判讀

- **價格創新高但 VWMA 沒有創新高**：上漲缺乏大量支撐，量價背離，可能是假突破
- **價格創新低但 VWMA 沒有創新低**：下跌缺乏大量拋壓，可能是底部訊號

## 參數選擇

### 週期 N 的選擇
- **短線（5-10 日）**：反應靈敏但噪音多，適合日內或極短線
- **中線（20-30 日）**：最常用，配合月線節奏
- **長線（50-60 日）**：趨勢確認用，反應慢但假訊號少

### 推薦組合
- **VWMA(20) + SMA(20)**：觀察兩者發散程度判斷量價健康度
- **VWMA(20) + VWMA(50)**：短期與長期大資金成本交叉
- **VWMA(20) + EMA(20)**：同時追蹤「大資金方向」和「近期趨勢方向」

## 台股實戰注意事項

### 1. 法人交易日量價更真實
台股三大法人佔成交比重 30-40%，法人大量買超的日子往往是趨勢起漲點。VWMA 在台股的量價訊號比美股更有效，因為法人行為更有規律性。

> 相關頁面：[[籌碼面分析/三大法人操作慣性|三大法人操作慣性]]

### 2. 除權息日要調整
除權息日股價跳空下跌但成交量可能不小，會扭曲 VWMA。建議用還原股價計算，或手動排除除權息日的數據。

### 3. 漲跌停鎖死日的特殊處理
漲停鎖死當天成交量極小但價格大漲，VWMA 權重反而降低。這會讓 VWMA 反應不及，需搭配 VWAP 和分時圖觀察。

> 相關頁面：[[操作策略/台股交易制度與漲跌幅限制|台股交易制度與漲跌幅限制]]

### 4. 與融資餘額交叉判讀
VWMA 上升但融資餘額也暴增 → 大量是散戶追價而非法人進場，訊號可信度降低。

> 相關頁面：[[籌碼面分析/大盤融資餘額判讀|大盤融資餘額判讀]]

## 策略組合建議

### VWMA 多頭確認策略
1. 價格站上 VWMA(20)
2. VWMA(20) 上穿 SMA(20)
3. 成交量 5 日均量 > 20 日均量（[[技術分析/量先價行原則|量先價行]]確認）
4. 進場，停損設 VWMA(20) 下方 1 ATR

### VWMA 突破過濾策略
1. 價格突破 20 日新高
2. 確認 VWMA(20) 同步創新高
3. VWMA(20) 在 SMA(20) 上方
4. 三條件滿足才進場，勝率顯著高於單純突破

## VWMA 的局限

### 1. 仍然有落後性
VWMA 本質還是移動平均，N 天的數據要 N 天才能完全替換。突發事件後 VWMA 反應比價格慢。

### 2. 盤整市無效
跟所有均線一樣，VWMA 在盤整市會反覆交叉產生假訊號。需搭配 ADX 或 [[技術分析/斬波指標Choppiness-Index|斬波指標 CHOP]] 過濾。

### 3. 成交量數據品質
台股盤後撮合、鉅額交易等特殊成交方式的量可能被納入或不被納入，不同資料源的成交量定義不完全一致，影響 VWMA 計算。
