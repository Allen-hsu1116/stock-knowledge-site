# 愛爾德溫度計 Elder's Thermometer

> Alexander Elder 設計的市場溫度計，用前一期與當期高低點的最大絕對差值衡量市場波動的「熱度」——溫度計越高代表市場越躁動，越低代表越平靜，是動態停損與部位控制的輔助工具。

## 核心概念

**Elder's Thermometer**（簡稱 THER）是 Alexander Elder 在《Trading for a Living》中提出的波動率衡量工具。跟 [[ATR平均真實波幅-Average-True-Range|ATR]] 類似，它衡量的是市場的波動程度，但計算方式更簡潔——只取前後期高低點的突破幅度，不看真實波動的完整範圍。

### 設計理念

Elder 把市場比擬為一鍋水：
- 溫度計讀數高 = 水在沸騰 = 市場波動劇烈
- 溫度計讀數低 = 水很平靜 = 市場波動微小

當市場溫度計從低檔開始攀升，代表「水正在加熱」，可能即將出現趨勢性行情；當溫度計從高檔回落，代表「火正在熄滅」，趨勢可能進入尾聲或盤整。

### 與其他波動率指標的差異

- **ATR**（[[ATR平均真實波幅-Average-True-Range]]）：用 True Range（當日高低+前日收盤的差距），考量跳空缺口
- **布林通道**（[[布林通道Bollinger-Bands三軌八型態]]）：用標準差衡量波動，有上下軌可視化通道
- **Elder's Thermometer**：只看高低點突破，計算最簡單，反應最快但容易受單根異常K線影響

## 計算公式

### 逐步計算

**Step 1：計算下方溫度（下突破幅度）**

$$Down_i = |Low_{i-1} - Low_i|$$

前一期的低點減去當期低點的絕對值。如果當期低點比前一期低點更低，這個值就是下突破的幅度。

**Step 2：計算上方溫度（上突破幅度）**

$$Up_i = |High_i - High_{i-1}|$$

當期高點減去前一期高點的絕對值。如果當期高點比前一期高點更高，這個值就是上突破的幅度。

**Step 3：計算溫度計讀數**

$$THER_i = \max(Down_i, Up_i)$$

取兩者的最大值——不管是往上突破還是往下突破，只要突破幅度大就是溫度高。

### 計算範例

假設三天的數據：

- **Day 1**：High=105, Low=98
- **Day 2**：High=108, Low=100
  - Down = |98-100| = 2
  - Up = |108-105| = 3
  - THER = max(2, 3) = **3**
- **Day 3**：High=110, Low=95
  - Down = |100-95| = 5
  - Up = |110-108| = 2
  - THER = max(5, 2) = **5**

Day 3 溫度計讀數從 3 跳到 5，代表市場波動明顯加劇——可能是趨勢啟動或重大消息衝擊。

### 信號線

實務上通常搭配一條 THER 的 EMA 作為信號線：

$$Signal = EMA(N, THER)$$

預設 N=13（與 Elder 其他指標如 [[Elder-Ray牛熊力量指標|Elder-Ray]] 和 [[Force-Index力量指標|Force Index]] 的參數一致）。

## 與 Elder 交易系統的整合

Elder 的完整交易系統包含多個互相搭配的指標：

- **[[Elder-Ray牛熊力量指標|Elder-Ray]]**：Bull Power + Bear Power 看多空力量
- **[[Force-Index力量指標|Force Index]]**：量價結合看趨勢力道
- **[[Elder-Impulse-System艾爾德衝擊系統|Elder Impulse System]]**：EMA + MACD 柱狀圖三色K棒
- **[[Elder-2%與6%雙重法則|Elder 2%與6%法則]]**：資金管理鐵律
- **Elder's Thermometer**：波動率溫度計，輔助停損與部位控制

溫度計在這個系統中的角色是「環境感測器」——告訴你現在市場是平靜還是躁動，藉此決定停損距離和部位大小。當溫度計讀數高，代表市場風險升高，應該縮小部位；讀數低，可以適度放大部位。

## 優缺點

**優點：**
- 計算極簡，只需要高低點數據
- 反應速度快，比 ATR 更早感知波動變化
- 直覺易懂，「溫度」比喻容易理解
- 與 Elder 其他指標系統無縫整合

**缺點：**
- 只看高低點不看收盤價，遺漏了日內價格行為的細節
- 容易被單根異常K線（如跳空缺口）扭曲
- 沒有方向性，只知道波動大小不知道往哪走
- 參數選擇缺乏學術驗證，過度依賴經驗值
- 台股適用性需考量除權息和漲跌停制度的特殊影響

## 總結

Elder's Thermometer 是一個輕量級的波動率感測器——不複雜但好用。它最大的價值不在於單獨使用，而在於與 Elder 的其他指標組合形成完整的交易系統：用 Elder-Ray 看多空力量、用 Force Index 看趨勢力道、用 Impulse System 看進出場時機、用 Thermometer 感測市場溫度調整停損和部位。如果你已經在用 Elder 的交易框架，溫度計是缺的那一塊拼圖。

## 實戰應用

### 四大判讀模式

**模式 1：溫度計從低檔攀升 → 趨勢啟動訊號**

溫度計長期在低檔（市場平靜），突然開始拉升且突破信號線，代表資金開始進場、波動擴大，可能是盤整即將結束、趨勢即將啟動。

- 操作：搭配 [[Elder-Impulse-System艾爾德衝擊系統|Elder Impulse System]] 或 [[ADX趨勢強度過濾盤整|ADX]] 確認趨勢方向
- 買進因子（Buy Factor）：當 THER 突破信號線且價格站上均線，視為加熱啟動

**模式 2：溫度計在高檔 → 波動劇烈但趨勢可能衰竭**

溫度計持續在高檔代表市場極度躁動，通常是趨勢中段或末端的特徵。如果溫度計開始從高檔回落但價格還在創新高，要警覺可能是 [[背離Divergence進階實戰|背離]] 訊號。

- 操作：收緊 [[移動停利停損Trailing-Stop|移動停損]]，保護已有利潤

**模式 3：溫度計從高檔驟降 → 趨勢結束警訊**

溫度計從極高檔快速回落到低檔，代表「火熄了」——推動價格的能量消退，趨勢可能即將反轉或轉入盤整。

- 操作：考慮獲利了結或減碼，等待下一波溫度計再次攀升

**模式 4：溫度計長期低檔 → 盤整中等待**

溫度計持續在低檔代表市場在睡覺，這時候用趨勢追蹤策略必定被洗來洗去。

- 操作：切換到 [[盤整市綜合操作策略Consolidation-Market-Strategy|盤整市策略]] 或空手等待，直到溫度計開始攀升

### 動態停損應用

Elder 建議用溫度計的讀數來動態調整停損距離：

- **溫度高 → 停損放寬**：市場波動大，停損太近容易被掃
- **溫度低 → 停損收緊**：市場波動小，停損可以設近一點

這跟 [[Chandelier-Exit吊燈出場指標|Chandelier Exit]] 用 ATR 動態調整停損的邏輯一樣，但 Elder's Thermometer 的計算更簡單、反應更快。

實務公式：

$$Stop = Price - (THER \times Multiplier)$$

Multiplier 通常設 2~3 倍，跟 ATR 停損的倍數概念一致。

## 注意事項

- **除權息缺口**：台股除權息日會產生人為的價格跳空，溫度計會突然飆高但不是真正的波動增加，需要扣除除權息因素後再判讀
- **漲跌停鎖死**：當個股漲停或跌停鎖死，高低點被壓縮，溫度計讀數可能偏低而非偏高，這與直覺相反需特別注意
- **配合量能**：溫度計攀升如果伴隨 [[量先價行進階實戰|量能擴增]]，趨勢啟動的可靠性更高；如果溫度計攀升但量能萎縮，可能是假突破
- **多時間框架**：日線溫度計與週線溫度計方向一致時，訊號可靠性更高（參考 [[多時間框架分析|多時間框架分析]]）
