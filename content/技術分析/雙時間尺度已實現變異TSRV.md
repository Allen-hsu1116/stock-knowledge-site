# 雙時間尺度已實現變異TSRV

> TSRV用交錯慢網格的平均RV，減掉由快網格估出的雜訊偏誤；不是兩條波動率隨便平均，也不是會自動排除跳躍的萬能風控指標。

## 核心概念

### 1. 估計對象與假設

Two-Scales Realized Volatility由Zhang、Mykland與Aït-Sahalia在2005年JASA論文提出。名稱雖有volatility，本文公式估的是**積分變異** $IV=\int_0^T\sigma_t^2dt$；若要波動率尺度，須在估計值適合開根號時再轉換。

基礎設定為 $Y_{t_i}=X_{t_i}+\epsilon_i$：有效對數價格 $X$ 是連續Itô過程；价格層級雜訊獨立同分布、均值零，並與 $X$ 獨立，且滿足論文的矩條件及取樣正則條件。這些不是寫完公式就自動成立的市場事實。

原理是普通全資料RV含約 $2n\eta^2$ 的雜訊偏誤；稀疏子網格減少每格雜訊累積，再用快速網格估出應扣除的部分。

### 2. 網格與計數：n是報酬數，不是價格數

觀察價格為 $Y_0,\ldots,Y_n$，共有 $n+1$ 個點、$n$ 個單期報酬。選擇整數 $K$，以 $j=0,\ldots,K-1$ 定義交錯網格：

$$
G_j=\{j,j+K,j+2K,\ldots\}\cap\{0,\ldots,n\}.
$$

每個網格的報酬數 $n_j=\lfloor(n-j)/K\rfloor$；本頁使用 $2\le K\le n$。各網格不強行補上共同端點，其平均報酬數為：

$$
\bar n=\frac{1}{K}\sum_{j=0}^{K-1}n_j=\frac{n-K+1}{K}.
$$

注意 $K$ 同時是「交錯網格數」與「在原始索引上跨幾個點取價」；在逐筆不等間隔資料上，跨 $K$ 筆不代表固定跨幾秒。必須說明使用交易時間還是日曆時間網格。

### 3. 快網格、慢網格平均與偏誤扣除

全資料估計：

$$
RV_{all}=\sum_{i=1}^{n}(Y_i-Y_{i-1})^2.
$$

慢網格平均：

$$
RV_{avg}=\frac{1}{K}\sum_{j=0}^{K-1}\sum_{m=1}^{n_j}(Y_{j+mK}-Y_{j+(m-1)K})^2
=\frac{1}{K}\sum_{i=K}^{n}(Y_i-Y_{i-K})^2.
$$

**除的是網格數 $K$，不是所有慢報酬總數。** 右式使用重疊的跨K期報酬，是左式的等價計算，不是額外加入一套獨立樣本。

基礎TSRV為：

$$
\widehat{IV}_{TSRV}=RV_{avg}-\frac{\bar n}{n}RV_{all}.
$$

原論文亦提供小樣本調整：

$$
\widehat{IV}_{adj}=\frac{RV_{avg}-(\bar n/n)RV_{all}}{1-\bar n/n}.
$$

直覺上，$RV_{avg}$ 的雜訊期望為 $2\bar n\eta^2$，而縮放後的 $RV_{all}$ 恰好扣掉同樣的量。但快網格RV還含有效價格變化，扣除時也會扣到訊號；分母調整用來處理這部分的一阶縮減。

**不能因此宣稱任意有限樣本精確無偏。** 各子網格未完整覆蓋相同端點，還有離散取樣與價格過程差異。論文的小樣本調整與漸近一致性，不等於小樣本、任何路徑都能精確還原IV。

### 4. K的選擇不是任意越大越好

原論文在其條件下用 $K$ 與 $n^{2/3}$ 同階，得到估計誤差 $n^{-1/6}$ 的收斂階數。這是大樣本平衡雜訊與離散誤差的理論，不是固定令 $K=n^{2/3}$ 就完成實戰調參。

K過小可能扣除不穩、調整分母過敏；K過大則每個網格剩很少報酬、端點遺失占比增加。比例常數仍取決於雜訊與波動特性；應採預先定義的候選K、敏感度分析與樣本外驗證。

## 實戰應用

### 1. 可重算教學案例：估出負數不代表市場負風險

以下為假設的「對數價格偏移，以基點為單位」：

```text
Y = [0, 1, 0, 2, 1, 3, 2]
n = 6，K = 2
G0價格 = [0, 0, 1, 2]，3個報酬
G1價格 = [1, 2, 3]，2個報酬
```

Python驗算結果，以下變異均為平方基點：

- 全資料 $RV_{all}=12$。
- 兩個慢網格RV各為2，因此 $RV_{avg}=2$，不是把所有報酬平方取平均。
- $\bar n=2.5$，$\bar n/n=5/12$。
- 基礎TSRV為 $2-(5/12)\times12=-3$。
- 小樣本調整為 $-3/(1-5/12)=-36/7$，約為−5.142857。

這個案例展示有限樣本下差分估計器可能為負，**不表示有效價格變異真的小於零**。不能直接開根號，也不能偷偷取絕對值再說風險很準；若系統為了計算而截為零，必須保留原值與截斷標記，觸發資料／模型品質檢查，禁止因此把部位放到最大。

單位也要守住：平方基點轉成小數對數報酬的平方，乘 $10^{-8}$；例如12平方基點等於 $0.00000012$。

### 2. 端點反例：調整過不等於有限樣本無偏

另一個純教學離散模型：六個有效價格增量各自獨立，以相同機率取正負一基點，不加觀察雜訊；列舉所有64條增量路徑，仍取 $n=6,K=2$。

- 全資料RV期望為6平方基點。
- 慢網格平均RV期望為5平方基點，因為平均涵蓋時間較短。
- 基礎TSRV期望為2.5平方基點。
- 原論文形式的小樣本調整後期望為 $30/7$，約4.285714平方基點，仍不是6。

這不是反駁TSRV的大樣本結果，而是提醒有限網格與端點不可忽略。離散模型只用來檢查代數與計數，不冒充連續時間漸近定理的數值重現。

此外，固定前例的有效價格路徑，列舉128種獨立正負一基點的價格雜訊組合，驗證全RV與平均RV的雜訊期望分別增加 $2n\eta^2$、$2\bar n\eta^2$，在TSRV相减時精確抵銷。**雜訊偏誤抵銷**與**完整IV有限樣本無偏**是兩件事。

### 3. 實作骨幹

```python
def tsrv(log_prices, k):
    n = len(log_prices) - 1
    if not 2 <= k <= n:
        raise ValueError("Require 2 <= K <= n")
    fast = sum((log_prices[i] - log_prices[i-1])**2
               for i in range(1, n+1))
    slow = sum((log_prices[i] - log_prices[i-k])**2
               for i in range(k, n+1)) / k
    nbar = (n-k+1) / k
    coefficient = nbar / n
    raw = slow - coefficient * fast
    return raw, raw / (1-coefficient)
```

此骨幹假設輸入已是清理後、有限數值、口徑一致的對數價格，沒有加入讀檔、時間戳檢核、異常處理或自動選K，不可直接當成生產級交易模組。研究程序應同時輸出原始RV、慢網格RV、K、平均報酬數、端點涵蓋率與負值旗標。

### 4. 怎麼用在股票研究

- 先畫取樣特徵圖，確認普通RV有沒有明顯頻率敏感度，再檢驗TSRV在不同K下是否改善穩定性。
- 流動性不同的股票不可共用未驗證的K與雜訊假設；零報酬、陳舊報價與跳動單位會影響估計。
- 用事前可得資料估計下一期部位尺度，並搭配既定最大部位、流動性與損失限制；事後IV不是未來IV。
- 只有日K、單日OHLC或即時快照時，不足以建立可信的TSRV；不要拿缺資料當理由捏造盤中價格。

## 注意事項

- **雜訊穩健不等於跳躍穩健**：基本推導針對連續有效價格；存在跳躍時，不能把輸出一律解釋為排除跳躍的連續IV，本文未實作跳躍擴充。
- **不要把TSRV直接塞進BPV差額**：不同估計器、取樣及端點口徑要先建立相容理論，不能宣稱TSRV減BPV就是無雜訊跳躍量。
- **相關雜訊會破壞簡單抵銷**：高頻市場的雜訊可能序列相關、內生或異質變異，基本iid版本不是通吃。
- **K=1退化**：快慢尺度相同，分母變零；實作必須拒絕，不回傳貌似正常的數字。
- **負值與小樣本**：差分估計可為負，截斷改變統計性質；小樣本調整也不保證每筆樣本更準。
- **不是台股績效證據**：本次只有定義學習、36項教學驗算與有限列舉，未抓台股逐筆資料、未執行獲利回測或完整論文模擬。
