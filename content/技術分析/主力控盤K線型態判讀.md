# 主力控盤K線型態判讀

> 主力控盤的K線型態是散戶最容易忽略的市場暗語——看懂主力在K線上留下的足跡，就能提前判斷拉升或出貨。

## 核心概念

### 什麼是主力控盤K線

主力控盤K線是指股市主力（大戶、法人、主力作手）在操作一檔股票時，刻意在K線圖上留下的特定型態。這些型態反映了主力的意圖：是在吸籌、洗盤、拉升還是出貨。

**主力為什麼會在K線上留下型態**：
- 主力資金量大，進出一定會影響K線
- 主力有時刻意做出某些型態來誘導散戶（騙線）
- 主力有時無法完全隱藏意圖，量價關係會暴露其行蹤
- 控盤程度越高，K線型態越規律越明顯

### 主力控盤的四大階段與K線特徵

| 階段 | 主力意圖 | K線特徵 | 量能特徵 |
|------|---------|--------|---------|
| 吸籌 | 低調收集籌碼 | 小紅小黑交替，底部不易看見 | 量縮，偶爾帶量紅K |
| 洗盤 | 震出浮額提高控盤度 | 長下影線、假跌破、急殺後急拉 | 洗盤帶量、收紅量增 |
| 拉升 | 快速拉抬脫離成本區 | 連續長紅、跳空缺口、帶量突破 | 量增明顯、攻擊量 |
| 出貨 | 逐步出脫籌碼 | 長上影線、高檔震盪、利好不漲 | 高檔爆量、量價背離 |

## 九大主力控盤K線型態

### 一、主力試盤K線

**型態特徵**：
- 主力在進場前先小量試探上檔賣壓
- K線出現帶上影線的小紅K或十字線
- 量能不明顯放大

**判讀要點**：
- 試盤後若賣壓輕（上影線短），主力可能隨後拉升
- 試盤後若賣壓重（上影線長），主力可能繼續洗盤
- 試盤出現在底部或長期盤整後最具參考價值

**實戰操作**：
- 試盤後1-3天觀察是否帶量長紅突破
- 若突破試盤K線高點，可跟進
- 停損設在試盤K線低點

### 二、主力洗盤長下影線

**型態特徵**：
- 早盤或盤中急殺，尾盤急拉
- K線留長下影線（至少實體2倍以上）
- 量能較前日略增或持穩

**判讀要點**：
- 洗盤長下影線與一般下影線的區別：洗盤下影線出現在底部或上升趨勢中，且第二天往往續漲
- 真正的支撐型下影線：尾盤拉升帶量，隔日開高
- 出貨型下影線：尾盤拉升量縮，隔日開低（主力趁反彈出貨）

**洗盤 vs 出貨關鍵差異**：

| 特徵 | 洗盤下影線 | 出貨下影線 |
|------|----------|----------|
| 位置 | 底部或上升趨勢 | 高檔或下降趨勢 |
| 隔日開盤 | 開高 | 開低 |
| 量能 | 尾盤帶量拉升 | 尾盤量縮拉抬 |
| 後續走勢 | 續漲 | 續跌 |

### 三、主力鎖碼量縮紅K

**型態特徵**：
- 連續小紅K或帶量紅K後量縮收紅
- 量能明顯縮小（低於5日均量）
- 價格卻持續上漲或橫盤不跌

**判讀要點**：
- 量縮不上漲是正常整理（主力休息）
- 量縮卻上漲或橫盤不跌=主力鎖碼，浮額已被洗乾淨
- 這是觀察主力是否還在的最佳訊號之一

**實戰操作**：
- 量縮紅K出現在拉升初期或中期 → 持股續抱
- 量縮紅K出現在高位且連續多日 → 注意主力是否開始出貨（量增長黑確認出貨）

### 四、主力做線：假突破假跌破

**型態特徵**：
- **假突破**：帶量突破壓力後，隔日或數日內回到壓力之下
- **假跌破**：帶量跌破支撐後，隔日或數日內回到支撐之上

**主力做線動機**：
- 假突破：引誘散戶追多，然後殺多
- 假跌破：引誘散戶停損或融券放空，然後拉軋空

**判讀要點**：
- 假突破：突破當天量能若不足（低於5日均量1.5倍），大概率是假突破
- 假跌破：跌破當天量能若過大（超過5日均量2倍以上且有長下影線），大概率是假跌破
- 真突破/跌破需收盤確認：連續3天站上壓力/跌破支撐才算確認

### 五、主力對倒K線

**型態特徵**：
- 突然出現帶量長紅K（或長黑K），但隔日立即回跌（或回漲）
- 量能暴增但價格無持續性

**主力對倒手法**：
- 主力左手賣右手買，製造大量交易假象
- 目的：吸引市場注意、誘導散戶跟進或恐慌
- 對倒K線後的走勢才是真正的意圖

**判讀要點**：
- 對倒長紅K後若量縮回跌 → 主力誘多，不要追
- 對倒長黑K後若量縮反彈 → 主力誘空，不要殺
- 看對倒後2-3天的走勢才能判斷主力真正意圖

### 六、主力護盤K線

**型態特徵**：
- 大盤重跌時個股跌幅極小或收紅
- K線留下長下影線或小實體紅K
- 量能未明顯放大

**判讀要點**：
- 護盤K線代表主力有強烈意願不讓股價跌
- 若連續2-3天出現護盤K線 → 主力成本區就在附近
- 護盤失敗（最終跌破護盤K線低點） → 恐慌性下跌

**實戰操作**：
- 護盤K線低點設停損
- 大盤止穩後護盤股率先反彈機率高
- 護盤失敗要果斷出場

### 七、主力出貨K線型態

**四大出貨K線**：

1. **長上影線**：高檔出現帶量長上影線，主力趁拉高出貨
2. **高檔爆量長黑**：大量長黑K線確認反轉
3. **利好不漲**：公司公布利多但股價開高走低，主力趁利多出貨
4. **連續量增價跌**：量增但價格持續下跌，主力持續出脫籌碼

**出貨K線辨識三原則**：
- 位置在高檔：股價已大漲一段時間
- 量能放大：主力大量出脫
- 後續走弱：出貨K線後價格持續下跌

### 八、主力誘多誘空型態

**誘多型態**（騙散戶追多）：
- 突破前高後隔日長黑跌破（假突破）
- 開高走低的帶量長黑（利好出盡）
- 連續小紅後突然一根長黑（誘多殺多）

**誘空型態**（騙散戶殺低或放空）：
- 跌破前低後隔日長紅站回（假跌破）
- 開低走高的帶量長紅（利空不跌）
- 連續小黑後突然一根長紅（誘空軋空）

### 九、主力養套殺K線型態

**完整型態（養套殺三階段）**：

**養（餵養階段）**：
- 底部盤整期間小紅K增多
- 偶爾帶量長紅拉升吸引目光
- 量能溫和放大，不過度急躁

**套（套牢階段）**：
- 高位出現帶量長紅（最後一根誘多K線）
- 隨後出現帶上影線的K線或高開低走
- 散戶以為是回檔買點，實際是被套

**殺（殺盤階段）**：
- 跌破養階段的支撐線
- 帶量長黑K確認出貨
- 量增價跌，主力大量出脫

## 實戰應用

### 主力控盤K線選股

**多方控盤股篩選條件**：
1. 底部連續小紅K（3根以上）
2. 突然帶量長紅突破（量能>5日均量1.5倍）
3. 隔日量縮不跌（主力鎖碼確認）
4. 5MA向上，10MA持平或即將轉向
5. 三大法人買超或主力買超

### 主力控盤K線搭配籌碼

**最有力的確認組合**：
- 主力吸籌K線 + 主力連續買超 → 即將拉升
- 量縮紅K + 千張大戶持股增加 → 主力鎖碼中
- 高檔爆量 + 主力買賣超由正轉負 → 主力出貨

### 多時間框架確認

主力控盤K線在不同時間框架的意義：
- **日線主力控盤K線**：影響1-5天走勢
- **週線主力控盤K線**：影響2-8週走勢
- **月線主力控盤K線**：影響1-6個月走勢

日線控盤K線配合週線方向，勝率最高。

## 注意事項

1. **主力控盤K線不是萬能的**：主力也會失敗，控盤K線只能提高勝率不能保證方向

2. **辨識主力控盤vs自然走勢**：小型股更容易出現主力控盤型態，大型權值股K線型態更多是市場共識而非單一主力

3. **量能是主力控盤K線的靈魂**：沒有量能配合的K線型態，不論多漂亮都可能是隨機走勢

4. **騙線是主力的生存之道**：主力有時會刻意做出型態誘導散戶。辨識騙線的最佳方法是等待2-3天的確認

5. **不要單獨看一根K線**：主力控盤K線必須結合位置（底部/高檔）、量能、均線、籌碼等多重確認

6. **不同股票的主力手法不同**：每個主力有自己的操作習慣，熟悉特定股票的主力的手法比學型態更重要

7. **停損是保命符**：主力控盤K線判斷錯誤時，果斷停損。主力比你資金多，你不可能跟主力硬拚
