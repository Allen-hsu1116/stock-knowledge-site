# 開盤集合競價與試撮判讀

> 開盤前8:30的試撮是主力免費的心理戰場，看懂它你比別人多15分鐘的準備時間。

## 核心概念

台股每日開盤前有8:30-9:00的集合競價時段，證交所每5秒揭露一次模擬開盤價（試撮），讓市場參與者預估開盤走势。這是盤前最重要的情報來源。

**試撮流程**：
- **08:30**：開始接受委託，每5秒揭露一次模擬價格
- **08:30-09:00**：持續撮合，價格逐步收斂
- **09:00**：正式開盤，第一次成交價即開盤價

**試撮價格的意義**：
- 試撮價格是所有委託單撮合後的「模擬開盤價」
- 試撮量是模擬開盤時的成交張數
- 委買委賣掛單量可以觀察多空力道

**試撮三大功能**：
1. **預判開盤方向**：試撮價高於昨收→偏多，低於昨收→偏空
2. **觀察主力動向**：大單掛在買方或賣方暴露主力意圖
3. **辨識假撮手法**：主力常用假掛單製造假象

## 實戰應用

### 試撮判讀五步法

**步驟一：看開盤價方向**
- 試撮價>昨收+1%以上：多方強勢，開高機率高
- 試撮價在昨收±0.5%之間：中性開盤，看盤中走勢
- 試撮價<昨收-1%以下：空方強勢，開低機率高

**步驟二：看委買委賣量**
- 委買量遠大於委賣量（2:1以上）：多方控盤
- 委賣量遠大於委買量：空方控盤
- 委買委賣量接近：多空均衡，看盤中方向

**步驟三：看試撮量與昨日量比較**
- 試撮量>昨日成交量5%：開盤熱絡，注意是否為換手量
- 試撮量<昨日成交量1%：開盤冷清，方向不明確

**步驟四：觀察試撮價格變動趨勢**
- 試撮價格逐步抬高：多方力量增強
- 試撮價格逐步走低：空方力量增強
- 試撮價格劇烈跳動：多空交戰激烈

**步驟五：辨識假單與真單**（見下方假撮辨識）

### 假撮辨識手法

主力和大戶常利用試撮期間掛假單製造多空假象：

**手法一：虛掛買單不成交**
- 在買方掛大量委託營造多方氛圍
- 開盤前最後5秒撤單（8:59:55撤單）
- 開盤後買盤消失，股價反而下跌

**手法二：虛掛賣單壓制開盤價**
- 在賣方掛大量委託壓低試撮價
- 企圖讓散戶恐慌賣出
- 開盤後賣盤撤單，主力趁低接貨

**手法三：對倒製造熱絡假象**
- 同時掛買賣單製造大量試撮量
- 看似開盤熱絡但實際是自彈自唱
- 辨識：觀察券商分點是否為同一券商

**假撮辨識四大準則**：
1. **掛單時間**：早期掛的比接近9:00才掛的更可信（早期掛單撤單成本高）
2. **掛單價格**：貼近成交價的比遠離的有意義（離成交價5檔以上的掛單多半是假單）
3. **掛單量**：超大單（>1000張）突然出現又消失，多半是假撮
4. **連續性**：持續掛單比忽掛忽撤更可信

### 開盤後前5分鐘策略

**開高3種情境**：
- **帶量開高**（開盤量>預估量15%）：多方強勢，9:02後可追多
- **量縮開高**（開盤量<預估量5%）：多方虛假，容易開高走低
- **開高後跌破昨收**：多方力道不足，反手做空或觀望

**開低3種情境**：
- **帶量開低**（開盤量>預估量15%）：空方強勢，不急著抄底
- **量縮開低**（開盤量<預估量5%）：空方虛假，可能是洗盤
- **開低後迅速站回昨收**：空方力道不足，低接買盤介入

### 試撮與國際盤的搭配

**台股開盤前先看**：
1. 美股收盤漲跌（影響台股開盤方向）
2. 台指期夜盤收盤價（最直接反映市場情緒）
3. 日韓股開盤狀況（亞股連動）
4. 法人期貨未平倉（[[外資期貨未平倉判讀]]）

**試撮價與夜盤價的關係**：
- 試撮價>夜盤收盤價：偏多，開盤後可能續漲
- 試撮價<夜盤收盤價：偏空，開盤後可能續跌
- 兩者接近：震盪機率高

### 試撮量的估算與應用

**預估量計算**（見[[預估量計算與量價操盤術]]）：
- 開盤前5分鐘的試撮量×比率可粗估全天量
- 開盤後：前15分鐘成交量×8≈全天成交量

**試撮量異常的判讀**：
- 試撮量突然暴增（>前一日開盤量3倍）：可能有重大訊息或法人大量進出
- 試撮量極度萎縮（<前一日開盤量50%）：市場觀望氣氛濃

## 注意事項

1. **試撮不是承諾**：試撮價格和掛單都可以在開盤前隨時變更，不要把試撮當成確定的事實來交易

2. **假撮是合法的**：在台灣證券法規下，集合競價期間掛單後撤單是完全合法的行為，主力可以利用這個機制製造假象

3. **不要只看試撮**：試撮只反映盤前情緒，盤中走勢受更多因素影響。試撮偏多但開盤後15分鐘量能不繼→開高走低的風險很大

4. **大型股vs小型股的試撮差異**：
   - 大型股（台積電等）試撮量大且穩定，參考性高
   - 小型股試撮量小且波動大，容易被少數大單影響，參考性低
   - 處置股集合競價撮合延長（每20秒或5分鐘），試撮節奏不同

5. **漲跌停股票的試撮**：
   - 漲停試撮價掛在漲停價→多方極強
   - 跌停試撮價掛在跌停價→空方極強
   - 但漲跌停的試撮量可能包含大量假單

6. **除權息日的試撮**：
   - 除權息日參考價會自動調整
   - 試撮價與參考價的差距才是真正的多空判斷基準
   - 不要拿昨收直接比試撮價
