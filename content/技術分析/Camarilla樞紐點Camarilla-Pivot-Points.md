# Camarilla樞紐點 Camarilla Pivot Points

> 樞紐點的「高密度版本」——用昨日HLC計算出8個密集關卡，專為當沖日內交易設計，比傳統Pivot Point更貼近當日價格區間。

## 核心概念

Camarilla（西班牙文「小房間」）由Nick Stott在1989年開發，核心思想是：**價格傾向回歸當日均值，極端偏離會被拉回**。與傳統[[CDP三關價與Pivot-Point樞紐點|Pivot Point]]只算7條線不同，Camarilla算出8個支撐壓力關卡（H3/H4/H5 + L3/L4/L5），且關卡之間距離用乘數因子壓縮，讓日內交易者有更精確的進出場點位。

### 與傳統樞紐點的差異

- **傳統Pivot Point**：P = (H+L+C)/3，支撐壓力線等距分布，適合波段與日線
- **Camarilla**：不用P值，直接用範圍(H-L)乘以不同因子生成8個關卡，關卡由近到遠非等距，適合日內當沖
- **CDP三關價**：台股版樞紐點，5條線，計算簡單適合極短線

## 計算公式

### 基本變數

- H = 前一交易日最高價
- L = 前一交易日最低價
- C = 前一交易日收盤價
- Range = H - L

### Camarilla 關卡公式（經典版）

**壓力（Resistance）**：
- R3 = C + Range × 1.1 / 4
- R4 = C + Range × 1.1 / 2
- R5 = C + Range × 1.1

**支撐（Support）**：
- S3 = C - Range × 1.1 / 4
- S4 = C - Range × 1.1 / 2
- S5 = C - Range × 1.1

### 現代版（更精細）

- R1 = C + Range × 1.0833 / 12
- R2 = C + Range × 1.0833 / 6
- R3 = C + Range × 1.0833 / 4
- R4 = C + Range × 1.0833 / 2
- S1 = C - Range × 1.0833 / 12
- S2 = C - Range × 1.0833 / 6
- S3 = C - Range × 1.0833 / 4
- S4 = C - Range × 1.0833 / 2

**關鍵因子**：1.0833 = 1 + 1/12，源自Stott的經驗常數。

### 計算範例

假設台積電昨日 H=1085, L=1060, C=1080：

- Range = 1085 - 1060 = 25
- R3 = 1080 + 25 × 1.0833 / 4 = 1080 + 6.77 ≈ **1086.8**
- R4 = 1080 + 25 × 1.0833 / 2 = 1080 + 13.54 ≈ **1093.5**
- R5 = 1080 + 25 × 1.0833 = 1080 + 27.08 ≈ **1107.1**
- S3 = 1080 - 25 × 1.0833 / 4 = 1080 - 6.77 ≈ **1073.2**
- S4 = 1080 - 25 × 1.0833 / 2 = 1080 - 13.54 ≈ **1066.5**
- S5 = 1080 - 25 × 1.0833 = 1080 - 27.08 ≈ **1052.9**

## 實戰用法

### 1. R3/S3 — 日內核心交易區

R3和S3是Camarilla最常用的交易關卡：

**做多（S3反彈）**：
- 價格觸及S3後止跌反彈 → 買進
- 停損設S4下方
- 目標R3

**做空（R3回落）**：
- 價格觸及R3後受阻回落 → 賣出
- 停損設R4上方
- 目標S3

### 2. R4/S4 — 突破關卡

- 價格站穩R4上方 → 強勢突破，追多
- 價格跌破S4下方 → 強勢破位，追空
- R4/S4是Camarilla系統的「突破確認線」

### 3. R5/S5 — 極端關卡

- R5/S5極少被觸及，一旦觸及代表極端行情
- 觸及R5是日內嚴重超買，傾向反向做空
- 觸及S5是日內嚴重超賣，傾向反向做多
- 但在強趨勢日R5/S5可能被穿越且不回頭——需搭配[[ADX趨勢強度過濾盤整|ADX]]判斷趨勢強度

### 4. 區間內回歸策略

最常見的用法——價格在S3-R3之間震盪：
- 觸及R3附近做空，目標回到中間區域
- 觸及S3附近做多，目標回到中間區域
- 停損設R4/S4外側
- 本質是[[均值回歸策略|均值回歸]]的日內版本

## 台股實戰注意事項

### 優勢

- 台股有明確的昨日HLC（收盤價為13:30收盤），計算乾淨
- 8個關卡密度高，適合台股±10%漲跌幅限制下的日內波動
- 與[[開盤集合競價與試撮判讀|開盤試撮]]搭配——開盤位置在R3上方偏多，在S3下方偏空

### 限制

- **盤整失效**：窄幅盤整日Range太小，關卡距離過近容易被假突破洗出
- **跳空問題**：台股跳空開盤常見，跳空後Camarilla關卡的參考價值下降
- **趨勢日陷阱**：強趨勢日價格從S3直接殺到S5不回頭，均值回歸策略會連續虧損
- **不適合波段**：Camarilla是日內工具，持倉過夜邏輯不成立

### 與其他日內工具搭配

- **+ [[CDP三關價與Pivot-Point樞紐點|CDP三關價]]**：兩套系統交叉確認，CDP的AH/AL與Camarilla的R5/S5重合時支撐壓力最強
- **+ [[VWAP成交量加權均價|VWAP]]**：VWAP確認當日成本方向，Camarilla給精確點位
- **+ [[分時圖判讀與日內交易時機Intraday-Timing|分時圖]]**：Camarilla關卡在分時圖上的反應最清晰
- **+ [[ADX趨勢強度過濾盤整|ADX]]**：ADX>25時用突破策略（R4/S4），ADX<20時用回歸策略（R3/S3）
- **+ [[ATR平均真實波幅-Average-True-Range|ATR]]**：ATR動態調整停損距離

## Camarilla vs 其他樞紐點系統

- **傳統Pivot**：7條線等距分布，適合日線波段
- **Camarilla**：8條線非等距密集分布，專為當沖
- **Fibonacci Pivot**：用38.2%/61.8%比例，偏自然律但無實證優勢
- **Woodie Pivot**：加重收盤權重，適合趨勢市
- **CDP三關價**：台股本土版，5條線計算簡單

## 策略總結

**Camarilla不是預測工具而是框架工具**——它給你8個預設關卡，讓你在開盤前就有完整的日內作戰計畫。核心是：

1. **開盤前算好8個關卡**
2. **看開盤位置判多空基調**（R3上方=多，S3下方=空，中間=震盪）
3. **R3/S3做回歸，R4/S4做突破**
4. **停損永遠在R4/S4外側**
5. **搭配ADX區分趨勢日vs盤整日選策略**
