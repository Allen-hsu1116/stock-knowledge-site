# 分形自適應移動平均線 FRAMA

> 用分形維度當變速箱——趨勢市緊貼價格、盤整市紋絲不動

## 核心概念

FRAMA（Fractal Adaptive Moving Average，分形自適應移動平均線）是 John Ehlers 於 2005 年提出的自適應均線。核心想法是用**分形維度**（Fractal Dimension）動態調整均線的追蹤速度：

- 市場有明確趨勢時 → 分形維度低（接近 1）→ 均線加速，緊貼價格
- 市場盤整震盪時 → 分形維度高（接近 2）→ 均線減速，避免假訊號

這讓 FRAMA 成為同時具備**趨勢追蹤**和**盤整過濾**能力的單一指標。

### 分形維度 D 與 Hurst Exponent

分形維度 D 衡量價格序列的「粗糙度」，範圍在 1~2 之間：

- **D ≈ 1**：價格路徑平滑如直線 → 強趨勢
- **D ≈ 1.5**：隨機漫步 → 不確定
- **D ≈ 2**：價格充滿整個平面 → 高度盤整

D 與 [[技術分析/赫斯特指數Hurst-Exponent|Hurst Exponent]] 的關係：**D = 2 - H**

### 計算步驟

1. **選取窗口 N**（實戰推薦 16~32，需為偶數）
2. **計算三段價格範圍**：
   - N1 = 前 N/2 期的 (最高價 - 最低價)
   - N2 = 後 N/2 期的 (最高價 - 最低價)
   - N3 = 整個 N 期的 (最高價 - 最低價)
3. **計算分形維度**：
   - D = (log(N1 + N2) - log(N3)) / log(2)
   - 限制 D 在 [1, 2] 區間（超出則截斷）
4. **計算指數衰減因子 α**：
   - α = exp(-4.6 × (D - 1))
   - D = 1（趨勢）→ α = 1，完全跟隨價格
   - D = 2（盤整）→ α ≈ 0.01，幾乎不動
5. **計算 FRAMA**：
   - FRAMA = α × Close + (1 - α) × FRAMA_prev

### 與其他自適應均線比較

- **[[技術分析/考夫曼自適應移動平均線KAMA|KAMA]]**：用效率係數（ER = |ΔPrice| / Σ|ΔPrice|）調整，概念簡單但突發波動會被誤判
- **[[技術分析/赫爾移動平均線HMA-Hull-Moving-Average|HMA]]**：用 WMA 雙重平滑最小化延遲，但不自適應
- **[[技術分析/McGinley-Dynamic麥金利動態指標|McGinley Dynamic]]**：用 (Price/MD)⁴ 四次方調整，過度敏感

FRAMA 的數學基礎最扎實，但計算也最複雜。實戰中 KAMA 和 FRAMA 表現接近，KAMA 更常用。

## 實戰應用

### 趨勢確認

- 價格站上 FRAMA 且 FRAMA 上彎 → 趨勢偏多確認
- 價格跌破 FRAMA 且 FRAMA 下彎 → 趨勢偏空確認
- FRAMA 接近水平 → 盤整狀態，趨勢策略不適用

### 交叉策略

- **多頭訊號**：價格由下往上穿越 FRAMA
- **空頭訊號**：價格由上往下跌破 FRAMA
- **過濾盤整**：搭配 [[技術分析/ADX趨勢強度過濾盤整|ADX]] > 25 或 [[技術分析/斬波指標Choppiness-Index|CHOP]] < 38.2 確認非盤整

### 動態停損

FRAMA 本身可作為移動停損線：
- 趨勢明確時 FRAMA 緊貼價格，停損距離自動縮小，鎖住獲利
- 盤整時 FRAMA 幾乎不動，停損不會被假突破觸發，避免反覆停損

與 [[風險管理/移動停利停損Trailing-Stop|移動停利停損]] 搭配使用效果最佳。

### 多時間框架

- 日線 FRAMA 判斷中長期趨勢方向
- 60 分鐘 FRAMA 找進場點
- 15 分鐘 FRAMA 微調停損位置

## 注意事項

1. **窗口 N 的選擇**：N 太小（如 8）分形維度估計不穩定、N 太大（如 64）反應太慢。台股日線建議 N=16~32
2. **D 值邊界限制**：D 必須限制在 [1, 2]，否則 α 會出現負值或超過 1 導致 FRAMA 發散
3. **盤整陷阱**：FRAMA 在盤整時接近水平，但價格可能在 FRAMA 上下反覆穿越產生假訊號，必須搭配震盪指標
4. **起點依賴**：FRAMA 的初始值會影響前期數值，通常以第一期收盤價初始化，前 N 期的 FRAMA 數值不宜使用
5. **計算複雜度**：FRAMA 計算涉及 log 運算，在即時看盤系統中需確認軟體支援，多數主流看盤軟體（TradingView、XQ）已內建
6. **與 KAMA 的選擇**：如果只能選一個，KAMA 更簡單且社群支持更廣。FRAMA 適合對分形理論有興趣的進階使用者
