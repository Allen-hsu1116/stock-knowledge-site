# 卡爾曼濾波器：即時狀態估計的遞迴算法

> Rudolf E. Kálmán 1960 年提出的遞迴估計算法，從含噪聲的觀測序列中估計系統的真實狀態。從阿波羅登月到現代自駕車都有它的影子，在計量金融中用於動態估計隱含狀態、即時濾噪與配對交易。

## 核心概念

**你有一個系統的真實狀態看不到，只能透過含噪聲的觀測值去推估。卡爾曼濾波器用「預測+修正」的兩步循環，不斷逼近真實狀態。**

打個比方：你在開車，GPS 每秒告訴你位置，但 GPS 有誤差。同時你知道車速和方向（物理模型）。卡爾曼濾波器把「根據車速預測的位置」和「GPS 測量的位置」做加權平均，比單靠任一方都更準。

## 兩階段循環

### 預測階段（Predict）

根據系統動態模型預測下一時刻的狀態：

```
x̂_{k|k-1} = F × x̂_{k-1|k-1} + B × u_k
P_{k|k-1} = F × P_{k-1|k-1} × F' + Q
```

- **x̂**：狀態估計（如真實價格、趨勢）
- **F**：狀態轉移矩陣（描述狀態如何隨時間演化）
- **B**：控制輸入矩陣
- **u_k**：控制輸入（在金融中通常為 0）
- **P**：估計的協方差（不確定性）
- **Q**：過程噪聲協方差（系統本身的隨機性）

### 更新階段（Update）

收到新觀測值後修正預測：

```
K_k = P_{k|k-1} × H' × (H × P_{k|k-1} × H' + R)⁻¹
x̂_{k|k} = x̂_{k|k-1} + K_k × (z_k - H × x̂_{k|k-1})
P_{k|k} = (I - K_k × H) × P_{k|k-1}
```

- **K_k**：卡爾曼增益（決定預測和觀測各佔多少權重）
- **H**：觀測矩陣（將系統狀態映射到觀測空間）
- **z_k**：實際觀測值
- **R**：觀測噪聲協方差（測量誤差大小）

## 卡爾曼增益的直覺

**K_k 是整個濾波器的靈魂。**

- 當觀測很可靠（R 小）→ K 趨近 1 → 更相信觀測值
- 當模型預測很可靠（P 小、Q 小）→ K 趨近 0 → 更相信預測值
- K 永遠在 0 和 1 之間，自動平衡兩者

這就是加權平均——不確定性大的那方權重低，不確定性小的那方權重高。

## 金融市場中的應用

### 應用一：即時價格濾噪

**模型設定**：
- 狀態：真實價格（看不見）
- 觀測：市場成交價（含噪聲）
- F = 1（價格隨機漫步）
- H = 1（直接觀測價格）

卡爾曼濾波器會平滑掉極端的 tick 數據，估計出「真實價格」。比 SMA 更即時，比 EMA 更自適應。

### 應用二：動態 Beta 估計

傳統 Beta 用回歸計算，是固定值。但市場關係在變化。

**模型設定**：
- 狀態：動態 Beta
- 觀測：個股報酬 = Beta × 市場報酬 + 噪聲
- F = 1（Beta 有慣性，短期不變）

Beta 會隨時間平滑演化，比滾動回歸更即時又不會跳動太大。

### 應用三：配對交易的動態價差

配對交易假設兩檔股票有穩定關係，但價差均值可能緩慢漂移。

**模型設定**：
- 狀態：價差的真實均值（緩慢漂移）
- 觀測：當前價差
- F = 1（均值漂移很慢）

濾波器持續估計價差均值的最新位置，比固定回望窗口更靈活。

### 應用四：隱含波動率平滑

選擇權市場的隱含波動率跳動很大，需要平滑。

- 狀態：真實 IV
- 觀測：逐筆成交推算的 IV（跳動大）
- 卡爾曼濾波器平滑出 IV 趨勢線

### 應用五：動態均值回歸水平

均值回歸策略假設價格圍繞某個均值波動，但均值本身在移動。

- 狀態：動態均值
- 觀測：最新價格
- F = 1（均值緩慢移動）

## 非線性擴展

標準卡爾曼濾波器假設系統是線性的。金融市場往往非線性，需要擴展：

### 擴展卡爾曼濾波器（EKF）
- 將非線性函數在當前估計點做泰勒展開（線性化）
- 簡單但線性化誤差可能累積

### 無跡卡爾曼濾波器（UKF）
- 用 sigma 黈採樣傳播非線性函數
- 比EKF更準確但計算量更大

### 粒子濾波器（Particle Filter）
- 用蒙地卡羅採樣近似任意分佈
- 最靈活但最耗計算

## Python 實作範例

```python
import numpy as np

class KalmanFilter1D:
    def __init__(self, x0, P0, Q, R, F=1, H=1):
        self.x = x0      # 狀態估計
        self.P = P0      # 不確定性
        self.Q = Q        # 過程噪聲
        self.R = R        # 觀測噪聲
        self.F = F        # 狀態轉移
        self.H = H        # 觀測映射

    def predict(self):
        self.x = self.F * self.x
        self.P = self.F * self.P * self.F + self.Q

    def update(self, z):
        K = self.P / (self.P + self.R)  # 卡爾曼增益
        self.x = self.x + K * (z - self.H * self.x)
        self.P = (1 - K * self.H) * self.P

    def step(self, z):
        self.predict()
        self.update(z)
        return self.x

# 動態均線範例
kf = KalmanFilter1D(x0=100, P0=1, Q=0.01, R=0.1)
prices = [101, 102, 99, 103, 100, 105, ...]
smoothed = [kf.step(p) for p in prices]
```

## Q 與 R 的調參心法

- **Q 大 R 小**：相信觀測、反應快但可能跟噪聲
- **Q 小 R 大**：相信模型、平滑但反應慢
- **Q = R**：預測和觀測各半
- 金融數據通常 Q 設小、R 設中——市場有慣性但數據有噪聲

## 與其他濾波/平滑方法的比較

**vs SMA/EMA**：
- SMA：固定窗口、等權重、有延遲
- EMA：固定衰減、比 SMA 快但參數固定
- Kalman：自適應權重、無固定延遲、但需正確設定模型

**vs 貝葉斯濾波**：
- 卡爾曼濾波器就是高斯線性系統下的貝葉斯濾波
- 貝葉斯濾波更廣義但計算量大

**vs Hodrick-Prescott（HP）濾波**：
- HP 濾波是事後平滑（需要整段數據）
- 卡爾曼是即時遞迴（只需到當前為止）

## 實戰應用

**1. 定義系統模型**
- 確定要估計的狀態變量（如動態 Beta、隱含均值）
- 寫出狀態轉移方程和觀測方程

**2. 設定參數**
- Q（過程噪聲）：系統變化的不可預測性
- R（觀測噪聲）：測量數據的誤差大小
- 初始狀態 x̂_0 和初始協方差 P_0

**3. 遞迴運行**
- 每收到新數據點：預測 → 更新 → 輸出估計值
- 不需要存歷史數據，只需當前估計和新觀測

**4. 驗證與調參**
- 殘差（innovation）應該是白噪聲
- 如果殘差有自相關，說明模型設定有問題
- 調 Q 和 R 的比例來平衡靈敏度與穩定性
