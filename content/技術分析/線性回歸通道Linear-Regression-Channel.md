# Linear Regression Channel 線性回歸通道

> Linear Regression Channel（線性回歸通道）是將統計學中的「最小平方法線性回歸」直接應用到股價圖表上的通道型指標。它不同於 [[技術分析/布林通道Bollinger-Bands三軌八型態|布林通道]]（用標準差）或 [[技術分析/肯特納通道Keltner-Channel|肯特納通道]]（用 ATR），而是用迴歸線本身作為中軸、用回歸殘差的標準差作為上下軌。

## 核心概念

Linear Regression Channel（線性回歸通道）是將統計學中的「最小平方法線性回歸」直接應用到股價圖表上的通道型指標。它不同於 [[技術分析/布林通道Bollinger-Bands三軌八型態|布林通道]]（用標準差）或 [[技術分析/肯特納通道Keltner-Channel|肯特納通道]]（用 ATR），而是用迴歸線本身作為中軸、用回歸殘差的標準差作為上下軌。

核心概念：**在指定期間內，用最小平方法擬合一條最佳直線（回歸線），然後在上下各加減 2 倍標準差形成通道。** 回歸線代表價格的「統計趨勢」，通道邊界代表價格偏離趨勢的「正常範圍」。

**一句話理解**：線性回歸通道 = 用統計學的「最佳擬合線」畫趨勢中軸 + 上下 2 個標準差畫通道邊界。

## 計算公式

### 第一步：線性回歸線

對指定期間 N 內的價格數據（通常用收盤價），用最小平方法擬合：

**y = a + b × x**

其中：
- y = 預測價格
- x = 時間序號（1, 2, 3, ..., N）
- b = 斜率 = [N × Σ(xy) − Σx × Σy] / [N × Σ(x²) − (Σx)²]
- a = 截距 = (Σy − b × Σx) / N

回歸線斜率 b 代表價格的平均變化速率——b > 0 上升趨勢、b < 0 下降趨勢。

### 第二步：計算殘差標準差

對每個時間點 i，殘差 = 實際價格 − 回歸預測值

**殘差標準差 σ = √[Σ(殘差²) / (N − 2)]**

（除以 N−2 而非 N，因為回歸線用了斜率和截距兩個自由度）

### 第三步：通道邊界

- **上軌** = 回歸線 + k × σ（通常 k = 2）
- **中軌** = 回歸線本身
- **下軌** = 回歸線 − k × σ

k 值通常設為 2（涵蓋約 95% 的價格點）或 3（涵蓋約 99.7%）。

### 常見參數
- N = 20（短期，約一個月）
- N = 50（中期，約兩個半月）
- N = 100（長期）
- k = 2（標準通道）或 k = 3（寬通道）

## 與其他通道指標的比較

- **vs [[技術分析/布林通道Bollinger-Bands三軌八型態|布林通道]]**：布林通道中軸是 SMA（水平移動），線性回歸通道中軸是回歸線（有斜率）。布林通道在趨勢中會嚴重滯後，回歸通道更貼合趨勢
- **vs [[技術分析/肯特納通道Keltner-Channel|肯特納通道]]**：肯特納用 ATR 作為通道寬度，回歸通道用殘差標準差。肯特納對突發波動更敏感，回歸通道更穩定
- **vs [[技術分析/價格通道Price-Channel|價格通道]]**：價格通道用期間內最高/最低價作為上下軌，沒有中軸回歸線。價格通道是「極值通道」，回歸通道是「統計通道」
- **vs [[技術分析/唐奇安通道Donchian-Channel|唐奇安通道]]**：唐奇安通道也是極值通道概念，與回歸通道的統計基礎完全不同
- **vs [[技術分析/趨勢線與通道線|手畫趨勢線]]**：手畫趨勢線依賴主觀判斷選擇高低點，回歸通道用數學方法自動擬合，完全客觀

## 判讀方式

### 1. 回歸線斜率判斷趨勢
- **斜率明顯為正（b > 0）**：上升趨勢
- **斜率明顯為負（b < 0）**：下降趨勢
- **斜率接近 0**：盤整無趨勢
- 斜率的絕對值越大 → 趨勢越強

### 2. 價格與通道邊界的關係
- **價格在上軌附近**：短期偏強，可能超買
- **價格在下軌附近**：短期偏弱，可能超賣
- **價格在中軌附近**：符合統計趨勢
- **價格觸及或突破上/下軌**：偏離趨勢過大，注意回歸風險

### 3. 通道寬度判斷波動率
- **通道變寬**：殘差標準差增大，波動率上升
- **通道變窄**：殘差標準差減小，波動率下降
- 通道收窄後的突破 → 類似 [[技術分析/布林通道Bollinger-Bands三軌八型態|布林通道]] 的 squeeze 概念

### 4. R-squared（決定係數）判斷趨勢品質
- R² = 1 − (殘差平方和 / 總平方和)
- R² 接近 1 → 回歸線解釋力高，趨勢穩定
- R² 接近 0 → 回歸線解釋力低，價格散亂無趨勢
- R² > 0.7 → 強趨勢，通道訊號可靠
- R² < 0.3 → 弱趨勢或盤整，通道訊號失效

## 適用場景

- ✅ 穩定趨勢市場的通道內擺盪交易
- ✅ 量化回測系統的通道突破策略
- ✅ 替代手畫趨勢線的客觀化方案
- ✅ 與 R² 結合判斷趨勢品質
- ❌ 盤整市場（R² 太低，通道無意義）
- ❌ 非線性趨勢（如抛物線加速上漲）
- ❌ 極短線交易（回歸通道的滯後太大）

## 台股應用注意事項

- 台股的除權息跳空會扭曲回歸線的斜率，需使用前復權數據
- 台股週 K 線的回歸通道比日 K 線更穩定（減少噪音）
- 適合用於台股 ETF（如 0050）的波段操作判斷
- 台股尾盤搓合機制可能造成 K 線極端值，影響回歸擬合
- 搭配 [[基本面分析/基本面分析總論|基本面分析]] 使用——純統計通道在台股的消息面驅動行情中容易被突破

## 總結

Linear Regression Channel 是通道指標中最「學術」的一種——它把統計學的線性回歸直接搬上圖表，用最小平方法找最佳擬合線，再用殘差標準差畫通道。這讓它比布林通道和肯特納通道更貼合趨勢，也更有數學美感。

但線性回歸的假設是「價格在時間軸上呈線性分佈」——這在現實市場中常常不成立。股價趨勢更多是指數型、S 型或階梯型，而非直線。**回歸通道最大的價值不在於通道本身，而在於 R² 這個趨勢品質量化指標——它告訴你「現在的趨勢值不值得用通道策略」。**

記住：**統計模型是對現實的簡化——線性回歸假設價格沿直線運動，但市場從不沿直線運動。回歸通道的價值在於它提供了「趨勢偏離度」的量化基準，而不是精確預測價格走向。** 用 R² 過濾掉不值得交易的盤整市，再用通道做擺盪或突破——這才是回歸通道的正確用法。

## 實戰應用

### 策略一：回歸通道均值回歸
1. 確認 R² > 0.5（趨勢品質尚可）
2. 價格觸及上軌 → 偏空/減碼
3. 價格觸及下軌 → 偏多/加碼
4. 價格回到中軌 → 平倉
5. 嚴格停損在通道外（上軌 + 1σ 做空停損 / 下軌 − 1σ 做多停損）
6. 適合在穩定趨勢中做「通道內擺盪」

### 策略二：通道突破追蹤
1. 價格突破上軌 + 成交量放大 → 趨勢加速，追多
2. 價格跌破下軌 + 成交量放大 → 趨勢崩潰，追空
3. 停損設在通道中軌
4. 注意：回歸通道的突破比布林通道更可靠，因為回歸線已經考量了趨勢斜率

### 策略三：多通道共振
1. 同時使用 N=20 和 N=50 兩個回歸通道
2. 短期通道在中期通道內 → 趨勢穩定
3. 短期通道突破中期通道 → 趨勢加速或反轉
4. 兩個通道方向一致 → 高確定性進場
5. 兩個通道方向相反 → 趨勢衝突，觀望

## 注意事項

### 優點
- **完全客觀**：用最小平方法自動擬合，無主觀畫線偏差
- **自帶趨勢斜率**：回歸線有方向性，比 SMA 中軌更有意義
- **統計基礎扎實**：有完整的數學理論支撐
- **R² 可量化趨勢品質**：不只判斷方向，還能量化趨勢的「可信度」
- **通道寬度自適應**：波動大時通道自動變寬，波動小時自動變窄

### 缺點
- **端點效應**：回歸線隨每根新 K 線重新擬合，通道會「漂移」
- **滯後性**：N 期回歸通道的轉折比價格本身晚 N/2 期
- **線性假設**：回歸線是直線，但股價趨勢常常是曲線（非線性）
- **對極端值敏感**：離群值會影響回歸線的斜率和截距
- **通道寬度變化慢**：殘差標準差的變化比 ATR 慢，對突發波動反應不及時
- **不適合非趨勢市場**：盤整時 R² 很低，通道訊號幾乎無效
