# 基本面因子選股總論Quantitative-Fundamental-Factors

> 用量化因子系統化挑出好股票，把「感覺這家公司好」變成「數據證明這家公司好」

## 核心概念

基本面因子選股（Fundamental Factor Investing）是將基本面分析量化為可衡量、可回測的因子，用數據驅動取代主觀判斷。每個因子代表一種財務特徵，歷史回測驗證這些特徵與超額報酬有統計顯著關係。

### 為什麼需要因子選股

1. **消除主觀偏誤**：把「看起來不錯」變成「數據支持」
2. **可回測可驗證**：歷史數據證明因子有效性
3. **系統化篩選**：從上千檔股票中快速篩出候選
4. **多因子分散風險**：單一因子可能失效，多因子組合更穩健
5. **與技術面籌碼面互補**：三面合一提高勝率

### 基本面因子分類體系

**價值因子（Value）**
- 本益比 P/E（低PE有效但需排除價值陷阱）
- 股價淨值比 P/B（低PBE歷史最強因子之一）
- 股價現金流量比 P/CF
- 企業價值倍數 EV/EBITDA
- FCF Yield 自由現金流殖利率

**成長因子（Growth）**
- 營收成長率 YoY
- EPS成長率
- 營收動能加速度
- 三率三升（毛利率、營利率、淨利率同時上升）
- 盈餘動能（SUE）

**品質因子（Quality）**
- ROE 杜邦分析
- 營業現金流對淨利比 OCF/NI
- 應計項目比率（低應計＝高品質）
- 利潤穩定性
- 資產負債表強度（低負債比）

**規模因子（Size）**
- 市值大小（小型股溢價）
- 流動性因子
- 在台股小型股效應特別明顯

**動能因子（Momentum）**
- 價格動能（6-12月報酬率）
- 盈餘動能（SUE）
- 營收動能
- 分析師修正動能

**低波動因子（Low Volatility）**
- 貝他係數
- 歷史波動率
- NATR60（60日標準化真實波幅）

## 實戰應用

### 多因子選股流程

**Step 1：因子篩選**
- 選擇3-5個互補因子（價值+品質+動能是經典組合）
- 避免相關性過高的因子（如PE和PB不要同時用）
- 設定每個因子的門檻值

**Step 2：股票池過濾**
- 流動性門檻：日均成交額 > 5000萬
- 上市櫃滿1年以上（排除IPO蜜月期）
- 財報無重大異常（排除全額交割股）

**Step 3：因子評分**
- 每個因子給0-100分的百分位排名
- 多因子等權或加權加總
- 綜合分數 > 80分進入候選池

**Step 4：產業分散**
- 同產業最多選3檔
- 避免因子集中在特定產業
- 產業中性化處理

**Step 5：進出場紀律**
- 月營收公告後重新評分
- 綜合分數跌出前30%就賣出
- 每季財報後全面換倉或增減

### 台股基本面因子回測重點發現

1. **價值+動能組合**最穩定，年化超額報酬8-15%
2. **品質因子**是價值因子的最佳搭檔，過濾掉價值陷阱
3. **營收動能**在台股特別有效（月營收公告制度獨步全球）
4. **低波動因子**長期有效但短期可能落後，需搭配品質因子
5. **小型股效應**在台股顯著，但流動性成本也要考慮

### 因子輪動策略

不同市場環境下，因子有效性輪動：

| 市場環境 | 強勢因子 | 弱勢因子 |
|---|---|---|
| 多頭初期 | 價值、小型 | 低波動 |
| 多頭中期 | 動能、成長 | 價值 |
| 多頭末期 | 品質、低波動 | 小型、動能 |
| 空頭初期 | 低波動、品質 | 動能、小型 |
| 空頭末期 | 價值 | 低波動 |

### 因子選股XQ腳本範例

```
// 多因子選股條件
value_rank = percentile(PE);     // 價值因子
quality_rank = percentile(ROE);  // 品質因子  
momentum_rank = percentile(revenue_YoY_3month); // 動能因子

composite_score = (1-value_rank)*0.3 + quality_rank*0.4 + momentum_rank*0.3;

condition1 = composite_score > 70;
condition2 = average_volume_20day > 50000000;
condition3 = PE > 0;
condition4 = revenue_YoY > 10;
condition5 = OCF_to_NI > 0.8;

select condition1 and condition2 and condition3 and condition4 and condition5;
```

## 注意事項

1. **因子衰退**：再有效的因子也會隨時間衰弱，擁擠效應讓更多人使用同一因子導致超額報酬減少（參考[[因子衰退Factor-Decay]]）
2. **數據挖掘偏誤**：回測100個因子總有幾個看起來有效，要區分真實效應和隨機噪音
3. **存活者偏差**：只用目前上市櫃公司回測會高估因子報酬
4. **產業集中風險**：價值因子可能集中在金融股、成長因子集中在科技股
5. **交易成本**：高週轉率因子的實際報酬遠低於回測報酬
6. **因子相關性**：價值和低波動正相關、價值和動能負相關——搭配負相關因子分散風險效果最好
7. **台股特殊性**：月營收公告制度讓營收動能因子在台股特別有效，但也意味這個因子的擁擠度可能較高
