# 生技股投資邏輯

> 生技股投資有別於一般科技股，需理解臨床試驗階段、法規審查、管線價值評估與專利保護等獨特面向。

## 核心概念

生技股投資的核心邏輯與一般股票不同：

1. **管線價值評估**：生技公司的價值主要來自研發管線（pipeline），而非現有營收
2. **臨床試驗里程碑**：Phase I（安全性）→ Phase II（療效）→ Phase III（大規模驗證），每階段成功率約 60-70% → 40% → 60%
3. **法規審查**：FDA（美）、EMA（歐）、TFDA（台）的審查結果直接影響股價
4. **專利保護**：專利到期後面臨學名藥競爭，營收將顯著下滑（專利悬崖）

## 實戰應用

- **事件驅動交易**：臨床數據發布、FDA 審查結果是股價最大催化劑
- **管線折現模型（rNPV）**：將每個管線藥物的預期營收按臨床成功率折現
- **平台型 vs 單一產品**：平台型公司（如基因編輯、抗體平台）估值可持續擴張，單一產品公司需關注管線延續性
- **CRO/CDMO 投資**：不承擔臨床失敗風險，受惠於產業外包趨勢

## 注意事項

- 單一臨床失敗可能導致股價腰斬
- 生技股常無獲利，傳統估值指標（PER、PB）適用性有限
- 需追蹤公司現金跑道（cash runway），資金不足有稀釋風險
- 法規政策變動（如藥價改革）可能影響整體產業估值
