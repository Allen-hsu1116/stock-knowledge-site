# Merton 結構化信用風險模型與 KMV 違約距離

> 把股東權益看成一張買權——公司資產價值跌破負債就是違約。Robert Merton 1974年用選擇權定價理論拆解信用風險，KMV模型進一步把它變成可實戰的「違約距離」指標。

## 核心概念

**Merton 模型**是 Robert C. Merton 於1974年提出的**結構化信用風險模型**（Structural Credit Risk Model）。核心思想是把公司股東權益視為一張以公司資產為標的、以負債面額為履約價的**歐式買權**。

- **公司資產價值 > 負債**：股東「執行買權」，償還債務，保留剩餘價值
- **公司資產價值 < 負債**：股東「放棄買權」，公司違約，債權人接管資產

這是第一個用微觀經濟模型（公司資本結構）來解釋違約為何發生的模型，與 Jarrow-Turnbull 等**縮減式模型**（Reduced-form Model，把違約當統計過程）形成對比。

## 數學框架

### 基本設定

- **V₀**：公司資產當前市場價值（不可直接觀察）
- **σ_V**：公司資產波動率（不可直接觀察）
- **D**：負債面額（到期日 T 需償還）
- **r**：無風險利率
- **E₀**：股東權益市場價值（可觀察）
- **σ_E**：股東權益波動率（可觀察）

### 資產過程（風險中立測度下）

dV = rV·dt + σ_V·V·dW_t

其中 W_t 為 Wiener 過程。

### 到期日損益

- **E_T = max(V_T - D, 0)** — 股東權益 = 買權損益
- **B_T = min(V_T, D)** — 債權人收回 = D - max(D - V_T, 0) = 無風險債券 - 賣權

### Black-Scholes 定價

股東權益的當前價值：

**E₀ = V₀·N(d₁) - D·e^(-rT)·N(d₂)**

其中：
- d₁ = [ln(V₀/D) + (r + σ_V²/2)·T] / (σ_V·√T)
- d₂ = d₁ - σ_V·√T
- N(·) = 標準常態分配累積分布函數

### 違約距離（Distance to Default）

**d₂ 就是「違約距離」**——d₂ 越小，違約機率越高。

### 風險中立違約機率

**PD = N(-d₂) = 1 - N(d₂)**

### 求解不可觀察變數

V₀ 和 σ_V 不可直接觀察，但對上市公司而言 E₀ 和 σ_E 可從市場取得。利用 Itô 引理：

**σ_E·E₀ = (∂E/∂V)·σ_V·V₀ = N(d₁)·σ_V·V₀**

此方程與權益定價方程構成聯立非線性方程組，可數值求解 V₀ 和 σ_V。

## KMV 模型（Moody's-KMV）

### 與 Merton 原始模型的差異

KMV 模型由 Kealhofer、McQuown 和 Vašíček 開發，現由 Moody's 提供。主要改良：

1. **違約點不是全部負債**：KMV 定義違約點 = 短期負債 + 50% 長期負債（因為長期負債有時間週轉）
2. **違約距離（DD）重新定義**：

   **DD = [E(V_T) - Default Point] / (σ_V·√T)**

   其中 E(V_T) = V₀·e^(μT)，μ 為資產預期報酬率

3. **預期違約頻率（EDF）**：KMV 不直接用 N(-DD) 算機率，而是用**歷史違約資料庫**將 DD 映射到實際違約頻率，更貼近現實

### KMV 三步驟

1. **估算資產價值與波動率**：從股價和權益波動率反推 V₀ 和 σ_V
2. **計算違約距離 DD**：用短期負債 + 半長期負債作違約點
3. **映射到 EDF**：用歷史資料庫找相同 DD 水準的實際違約率

## 與其他信用風險模型的比較

- **vs [[基本面分析/Altman-Z-Score破產預測模型|Altman Z-Score]]**：Z-Score 用會計比率（靜態），Merton/KMV 用市場數據（動態、前瞻）
- **vs [[基本面分析/信用評等與公司債違約風險判讀Credit-Rating-and-Default-Risk|信用評等]]**：評等是離散等級（AAA/AA/A...），EDF 是連續機率，更靈敏
- **vs [[基本面分析/信用違約交換CDS-Credit-Default-Swap|CDS]]**：CDS 價差反映市場對違約的定價，Merton 模型從資本結構推導違約機率，兩者可交叉驗證

## 實戰應用

### 1. 信用風險監控

- 計算個股的違約距離 DD，DD < 2 為高危險區
- 追蹤 DD 的時間序列變化，DD 持續下降 = 信用惡化前兆
- 比 Altman Z-Score 更靈敏，因為融入即時股價資訊

### 2. 債券投資

- 用 EDF 評估公司債信用風險溢酬是否合理
- EDF 高但 CDS 價差低 = 市場低估信用風險，可能做空 CDS 或避開該債券
- EDF 低但債券殖利率高 = 市場過度恐慌，可能有買入機會

### 3. 選股過濾

- 把 DD 當「信用健康度」濾網，排除 DD 持續下降的個股
- 搭配 [[基本面分析/Piotroski-F-Score財務品質評分模型|Piotroski F-Score]] 使用：F-Score 看會計品質，DD 看市場對信用風險的定價

### 4. 系統性風險預警

- 市場平均 DD 大幅下降 = 整體信用環境惡化
- 2008年金融海嘯前，金融股 DD 普遍降至 1 以下，提前預警

## 模型限制

1. **假設資產價值服從幾何布朗運動**：現實中資產價值有跳躍（jump），特別是危機時期
2. **違約只發生在到期日**：現實中違約可在任何時點發生（KMV 部分修正此問題）
3. **資產波動率需從權益波動率反推**：求解過程依賴模型假設，估計誤差可能放大
4. **未考慮流動性風險**：公司可能資產 > 負債但因流動性枯竭而違約
5. **台股適用性**：台股個股的權益波動率較易取得，但負債結構較複雜（可轉債、私募等），需調整違約點定義
