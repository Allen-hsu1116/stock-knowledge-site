# 自由現金流進階選股與估值FCF-Advanced-Valuation

> FCF不只是「公司賺多少現金」，更是判斷公司能不能活、值不值得投資的終極指標——巴菲特最愛的數字

## 核心概念

自由現金流（Free Cash Flow, FCF）= 營業現金流 − 資本支出，代表企業支付所有必要支出後真正能自由運用的現金。FCF是所有估值模型的基礎，比EPS更能反映公司真實獲利能力。

### 為什麼FCF比EPS更可靠

1. **EPS可以被會計手法操縱**：收入認列時點、折舊方法、費用資本化都影響EPS但不影響現金流
2. **FCF是硬數字**：現金進來多少、出去多少，無法用會計手法創造
3. **應計項目異常**：高應計項目公司未來報酬系統性偏低（Sloan異象），FCF不受影響
4. **巴菲特的選擇**：「我喜歡的企業是那種能產生大量現金的公司」

### FCF三種計算方式

**1. 基本FCF**
```
FCF = 營業現金流 − 資本支出
```
最常用的計算方式，包含維持性支出和擴張性支出。

**2. 自由現金流對所有人（FCFF）**
```
FCFF = EBIT × (1−稅率) + 折舊攤銷 − 資本支出 − 營運資金變動
```
扣除稅但未扣除利息，反映整個公司的現金流，適合跨公司跨產業比較。

**3. 自由現金流對股東（FCFE）**
```
FCFE = FCFF − 利息支出(稅後) + 淨借債變動
```
真正屬於股東的現金流，直接用於DCF估值。

### FCF Yield（自由現金流殖利率）

```
FCF Yield = FCF / 企業價值(EV)
```

FCF Yield是比股息率更純粹的價值因子：
- 股息率只看配出去的現金，FCF Yield看全部可分配現金
- 高股息率可能是股價下跌的結果，但高FCF Yield代表真的在產生現金
- 歷史回測：FCF Yield是最穩定的價值因子之一

## 實戰應用

### FCF選股五步驟

**Step 1：FCF篩選**
- FCF > 0（排除現金流為負的公司）
- FCF持續3年以上（排除一次性現金流）
- FCF/營收 > 5%（確保現金流品質）

**Step 2：FCF品質驗證**
- OCF/NI > 0.7（營收有現金支撐，排除紙面富貴）
- FCF/淨利 > 0.8（利潤真的轉成現金）
- 資本支出率合理（CapEx/營收在產業正常範圍）

**Step 3：FCF趨勢判斷**
- FCF 3年CAGR > 10%（現金流在成長）
- 資本支出轉化率 = 營收增量/CapEx增量 > 0.5（投資真的帶來成長）
- FCF Margin趨勢向上（現金流效率改善）

**Step 4：FCF估值**
- FCF Yield同業排名前30%
- DCF估值 > 當前股價20%以上安全邊際
- P/FCB < 同業中位數

**Step 5：陷阱排除**
- 排除「變賣家產型FCF」：出售資產帶來的一次性現金流
- 排除「剋扣投資型FCF」：CapEx下降只是因為延後投資
- 排除「融資依賴型FCF」：靠借債維持的現金流不可持續

### FCF三大陷阱

**陷阱1：一次性現金流**
- 出售資產、處分轉投資、收到保險理賠
- 辨識：OCF/NI突然飆高 + 投資現金流大額正數
- 應對：用3年平均FCF，排除一次性項目

**陷阱2：投資不足**
- 降低CapEx短期提升FCF，但損害長期競爭力
- 辨識：CapEx/折舊攤銷 < 1（沒在更新設備）+ 營收看得到衰退
- 應對：看5年CapEx趨勢，投資不足的公司要折價

**陷阱3：營運資金操控**
- 壓迫供應商（應付帳款暴增）、催收客戶（應收帳款暴減）
- 辨識：營運資金變動佔OCF比例過大
- 應對：排除營運資金變動看調整後FCF

### DCF估值實戰流程

**1. 歷史FCF分析**
- 過去5-10年FCF趨勢與波動性
- FCF Margin穩定度
- 資本支出佔營收比趨勢

**2. FCF預測**
- 成長期：預測5-10年FCF成長率（參考營收成長率×FCF Margin趨勢）
- 穩定期：假設FCF成長率收斂到GDP成長率（3-4%）
- 終值：用Gordon成長模型或退出倍數法

**3. 折現**
- WACC計算（參考[[WACC加權平均資本成本]]）
- 敏感度分析：改變成長率和折現率看估值範圍
- 安全邊際：至少20%

**4. 蒙地卡羅模擬**
- 關鍵變數機率分布
- 跑1000次模擬看估值分布
- P10、P50、P90估值範圍

### FCF與其他估值指標比較

| 指標 | 優點 | 缺點 |
|---|---|---|
| P/E | 簡單易懂 | 盈餘可操縱、虧損公司無法用 |
| P/B | 適合資產密集產業 | 無形資產多的公司失真 |
| P/FCF | 最真實的獲利能力 | CapEx高的成長期公司FCF偏低 |
| EV/EBITDA | 跨產業可比 | 折舊攤銷被加回可能低估風險 |
| FCF Yield | 現金殖利率概念 | FCF不穩定公司難以評估 |

## 注意事項

1. **成長期公司FCF可能為負**：大量資本支出壓縮FCF不代表公司不好，需看投資轉化率（參考[[資本支出CapEx與自由現金流判讀]]）
2. **週期性公司的FCF極不穩定**：景氣高峰FCF暴增、谷地FCF為負，用5-10年平均FCF更合理
3. **折舊攤銷與CapEx的時間差**：重資產公司折舊大但CapH可能更大，導致FCF低估或高估
4. **庫藏股影響**：大量買回庫藏股會減少現金但不影響FCF計算，但影響每股FCF
5. **稅率變化影響**：稅率改變直接影響FCFF和FCFE，跨年度比較需調整
6. **合併報表複雜度**：少數股權、轉投資損益都會影響FCF計算，要用合併報表數字
7. **台股特殊性**：高殖利率公司配息率可能遠高於FCF Yield，代表在吃老本或借錢配息（參考[[現金股利保障倍數與配息安全性判讀Cash-Dividend-Coverage-Ratio]]）
