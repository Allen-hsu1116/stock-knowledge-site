# 工業生產指數 Industrial Production Index (IPI)

> 製造業的月度心跳圖——工廠轉速加快還是放慢，一看便知

## 核心概念

### 什麼是工業生產指數
工業生產指數（Industrial Production Index, IPI）是美國聯準會（Federal Reserve）每月發布的製造業、礦業和公用事業實際產出量測指標。它衡量的是工廠、礦場和電力公司實際生產了多少東西——不是訂單、不是信心、不是預期，而是已經生產出來的實物量。

IPI是少數由聯準會親自編製的經濟指標（大多數總經指標由普查局或BEA負責），這也讓它帶有「聯準會內部視角」的特殊地位——政策制定者用它來判斷經濟的真實產出狀況。

## 關鍵數據結構

- **發布機構**：美國聯邦準備理事會（Federal Reserve Board）
- **發布時間**：每月15日左右，美東時間9:15
- **頻率**：每月一次
- **基期**：以2017年為基期（2017=100）
- **數據特性**：數量指標（volume），非金額指標——已剔除價格變動影響
- **修正頻率**：每月修正前兩個月數據，每年4月進行年度大幅修正

### 三大組成部分

1. **製造業（Manufacturing）**——佔IPI約74%
   - 耐久財製造：機械、汽車、電子、航太等
   - 非耐久財製造：食品、紡織、化學、造紙等
2. **礦業（Mining）**——佔IPI約15%
   - 石油天然氣開採
   - 煤礦、金屬礦石
   - 礦業與能源價格高度連動
3. **公用事業（Utilities）**——佔IPI約11%
   - 電力、天然氣、供水
   - 受天氣影響極大（極端高溫/低溫→用電暴增）

### 關鍵附帶指標

- **產能利用率（Capacity Utilization Rate）**：實際產出佔最大產能的百分比，是IPI報告的黃金搭檔
  - 78-82%：正常健康區間
  - >85%：產能吃緊，可能引發通膨壓力
  - <75%：產能閒置嚴重，經濟降溫訊號
- **製造業生產（Manufacturing Output）**：剔除礦業和公用事業後的純製造業產出，市場更關注此數據

## 對股市的影響管道

### 直接影響

- **製造業類股**：IPI上升→製造業營收預估上修
- **原物料類股**：工業生產強→原物料需求增加
- **能源類股**：礦業分項與能源開採連動
- **運輸類股**：工業產出增加→物流貨運需求上升

### 間接影響

- **GDP預期**：IPI直接計入GDP的工業產出分項
- **通膨預期**：產能利用率過高→通膨壓力→升息預期
- **企業盈餘**：製造業產出與企業營收高度正相關

### 對台股的傳導

1. **半導體供應鏈**：美國製造業生產強→電子產品需求高→台灣半導體和零組件出貨增加
2. **機械設備**：美國工業生產擴張→工具機、自動化設備需求→台灣機械類股受惠
3. **原物料價格**：工業生產強→銅鐵塑膠等原物料需求→台灣塑化鋼鐵類股
4. **利率管道**：產能利用率過高→美國升息預期→外資從台股撤出風險

## IPI vs PMI vs 耐久財訂單

三大製造業指標的定位差異：

- 比較項目：工業生產指數IPI / PMI / 耐久財訂單
- 發布機構：聯準會 / ISM/Markit / 普查局
- 觀察面向：實際產出量 / 採購經理人主觀感受 / 新訂單金額
- 指標性質：硬數據（落後確認） / 軟數據（領先） / 硬數據（領先）
- 時間軸：已經生產的 / 正在採購的 / 未來要生產的
- 最大優勢：量化的實質產出 / 最快最前瞻 / 訂單金額可追蹤

三個指標一起看形成完整的製造業觀測鏈：耐久財訂單（未來要做的）→ PMI（正在做的感受）→ IPI（已經做出來的量）。

## 實戰判讀SOP

### 第一步：看製造業生產月增率

- Manufacturing MoM > +0.3%：製造業穩健擴張
- Manufacturing MoM 0% ~ +0.2%：溫和成長
- Manufacturing MoM < 0%：製造業收縮，需連續確認

### 第二步：看產能利用率

- 78-82%：健康區間，經濟穩定成長
- > 82%：產能吃緊，通膨壓力浮現，聯準會可能偏鷹
- < 75%：產能閒置，經濟疲軟，聯準會可能偏鴿

### 第三步：排除天氣和礦業干擾

- 整體IPI大增但製造業平平→可能是天氣帶動公用事業
- 礦業暴增暴跌→查油價和罷工新聞
- 只看製造業生產才是最乾淨的訊號

### 第四步：看分項結構

- 耐久財製造強→資本支出週期上行
- 非耐久財製造強→日常消費需求穩定
- 汽車製造分項→單獨看，因為佔製造業比重約7-8%且波動大

### 第五步：與PMI交叉確認

- IPI和PMI同向上行→製造業擴張確認
- PMI下行但IPI仍上升→PMI領先性正在發揮，IPI可能即將跟跌
- PMI上行但IPI下降→PMI可能過度樂觀，或IPI數據滯後

## 與AI時代的關聯

2025-2026年AI資本支出超級週期中，IPI有了新的解讀維度：

- **電腦與電子產品製造分項**成為觀察AI伺服器量產的官方窗口
- 美國製造業產能利用率在AI伺服器需求拉動下從75%升至80%+，是2020年代罕見的產能吃緊
- 但需注意：IPI衡量的是「美國國內產出」，台積電在亞洲生產的晶片不計入。美國本土製造的伺服器組裝和半導體（Intel、GF等）才會反映在IPI中
- 礦業分項中的天然氣開採與AI資料中心電力需求產生新的關聯——資料中心用電暴增推動天然氣發電需求

## 實戰應用

### 如何判讀工業生產指數
### 看月增率和產能利用率雙指標

- **月增率（MoM）**：季節調整後的環比變化，+0.3%以上代表穩健擴張
- **年增率（YoY）**：與去年同期比較，+2%以上代表工業部門健康成長
- **產能利用率**：與IPI一起看，產出增加但利用率下降代表擴產速度超過需求

### 製造業是核心

- 社會只看整體IPI容易受礦業和公用事業干擾
- 製造業生產單獨看更能反映經濟實質動能
- 製造業生產連續三個月下降→工業衰退訊號

### 天氣干擾要排除

- 公用事業受天氣影響極大——嚴冬酷暑用電暴增不代表經濟變強
- 礦業受油價和罷工影響——一次罷工就能讓礦業產出暴跌
- 製造業是最穩定的觀察標的

### 產能利用率的通膨意涵

- 產能利用率 > 80%：製造商接近滿載運轉，漲價能力增強→通膨壓力上升
- 產能利用率 < 75%：大量設備閒置，製造商沒有漲價能力→通膨壓力下降
- 聯準會歷史上在產能利用率持續高於82%時傾向升息

## 注意事項
- **把整體IPI當製造業指標**：整體IPI受公用事業（天氣）和礦業（油價）嚴重干擾，製造業分項才是核心
- **忽略年度大幅修正**：每年4月聯準會會大幅修正歷史IPI數據，過去的趨勢可能完全改觀
- **只看月增率不看產能利用率**：產出增加但利用率下降代表擴產太快，反而不利於未來
- **忘記IPI是落後指標**：IPI確認趨勢但不能預測，搭配PMI和耐久財訂單才有前瞻性
