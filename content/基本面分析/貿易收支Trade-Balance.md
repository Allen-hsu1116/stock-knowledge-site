# 貿易收支 Trade Balance

> 一國進出口的體檢表——順差不代表健康、逆差不代表生病，關鍵看結構而非數字

## 核心概念

### 什麼是貿易收支
貿易收支（Trade Balance）是一國在特定期間內商品出口總額與進口總額的差額，是國際收支帳（Balance of Payments）中經常帳（Current Account）的核心組成部分。

- **貿易順差（Trade Surplus）**：出口 > 進口，差額為正
- **貿易逆差（Trade Deficit）**：進口 > 出口，差額為負
- IMF 官方定義只計算商品（Goods），但部分統計也包含服務（Services）

貿易收支是流量變數（Flow Variable），衡量一段時間內的進出口差額，而非存量。

## 關鍵數據結構

- **發布機構**：美國普查局（Census Bureau）與經濟分析局（BEA）聯合發布
- **發布時間**：每月第二週，美東時間8:30
- **頻率**：每月一次
- **時間落差**：數據落後參考月約6週
- **台灣對應指標**：財政部進出口貿易統計，每月上旬發布

### 美國貿易收支核心數據

- **商品貿易收支（Goods Balance）**：僅計算商品進出口
- **服務貿易收支（Services Balance）**：服務業進出口（美國服務業通常順差）
- **總貿易收支（Total Balance）**：商品 + 服務

美國長期處於商品貿易逆差，但服務貿易順差部分抵消。2024年美國商品貿易逆差超過1.15兆美元，是全球最大逆差國。

## 影響貿易收支的因素

- **匯率變動**：本國貨幣升值使出口變貴、進口變便宜，逆差擴大；貶值反之
- **生產成本**：土地、勞動、資本、稅負等成本結構決定出口競爭力
- **原物料與中間財**：供應鏈上下游的可用性與成本
- **貿易政策**：關稅、非關稅壁壘（環保、健康、安全標準）、自由貿易協定
- **外匯存量**：是否有足夠外匯支付進口
- **國內需求**：內需強 → 進口增 → 逆差擴大；內需弱 → 進口減
- **經濟週期**：出口導向經濟在擴張期順差擴大；內需導向經濟在擴張期逆差擴大

## 貿易收支與 GDP 的關係

貿易收支是 GDP 計算公式中的淨出口分項：

**GDP = C + I + G + (X - M)**

其中 (X - M) 就是淨出口（貿易收支）。當貿易逆差擴大，若其他分項不成長，GDP 會被拖累。但美國長期逆差卻維持高成長，因為消費（C）和投資（I）成長遠超過逆差的拖累。

### 儲蓄率與貿易收支

經濟學基本恆等式：**貿易收支 = 國民儲蓄 - 國內投資**

- 儲蓄 > 投資 → 貿易順差（日本、德國、中國）
- 儲蓄 < 投資 → 貿易逆差（美國、英國、印度）

美國低儲蓄率是貿易逆差的根本結構性原因，與匯率和關稅政策的直接關係較弱。

## 貿易逆差真的不好嗎？

主流經濟學家**普遍反對**「貿易逆差必然有害」的觀點：

- **Joseph Stiglitz**（諾貝爾獎得主）：順差國對貿易夥伴施加「負外部性」，順差比逆差對全球繁榮的威脅更大
- **Ben Bernanke**（前聯準會主席）：歐元區內部持續不平衡不健康，德國持續順差等於從鄰國抽走需求和就業
- **美國貿易逆差的「三好處」**（經濟學家 Carla Norrlöf 指出）：
  1. 更高的全球合作與供應鏈整合
  2. 美國消費者享受更低價格
  3. 外國賺到的美元回流投資美國國債，壓低借貸成本

但 IMF 也警告，持續大額逆差可能導致國際收支問題、外匯短缺，影響經濟穩定。

## 美台貿易結構的特殊視角

台灣是典型的出口導向經濟，長期維持大幅貿易順差：

- **台灣對美國出超**：2026年超過1,040億美元
- **台灣整體出超**：約974億美元
- **扣除美國後為逆差**：台灣對美國以外市場整體是貿易逆差——美國是台灣唯一的大幅順差來源

這個結構意味著：
1. 台灣經濟高度依賴美國市場需求
2. 美台貿易順差擴大可能引發美國301關稅壓力
3. 台幣匯率受貿易順差影響，順差擴大 → 台幣升值壓力

## 與其他總經指標的關係

- **與 [[基本面分析/GDP國內生產毛額Gross-Domestic-Product|GDP]]**：貿易收支是 GDP 的淨出口分項，直接影響 GDP 計算
- **與 [[基本面分析/殖利率曲線分析Yield-Curve-Analysis|殖利率曲線]]**：持續大額逆差需外國資金流入融資，影響國債殖利率
- **與匯率**：貿易收支是匯率的根本驅動力之一，順差國貨幣長期升值趨勢
- **與 [[基本面分析/FOMC聯邦公開市場委員會與利率決策Federal-Open-Market-Committee|FOMC 利率決策]]**：聯準會關注貿易收支對通膨和經濟成長的影響

## 統計問題與盲點

### 全球貿易數據「1%黑洞」
當全球所有國家的貿易數據加總，出口竟比進口多出近1%——全球對自己出現順差，這在數學上不可能。差異被歸因於洗錢、逃稅、走私等隱藏交易，且多數差異發生在統計可信度高的已開發國家之間。

### 中間財重複計算
全球供應鏈中，同一批零組件可能跨越多國邊境，每次進出口都被記錄，導致貿易收支數字被放大。例如一支iPhone的零件從日本到台灣再到中國組裝，每段都被計為貿易額，但最終價值只有一次。

### 物質貿易 vs 金融貿易
金融貿易收支只記錄金額，不記錄物質流動。已開發國家大量進口原物料、出口高附加價值成品，金融面上順差但物質面上可能大幅逆差。

## 總結

貿易收支是衡量一國國際經濟地位的核心指標，但「順差好、逆差壞」的重商主義思維早已被現代經濟學否定。美國長期逆差卻是全球最強經濟體，中國長期順差卻面臨結構性轉型壓力——貿易收支的數字本身不說好壞，結構才是關鍵。對台股投資人而言，貿易收支最直接的意義是出口動能的宏觀確認和匯率趨勢的指引，搭配外銷訂單和PMI能形成完整的出口景氣觀測體系。

## 實戰應用

### 與台股的實戰連動
### 匯率傳導
- 貿易順差擴大 → 台幣升值壓力 → 外資匯入成本降低 → 有利外資買超台股
- 貿易順差縮小 → 台幣貶值壓力 → 外資匯出成本上升 → 可能引發外資賣超

### 出口動能直接影響企業獲利
- 台灣出口以電子零組件和半導體為主（佔比超過65%）
- 貿易收支數據是電子業和半導體供應鏈營收的宏觀領先指標
- 出口年增率連續下滑 = 科技股營收承壓的前兆

### 與關稅政策的連動
- 川普301關稅政策直接衝擊台灣出口結構
- 台灣被課10%關稅意味著出口競爭力下降
- 貿易收支數據是觀察關稅政策實際影響的量化工具
