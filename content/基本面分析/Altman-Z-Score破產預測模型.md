# Altman Z-Score 破產預測模型

> Edward Altman 於 1968 年開發的多變量線性判別模型，用五個財務比率的加權組合預測企業在兩年內破產的機率，是信用風險分析與價值投資排雷的經典工具

## 核心概念

Altman Z-Score 由紐約大學教授 Edward I. Altman 在 1968 年的論文《Financial Ratios, Discriminant Analysis and the Prediction of Corporate Bankruptcy》中提出。它使用**多變量線性判別分析（MDA）**，將五個財務比率以不同權重組合成一個綜合分數（Z-Score），用以判斷企業的財務健康程度與破產風險。

這不是單看一個比率（如負債比或流動比），而是把多個維度的財務數據用統計方法找出最佳加權組合，大幅提升預測能力。

### 原始模型（1968，適用上市公司）

```
Z = 1.2×A + 1.4×B + 3.3×C + 0.6×D + 1.0×E
```

- **A** = 營運資金 / 總資產（Working Capital / Total Assets）
- **B** = 保留盈餘 / 總資產（Retained Earnings / Total Assets）
- **C** = EBIT / 總資產（息稅前盈餘 / 總資產）
- **D** = 股東權益市值 / 總負債帳面價值（Market Value of Equity / Book Value of Total Liabilities）
- **E** = 營收 / 總資產（Sales / Total Assets）

### 五個比率的意義

1. **營運資金 / 總資產（A）**：衡量短期流動性。營運資金 = 流動資產 - 流動負債。比值越高代表企業有越充裕的短期資金周轉空間。若為負值代表流動負債大於流動資產，短期周轉壓力大。

2. **保留盈餘 / 總資產（B）**：衡量企業的歷史累積獲利能力與內部融資能力。一家公司累積的保留盈餘越多，代表過去持續獲利，面對困境時有更厚的緩衝。新創公司此項通常為負或很低，這也是 Z-Score 對新公司偏向保守的原因。

3. **EBIT / 總資產（C）**：衡量資產的獲利效率。這是 Z-Score 中**權重最高（3.3）**的分量，說明 Altman 認為資產創造營業利益的能力是判斷企業存亡最關鍵的指標。這與 [[基本面分析/CROIC現金投入資本報酬率|CROIC]] 和 [[基本面分析/資產周轉率進階判讀Asset-Turnover-Advanced|資產周轉率]] 的精神一致。

4. **股東權益市值 / 罷債帳面值（D）**：衡量市場對公司的估值是否足以覆蓋負債。這是唯一使用市值而非帳面值的比率，引入了市場的投票結果。比值越高代表市場對公司有信心，且公司不太可能資不抵債。

5. **營收 / 總資產（E）**：衡量資產周轉效率，即每單位資產能創造多少營收。這與 [[基本面分析/資產周轉率進階判讀Asset-Turnover-Advanced|資產周轉率]] 的概念相同。權重 1.0，代表 Altman 認為營運效率也是重要的存活因素。

### 判讀區間

- **Z > 2.99**：安全區（Safe Zone），破產風險低
- **1.81 < Z < 2.99**：灰色區（Gray Zone），需要進一步觀察，財務狀況不明朗
- **Z < 1.81**：危險區（Distress Zone），破產風險高，兩年內破產的統計機率顯著增加

## 模型演進

### Z' 模型（適用私人公司，1983）

由於原始模型的 D 項需要股東權益市值（上市公司才有），Altman 在 1983 年推出了適用私人公司的修正版：

```
Z' = 0.717×A + 0.847×B + 3.107×C + 0.420×D' + 0.998×E
```

D' = 股東權益帳面值 / 總負債帳面值（用帳面值替代市值）

判讀區間調整為：
- Z' > 2.9：安全
- 1.23 < Z' < 2.9：灰色區
- Z' < 1.23：危險

### Z'' 模型（適用非製造業，1995）

進一步修正適用服務業等非製造業公司，因為 E 項（營收/總資產）在不同行業間差異極大：

```
Z'' = 6.56×A + 3.26×B + 6.72×C + 1.05×D'
```

移除了營收/總資產項，調整了各項權重。判讀區間：
- Z'' > 2.6：安全
- 1.1 < Z'' < 2.6：灰色區
- Z'' < 1.1：危險

### Z-Score 模型對照

- **Z**（1968 原始）：適用上市製造業公司
- **Z'**（1983）：適用私人製造業公司
- **Z''**（1995）：適用非製造業，也被廣泛用於新興市場

## 實戰應用

### 1. 排雷選股（價值投資角度）

Z-Score 最直接的用途是**排除高危險公司**。在選股流程中加入 Z-Score > 2.99 作為濾網，可以自動剔除財務結構不健全的公司。這比單看單一比率更全面，因為 Z-Score 同時考慮了流動性、獲利能力、市場估值和營運效率。

### 2. 信用風險評估

銀行和債券投資者使用 Z-Score 評估企業的違約風險。Z-Score 進入危險區的公司，其公司債的違約機率顯著上升，應要求更高的風險溢價。這與 [[基本面分析/信用評等與公司債違約風險判讀Credit-Rating-and-Default-Risk|信用評等與公司債違約風險判讀]] 的分析互相補充。

### 3. 轉機股的風險控管

在尋找[[基本面分析/轉機股選股實戰|轉機股]]時，Z-Score 是一個很好的風險控管工具。轉機股的特徵是「現在不好但未來可能好」，但你需要確認它「不會在轉機實現前就破產」。Z-Score 在灰色區或危險區的轉機股，需要更高的潛在報酬來補償其破產風險。

### 4. 搭配盈餘品質分析

Z-Score 衡量的是「靜態的財務結構」，但如果公司的財報本身有問題，Z-Score 的計算結果就不可靠。因此應搭配[[基本面分析/盈餘品質分析|盈餘品質分析]]和[[基本面分析/財報假帳偵測|財報假帳偵測]]來確認輸入數據的可靠性。

## 計算實例

以某公司為例（數字為假設）：

- 營運資金 = 500M，總資產 = 2000M → A = 0.25
- 保留盈餘 = 300M，總資產 = 2000M → B = 0.15
- EBIT = 250M，總資產 = 2000M → C = 0.125
- 股東權益市值 = 1800M，總負債 = 800M → D = 2.25
- 營收 = 1500M，總資產 = 2000M → E = 0.75

```
Z = 1.2×0.25 + 1.4×0.15 + 3.3×0.125 + 0.6×2.25 + 1.0×0.75
Z = 0.30 + 0.21 + 0.4125 + 1.35 + 0.75
Z = 3.02
```

Z = 3.02 > 2.99，進入安全區，破產風險低。

## 優缺點

**優點**：
- 五個維度的綜合判斷比任何單一比率更全面
- 有明確的量化區間，減少主觀判斷
- 經過數十年的實證驗證，預測準確率在統計上顯著
- 適用全球市場，不限於美國

**缺點**：
- 1968 年的模型權重可能不完全適用現代產業結構（尤其科技業、平台經濟）
- 不適用金融業和公用事業（資產結構與製造業完全不同）
- 無法偵測會計操縱——若公司造假，Z-Score 的輸入就是錯的
- 靜態指標，不反映趨勢變化——應連續追蹤多季的 Z-Score 走勢
- 新創公司天然 Z-Score 偏低（保留盈餘少），不適合直接套用

## 台股應用注意事項

1. **台灣上市公司多為製造業**，原始 Z 模型適用性較高
2. **半導體和電子業**的資產結構（重資產 vs 輕資產）差異大，建議用 Z'' 模型
3. **金控和保險業完全不適用**，應使用專門的金融業風險指標
4. **台積電等大型公司**的 Z-Score 極高（保留盈餘龐大、市值遠超負債），幾乎不可能進入危險區
5. **中小型電子股**才是 Z-Score 最有價值的警示範圍——這些公司容易在景氣循環低點出現財務危機

## 與其他財務健康指標的關係

- **vs [[基本面分析/財報綜合健康評分法Comprehensive-Financial-Health-Scoring|財報綜合健康評分法]]**：Z-Score 是最早的系統性多維度財務健康評分，現代的綜合評分法很多都借鑒了 Z-Score 的思路
- **vs [[基本面分析/負債比率與財務結構分析Debt-Ratio-and-Financial-Structure|負債比率分析]]**：負債比只看一個維度，Z-Score 同時考慮流動性、獲利和周轉效率
- **vs [[基本面分析/信用評等與公司債違約風險判讀Credit-Rating-and-Default-Risk|信用評等]]**：信用評等是質化+量化的綜合判斷，Z-Score 是純量化模型，兩者可互補
