# 盈餘動力價值 Earnings Power Value EPV

> 假設公司零成長、全部盈餘可分配，算出來的「現有賺錢能力值多少錢」——Bruce Greenwald 的估值利器，當成長股估值被炒到天上時，EPV 告訴你剝掉成長幻想後公司到底值多少

## 核心概念

盈餘動力價值（Earnings Power Value, EPV）由哥倫比亞大學商學院教授 Bruce Greenwald 在《Value Investing: From Graham to Buffett and Beyond》（2001）中提出。它是價值投資估值工具中獨特的一員，因為它**刻意忽略成長**。

EPV 的核心假設：公司目前的盈餘水平是可持續的，但不會成長。用當前盈餘除以資本成本，得到「零成長情境下的公司價值」。

### 為什麼忽略成長？

Greenwald 的邏輯很直接：

1. **成長極難預測**：分析師對 3 年後的盈餘預測平均誤差超過 50%
2. **成長需要再投資**：成長不是免費的，公司需要將盈餘再投資，股東不能全拿
3. **成長的價值有上限**：競爭終將侵蝕超額報酬，長期 ROE 會回歸資本成本
4. **剝離成長看到底線**：如果 EPV > 市值，就算完全不成長也便宜；如果 EPV < 市值，市場定價大量依賴成長預期

## 計算公式

### 基本公式

```
EPV = 調整後盈餘 / 資本成本
```

### Step 1：計算調整後盈餘（Adjusted Earnings）

不能用單純的 EPS，需要做以下調整：

```
調整後盈餘 = 正常化 EBIT × (1 - 稅率)
```

具體調整項目：
- **正常化 EBIT**：取過去 3-5 年平均，消除週期性高低谷
- **消除一次性項目**：剔除處分資產利益、減損損失、訴訟賠償等非經常性損益
- **租金調整**：如果使用營業租賃，將租金加回 EBIT（因為自有資產的對應成本是折舊）
- **研發資本化修正**：將研發費用的效果適度資本化，而非全額費用化（可選）

### Step 2：決定資本成本（Cost of Capital）

```
WACC = E/(D+E) × Cost of Equity + D/(D+E) × Cost of Debt × (1 - 稅率)
```

- **權益成本**：用 CAPM 估計，台股無風險利率取 10 年公債殖利率（約 1-1.5%），市場風險溢價約 5-6%
- **負債成本**：公司實際借款利率
- **實務簡化**：台股多數公司負債比率不高，可直接用權益成本作為資本成本，通常取 8-10%

### Step 3：計算 EPV

```
EPV = 調整後盈餘 / 資本成本
```

### Step 4：與市值比較

```
EPV / 市值 = 盈餘動力比值

比值 > 1：市場低估了公司的現有賺錢能力（便宜）
比值 < 1：市場定價包含大量成長預期（昂貴）
比值 ≈ 1：市場定價約等於零成長價值（合理）
```

## EPV 與其他估值法的比較

### EPV vs [[現金流量折現法DCF估值|DCF]]
- DCF：需要預測未來 5-10 年現金流 + 終值，對成長假設極度敏感
- EPV：完全忽略成長，只看當前盈餘的資本化價值
- **關係**：EPV 是 DCF 在「零成長」假設下的特例

### EPV vs [[股利折現模型DDM估值|DDM]]
- DDM：用股利折現，適合穩定配息公司
- EPV：用盈餘資本化，不需要配息，適用範圍更廣

### EPV vs [[企業價值倍數EV-EBIT與EV-EBITDA|EV/EBITDA]]
- EV/EBITDA：倍數法，需要同業比較找合理倍數
- EPV：絕對估值法，不需要同業比較，但需要估計資本成本

### EPV vs [[Greenblatt魔力公式選股法Magic-Formula-Investing|魔力公式]]
- 魔力公式：用 ROIC + 盈餘殖利率排名選股
- EPV：絕對估值法，計算內含價值並與市值比較

## EPV 的進階應用

### 1. 成長價值分離

Greenwald 進一步將公司價值拆分為三部分：

```
公司價值 = 資產價值 + 盈餘動力價值（EPV） + 成長價值
```

- **資產價值（Asset Value）**：重置成本，即競爭者複製這家公司需要花多少錢
- **EPV**：現有營運的盈餘資本化
- **成長價值**：未來成長的淨現值

如果 EPV > 資產價值，代表公司有[[經濟護城河Economic-Moat|經濟護城河]]——不僅能賺錢，還能賺超過重置成本的報酬。
如果 EPV ≈ 資產價值，代表公司在競爭性均衡狀態，沒有特殊優勢。
如果 EPV < 資產價值，代表公司營運效率低於行業，可能在破壞價值。

### 2. 護城河量化

```
特許經營價值 = EPV - 資產價值
```

這是量化護城河最直接的方法。台積電的 EPV 遠超過其晶圓廠重置成本，代表製程領先和客戶鎖定帶來巨大特許經營價值。

### 3. 價值陷阱識別

如果 EPV < 市值但公司已經成熟、成長率接近零，這就是[[估值陷阱與價值陷阱識別Value-Trap-Detection|價值陷阱]]——市場還在用成長估值，但成長已經消失。

## EPV 的限制

1. **資本成本估計敏感**：資本成本從 8% 改為 9%，EPV 就差 12.5%。這是 EPV 最大的實務挑戰

2. **正常化盈餘主觀**：什麼是「正常」的 EBIT？不同人不同答案，尤其是週期性公司

3. **忽略資產負債表**：EPV 只看盈餘，不看資產品質。一家有大量隱藏資產（如土地）的公司，EPV 可能嚴重低估

4. **不適合虧損公司**：如果公司正在虧損或盈餘極低，EPV 失去意義

5. **忽略成長的價值**：完全忽略成長是 EPV 的特色也是弱點。對於真正能持續高成長的公司（如早期的台積電），EPV 會嚴重低估

## 總結

盈餘動力價值是價值投資工具箱中最獨特的工具——它不預測成長，只看現在。在 AI 熱潮中所有人都在算台積電 5 年後賺多少時，EPV 提供了一個「如果完全不成長，現在值多少」的錨點。如果 EPV 遠低於市值，你知道自己付了多少成長溢價；如果 EPV 高於市值，你可能找到了市場忽略的便宜貨。

實戰上，EPV 最適合配搭[[安全邊際Margin-of-Safety進階實戰|安全邊際]]一起用：用 EPV 算出零成長價值，再要求一定比例的折扣才買進。對於穩定配息的金融股、電信股特別有效，對於高成長科技股則需要謹慎解讀。

## 實戰應用

### 範例：台積電（2330）

假設以下數據（示意）：
- 正常化 EBIT：1.2 兆元
- 稅率：20%
- 調整後盈餘 = 1.2 兆 × (1 - 0.2) = 9600 億
- 資本成本：9%
- EPV = 9600 億 / 0.09 = 10.67 兆元

對比市值（假設 25 兆）：
- EPV / 市值 = 10.67 / 25 = 0.43
- **解讀**：市值只有 43% 來自現有賺錢能力，57% 來自成長預期。以台積電的 AI 超級循環來看可能合理，但代表市場定價高度依賴成長持續

### 範例：中華電（2412）

假設以下數據（示意）：
- 正常化 EBIT：500 億
- 稅率：20%
- 調整後盈餘 = 500 × 0.8 = 400 億
- 資本成本：8%
- EPV = 400 / 0.08 = 5000 億

對比市值（假設 5500 億）：
- EPV / 市值 = 5000 / 5500 = 0.91
- **解讀**：市值接近 EPV，市場幾乎不計入成長預期。以中華電的穩定獲利模式，這代表估值相當合理

## 注意事項

1. **景氣循環股不適用**：DRAM、面板、航運等循環股的「正常化 EBIT」極難估計，EPV 可能嚴重失真。建議用完整循環（5-7 年）的平均 EBIT

2. **高槓桿公司需調整**：負債比高的公司，盈餘波動大，需要用 WACC 而非純權益成本。但 WACC 估計本身也有誤差

3. **台積電等資本密集股**：EPV 不扣除資本支出，對資本密集公司可能高估。可以改用「調整後盈餘 - 維持性資本支出」作為分子（接近自由現金流的概念）

4. **配息穩定公司最適合**：金融股、電信股、公用事業等穩定配息公司，EPV 的估計最可靠，因為盈餘波動小、成長率低

5. **與[[FCF估值模型自由現金流15公式與選股實戰|FCF估值]]交叉驗證**：EPV 基於會計盈餘，FCF 基於現金流。兩者差距大時需要深究原因（可能是盈餘品質問題）
