# 反向DCF估值法 Reverse Engineered DCF

> 正向DCF問「這家公司值多少錢」，反向DCF問「現在的股價隱含了什麼樣的成長預期」——不用猜未來，而是從市場定價反推假設是否合理

## 核心概念

反向DCF（Reverse Engineered DCF）是傳統DCF的鏡像操作。傳統DCF的流程是：預估未來現金流 → 設定折現率 → 算出內在價值 → 與市價比較。反向DCF把流程倒過來：**用當前市價當作DCF的輸出值，反推出市場隱含的增長率和其他假設**。

### 為什麼需要反向DCF

傳統DCF最大的問題是**對假設極度敏感**：

- 增長率從10%改成12%，估值可能翻倍
- 折現率從8%改成10%，估值可能腰斬
- 終值假設的微小變動會導致結果劇烈波動

這導致DCF實務上有一個尷尬的問題：分析師很容易「先有結論再找數字」——想證明股票便宜就調高增長率、調低折現率。反向DCF避免了這個陷阱，因為它不要求你預測未來，而是問你一個更簡單的問題：**市場現在的定價，需要什麼條件才能成立？你相不相信這些條件？**

### 正向DCF vs 反向DCF

- **正向DCF**：輸入假設 → 輸出價值 → 與市價比較
  - 問題：假設太多太敏感，容易自欺欺人
  - 適合：你有很強的產業洞察和預測能力

- **反向DCF**：輸入市價 → 反推假設 → 判斷假設合理性
  - 優勢：不用預測未來，只需判斷市場預期是否合理
  - 適合：大多數投資人——判斷別人是否太樂觀或太悲觀

## 計算方法

### Step 1：設定已知條件

- **當前股價**（市值）：從市場直接取得
- **當前自由現金流（FCF）**：從最新財報取得
- **折現率（WACC）**：用CAPM或行業平均估算，通常8-12%
- **終值增長率（g）**：通常設2-3%（長期GDP成長率+通膨）
- **預測期**：通常5-10年

### Step 2：反推隱含增長率

DCF公式：

```
Price = ∑ [FCF₀ × (1+g)^t / (1+WACC)^t] + TV / (1+WACC)^n
```

其中終值 TV = FCF_n × (1+g) / (WACC - g)

在反向DCF中，Price是已知的（當前市值），我們要反推的是g（隱含增長率）。這通常需要用數值方法（如Excel的Goal Seek或Python的scipy.optimize）求解，因為g同時出現在分子和分母中，無法直接代數求解。

### Step 3：判斷隱含增長率是否合理

反推出g之後，問自己：

- 這個增長率與公司過去的實際增長率相比如何？
- 這個增長率與行業平均相比如何？
- 這個增長率在未來5-10年內是否可持續？
- 公司的護城河能否支撐這個增長率？
- 宏觀環境（人口、GDP、利率）是否支持？

## 實戰應用

### 1. 判斷市場預期是否過度樂觀

假設你分析一家科技公司：
- 當前市值：1兆元
- 當前FCF：200億元
- WACC：10%
- 終值增長率：3%
- 反推結果：市場隱含未來10年年化FCF增長率 = 25%

問題：25%的年化增長率連續10年，有多少公司能做到？歷史上只有極少數公司（如蘋果、亞馬遜）在特定時期實現過。如果你認為這家公司不是下一個蘋果，那市場定價就太樂觀了。

> 相關頁面：[[基本面分析/成長股與價值股投資策略Growth-vs-Value-Investing]] — 成長股的陷阱就是市場隱含增長率過高

### 2. 發現被低估的股票

反向的例子：
- 當前市值：500億元
- 當前FCF：50億元
- WACC：10%
- 終值增長率：3%
- 反推結果：市場隱含未來10年年化FCF增長率 = 2%

問題：一家FCF 50億、ROE 20%、護城河穩固的公司，市場只預期它未來每年增長2%？如果你認為5-8%是合理的，那市場定價就太保守了，存在安全邊際。

> 相關頁面：[[基本面分析/安全邊際Margin-of-Safety進階實戰]] — 反向DCF是量化安全邊際的有效工具

### 3. 比較同業的隱含預期

同一行業的不同公司，反推出的隱含增長率差異可以揭示：
- 市場給A公司隱含增長率15%，B公司只有5%——是A真的比B好三倍，還是市場偏見？
- 隱含增長率最高的公司往往是市場最擁擠的交易——一旦預期未達成，跌幅最大

> 相關頁面：[[基本面分析/同業比較分析選股實戰Peer-Comparison]] — 比較隱含增長率是同業分析的高級應用

### 4. 評估併購溢價的合理性

併購時買方支付溢價，反向DCF可以算出：
- 收購價隱含的目標公司增長率是多少？
- 這個增長率是否需要協同效應才能實現？
- 如果沒有協同效應，溢價是否合理？

### 5. 台股實戰考量

- **台積電**：用反向DCF可以算出市場隱含的未來增長率，判斷當前股價是否已反映AI超級週期
- **高殖利率股**：反向DCF常顯示市場對成熟股的隱含增長率接近零甚至負值——如果你認為它至少能維持現狀，就有安全邊際
- **轉機股**：反向DCF可以算出市場隱含的轉機幅度——需要營收增長多少才能支撐當前股價

> 相關頁面：[[基本面分析/轉機股選股實戰]] — 反向DCF幫助判斷轉機股的市場預期是否合理

## 反向DCF的優勢與局限

### 優勢

1. **避免預測偏誤**：不用猜未來增長率，而是判斷市場的猜測是否合理——判斷別人比預測未來容易
2. **量化市場預期**：把模糊的「市場太樂觀/太悲觀」變成具體的數字——「市場預期25%增長」比「太貴了」有說服力
3. **跨公司可比**：不同公司的隱含增長率可以直接比較，不受產業倍數差異影響
4. **與估值倍數互補**：PE 30倍是貴還是便宜？取決於隱含增長率——反向DCF告訴你PE 30隱含的增長率是多少

### 局限

1. **仍需設定折現率**：WACC的假設仍然主觀，不同WACC反推出的隱含增長率差異大
2. **終值敏感**：終值通常佔DCF價值的60-80%，終值增長率g的假設影響巨大
3. **不適合虧損公司**：FCF為負的公司無法做反向DCF——這恰恰是最需要估值的成長初期公司
4. **不適合週期股**：當前FCF可能在週期頂部或底部，不代表正常水準
5. **忽略選擇權價值**：DCF框架不考慮管理層的彈性選擇（如擴張、縮編、放棄），真實選擇權價值被忽略
6. **假設市場是理性的**：反向DCF假設當前股價至少反映了某種系統性預期，但市場可能只是非理性繁榮或恐慌

## 散戶實戰要點

1. **先做反向DCF再做正向DCF**：先了解市場預期什麼，再決定你同意不同意——比直接做正向DCF更不容易自欺
2. **用區間不用點估計**：WACC設8-12%，看隱含增長率在這個區間內如何變化，而不是假設一個精確值
3. **與歷史增長率對比**：反推出的隱含增長率如果遠高於公司過去5-10年的實際增長率，就要小心
4. **與行業天花板對比**：隱含增長率20%但行業整體只增長5%——公司必須搶市佔才能達標，風險很大
5. **配合PE/PEG交叉驗證**：反向DCF隱含增長率10% + PEG 2.0 = 市場為10%增長支付了過高溢價

> 相關頁面：[[基本面分析/PEG本益成長比]]、[[基本面分析/本益比進階判讀PE-Ratio-Advanced]]

6. **對AI概念股特別有用**：2026年AI熱潮中很多股票本益比極高，反向DCF可以算出市場隱含了多麼瘋狂的增長假設
