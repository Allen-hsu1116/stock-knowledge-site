# M2 貨幣供給與市場流動性 Money Supply M2

> 貨幣供給是市場的血液系統，M2 是衡量系統內流動性總量的核心指標。聯準會看 M2 判斷通膨壓力與經濟動能，投資人看 M2 判斷資金面是寬鬆還是緊縮。

## 什麼是 M2

**M2 是廣義貨幣供給量**，涵蓋經濟體中所有可立即或短期內動用的購買力。

- **M1（狹義）**：現金 + 活期存款 + 支票存款 — 隨時可花的錢
- **M2（廣義）= M1 +**：
  - 儲蓄存款（Savings deposits）
  - 小額定期存款（Small-denomination time deposits，<10萬美元）
  - 零售貨幣市場基金（Retail money market funds）

簡單說，M1 是「口袋裡的錢」，M2 是「口袋裡的錢 + 銀行裡隨時可以領出來的錢」。

## 為什麼 M2 對股市很重要

### 1. M2 成長率 = 流動性溫度計

- **M2 年增率上升** → 銀行放貸增加 → 資金充裕 → 股市有柴火
- **M2 年增率下降** → 銀行收傘 → 資金收緊 → 股市缺血
- **M2 負成長** → 歷史上極為罕見，通常出現在重大信用收縮期

### 2. M2 與通膨的關係

**貨幣數量理論（Quantity Theory of Money）**：MV = PQ

- M = 貨幣供給
- V = 貨幣流通速度（Velocity）
- P = 物價水準
- Q = 實質產出（GDP）

當 V 和 Q 相對穩定時，M 增加最終會推升 P（通膨）。這就是為什麼 2020-2021 年美國 M2 飆升 25% 後，2022 年出現 40 年來最高通膨的邏輯基礎。

### 3. M2 流速（Velocity）是隱藏變數

M2 本身不說明全部故事，**流速**才是關鍵：

- **高流速**：錢轉得快，同樣的 M2 創造更多經濟活動和通膨壓力
- **低流速**：錢躺在銀行不動，M2 再多也是死水
- 2008 年後 M2 大增但流速持續下降，所以通膨沒起來
- 2021 年流速觸底反彈，疊加高 M2，通膨一發不可收拾

### 4. M2 與資產價格的領先關係

歷史數據顯示 M2 成長率變化**領先股市約 6-12 個月**：

- M2 成長率見頂 → 股市通常在 6-12 個月後見頂
- M2 成長率見底 → 股市通常在 6-12 個月後見底
- 但 QE 時代後這個領先關係變得模糊，因為聯準會直接擴表繞過銀行體系

## 台灣的 M2 觀察

### 台灣貨幣供給定義

- **M1B**（台灣用 M1B 而非 M1）：現金 + 活期存款 + 支票存款 + 活期儲蓄存款
- **M2** = M1B + 定期存款 + 定期儲蓄存款 + 外匯存款 + 郵政存款

### 台灣 M2 與股市的實戰觀察

- **M1B 年增率 > M2 年增率**：資金從定存流向活存，市場資金活絡，股市通常偏多
- **M1B 年增率 < M2 年增率**：資金從活存流向定存，市場資金保守，股市通常偏空
- 這個**黃金交叉/死亡交叉**是台股傳統的資金面訊號
- 但近年 ETF 規模暴增（從 5700 億到 5 兆以上），這個訊號的可靠性下降，因為資金流向 ETF 而非傳統存款

### 外資匯入與 M2

- 外資匯入買台股 → 央行買匯放出台幣 → M2 被動擴張
- 外資匯出賣台股 → 央行賣匯收回台幣 → M2 被動收縮
- 所以外資賣超和 M2 收縮是硬幣兩面

## 實戰應用

### 投資人該如何追蹤 M2

1. **看美國 M2 年增率**：聯準會每週四公布 H.6 報告，關注年增率趨勢而非絕對值
2. **看台灣 M1B vs M2 交叉**：央行每月公布，關注是否有交叉訊號
3. **搭配聯準會資產負債表**：M2 擴張靠銀行放貸，QE 直接擴表則繞過銀行體系
4. **觀察貨幣流速**：GDP / M2 就是簡單的流速指標

### M2 與其他指標的搭配

- **M2 + 殖利率曲線**：M2 擴張 + 殖利率曲線陡峭 = 最寬鬆環境
- **M2 + VIX**：M2 收縮 + VIX 上升 = 雙重壓力訊號
- **M2 + 信用利差**：M2 收縮 + 信用利差擴大 = 信用收縮確認

### M2 的限制

- **QE 扭曲了 M2 的意義**：2008 年後聯準會擴表不一定反映在 M2 上，因為超額準備金堆在聯準會而不進入銀行體系
- **金融創新稀釋 M2**：穩定幣、DeFi 等新型流動性不完全計入 M2
- **全球化使 M2 參考性下降**：美元是全球貨幣，美國 M2 不能完全反映全球美元流動性，需看 Eurodollar 市場

## 歷史案例

### 2020 年 COVID 期間

- 聯準會無限 QE + 財政刺激 2 兆美元 → M2 年增率飆至 25% 歷史最高
- 結果：2020-2021 股市大漲，但 2022 年通膨爆發
- 教訓：M2 暴增的後果不會立即顯現，但一定會來

### 2022-2023 年緊縮

- 聯準會升息 + QT → M2 出現史上首次負成長
- 結果：2022 年股市大跌，但 2023 年因 AI 熱潮股市仍反彈
- 教訓：M2 收縮不必然等於股市崩跌，產業催化劑可以對抗流動性收縮

### 台灣 2025-2026 年

- 超額儲蓄率 26.9% 創 1951 年新高，M2 持續擴張
- ETF 規模從 5700 億暴增至 5 兆，第四法人打死不賣
- 這是台股在高 M2 環境下的特殊支撐力量
