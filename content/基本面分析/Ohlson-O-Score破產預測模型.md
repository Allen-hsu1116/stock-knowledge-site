# Ohlson O-Score 破產預測模型

> Ohlson O-Score 由 James Ohlson 於 1980 年發表，是繼 [[基本面分析/Altman-Z-Score破產預測模型|Altman Z-Score]] 之後最具影響力的破產預測模型之一。與 Z-Score 使用線性判別分析（MDA）不同，Ohlson 採用 **Logit 迴歸**（邏輯迴歸），直接輸出破產機率，這讓結果更容易解讀——你拿到的是一個 0~1 的機率值，而不是一個需要對照區間的分數。

## 核心概念

Ohlson O-Score 由 James Ohlson 於 1980 年發表，是繼 [[基本面分析/Altman-Z-Score破產預測模型|Altman Z-Score]] 之後最具影響力的破產預測模型之一。與 Z-Score 使用線性判別分析（MDA）不同，Ohlson 採用 **Logit 迴歸**（邏輯迴歸），直接輸出破產機率，這讓結果更容易解讀——你拿到的是一個 0~1 的機率值，而不是一個需要對照區間的分數。

Ohlson 的另一個創新是引入了 **「兩年內是否曾虧損」和「淨利為負」等二元觸發變數**，讓模型能捕捉非線性的風險觸發機制。

## 模型公式

**O-Score = -1.32 - 0.407×ln(TA) + 6.03×(TL/TA) - 1.43×(WC/TA) + 0.0757×(CL/CA) - 2.37×(NI/TA) - 1.83×(FFO/TL) + 0.521×(NI_t/NI_{t-1}) - 0.464×DUMMY1 - 1.23×DUMMY2**

然後代入 Logit 轉換：

**P(破產) = e^(O-Score) / (1 + e^(O-Score)) = 1 / (1 + e^(-O-Score))**

### 變數定義

- **TA** = 總資產（Total Assets）
- **TL** = 總負債（Total Liabilities）
- **WC** = 營運資金 = 流動資產 - 流動負債（Working Capital）
- **CA** = 流動資產（Current Assets）
- **CL** = 流動負債（Current Liabilities）
- **NI** = 淨利（Net Income）
- **FFO** = 營運資金流量 = 營業現金流（Funds From Operations）
- **NI_t / NI_{t-1}** = 本期淨利 / 前期淨利（淨利變動率）
- **DUMMY1** = 1 if NI < 0（過去兩年至少一年虧損），否則 0
- **DUMMY2** = 1 if TL > TA（資不抵債），否則 0

### 各係數的經濟含義

- **ln(TA) 係數 -0.407**：規模越大越不容易破產（大公司有更多資源緩衝）
- **TL/TA 係數 +6.03**：負債比率越高破產機率越高（權重最大，最關鍵的變數）
- **WC/TA 係數 -1.43**：營運資金佔總資產比越高越安全
- **CL/CA 係數 +0.0757**：短期償債壓力越大越危險
- **NI/TA 係數 -2.37**：資產報酬率越高越安全
- **FFO/TL 係數 -1.83**：現金流對負債的覆蓋能力越強越安全
- **淨利變動率 +0.521**：獲利成長（正值）反而提高破產機率？Ohlson 認為這可能是因為從虧損轉盈的波動期，公司仍處於不穩定狀態
- **DUMMY1 係數 -0.464**：曾有虧損紀錄會提高破產風險
- **DUMMY2 係數 -1.23**：資不抵債是極度危險訊號

## 破產機率判讀

- **P < 0.038（3.8%）**：安全區域，破產風險極低
- **0.038 ~ 0.5**：灰色地帶，需進一步審查
- **P > 0.5（50%）**：高危險區域，破產風險顯著

Ohlson 原始論文中以 0.038 作為分界點，是基於成本最小化的切點（Type I 和 Type II 誤差的平衡）。

## 與 Altman Z-Score 的比較

**Altman Z-Score：**
- 方法：多變量線性判別分析（MDA）
- 輸出：分數值，需對照安全/灰色/危險三區間
- 假設：常態分佈、等變異數（統計假設較嚴格）
- 適用：原始版針對上市製造業，後續有 Z'、Z'' 版本擴展
- 優點：歷史悠久、引用量大、行業適配版多

**Ohlson O-Score：**
- 方法：Logit 迴歸（邏輯迴歸）
- 輸出：直接輸出破產機率（0~1），解讀更直覺
- 假設：不需要常態分佈假設，統計假設更寬鬆
- 適用：原始版就用全產業樣本，適用範圍更廣
- 優點：引入二元觸發變數（虧損、資不抵債）、機率輸出直覺
- 缺點：對「淨利變動率」的係數解讀不夠直覺

**實戰建議**：兩個模型一起用，如果 Z-Score 和 O-Score 都亮紅燈，破產風險的可信度就大幅提升。這是多重確認的基本邏輯。

## 與其他財務風險模型的關聯

- **[[基本面分析/Altman-Z-Score破產預測模型|Altman Z-Score]]**：最經典的破產預測，MDA 方法，本模型的前身與競爭者
- **[[基本面分析/Beneish-M-Score財報舞弊偵測|Beneish M-Score]]**：偵測財報舞弊，與破產預測互補——舞弊的公司往往即將破產才需要造假
- **[[基本面分析/Piotroski-F-Score進階實戰|Piotroski F-Score]]**：評估財務體質改善/惡化，F-Score 低分可作為 O-Score 的預警先行指標
- **[[基本面分析/盈餘品質分析|盈餘品質分析]]**：低盈餘品質會影響 NI/TA 的可信度，需交叉判讀

## 實戰應用

### 1. 排雷選股
在選股流程中加入 O-Score 篩選：
- 計算候選標的的破產機率 P
- 排除 P > 0.1（10% 以上）的個股
- 與 [[基本面分析/盈餘品質分析|盈餘品質分析]] 交叉確認

### 2. 轉機股風控
轉機股通常伴隨虧損紀錄（DUMMY1=1）和高負債（TL/TA 高），O-Score 會自然給出較高的破產機率：
- 轉機股投資必須檢查 O-Score，確認破產風險在可控範圍
- 如果 DUMMY2=1（資不抵債），不論題材多誘人，都應極度謹慎

### 3. 信用風險評估
對於持有公司債或考慮債券投資的人：
- O-Score 可直接作為信用風險量化指標
- P > 0.2 的公司債應要求更高的信用利差

### 4. 與 F-Score 結合的雙重確認
- **F-Score 低分（≤3）+ O-Score 高（P > 0.1）**：財務體質惡化 + 破產風險升高 = 強烈賣出訊號
- **F-Score 高分（≥7）+ O-Score 低（P < 0.05）**：財務體質改善 + 破產風險低 = 安全邊際高的標的

## 台股適用注意事項

1. **會計準則差異**：Ohlson 使用美國 GAAP 數據建立，台股使用 IFRS。FFO（營運資金流量）在 IFRS 下對應「營業活動現金流量」，定義接近但需注意分類差異
2. **產業適配**：金融業的資產負債結構與製造業完全不同（TL/TA 天生就高），O-Score 直接套用金融股會失真，建議金融業使用 [[基本面分析/淨負債EBITDA槓桿倍數|其他風控指標]]
3. **台股特有風險**：台股有 [[籌碼面分析/大股東質押斷頭連鎖效應|大股東質押]] 斷頭風險，這在 O-Score 模型中未涵蓋，需額外考量
4. **數據頻率**：台股季報就有完整數據，可每季更新 O-Score，建立破產風險的時間序列追蹤

## 模型局限

1. **樣本偏誤**：1980 年的美國上市公司數據，產業結構與現代差異大
2. **忽略市場資訊**：純財報數據，不考慮股價、市場情緒、信用利差等市場訊號
3. **淨利變動率係數矛盾**：NI_t/NI_{t-1} 係數為正，意味獲利成長反而提高破產機率，這在直覺上不合理（Ohlson 自己也承認這可能是樣本噪音）
4. **不適用新創/虧損公司**：DUMMY1=1 會被觸發，但很多新創雖然虧損卻有強大現金儲備
5. **不考慮無形資產**：科技公司的研發投入、品牌價值等無形資產在 TA 中被低估

## 總結

Ohlson O-Score 是破產預測領域的里程碑，它的貢獻在於：
- 用 Logit 迴歸取代 MDA，統計假設更寬鬆
- 直接輸出破產機率，解讀門檻低
- 引入二元觸發變數，捕捉非線性風險跳變

實戰中它不應單獨使用，而是與 Z-Score、F-Score、M-Score 構成多重確認的財務風險評估體系。當多個模型同時亮紅燈時，才是真正需要撤退的訊號。
