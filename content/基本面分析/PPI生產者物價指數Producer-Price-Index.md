# PPI 生產者物價指數 Producer Price Index

> CPI 的上游領先指標，生產端通膨壓力的第一手訊號。

## 什麼是 PPI

PPI（Producer Price Index，生產者物價指數）衡量國內生產者出廠價格的變動，是 CPI 的上游指標。1978 年以前稱為批發物價指數（WPI, Wholesale Price Index），由美國勞工統計局（BLS）每月公布。

- **涵蓋範圍**：採礦、製造、農業、漁業、林業、天然氣、電力、廢料等生產端
- **不包括**：進口商品
- **調查規模**：超過 16,000 家企業提供約 64,000 個價格報價
- **公布時間**：每月中旬，通常在 CPI 公布後 1-2 個工作天

## PPI vs CPI 的關係

- **PPI 是領先指標**：生產端成本上升 → 企業要么吸收成本（利潤壓縮）、要么轉嫁給消費者（CPI 上升）
- **時間差**：PPI 通常領先 CPI 約 1-3 個月
- **傳導不一定 100%**：企業競爭激烈時無法完全轉嫁，PPI 上漲但 CPI 不漲代表企業利潤被壓縮
- **核心 PPI**：同樣剔除食品和能源，觀察趨勢性生產端通膨

## PPI 的兩種成本處理

當生產成本上升時，企業面臨兩個選擇：
1. **吸收成本**：維持售價不變 → 毛利率下降 → 股東吃虧但消費者無感
2. **轉嫁成本**：提高售價 → 消費者感受通膨 → 但企業利潤率可能維持

這個選擇取決於：
- 企業的定價能力（護城河強弱）
- 產業競爭程度
- 需求彈性（必需品 vs 非必需品）
- 供給是否吃緊

## PPI 對股市的影響

- **PPI 高於預期**：生產端通膨壓力大 → 企業成本上升 → 如果無法轉嫁則利潤壓縮 → 股市承壓
- **PPI 低於預期**：成本壓力減輕 → 企業利潤空間擴大 → 股市正面
- **PPI 上漲但 CPI 不漲**：企業正在吸收成本，利潤率壓縮，是盈餘下修的前兆
- **PPI 與 CPI 同漲**：通膨壓力全面上升，聯準會升息壓力大

## PPI 觀察重點

- **年增率（YoY）**：最常被引用
- **核心 PPI**：剔除食品能源後的趨勢性指標
- **PPI-CPI 剪刀差**：PPI 漲幅大於 CPI → 企業利潤壓縮；PPI 漲幅小於 CPI → 企業利潤擴張
- **細項關注**：原物料（能源、金屬、化學品）是 PPI 的主要驅動
- **預期差**：與市場共識的差距才是驅動市場的力量

## PPI 的局限

- **不含服務業**：PPI 主要衡量商品生產端，服務業佔美國 GDP 80% 但 PPI 涵蓋有限
- **製造業占比下降**：製造業在 GDP 中的占比持續下降，PPI 的代表性也在降低
- **不反映進口價格**：進口商品價格變動不在 PPI 涵蓋範圍
- **品質調整**：新產品、品質提升的價格調整存在技術困難

## 散戶實戰要點

- PPI 是 CPI 的先行指標，看 PPI 可以提前判斷 CPI 走勢
- PPI 報告日（通常在 CPI 後 1-2 天）也是高波動日
- PPI 上漲但 CPI 不漲時，要注意企業盈餘下修風險
- 原物料相關個股對 PPI 特別敏感（石化、鋼鐵、水泥）
- 不要只看 PPI 數字，要看 PPI 與 CPI 的剪刀差判斷企業利潤方向
