# Dechow-Dichev應計項目品質模型 Accrual Quality Score

> 應計項目偏離現金流的程度越大，盈餘品質越差——Dechow-Dichev模型用殘差衡量應計項目與現金流的匹配度，殘差越小代表盈餘越能反映真實經濟活動，是學術界最被廣泛引用的盈餘品質量化模型之一。

## 核心概念

### 應計項目品質是什麼

[[基本面分析/盈餘品質分析|盈餘品質]]衡量帳面盈餘有多少是「真實現金」、有多少是「會計調整」。應計項目（Accruals）是兩者之間的橋樑——公司認列了收入但還沒收到現金，或認列了費用但還沒付錢，這些時間差就是應計項目。

**關鍵洞察**：在完美的會計下，應計項目最終會轉化為現金流。如果應計項目與未來現金流的偏差持續很大，代表管理層可能在利用應計項目操縱盈餘。

Dechow、Kothari和Watts（1999）以及Dechow和Dichev（2002）提出了量化這種偏差的方法，成為學術界盈餘品質研究的基石。

### Dechow-Dichev模型公式

**原始模型（DD模型）**：

```
Accruals_Quality = |ΔWC_t - (CFO_{t+1} + CFO_t - CFO_{t-1}) / 2|
```

其中：
- ΔWC_t = 第t期營運資金變動（流動資產變動 - 流動負債變動 - 現金變動 + 短期借款變動）
- CFO = 來自營業活動的現金流
- 取絕對值，殘差越小代表應計項目品質越好

**改良模型（DD Modified，McNichols 2002加入總營收變動與PPE）**：

```
ΔWC_t = α₀ + α₁·CFO_{t-1} + α₂·CFO_t + α₃·CFO_{t+1} + α₄·ΔRev_t + α₅·PPE_t + ε_t
```

- ΔRev_t = 當期營收變動
- PPE_t = 固定資產（廠房設備）
- ε_t 即為應計項目品質殘差，取絕對值越小越好

### 與Sloan應計項目異象的區別

[[基本面分析/應計項目異象Accrual-Anomaly|Sloan應計項目異象]]關注的是「高應計項目公司未來報酬偏低」這個市場定價偏差，核心邏輯是市場會高估高應計公司的盈餘持續性。

Dechow-Dichev模型關注的是「應計項目本身品質」這個更上游的問題——不是所有高應計都是壞的，但如果應計項目與現金流的匹配關係差，那無論應計項目高低都代表盈餘品質有問題。

**簡單說**：Sloan看「應計項目多不多」，Dechow-Dichev看「應計項目準不準」。

## 台股應用限制

### 數據取得與計算門檻

1. **需要5年以上連續財報數據**：台灣小型上市公司可能歷史不足或早期數據品質差
2. **IFRS轉換斷層**：2013年台灣全面採用IFRS，IFRS前後的營運資金定義可能不一致，建議只用2013年後數據
3. **合併報表vs個體報表**：集團企業建議用合併報表，但要注意[[基本面分析/合併財報與非控制權益判讀|非控制權益]]的影響
4. **產業特性差異**：營建業、生技業的應計項目結構與一般製造業差異大，不建議跨產業直接比較殘差絕對值

### 台股免費數據來源

- **TWSE公開資訊觀測站**：可下載歷年資產負債表和現金流量表
- **MOPS（公開資訊觀測站）**：可查詢簡明財務報表四季數據
- **台灣經濟新報（TEJ）**：學術研究最常用，但需付費
- **Python計算**：可用pandas和statsmodels實現OLS回歸，5年數據約需20分鐘手動整理

## 實戰應用

### 五步計算流程

**步驟一：收集數據（至少5年）**
- 營運資金變動（ΔWC）：從資產負債表取得流動資產、流動負債、現金、短期借款
- 營業現金流（CFO）：從現金流量表取得
- 營收變動（ΔRev）：從損益表取得前後兩期營收差
- 固定資產（PPE）：從資產負債表取得

**步驟二：計算營運資金變動**
```
ΔWC = (流動資產_t - 流動資產_{t-1}) - (現金_t - 現金_{t-1}) 
      - (流動負債_t - 流動負債_{t-1}) + (短期借款_t - 短期借款_{t-1})
```

**步驟三：用OLS回歸**
- 將ΔWC對CFO_{t-1}、CFO_t、CFO_{t+1}、ΔRev_t、PPE_t做回歸
- 需要至少5年數據（因為回歸需要t+1的現金流，實際需要至少5年完整數據）

**步驟四：計算殘差**
- 殘差ε_t = 實際ΔWC_t - 回歸預測的ΔWC_t
- 取絕對值|ε_t|，這就是應計項目品質分數

**步驟五：跨公司比較**
- 將|ε_t|除以總資產進行規模標準化
- 在同產業內排名，排名越前面（殘差越小）代表品質越好
- 跨年趨勢比絕對值更重要——殘差連年擴大是最大警訊

### 四級判讀標準

**A級（殘差<總資產3%）**：盈餘品質優良
- 應計項目與現金流高度匹配
- 帳面盈餘可信度高，可直接用於估值

**B級（殘差3-5%）**：盈餘品質良好
- 存在少量時間差但屬正常營運
- 可搭配其他指標確認

**C級（殘差5-8%）**：盈餘品質堪憂
- 應計項目與現金流明顯不匹配
- 需深入檢查是否存[[基本面分析/盈餘管理手法識別與判讀|盈餘管理]]

**D級（殘差>8%）**：盈餘品質危險
- 高度可能存在盈餘操縱
- 應搭配[[基本面分析/Beneish-M-Score財報舞弊偵測|Beneish M-Score]]和[[基本面分析/Altman-Z-Score破產預測模型|Altman Z-Score]]交叉驗證

### 與其他盈餘品質工具的系統整合

Dechow-Dichev模型不應單獨使用，建議與以下工具組合：

- **搭配[[基本面分析/營業現金流對淨利比判斷盈餘品質OCF-NI-Ratio|OCF/NI Ratio]]**：OCF/NI<0.7時即使DD殘差不大也需警覺
- **搭配[[基本面分析/Piotroski-F-Score進階實戰|Piotroski F-Score]]**：F-Score<5 + DD殘差偏高 = 雙重紅旗
- **搭配[[基本面分析/應計項目異象Accrual-Anomaly|Sloan應計項目比]]**：Sloan比>10% + DD殘差偏高 = 應計項目又多又差，最高危險等級
- **搭配[[基本面分析/現金流量表間接法調整項目判讀Indirect-Method-Adjustments|間接法調整分析]]**：看具體哪個調整項目造成殘差

## 注意事項

### 五大使用陷阱

**陷阱一：殘差小不等於沒有盈餘管理**
- 管理層可能同時操縱應計項目和現金流（如透過關聯交易同時調整收入認列和現金回收）
- 正解：搭配[[關聯交易判讀Related-Party-Transaction-Analysis|關聯交易分析]]

**陷阱二：行業特性造成系統性偏差**
- 資本密集產業的PPE項可能主導回歸結果
- 正解：分產業做回歸，或加入產業固定效應

**陷阱三：一次性的大額應計項目**
- 併購、重整、資產減損等一次性事件可能造成年度殘差暴增
- 正解：剔除異常年度，或用3年平均殘差

**陷阱四：只看一年不看趨勢**
- 單年殘差可能受會計估計變更影響
- 正解：至少看3年趨勢，連年上升的殘差才是真實警訊

**陷阱五：把模型當萬能照妖鏡**
- Dechow-Dichev衡量的是「應計與現金的匹配度」，不直接偵測造假
- 正解：與[[基本面分析/Beneish-M-Score財報舞弊偵測|Beneish M-Score]]互補使用，前者看品質，後者看造假
