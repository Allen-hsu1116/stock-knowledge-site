# 營收季節性分析與時間序列判讀

> 台股每月10號公告月營收，讀懂季節性模式才能分辨「正常波動」和「趨勢改變」

## 核心概念

**營收季節性（Revenue Seasonality）**是指企業營收在一年內呈現規律性的高低起伏。台股獨步全球的月營收公告制度（每月10號前公告上月合併營收），讓投資人可以追蹤逐月變化，但如果不懂季節性，很容易把正常的淡季低迷誤判為衰退，或把旺季高峰當成成長。

### 為什麼季節性很重要

1. **避免誤判**：QoQ衰退20%可能是正常淡季而非經營惡化
2. **提前佈局**：在旺季前1-2個月卡位，在淡季前減碼
3. **驗證管理層說法**：「第二季是傳統淡季」是真的還是藉口？
4. **捕捉異常訊號**：旺季不旺是壞訊號、淡季不淡是好訊號

### 台股主要產業季節性模式

**電子零組件 / 半導體**
- Q1（1-3月）：傳統淡季，農曆年工作天數少，2月最低
- Q2（4-5月）：逐步回溫，客戶開始拉貨備庫存
- Q3（7-9月）：旺季啟動，下半年聖誕節/年終備貨
- Q4（10-12月）：高檔或略降，視出貨节奏而定
- 特徵：上下半年比約 40:60

**IC設計**
- Q1淡季、Q2開始設計打入客戶、Q3-Q4出貨放量
- 新晶片Tape-out到量產約6-9個月，營收有遞延效應

**PCB / 被動元件**
- 跟終端產品出貨節奏高度相關
- 上半年淡、下半年旺，但被動元件AI需求正在改變傳統季節性

**塑化 / 紡纖（景氣循環股）**
- 跟原油報價和終端需求聯動，季節性不明顯
- 更重要的是看報價趨勢而非季節

**食品 / 飲料**
- Q2-Q3夏季飲料旺季、Q4年節禮盒、Q1元宵節後淡季
- 季節性非常規律，YoY比QoQ更有參考價值

**營建**
- 交屋認列集中在Q3-Q4（年底前交屋入帳壓力）
- Q1-Q2通常營收極低，不能單看月營收判斷

**零售 / 百貨**
- Q4年節採購旺季、Q2母親節檔期、Q3相對淡
- 會員日/週年慶集中在9-11月

## 實戰應用

### 季節性分析四步法

**Step 1：建立歷史季節性基準**

至少收集3年以上月營收數據，計算：
- **月均營收比值**：每月營收 / 年平均月營收（正常化後）
- **月环比指數**：每月營收 / 上月營收的中位數
- **上下半年比**：H1/H2的營收比例

範例（半導體公司典型模式）：
- 1月：85%、2月：60%（春節）、3月：95%、4月：100%、5月：105%
- 6月：110%、7月：115%、8月：125%、9月：130%
- 10月：120%、11月：110%、12月：105%

**Step 2：計算季節調整後營收**

```
季節調整後營收 = 實際營收 / 季節指數
```

- 季節調整後營收上升 → 真正的成長趨勢
- 季節調整後營收下降 → 真正的衰退趨勢
- 季節調整後營收持平 → 只有季節性波動，趨勢不變

**Step 3：異常訊號判讀**

**旺季不旺（最嚴重的警示訊號）**
- 定義：旺季月份營收低於過去3年同月平均的90%
- 意義：終端需求出問題或客戶轉單
- 行動：確認是個別公司問題還是產業問題，如果是產業問題 → 減碼

**淡季不淡（正面訊號）**
- 定義：淡季月份營收高於過去3年同月平均的110%
- 意義：新產品放量、客戶提前拉貨、或需求結構性增長
- 行動：確認原因是否可持續，如果是 → 提前佈局

**春節效應校正**
- 2月營收必然偏低（工作天數少），直接用QoQ比較會失真
- 正確做法：用2月營收 / 2月工作天數 與 1月營收 / 1月工作天數 比較
- 或直接跳過2月，比較1月vs3月

**Step 4：預測與驗證**

- 基於季節性模式預估下月營收範圍
- 公告後比對：在預估範圍內=符合預期、超出=異常需追查
- 連續2個月超出預估範圍 → 趨勢可能改變

### 時間序列判讀三維度

**1. 趨勢（Trend）**
- YoY成長率的方向和速度
- MA3（3個月移動平均）的斜率
- 營收移動平均線（5月線、10月線）的多空排列

**2. 季節性（Seasonality）**
- 每年重複的模式
- 用季節指數量化各月份的相對強弱
- 季節調整後數據去除季節性看純趨勢

**3. 不規則變動（Irregular Component）**
- 突發事件（地震、罷工、客戶臨時大單）
- 通常1-2個月後回歸正常
- 如果3個月以上未回歸 → 可能代表結構性變化

### 台股月營收公告效應

**公告日效應**
- 營收創歷史新高：公告後5天上漲機率65%
- 營收低於預期：公告後5天下跌機率70%
- 最佳買點：營收超預期 + 股價尚未反映

**公告日曆**
- 每月10號前公告（遇假日順延）
- 10號當天盤後公告 → 影響隔天開盤
- 1-9號已有市場預期在醞釀

## 注意事項

- **2月數據必須校正**：春節效應讓2月數據不可直接比較，至少用日均營收校正
- **單月數據噪音大**：一個月的營收波動可能是客戶拉貨節奏，連續3個月趨勢才可靠
- **YoY優先於QoQ**：YoY自動消除季節性，QoQ需要季節調整後才有意義
- **合併營收優先**：個別公司的合併營收才是集團真實規模，單一子公司可能扭曲
- **產業季節性正在改變**：AI供應鏈的全年均勻出貨模式正在改寫傳統電子業的季節性
- **景氣循環 > 季節性**：當整體景氣下行時，旺季可能一樣衰退；反之上行時淡季也會成長
- **營收不等於獲利**：營收成長但如果毛利率壓縮或費用暴增，獲利可能不增反減
