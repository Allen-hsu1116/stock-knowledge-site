# Repo 市場與附買回操作 Repurchase Agreement

> 金融體系的影子銀行血脈——每天1兆美元的交易量讓它成為比傳統存款更龐大的短期資金市場，2008年金融海嘯的引爆點就在這裡

## 核心概念

### 定義

附買回操作（Repurchase Agreement，簡稱 Repo）是一種**有擔保的短期借貸**：交易一方賣出證券給另一方，並約定在未來某個日期以稍高的價格買回。價差就是借貸的利息，證券就是抵押品。

- **Repo（附買回）**：賣出證券→拿錢→之後買回 = **借錢方**
- **Reverse Repo（附賣回）**：買入證券→付錢→之後賣回 = **借出錢方**
- **Repo Rate**：借貸的年化利率 = (買回價 - 賣出價) / 賣出價 × 365 / 天數
- **Haircut（折價/估值扣減）**：抵押品市值超過借貸金額的部分，例如借80元、抵押品值100元，haircut 就是20%

### 為什麼不是「貸款」？

法律上 Repo 是一筆「賣斷+買回」的兩筆交易，不是貸款。這個結構設計的關鍵好處：

- **破產保護**：如果借款方違約，貸款方直接持有抵押品（證券），不需要走破產程序的自動停止令
- **法律所有權轉移**：抵押品的法律所有權在交易期間確實轉移給貸款方
- **稅務處理**：不視為處置和回購，而是一筆交易

## 市場結構

### 參與者

- **貸款方（出錢的）**：貨幣市場基金、保險公司、退休基金、銀行（有富裕資金的）
- **借款方（需要錢的）**：投資銀行、避險基金、Primary Dealer（一級交易商）
- **美國公債是最主要抵押品**：流動性最高、信用風險最低、最容易在市場上變現

### 三種交易類型

1. **三方 Repo（Tri-party Repo）**：由第三方清算機構（如 BNY Mellon）提供託管、監控和結算服務。2024年美國日均交易量約4000億美元
2. **一般抵押融資（GCF Repo）**：透過固定收益清算公司（FICC）清算，交易商之間的匿名撮合
3. **雙邊 Repo（Bilateral Repo）**：交易雙方直接成交，可透過 FICC DVP 服務清算或完全自行結算

### 市場規模

- 美國 Repo 市場日均擔保品交易量約**1兆美元**
- 2004年底美國 Repo 市場規模達5兆美元
- 2008年金融海嘯後一度萎縮，2010年中期恢復並超越危機前水平
- [[基本面分析/SOFR擔保隔夜融資利率Secured-Overnight-Financing-Rate|SOFR]] 就是基於這個市場的交易數據計算

## 對股市的影響

### Repo 市場壓力 = 股市前兆警訊

Repo 市場是金融體系的「血液循環系統」，當它出問題，股市必然受衝擊：

### 2008年金融海嘯的真正引爆點

- 投資銀行（Bear Stearns、Lehman Brothers）大量依賴 Repo 市場融資
- 當次貸問題浮現，抵押品（MBS）價值下跌，貸款方要求更高的 haircut
- Haircut 從3%升至20%+，等於借款方需要追加大量擔保品
- 追加不出擔保品→融資斷裂→被迫變賣資產→價格進一步下跌→惡性循環
- **這就是「Repo Run」**，Yale 經濟學家 Gary Gorton 稱之為「影子銀行的銀行擠兌」

### 2019年9月 Repo 危機

- SOFR 從2.25%飆至5.25%，而 [[基本面分析/聯邦基金利率Federal-Funds-Rate|聯邦基金利率]] 維持不動
- 原因：企業繳稅日+國債結算日重疊，銀行體系準備金突然短缺
- 聯準會緊急介入，這是2008年以來首次直接向 Repo 市場注入流動性
- **股市教訓**：那天 S&P 500 沒怎麼跌，但如果聯準會沒介入，流動性枯竭會迅速蔓延

### Repo 與 QT 的危險組合

- [[基本面分析/QT量化緊縮與聯準會資產負債表Quantitative-Tightening|QT]] 縮減聯準會資產負債表→銀行準備金減少→Repo 市場可借資金減少
- 當準備金降到某個臨界點（目前估計2.5-3兆美元），Repo 市場可能再次出現2019年式壓力
- 2026年聯準會在 QT 過程中密切監控準備金水平，必要時暫停或減速縮表

### 觀察指標

- **SOFR-EFFR 利差**：SOFR 大幅高於 EFFR 代表 Repo 市場壓力，類似 [[基本面分析/TED-Spread泰德利差與銀行間信用壓力TED-Spread|TED Spread]] 的功能
- **ON RRP 餘額**：餘額下降代表資金從聯準會回流市場，流動性改善；餘額上升代表市場資金過剩無去處
- **聯準會 Repo 操作量**：聯準會主動提供 Repo 代表市場資金不足，是流動性注入訊號
- **Haircut 變化**：抵押品 haircut 突然上升代表貸款方風險偏好下降，信用收縮開始

## 對台股的影響

### 間接但重要
- **全球美元流動性**：Repo 市場是美元流動性的樞紐，壓力上升→全球美元借貸成本上升→外資減持新興市場資產
- **外資借貸成本**：外資用 Repo 市場融資再投入台股，Repo 利率上升直接侵蝕套利空間
- **金融股曝險**：台灣金融機構持有美元資產，Repo 市場波動影響其美元資產的融資成本和估值

## 歷史重大事件

- **1982年 Drysdale 倒閉**：因 accrued interest 計算問題導致 Chase Manhattan 虧損2.85億美元
- **1985年 ESM 倒閉**：引發俄亥俄州 Home State Savings Bank 倒閉和銀行擠兌
- **2008年 Repo Run**：金融海嘯中投資銀行的影子銀行擠兌
- **2019年9月 Repo 危機**：聯準會2008年來首次緊急注入 Repo 市場
- **2020年3月 COVID 衝擊**：Repo 市場再次承壓，聯準會大幅擴張操作

## 實戰判讀要點

- **Repo 市場是流動性的地下水層**：表面平靜不代表底下沒問題，一旦壓力浮現往往來勢洶洶
- **觀察 SOFR 異常跳升**：比 VIX 更早反映信用市場壓力，是真正的早期預警系統
- **QT 階段格外關注**：聯準會縮表減少準備金供給，Repo 市場是最先出現壓力的地方
- **Haircut 是信用收縮的前瞻指標**：在市場壓力升高時，貸款方先調高 haircut 再調高利率
- **Repo 市場穩定 ≠ 股市安全**：但 Repo 市場不穩定 = 股市必然受衝擊

## 實戰應用

### 聯準會的 Repo 操作
聯準會透過 Repo 和 Reverse Repo 來管理銀行體系的準備金：

### 聯準會的 Repo（向市場注入流動性）
聯準會買入公債（給錢）→ 約定未來賣回（收錢），等於聯準會借錢給市場

### 聯準會的 Reverse Repo（從市場抽走流動性）
聯準會賣出公債（收錢）→ 約定未來買回（還錢），等於市場借錢給聯準會

- **ON RRP（隔夜附賣回）**：聯準會提供給非銀行金融機構（如貨幣市場基金）的工具，是 [[基本面分析/聯邦基金利率Federal-Funds-Rate|聯邦基金利率]] 目標區間的**地板工具**
- **2020-2022年零利率時期**：ON RRP 使用量飆升至2.4兆美元歷史新高，因為貨幣市場基金找不到更好的投資標的
- **2023年後**：隨著聯準會升息，ON RRP 餘額從高峰下降，資金回流至其他短天期工具
