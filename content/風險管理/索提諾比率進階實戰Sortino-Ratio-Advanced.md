# 索提諾比率進階實戰 Sortino Ratio Advanced

> 夏普比率把上漲也當風險，Sortino 只懲罰下跌——因為賺錢的波動不是風險，虧錢的波動才是。

## 核心概念

Sortino Ratio 是 Sharpe Ratio 的改進版，由 Frank Sortino 於 1994 年提出。兩者最大差異：

- **Sharpe Ratio**：用總標準差（包含上漲和下跌的波動）當分母
- **Sortino Ratio**：只用下行標準差（downside deviation）當分母

這解決了 Sharpe Ratio 最被詬病的問題——**上漲的波動是好事不是壞事**。一個策略大賺大賳，Sharpe 會懲罰它的大波動；但 Sortino 只看虧損端的波動，認為「賺很多」不應該被當風險。

## 公式與計算

```
Sortino Ratio = (R - T) / DR

R = 平均報酬率
T = 目標報酬率（通常用無風險利率或 MAR）
DR = 下行標準差（Downside Deviation）
```

**下行標準差計算步驟：**

1. 找出所有低於目標報酬率 T 的期間報酬
2. 計算每期與 T 的差距（只取負值，正報酬視為 0）
3. 將差距平方、加總、除以總期數（注意：分母是全部期數，不是只算負報酬期數）
4. 開根號得到 DR

**範例計算（10 年報酬：4%, 10%, 15%, 20%, -5%, -2%, -6%, 8%, 23%, 13%）**

- 平均報酬 R = 8%
- 目標報酬 T = 7%（假設無風險利率）
- 超額報酬 = 1% = 0.01
- 低於 7% 的期間：-5%, -2%, -6%（差距分別 -12%, -9%, -13%）
- 下行方差 = (0.0144 + 0.0081 + 0.0169) / 10 = 0.00394
- DR = √0.00394 ≈ 0.0628
- **Sortino = 0.01 / 0.0628 ≈ 0.159**

## 判讀標準

**Sortino Ratio 基準：**
- **< 0**：策略虧損，低於目標報酬
- **0 ~ 1**：報酬勉強補償下行風險，偏低
- **1 ~ 2**：可接受的風險調整報酬
- **> 2**：優秀的風險調整報酬
- **> 4**：極優異，但需警惕過度擬合

**vs Sharpe Ratio 的比較基準：**
- Sharpe > 1 被視為不錯，> 2 被視為優秀
- Sortino 通常比 Sharpe 高 30%~100%（因為分母只算下行波動），所以 Sortino > 2 才相當於 Sharpe > 1 的水準
- **永遠不要直接比較 Sortino 和 Sharpe 的絕對值**，它們衡量的是不同的東西

## 進階應用

### 1. 策略比較與選擇
兩個策略年報酬都是 20%：
- 策略 A：大賺大賠，每月報酬從 +15% 到 -8%
- 策略 B：穩定獲利，每月報酬從 +3% 到 +1%

Sharpe 可能差不多，但 Sortino 會明顯偏好策略 B（下行波動小）。如果你受不了大回撤，Sortino 比 Sharpe 更能反映你的真實感受。

### 2. 目標報酬率 T 的選擇
- **無風險利率**（如美國10年期公債殖利率）：最常見，與 Sharpe 直接比較
- **MAR（Minimum Acceptable Return）**：機構投資者常用的最低可接受報酬，如 5% 或通膨+2%
- **0%**：最保守，所有虧損都算風險
- **改變 T 會改變 Sortino 的值**：T 越高，更多期間被歸入「下行」，DR 越大，Sortino 越低

### 3. 與其他風險指標的組合
- **Sortino + [[風險管理/Calmar比率與最大回撤分析Calmar-Ratio-and-Maximum-Drawdown]]**：Sortino 看下行波動，Calmar 看最大回撤，兩者一起看才能完整評估風險
- **Sortino + [[風險管理/Omega比率Omega-Ratio]]**：Omega 是 Sortino 的廣義版本，不需假設報酬常態分佈
- **Sortino vs [[風險管理/摩迪里亞尼風險調整績效M2-Modigliani-Risk-Adjusted-Performance]]**：M2 用總波動調整，Sortino 只用下行波動，後者更貼近投資者真實感受

### 4. 回測中的陷阱
- **樣本期間太短**：下行波動在短期可能被低估，Sortino 虛高
- **沒有足夠的下跌月份**：牛市中計算的 Sortino 意義不大
- **存活者偏差**：只看活下來的策略，倒閉的策略 Sortino 是多少你永遠不知道
- **目標報酬率的後視偏差**：用事後選擇的 T 來美化 Sortino

## 與 Sharpe Ratio 的關鍵差異

**何時用 Sharpe：**
- 報酬分佈接近常態（對稱）
- 上下波動都視為風險
- 比較流動性高、波動對稱的標的

**何時用 Sortino：**
- 報酬分佈偏態（skewed）
- 只關心下行風險
- 評估非對稱報酬策略（如選擇權賣方）
- 投資者對虧損的痛苦遠大於對獲利的愉悅（損失厭惡）

**現實中**：大部分投資者的心理感受更接近 Sortino——賺 10% 的喜悅遠不及虧 10% 的痛苦。Sortino 比Sharpe 更貼近「人」的風險感知。

## 實戰應用

### 個股比較範例
比較台積電（2330）和一檔高波動小型股：
- 台積電年報酬 25%，下行標準差 12% → Sortino = (25%-2%) / 12% = 1.92
- 小型股年報酬 40%，下行標準差 28% → Sortino = (40%-2%) / 28% = 1.36

結論：雖然小型股報酬更高，但 Sortino 顯示其下行風險調整後的報酬反而不如台積電。**高報酬不等於好策略，Sortino 幫你看穿數字背後的風險。**

### 定期定額策略評估
定期定額（DCA）策略的 Sortino 通常比波段操作高，因為定期買入降低了擇時風險，下行波動自然較小。但 Sortino 高不代表絕對報酬高——定期定額的總報酬可能不如精準擇時，但 Sortino 說「過程比較不痛苦」。

## 注意事項

- **只看下行波動，忽略上行風險**：對做多策略合適，但做空策略的上行風險被忽略
- **假設目標報酬率 T 是明確的**：實際上 T 的選擇主觀且影響很大
- **不考慮極端尾部風險**：下行標準差是平均概念，不看極端事件
- **需要足夠的負報酬樣本**：牛市中計算的 Sortino 不具代表性
- **不是萬能指標**：高 Sortino 不代表策略沒有風險，只是下行波動較小
