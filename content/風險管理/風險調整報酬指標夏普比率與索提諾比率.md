# 風險調整報酬指標：夏普比率與索提諾比率

> 賺多少不重要，冒多少風險才重要——夏普比率用總波動衡量，索提諾比率只看下行風險，兩者搭配才是評估策略品質的完整工具

## 核心概念

### 為什麼需要風險調整報酬？

同樣賺 20%，一個波動 5%、一個波動 40%，前者風險調整後的表現遠優於後者。只用絕對報酬評估策略就像只看車速不看路況——數字漂亮但可能隨時翻車。

**核心原則**：報酬率只是故事的一半，風險是另一半。

### 夏普比率（Sharpe Ratio）

**公式**：
```
Sharpe Ratio = (Rp - Rf) / σp
```
- Rp = 投資組合報酬率
- Rf = 無風險利率
- σp = 報酬率標準差（總波動）

**定義**：每承擔一單位總風險，獲得多少超額報酬。

### 索提諾比率（Sortino Ratio）

**公式**：
```
Sortino Ratio = (Rp - Rf) / σd
```
- σd = 下行標準差（Downside Deviation），只計算低於目標報酬率的波動

**定義**：每承擔一單位下行風險，獲得多少超額報酬。

### 兩者最關鍵的差異

| 比較項目 | 夏普比率 | 索提諾比率 |
|---------|---------|-----------|
| 風險衡量 | 總標準差 | 下行標準差 |
| 上漲波動 | 算做風險 | 不算風險 |
| 適用場景 | 一般投資組合 | 不對稱報酬策略 |
| 核心哲學 | 所有波動都是壞的 | 只有下跌才是風險 |

## 實戰應用

### 判讀標準

**夏普比率評估基準**：

| 夏普比率 | 評價 |
|---------|------|
| < 0 | 跑輸無風險利率，不如定存 |
| 0 ~ 0.5 | 低效，風險調整後報酬不佳 |
| 0.5 ~ 1.0 | 尚可，但仍有改善空間 |
| 1.0 ~ 2.0 | 良好，專業基金常見範圍 |
| 2.0 ~ 3.0 | 優秀，頂級量化策略等級 |
| > 3.0 | 異常，需警惕過度擬合或數據偏誤 |

**索提諾比率**通常比夏普比率高，基準相應上移：
- Sortino > 2.0 算良好
- Sortino > 3.0 算優秀

### 四種典型情境判讀

**情境一：高夏普、高索提諾**
- 策略穩定獲利、波動小且不對稱度低
- 典型：市場中性策略、套利策略
- 判讀：優質策略，值得投入

**情境二：低夏普、高索提諾**
- 上漲波動大但下行風險小
- 典型：趨勢追蹤策略（獲利時大赚，虧損時小賠）
- 判讀：夏普比率低估了策略品質，索提諾比率更能反映真實表現

**情境三：高夏普、低索提諾**
- 極端罕見，通常意味計算錯誤或數據異常
- 正常情況下索提諾 ≥ 夏普（因為σd ≤ σp）

**情境四：低夏普、低索提諾**
- 策略全面失敗，總風險和下行風險都高
- 判讀：放棄或重建策略

### 下行標準差的計算

```
目標報酬率 T = Rf（無風險利率）或 0 或自訂

σd = √(1/N × Σ(min(Ri - T, 0))²)
```

- 只有低於目標報酬率的報酬才參與計算
- 高於目標的報酬視為 0（不算風險）
- N 是觀測期數（**不是低於目標的期數**，這是常見計算錯誤）

### Rollling 夏普比率

回測期間的整段夏普比率可能掩蓋時序變化，Rolling 夏普（如 60 日滾動）能看出：
- 策略在不同市場環境下的穩定性
- 績效是在哪些時段創造的（是持續穩定還是靠少數大波段）
- 策略是否正在失效（Rolling 夏普持續下降）

**實戰建議**：Rolling 夏普低於 0 的時段超過 30%，策略需要重新評估。

## 注意事項

### 1. 夏普比率的五大盲區

- **上行波動懲罰**：大漲也會降低夏普比率，因為總標準差包含上漲波動。趨勢追蹤策略的夏普比率通常偏低，不代表策略不好
- **常態分佈假設**：夏普比率假設報酬率常態分佈，但市場實際上有肥尾效應，極端事件發生頻率高於常態分佈的預測
- **時間頻率影響**：日頻率夏普比年頻率高（波動被放大），不同頻率計算的夏普比率不能直接比較，需要年化統一
- **無風險利率選擇**：Rf 的選擇影響結果，台灣常用台灣10年期公債殖利率（約1.5-2%），美國常用10年期國庫券
- **樣本期間敏感性**：不同期間算出的夏普比率差異大，包不包括2008金融海嘯會完全改變結果

### 2. 索提諾比率的三大限制

- **目標報酬率設定主觀**：用 0、Rf 還是其他基準，結果差很多，沒有統一標準
- **下行數據不足時失真**：短期間內如果很少出現下行報酬，σd 估計不穩定
- **同樣假設下行波動對稱**：但「大跌」和「小跌」的機率分佈也不對稱（肥尾效應仍存在）

### 3. 年化處理

**年化夏普比率**：
```
Sharpe_annual = Sharpe_daily × √252
```
- 日頻率 → 乘 √252
- 週頻率 → 乘 √52
- 月頻率 → 乘 √12
- **不同頻率計算的夏普比率必須年化後才能比較**

### 4. 風險比率選擇決策樹

- 報酬分佈接近常態 → 用夏普比率
- 報酬分佈正偏態（右偏，趨勢策略）→ 用索提諾比率
- 需要拆解風險來源 → 用 [[風險管理/詹森Alpha與特雷諾比率Jensen-Alpha-and-Treynor-Ratio|詹森Alpha與特雷諾比率]]（用Beta而非標準差）
- 需要衡量主動管理能力 → 用 [[風險管理/信息比率與追蹤誤差Information-Ratio-and-Tracking-Error|信息比率IR]]
- 需要衡量最大回撤風險 → 用 [[風險管理/Calmar-Ratio年化報酬MDD|Calmar Ratio]]

### 5. 五個常見誤區

- **誤區一**：夏普比率越高就越好 → 超過3可能是過度擬合的訊號
- **誤區二**：不同策略的夏普比率可以直接比較 → 必須相同期間、相同頻率、相同資產類別
- **誤區三**：只用夏普比率就夠了 → 索提諾比率補充下行風險視角，兩者搭配才完整
- **誤區四**：歷史夏普比率代表未來表現 → 215個策略研究顯示回測夏普中位數1.20，實盤僅0.31，衰退73%
- **誤區五**：忽略流動性和交易成本 → 未扣除成本的夏普比率是虛幻的
