# 詹森Alpha與特雷諾比率 Jensen's Alpha & Treynor Ratio

> Alpha衡量選股能力——超越市場的額外報酬；Treynor衡量風險效率——每單位系統性風險的報酬

## 核心概念

### 詹森Alpha（Jensen's Alpha）

詹森Alpha衡量的是**投資者超越市場的選股能力**。它回答的問題是：「扣掉承擔市場風險應得的報酬後，額外賺了多少？」

```
Alpha = 實際報酬 - [無風險利率 + Beta × (市場報酬 - 無風險利率)]
```

換句話說，Alpha = 實際報酬 - CAPM預期報酬。

| Alpha 值 | 判讀 |
|----------|------|
| Alpha > 0 | 跑贏市場，有選股能力 |
| Alpha = 0 | 剛好等於市場風險溢酬 |
| Alpha < 0 | 跑輸市場，不如買指數 |

**舉例**：
- 無風險利率：2%
- 市場報酬：10%
- 某基金Beta：1.2
- 基金實際報酬：14%

CAPM預期報酬 = 2% + 1.2 × (10% - 2%) = 11.6%
Alpha = 14% - 11.6% = **2.4%**

這2.4%就是基金經理人「真正」創造的價值，不是靠承擔市場風險來的。

### 特雷諾比率（Treynor Ratio）

特雷諾比率衡量的是**每單位系統性風險（Beta）的風險溢酬**。它回答的問題是：「承擔每一單位系統性風險，換來多少超額報酬？」

```
Treynor Ratio = (投資組合報酬 - 無風險利率) / Beta
```

| Treynor 值 | 判讀 |
|------------|------|
| > 市場Treynor | 優於市場 |
| = 市場Treynor | 等於市場 |
| < 市場Treynor | 不如買指數 |

**與Sharpe Ratio的差異**：

| 指標 | 分母 | 衡量風險 | 適用情境 |
|------|------|---------|---------|
| Sharpe Ratio | 標準差（總風險） | 總風險 | 單一資產、投資組合 |
| Treynor Ratio | Beta（系統性風險） | 只看系統性風險 | 充分分散的投資組合 |

**關鍵區別**：Sharpe用標準差（包含系統性+非系統性風險），Treynor只用Beta（只有系統性風險）。對於充分分散的組合，兩者結論一致；對於未分散的組合，Sharpe更合適。

### 三大風險調整報酬指標比較

| 指標 | 公式 | 分母 | 適用場景 | 限制 |
|------|------|------|---------|------|
| Sharpe Ratio | (R-Rf) / σ | 標準差 | 任何投資組合 | 不區分上下行波動 |
| Treynor Ratio | (R-Rf) / β | Beta | 充分分散的組合 | Beta不穩定時失真 |
| Jensen's Alpha | R - [Rf + β(Rm-Rf)] | — | 評估選股能力 | 依賴市場基準選擇 |

## 實戰應用

### 1. 用Alpha評估選股能力

Alpha的核心價值是**分離選股能力與市場報酬**：

- **Alpha > 0**：選股能力超越市場。長期正Alpha是最難持續的成績。
- **Alpha ≈ 0**：沒有選股能力，報酬完全來自市場風險溢酬。不如買0050。
- **Alpha < 0**：選股能力不如市場。考慮換策略或改买指數。

**台股實戰**：
- 2024年台股加權指數報酬約28%
- 某主動型基金報酬35%，Beta = 1.1
- 無風險利率1.5%
- Alpha = 35% - [1.5% + 1.1 × (28% - 1.5%)] = 35% - 30.65% = **4.35%**
- 4.35%才是真正靠選股能力賺到的，其餘只是承擔市場風險的報酬

### 2. 用Treynor評估風險效率

Treynor告訴你「承擔的系統性風險換來多少回報」：

- 市場Treynor = 市場風險溢酬 = 10% - 2% = 8%（市場Beta=1）
- 投資組合Treynor = (15% - 2%) / 1.3 = 10%
- 10% > 8% → 承擔每單位系統性風險的報酬優於市場

**比較兩個投資組合**：

| 組合 | 報酬 | Beta | Treynor |
|------|------|------|---------|
| A | 15% | 1.3 | 10.0% |
| B | 12% | 0.8 | 12.5% |

B的報酬較低，但Treynor較高→B的風險效率更好。

### 3. 三指標交叉驗證

單一指標可能誤導，三指標交叉驗證才可靠：

| 組合 | Sharpe | Treynor | Alpha | 判讀 |
|------|--------|---------|-------|------|
| A | 1.2 | 10% | 3% | 三指標一致看多，優質選股 |
| B | 0.8 | 12% | 1% | 分散不夠但選股有超額，需調整配置 |
| C | 1.5 | 6% | -1% | 報酬高但靠非系統性風險，選股能力不足 |

### 4. Alpha的實戰陷阱

#### 陷阱一：基準選擇影響Alpha

用不同基準計算Alpha結果差異很大：

| 基準 | 某基金Alpha |
|------|-------------|
| 台灣加權指數 | +2.5% |
| 台灣50 | +1.8% |
| 摩根台灣指數 | +0.3% |

**建議**：選擇與投資風格最匹配的基準。大型股用加權指數，中小型股用櫃買指數。

#### 陷阱二：正Alpha不保證未來持續

- 過去3年Alpha > 0不代表未來3年Alpha > 0
- 學術研究顯示，主動型基金的正Alpha在3年後有一半會消失
- **持續性檢驗**：分前後兩期，看前期Alpha高的後期是否也高

#### 陷阱三：高Beta掩蓋選股能力

Beta=1.5的組合在多頭市場容易有高報酬，但Alpha可能為負：
- 市場漲20%，Beta=1.5的組合預期漲30%
- 實際漲28%，看起來很棒？Alpha = 28% - 30% = **-2%**
- 扣掉市場風險溢酬，其實跑輸了

### 5. 台股基金經理的Alpha實證

台股主動型基金的Alpha分佈：
- **前25%基金**：年化Alpha 3-8%
- **中位數基金**：年化Alpha約0%（扣掉管理費後為負）
- **後25%基金**：年化Alpha -5%~-2%

這就是為什麼巴菲特說「多數投資者應該買指數基金」——扣除費用後，正Alpha很難持續。

## 注意事項

### 1. Beta不穩定性

Treynor和Alpha都依賴Beta，而Beta並不穩定：
- **不同計算期間**：60日Beta和250日Beta可能差很大
- **市場狀態變化**：空頭市場的Beta通常比多頭高
- **產業輪動**：持股比例變化會改變組合Beta

**建議**：使用滾動Beta（如250日滾動回歸），而非固定Beta。

### 2. 單因子模型的局限

CAPM只有一個因子（市場風險溢酬），現實中還有規模因子、價值因子、動量因子等：
- 正Alpha可能只是因子暴露的結果，不是真正的選股能力
- **Fama-French三因子Alpha**比單因子Alpha更可靠
- 台股的小型股效應和價值效應尤其顯著

### 3. 樣本期間影響

- 短期（1年以內）：Alpha受隨機波動影響大
- 中期（3-5年）：較可靠的Alpha估計
- 長期（10年以上）：市場結構可能已改變，早期Alpha不適用

**建議**：至少用3年數據計算Alpha，5年更可靠。

### 4. 交易成本與稅務

理論Alpha不包含交易成本和稅：
- 主動型基金年管理費1-2%
- 交易成本0.1-0.5%（視周轉率）
- 資本利得稅
- **實際Alpha = 理論Alpha - 各項成本**

### 5. Alpha與投資風格的關係

不同投資風格的Alpha有不同特性：

| 風格 | Alpha特性 | 適合Treynor衡量？ |
|------|----------|------------------|
| 大型成長股 | Alpha低但穩定 | 是，Beta穩定 |
| 小型價值股 | Alpha高但不穩定 | 不太適合，Beta不穩定 |
| 當沖交易 | Alpha波動劇烈 | 不適合，日內Beta無意義 |
| 被動指數 | Alpha ≈ 0（扣費後為負） | 適合，驗證追蹤誤差 |
