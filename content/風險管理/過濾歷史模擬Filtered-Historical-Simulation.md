# 過濾歷史模擬 (Filtered Historical Simulation)


> 過濾歷史模擬 FHS 先用 EWMA 或 GARCH 把歷史報酬除以當時條件波動率，取得近似同尺度的標準化殘差，再乘上目前預測波動率重建損益情境；它保留歷史偏態與肥尾，又避免普通歷史模擬把低波動年代和高波動今天當成同一種天氣。

## 核心概念
過濾歷史模擬 FHS 先用 EWMA 或 GARCH 把歷史報酬除以當時條件波動率，取得近似同尺度的標準化殘差，再乘上目前預測波動率重建損益情境；它保留歷史偏態與肥尾，又避免普通歷史模擬把低波動年代和高波動今天當成同一種天氣。

## 普通歷史模擬的毛病

普通歷史模擬直接拿過去 $N$ 天報酬重播，依損失分位數計算[[風險管理/VaR風險值Value-at-Risk|VaR]]。

優點是：

- 不必假設常態分布
- 保留歷史偏態、肥尾和跨資產同日關係
- 方法透明、容易解釋
- 非線性商品可在每個情境下完整重估

問題是它隱含：

- 每個歷史日都與今天同樣相關
- 波動率在樣本內大致穩定
- 很久以前的低波動報酬可以原封不動代表現在
- 最近危機日也可以原封不動代表平靜期

金融報酬明明有波動率聚集，普通歷史模擬卻裝作每一天都同款。FHS 的目的就是先把天氣單位校正，再重播歷史衝擊。

## 核心模型

對報酬序列：

$$r_t=\mu_t+\sigma_t z_t$$

其中：

- $\mu_t$：條件平均，日資料常簡化為零或短期均值
- $\sigma_t$：當時條件波動率
- $z_t$：標準化殘差

先估計條件波動率，再計算：

$$z_t=\frac{r_t-\mu_t}{\sigma_t}$$

用目前資訊預測下一期尺度：

$$\widehat\sigma_{T+1|T}$$

將每一個歷史殘差重建成明日情境：

$$r_{T+1}^{(i)}=\widehat\mu_{T+1|T}+\widehat\sigma_{T+1|T}z_i$$

若忽略條件均值，等價於：

$$r_i^*=r_i\frac{\widehat\sigma_{T+1|T}}{\widehat\sigma_i}$$

當今日預測波動率高於第 $i$ 天的歷史波動率，該日報酬會被放大；反之則縮小。

## 波動率過濾器

### EWMA

常見 RiskMetrics 形式：

$$\sigma_{t+1}^2=\lambda\sigma_t^2+(1-\lambda)r_t^2$$

特性：

- 參數少、更新快
- 越新的觀測權重越高
- 沒有明確長期變異數中樞
- 單日極端值可能長時間污染尺度

### GARCH(1,1)

[[風險管理/GARCH模型與波動率預測GARCH-Model-and-Volatility-Forecasting|GARCH(1,1)]]：

$$\sigma_{t+1}^2=\omega+\alpha\epsilon_t^2+\beta\sigma_t^2$$

特性：

- 能描述波動率聚集與均值回歸
- $\alpha$ 控制新衝擊反應
- $\beta$ 控制波動持續性
- 參數錯估或過度持續會讓風險尺度反應過慢

### 非對稱波動率模型

股票下跌往往比同幅上漲更容易推高未來波動，可使用：

- GJR-GARCH
- EGARCH
- 其他帶槓桿效應的波動率模型

但濾網越複雜，不代表風險越聰明。參數多到每天重估都換人格，那只是模型在加班發瘋。

## 單資產計算流程

1. 準備足夠長且乾淨的報酬序列
2. 估計 EWMA、GARCH 或非對稱 GARCH
3. 取得每一天的條件波動率 $\widehat\sigma_t$
4. 計算標準化殘差 $z_t$
5. 檢查殘差是否仍有顯著自相關或 ARCH 效應
6. 預測 $\widehat\sigma_{T+1|T}$
7. 以歷史 $z_t$ 重建下一期報酬情境
8. 將情境轉成損益
9. 取損失分位數得到 VaR
10. 對超過 VaR 的尾部損失平均得到 CVaR或Expected Shortfall
11. 用實際下一日損益做滾動回測

## 多資產組合

令報酬向量：

$$r_t=\mu_t+D_t z_t$$

其中 $D_t$ 可是各資產條件波動率的對角矩陣。

最基本作法：

- 同一天抽取完整殘差向量 $z_t$
- 以各資產目前預測波動率重新縮放
- 套用目前持倉權重或完整定價模型

必須保留同日抽樣，因為跨資產共同衝擊才是分散投資真正會痛的地方。逐資產獨立打亂殘差，會製造歷史上從沒出現過的相關組合。

進階作法可用動態條件相關或協方差矩陣白化與重新著色，但需要：

- 穩定且正定的協方差矩陣
- 足夠樣本
- 對高維矩陣做收縮估計
- 檢查危機時相關性是否被平滑掉

## 非線性部位

對選擇權、可轉債或帶障礙條件的商品，流程應是：

1. FHS 產生風險因子情境
2. 對現貨、波動率、利率、匯率等因子同步衝擊
3. 在每個情境下完整重估商品
4. 形成組合損益分布
5. 再計算 VaR 與 Expected Shortfall

只用 Delta 近似：

$$\Delta P\approx\Delta\cdot\Delta S$$

會漏掉 Gamma、Vega、Vanna 與跳躍。平常誤差小不代表尾部也有禮貌。

## FHS與其他方法比較

### 參數法VaR

- 假設特定分布，常見為常態或 Student-t
- 計算快
- 分布假設錯誤會直接污染尾部
- FHS 對殘差分布較少設限

### 普通歷史模擬

- 原樣重播歷史報酬
- 完全保留歷史情境
- 無法快速適應目前波動尺度
- FHS 多了一層波動率過濾與重縮放

### 蒙地卡羅模擬

[[風險管理/蒙地卡羅模擬交易驗證Monte-Carlo-Simulation|蒙地卡羅]]可生成歷史未見情境，但結果高度依賴模型與分布假設。FHS 的創新程度較低，主要重用歷史殘差，因此較透明，卻也受限於歷史樣本。

### 壓力測試

FHS 是機率分布工具，[[風險管理/策略壓力測試Stress-Testing|壓力測試]]是指定極端敘事情境。兩者必須並用：歷史殘差沒見過的停牌、戰爭、熔斷或流動性消失，不能期待 GARCH 幫你腦補。

## 參數選擇

### 樣本長度

- 太短：尾部觀測不足、VaR跳動大
- 太長：納入過時市場結構
- 常見做法是固定滾動窗，再搭配較長壓力樣本
- 高信心水準需要更多樣本，99% VaR 用 250 日只有約 2.5 個理論例外，檢驗力寒酸得很

### 波動率半衰期

EWMA 的 $\lambda$ 或 GARCH 的持續性決定新舊資訊權重：

- 反應太快：風險值追著單日噪音暴衝暴跌
- 反應太慢：危機初期低估、危機後期長時間高估

### 殘差加權

標準 FHS 常對歷史殘差等權抽樣，也可使用：

- 時間衰減權重
- 壓力期加權
- 體制條件抽樣
- block bootstrap 保留短期序列結構

加權越多，方法越不像純歷史模擬，也越需要樣本外回測證明不是調參自嗨。

## 模型診斷

好的過濾器應讓標準化殘差接近：

- 均值穩定
- 方差接近 1
- 殘差自相關弱
- 殘差平方自相關弱
- 不再有明顯 ARCH 效應

若殘差平方仍成群：

- 波動率模型漏掉持續性
- 非對稱效果未建模
- 存在體制轉換
- 使用錯誤資料頻率
- 結構性斷點未處理

這時直接拿殘差做 FHS，只是把沒過濾乾淨的垃圾重新噴漆。

## 限制與陷阱

- **歷史盲區**：樣本沒發生過的事件不會自動出現
- **波動率模型風險**：EWMA與GARCH參數錯誤會直接污染縮放
- **體制切換延遲**：危機剛開始時過濾器可能來不及追上
- **殘差非獨立**：剩餘聚集或序列相關會破壞重抽樣假設
- **相關性處理不足**：逐資產縮放未必捕捉協方差體制變動
- **流動性缺失**：收盤價報酬不含大部位清算衝擊與買賣價差擴張
- **非線性重估成本**：複雜衍生品需要大量完整定價
- **順週期性**：低波動時 VaR下降促使加槓桿，高波動時 VaR暴升迫使去槓桿
- **資料錯誤放大**：壞價格被標準化再放大後會主宰尾部

## 實戰檢查清單

- 報酬資料是否處理股利、拆分、除權息與錯價
- 條件均值是否需要建模
- EWMA或GARCH參數是否穩定
- 標準化殘差是否仍有自相關與ARCH效應
- 多資產是否同日抽樣殘差向量
- 選擇權是否完整重估而非只用 Delta
- 是否加入交易成本與[[風險管理/流動性風險量化衡量與流動性調整VaR-Liquidity-Adjusted-VaR|流動性調整]]
- 是否比較普通HS、FHS與壓力情境
- 是否做滾動樣本外回測
- 多日風險是否模擬波動率路徑而非盲乘平方根

## 關鍵啟示

1. FHS 的核心是先除掉歷史波動尺度，再乘上今日預測尺度
2. 它保留歷史殘差的偏態與肥尾，又能快速回應波動率聚集
3. 多資產必須保留同日殘差向量，非線性部位必須完整重估
4. GARCH過濾不會創造歷史未見的黑天鵝，也不會自動加入流動性衝擊
5. 真正好壞要看樣本外 VaR 回測與例外群聚，不是看模型名稱多長

## 實戰應用

### 每日風險限額

可把 FHS VaR 與 Expected Shortfall 納入[[風險管理/風險儀表板與每日風控檢查Risk-Dashboard|每日風險儀表板]]：

- 目前預測波動率
- 一日與多日 VaR
- Expected Shortfall
- 例外次數
- 最大情境損失
- 與普通歷史模擬的差值

### 體制轉換預警

若 FHS VaR 快速高於普通歷史模擬，代表目前波動率高於大部分歷史樣本；若兩者差距反向擴大，可能是危機過後波動降溫。

但[[風險管理/波動率體制轉換模型Volatility-Regime-Switching-Model|體制轉換]]不是單靠比例就能確認，仍要搭配 VIX、流動性、相關性與信用利差。

### 部位縮放

可依 FHS Expected Shortfall 對部位做風險預算，讓不同資產以相近尾部風險貢獻配置，而不是只看名目金額。

## 注意事項

### 多日VaR陷阱
直接使用平方根時間法則：

$$\operatorname{VaR}_h\approx\operatorname{VaR}_1\sqrt h$$

需要報酬近似獨立同分布、波動率穩定。FHS 本來就是為了解決波動率不穩定，再硬套平方根放大多少有點人格分裂。

較合理方法：

- 模擬未來每一天波動率遞迴
- 逐日抽取或 block bootstrap 殘差
- 累積完整 $h$ 日損益
- 對非線性商品逐日或終點重估
