# Ulcer Index 潰瘍指數與 Martin Ratio

> Ulcer Index 只衡量下跌回撤造成的痛苦，不把上漲波動當風險；對真正拿錢在市場裡活的人來說，這比標準差更像人話。

## 核心概念

Ulcer Index（潰瘍指數）由 Peter Martin 與 Byron McCann 在 1987 年提出，用來衡量投資人在一段期間內承受的下行風險。它不看價格上下震盪的總波動，而是只看「從近期高點回落多少、回落多久」。

計算邏輯：

1. 選定回看期間，例如 14 日或 52 週。
2. 每一天計算收盤價相對期間高點的回撤百分比。
3. 將回撤百分比平方後取平均。
4. 再開平方根，得到 Ulcer Index。

公式味道不重要，重點是：

- 回撤越深，UI 越高。
- 回撤持續越久，UI 也越高。
- 新高附近穩定上漲，UI 接近 0。
- 上漲波動不會被懲罰，因為賺錢造成的波動不是問題，會讓你胃痛的是虧損。

## 實戰應用

### 1. 比標準差更貼近交易痛苦

Sharpe Ratio 使用標準差，把上漲和下跌波動都視為風險。問題是，股票漲太快通常不是你半夜睡不著的原因，跌了又爬不起來才是。Ulcer Index 直接盯著回撤，因此特別適合：

- 評估基金、ETF、投資組合的持有舒適度。
- 比較兩個報酬率相近策略時，誰的回撤更折磨人。
- 檢查趨勢策略是否長期陷入資金曲線回落。
- 作為 [[風險管理/資金曲線管理Equity-Curve-Management|資金曲線管理]] 的監控指標。

### 2. 搭配 Martin Ratio 衡量回撤效率

Martin Ratio 又稱 Ulcer Performance Index，常見概念是：

```text
Martin Ratio = 超額報酬 / Ulcer Index
```

它回答的是：每承受一單位「回撤痛苦」，策略給你多少報酬。這比單看年化報酬更有意義，因為年化 30% 但中途跌 60% 的策略，對多數人來說只是漂亮的刑具。

實務判讀：

- Martin Ratio 越高，代表承受的回撤痛苦越值得。
- 若兩個策略年化報酬接近，優先選 UI 較低、Martin Ratio 較高者。
- 若策略 Sharpe 不錯但 UI 很高，代表它可能有長時間深度回撤，心理與資金壓力被 Sharpe 掩蓋。

### 3. 用於台股投資組合監控

台股波動大、類股輪動快，Ulcer Index 可用來當週期性風控儀表板：

```text
每週檢查：
1. 投資組合近 13 週 Ulcer Index
2. 投資組合近 52 週 Ulcer Index
3. 與加權指數或 0050 的 UI 比較
4. 若組合 UI 高於大盤但報酬沒有同步提高，代表承擔了不值得的痛苦
```

對波段交易者，可以用 UI 補足 [[風險管理/MDD最大回撤進階實戰各資產歷史回撤與管理方法|MDD]] 的盲點。MDD 只看最深的一刀，Ulcer Index 會把「慢慢割、割很久」也算進去，這才是真正折磨帳戶和心態的地方。

## 注意事項

1. **UI 不是進出場訊號**：它是風險衡量，不是看到高就買、低就賣的技術指標。
2. **期間設定會影響結果**：短期 UI 對近期回撤敏感，長期 UI 更適合資產配置與基金比較。
3. **低 UI 不等於高報酬**：防守型標的 UI 低很正常，但若報酬也低，要搭配 Martin Ratio 判斷效率。
4. **不能取代 MDD**：UI 衡量平均回撤痛苦，MDD 衡量最壞單點損失，兩者要一起看。
5. **策略容量與流動性仍要檢查**：UI 只看價格路徑，不會告訴你實盤賣不賣得掉。
