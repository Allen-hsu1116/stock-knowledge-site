# 模型信賴集合Model Confidence Set

## 一句話解釋

Model Confidence Set（MCS）不硬選一個回測冠軍，而是逐步淘汰有證據顯著較差的候選，最後留下在給定信心水準下仍不能被排除為最佳的模型集合；資料不夠有辨識力時就老實留多人，總比瞎封一個王好。

## 它要解決什麼問題

假設同時比較50個策略，樣本外Sharpe最高的是策略17。直接選17等於假裝：

- 排名沒有抽樣誤差
- 其他49個候選不存在
- 最高者顯著優於第二名
- 目前樣本足以辨認唯一最佳策略

MCS把問題改寫成：

> 在事前指定的損失函數下，哪些候選仍無法被資料排除在最佳集合之外？

它和參數的信賴區間很像。信賴區間寬，不是參數同時等於一堆值，而是資料無法精準辨認；MCS成員多，也不是大家都封神，是資料講不出誰真贏。

## 基本設定

候選集合記為：

$$\mathcal M_0=\{1,2,\ldots,m\}$$

模型或策略$i$在時間$t$的損失為$\ell_{i,t}$，成對相對損失為：

$$d_{ij,t}=\ell_{i,t}-\ell_{j,t}$$

因此：

- $d_{ij,t}>0$：模型$i$比模型$j$差
- $d_{ij,t}<0$：模型$i$比模型$j$好
- $c_{ij}=E[d_{ij,t}]$：母體平均相對損失

也可定義模型$i$相對集合其他成員的平均損失：

$$d_{i\cdot,t}=\frac{1}{m-1}\sum_{j\in\mathcal M,\,j\ne i}d_{ij,t}$$

## 損失函數先決定你在比什麼

MCS只負責統計比較，不會替研究者決定目標。交易研究可使用：

- 負的成本後報酬
- 預測平方誤差
- 絕對預測誤差
- 負的風險調整效用
- VaR或Expected Shortfall預測損失
- 實施短缺或其他執行成本

若用負報酬當損失，報酬越高、損失越低；若用預測誤差，選出的則是預測較準模型。看完結果再換損失函數挑自己愛的集合，只是把p-hacking穿上西裝。

## 等預測能力假設

MCS在目前集合$\mathcal M$上反覆檢定Equal Predictive Ability（EPA）。常見兩種表示：

### 成對等效

$$H_{0,\mathcal M}:c_{ij}=0\quad\text{for all }i,j\in\mathcal M$$

### 相對集合平均等效

$$H_{0,\mathcal M}:c_{i\cdot}=0\quad\text{for all }i\in\mathcal M$$

若無法拒絕，代表現有資料不足以區分集合內候選；不是證明它們真實績效完全一樣。

## 兩種常用統計量

先studentize相對損失：

$$t_{ij}=\frac{\bar d_{ij}}{\sqrt{\widehat{\operatorname{Var}}(\bar d_{ij})}}$$

$$t_{i\cdot}=\frac{\bar d_{i\cdot}}{\sqrt{\widehat{\operatorname{Var}}(\bar d_{i\cdot})}}$$

### Range統計量

$$T_{R,\mathcal M}=\max_{i,j\in\mathcal M}|t_{ij}|$$

它看集合內最極端的成對差異。

### Max統計量

$$T_{\max,\mathcal M}=\max_{i\in\mathcal M}t_{i\cdot}$$

它看哪個模型相對集合平均最差。

兩者的虛無分布不是一般常態分布，通常用bootstrap估計。

## MCS逐步淘汰流程

1. 以全部候選建立初始集合$\mathcal M=\mathcal M_0$
2. 對目前集合檢定EPA
3. 若無法拒絕EPA，停止並輸出$\widehat{\mathcal M}_{1-\alpha}^{*}$
4. 若拒絕EPA，依與統計量一致的淘汰規則移除最差模型
5. 對縮小後的集合重複檢定

常見淘汰方向：

- 搭配$T_{\max}$：移除$t_{i\cdot}$最大的模型
- 搭配$T_R$：移除相對其他模型最差的成對studentized損失者

程序的信心水準是$1-\alpha$。在理論條件下，最終隨機集合以至少該漸近覆蓋率包含母體最佳模型集合。

## 為什麼需要Block Bootstrap

金融損失序列常有：

- 自相關
- 波動率聚集
- 持有期重疊
- 同期市場衝擊
- 不同策略間高度相關

因此每次重抽要同步抽取整個模型損失向量，並保留時間區塊。若把各策略各自亂抽，策略間相關性被打爛，最大統計量的虛無分布也跟著變成統計廚餘。

實作時要對下列設定做敏感度分析：

- 區塊長度
- bootstrap次數
- 隨機種子
- $T_R$或$T_{\max}$
- 損失函數
- 顯著水準

## 交易策略實作SOP

### 第一步：凍結候選宇宙

保留所有實際比較過的：

- 策略邏輯
- 參數版本
- 資產池
- 持有期
- 成本假設
- 研究期間

不能只把決賽圈丟進MCS。先偷刪敗犬再做公平選秀，統計學也救不了這種厚臉皮。

### 第二步：產生同步樣本外損失

優先使用：

- 封存樣本
- Walk-Forward樣本外預測
- 經淨化與embargo處理的切分
- 相同日期、缺值與成本口徑

### 第三步：選定單一主要損失

例如：

$$\ell_{i,t}=-r^{net}_{i,t}$$

或風險厭惡效用損失：

$$\ell_{i,t}=-(r^{net}_{i,t}-\tfrac{\gamma}{2}r_{i,t}^{2})$$

主要損失應事前指定；其他損失只能當穩健性檢查並完整揭露。

### 第四步：執行MCS

- 對同期損失矩陣做區塊重抽
- 每輪檢定EPA
- 拒絕時淘汰最差者
- 保存每輪集合、統計量、p值與淘汰順序

### 第五步：對存活者做第二層驗證

MCS存活不是上線許可證，還要檢查：

- 經濟顯著性
- 交易成本與滑價
- 容量與成交限制
- 參數鄰域穩定
- 不同市場體制
- 最大回撤與尾部風險
- 實盤監控觸發條件

## 結果怎麼解讀

### 集合只剩一個

代表在目前候選、損失、樣本和顯著水準下，資料能排除其他模型而只留下單一候選。

不能推論：

- 它是真模型
- 它未來一定最佳
- 換成本或體制仍最佳
- 沒有候選集合外的更好模型

### 集合留下很多個

可能代表：

- 候選真實績效很接近
- 樣本太短
- 相對損失變異太大
- 候選高度相關
- 時間相依降低有效樣本數
- 損失函數辨識力弱

此時最合理的動作可能是保留多模型、做模型平均、增加新資料，或依成本與可解釋性做第二層決策；不是偷偷把回測第一名硬推出道。

## 和鄰近方法的差別

- [[風險管理/White-Reality-Check與Hansen-SPA多重策略檢定|White Reality Check與Hansen SPA]]：檢驗候選集合中是否至少有一個優於事前基準
- MCS：逐步排除顯著較差者，留下不能排除為最佳的集合
- [[風險管理/通縮夏普比率Deflated-Sharpe-Ratio|通縮夏普比率]]：針對被挑出的Sharpe修正多重試驗、樣本長度與非正態偏差
- [[風險管理/組合式淨化交叉驗證CPCV-Combinatorial-Purged-Cross-Validation|CPCV]]：產生多條淨化後樣本外路徑與績效分布，不直接建立最佳模型信賴集合

## 限制

- **相對而非絕對**：一群爛模型也會有最佳者；最佳只代表比較沒那麼爛
- **候選依賴**：加入或移除模型可能改變檢定與淘汰路徑
- **損失依賴**：換目標函數就可能換集合
- **樣本辨識力**：集合大可能只是統計力不足
- **時間穩定性**：結構轉折可能讓歷史相對排名失效
- **重抽設定敏感**：區塊長度與bootstrap次數會影響結果
- **共同資料偏差**：生存者偏差、前瞻偏差與錯誤成本不會被MCS自動洗掉
- **無法補救事後研究**：看完結果才定候選、損失與期間，覆蓋率承諾已經被研究者自己拆了

## 實戰檢查清單

- 候選集合是否包含所有實際比較版本
- 損失函數是否事前指定且有經濟意義
- 是否使用同步樣本外損失
- 是否扣除成本與滑價
- 是否以區塊重抽保留時間相依
- 是否同步保留策略間相關性
- 是否報告完整淘汰順序與最終集合
- 集合大小是否被正確解讀成資料辨識力
- 是否搭配容量、回撤與市場體制驗證
- 是否避免把「無法排除」講成「已證明有效」

## 實戰啟示

1. 資料沒能力選唯一冠軍時，就別逼它演算命仙
2. MCS把模型選擇從單一排名改成有覆蓋率概念的集合推論
3. 存活者只是不能被排除為最佳，不代表每個都值得下เงินจริง
4. 損失函數、候選全集與時間序列重抽樣，三個少一個都會歪
5. 最合理的輸出有時不是一個策略，而是一個可再平均、審查與實盤驗證的候選集合
