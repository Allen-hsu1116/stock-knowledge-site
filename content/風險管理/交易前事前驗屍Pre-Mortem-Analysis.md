# 交易前事前驗屍 Pre-Mortem Analysis

> 在下單前先假設這筆交易已經慘敗，倒推失敗原因；不是唱衰，是趁市場還沒收你學費前先把洞補起來。

## 核心概念

事前驗屍（Pre-Mortem Analysis）是把一般「事後檢討」提前到進場前：先想像一年後這筆投資或交易已經失敗，再從未來回頭列出可能原因。WorldlyInvest 引述 Michael Mauboussin 對 Gary Klein 方法的說明：人在站到「未來失敗後」回看現在時，能比單純從現在預測未來多辨識約 30% 的因素與變數。

這個方法專門處理兩種交易大病：

1. **過度自信**：覺得自己研究很完整，其實只是在替既有看法找理由。
2. **確認偏誤**：只收集支持買進的證據，忽略會讓部位爆掉的條件。

事前驗屍不是要你永遠悲觀，而是把「如果我錯了，會錯在哪裡」寫成清單。沒寫下來的風險，最後都會變成市場幫你寫，字很醜，還很貴。

## 實戰應用

### 五步流程

1. **定義交易假設**：寫下標的、進場理由、預期持有時間、停損與停利條件。
2. **假設已經失敗**：例如「三個月後這筆交易虧損 12%，且停損執行失敗」。
3. **倒推失敗原因**：從市場、產業、公司、籌碼、技術、流動性、自己執行力七個面向列原因。
4. **建立監控觸發器**：把每個失敗原因變成可觀察訊號，例如營收 YoY 轉負、跌破關鍵均線、法人連續賣超、成交量萎縮。
5. **決定調整動作**：觸發後是減碼、停損、暫停加碼、改用避險，不能只寫「再觀察」。再觀察通常只是懶得認錯的高級講法。

### 台股交易事前驗屍模板

```markdown
## 交易前事前驗屍

**標的**：
**進場理由**：
**預期持有期**：
**最大可承受虧損**：

### 假設失敗情境
三個月後這筆交易虧損 X%，原因可能是：

1. 市場風險：大盤轉空、外資撤出、利率或匯率變動
2. 產業風險：題材降溫、報價反轉、競爭加劇
3. 公司風險：營收不如預期、毛利率下滑、法說會展望轉弱
4. 籌碼風險：法人買盤中斷、融資暴增、主力出貨
5. 技術風險：跌破關鍵支撐、假突破、量價背離
6. 流動性風險：成交量不足，想賣賣不掉
7. 執行風險：沒照停損、加碼過快、情緒交易

### 對應觸發器與動作
- 觸發器 1：____ → 動作：____
- 觸發器 2：____ → 動作：____
- 觸發器 3：____ → 動作：____
```

### 適用場景

- **重大部位進場前**：單一部位超過帳戶 10% 或風險超過 1R 時必做。
- **高題材熱度股票**：市場越熱，越需要反向想失敗劇本。
- **長線投資**：不只問「會不會漲」，還要問「如果 thesis 對但時間太久，我撐不撐得住」。
- **財報或法說會前**：把不如預期的情境先寫好，避免盤中被情緒拖去砍在低點或凹在高點。

## 注意事項

1. **事前驗屍不能只寫空話**：例如「景氣不好」沒用，要寫成「PMI 連續兩月跌破 50 且公司接單能見度下修」。
2. **每個風險都要有處置動作**：沒有動作的風險清單只是文青筆記，不是風控。
3. **不要把驗屍變成不交易的藉口**：所有交易都有風險，重點是風險是否可定義、可監控、可承受。
4. **團隊或社群討論時要先獨立列清單**：先各自寫，再合併討論，避免第一個人講完大家就羊群化。
5. **定期回看清單**：持倉期間每週檢查一次，因為風險不是寫完就自動消失，市場沒那麼貼心。
