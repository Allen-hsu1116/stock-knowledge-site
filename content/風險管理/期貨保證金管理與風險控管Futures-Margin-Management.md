# 期貨保證金管理與風險控管

> 保證金是期貨市場的空氣——不夠就斷頭，太多就浪費資金效率，精準管理保證金是期貨交易者的生存基本功

## 核心概念

### 保證金三層結構

期貨交易的保證金分為三層，理解這三層是生存的第一步：

1. **原始保證金（Initial Margin）**：建部位時必須繳交的最低金額，通常為合約價值的5-15%
2. **維持保證金（Maintenance Margin）**：部位必須維持的最低金額，通常為原始保證金的75%
3. **追繳保證金（Variation Margin）**：當保證金低於維持保證金時，必須補足到原始保證金的差額

**計算公式**：
- 原始保證金 = 合約價值 × 保證金比率
- 維持保證金 ≈ 原始保證金 × 75%
- 追繳金額 = 原始保證金 - 帳戶餘額（當帳戶餘額 < 維持保證金時）

### 台指期保證金實例

以台指期小型合約（小台）為例：
- 小台原始保證金：約83,500元（2026年行情估算）
- 小台維持保證金：約64,000元
- 大台原始保證金：約251,000元
- 大台維持保證金：約192,000元

**情境**：小台1口，指數20,000點
- 合約價值 = 20,000 × 50 = 1,000,000元
- 原始保證金 = 83,500元（約8.35%保證金比率）
- 槓桿倍數 ≈ 12倍

**這意味著**：指數每變動1%，你的保證金變動約12%！

### 保證金追繳流程

```
帳戶餘額變化：
原始保證金 ──────→ 維持保證金 ──────→ 強制平倉（斷頭）
   ↑ 正常          ↑ 警告區           ↑ 生存線
   │                │                  │
   │    虧損中...   │    持續虧損...    │
   └──────────────┴─────────────────┘
        安全區            危險區
```

1. **觸發追繳**：帳戶餘額 < 維持保證金
2. **追繳通知**：券商發出Margin Call
3. **補繳期限**：通常T+1日中午前須補足
4. **未補繳結果**：強制平倉（斷頭），而且可能在補繳期限前就開始砍倉

## 實戰應用

### 保證金管理的四條鐵律

**鐵律一：保證金使用率永遠不要超過50%**
- 使用率 = 部位原始保證金 / 帳戶總資金
- 30-50%是健康區間
- 超過70%是危險區
- 接近100%是死亡區

**鐵律二：單一部位風險不超過帳戶2%**
- 部位口數 = （帳戶資金 × 2%）/ （單口停損金額）
- 1點=200元（大台）、50元（小台）
- 範例：帳戶50萬，停損100點，大台口數 = 500,000 × 0.02 / （100 × 200）= 0.5口 → 最大0口或換小台

**鐵律三：預留3倍保證金的波動空間**
- 如果1口大台保證金25萬，帳戶至少要有75萬才能操作1口
- 這75萬 = 25萬保證金 + 50萬緩衝區
- 緩衝區讓你在虧損時不會被迫停損

**鐵律四：絕不讓保證金使用率超過80%**
- 超過80%代表幾乎沒有容錯空間
- 一個跳空缺口就可能斷頭
- 遇到跳空，損失可能遠超過停損點

### 保證金使用率計算

```
保證金使用率 = 所有部位原始保證金合計 / 帳戶總權益

範例：
帳戶權益 = 200萬
大台2口 = 25萬 × 2 = 50萬
小台3口 = 8.35萬 × 3 = 25.05萬
總原始保證金 = 75.05萬
保證金使用率 = 75.05 / 200 = 37.5% ✅ 健康
```

### 不同行情的保證金策略

| 行情狀態 | 保證金使用率建議 | 因應策略 |
|---------|----------------|---------|
| 多頭趨勢 | 40-60% | 順勢加碼，但留足追繳空間 |
| 盤整市 | 20-40% | 輕倉渡過，波動收縮時保證金效率低 |
| 高波動市 | 15-30% | 大幅降低使用率，防止跳空斷頭 |
| 事件前夕 | 10-25% | 選舉、央行會議前大幅減倉 |
| 逆勢操作 | 不超過20% | 逆勢天然高風險，保證金效率必須極低 |

### 跳空缺口與保證金管理

期貨最恐怖的不是盤中波動，而是**隔夜跳空**：
- 停損設在100點，隔天開盤跳空300點
- 實際虧損300點，不是100點
- 保證金瞬間歸零甚至變負數

**防範跳空缺口**：
1. 降低隔夜部位：收盤前減倉
2. 保證金使用率降至20%以下
3. 用選擇權代替期貨（最大虧損是權利金）
4. 設定夜盤停損單（如果券商支援）

## 注意事項

### 五大致命錯誤

1. **保證金用滿滿倉操作**：波動2-3%就斷頭，完全沒有容錯空間
2. **忽略結算日風險**：到期前保證金比率可能調整，未平倉部位可能被強制結算
3. **跨月轉倉風險**：轉倉時近遠月價差可能造成額外虧損
4. **多部位保證金加成**：同時持有多口合約或相關性高的部位，保證金需求不是線性相加
5. **忽略交割風險**：現金交割的期貨結算價可能不同於最後交易日的收盤價

### 保證金比率調整時機

交易所會在以下情況調整保證金比率：
- 選舉、重大政策公布前
- 連續漲跌停板時
- 連續假期前
- 國際市場大幅波動時
- 結算日前

**調高保證金 → 你必須補繳或減倉，這是被動減槓桿！**

### 期貨與選擇權保證金差異

| 項目 | 期貨保證金 | 選擇權保證金 |
|------|----------|------------|
| 買方 | 不需要（付權利金） | 不需要 |
| 賣方 | 不適用 | 需要（風險較高） |
| 維持保證金 | 有（75%原始） | 有（按風險計算） |
| 追繳機制 | 有 | 有 |
| 最大虧損 | 理論上無限（期貨） | 理論上無限（裸賣） |

### 實戰檢查清單

每天收盤後檢查：
- [ ] 保證金使用率是否在安全範圍？（<50%）
- [ ] 帳戶餘額是否大於維持保證金的1.5倍？
- [ ] 是否有即將到期的部位需要處理？
- [ ] 明天是否有重要事件可能導致跳空？
- [ ] 所有部位的停損點是否正確設定？
- [ ] 是否需要調整部位大小以因應保證金變化？
