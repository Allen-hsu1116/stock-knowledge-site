# 獲利因子 Profit Factor

> 獲利交易的總利潤除以虧損交易的總虧損——大於1才能活，大於2才算好策略

## 核心概念

獲利因子（Profit Factor, PF）是衡量交易策略品質的最直覺指標之一。它回答一個簡單的問題：**你賺的錢是你賠的錢的幾倍？**

### 計算公式

```
Profit Factor = 獲利交易總利潤 / 虧損交易總虧損
```

例如：
- 策略A：獲利交易總計賺了 50,000，虧損交易總計賠了 25,000
- PF = 50,000 / 25,000 = **2.0**

### PF 值的判讀標準

| PF 範圍 | 判讀 | 實戰意義 |
|---------|------|---------|
| PF < 1.0 | 虧損策略 | 賺的比賠的少，長期必虧 |
| PF = 1.0 | 損益兩平 | 扣掉手續費和滑價後實際虧損 |
| PF 1.0-1.5 | 勉強獲利 | 交易成本和執行偏差可能吃掉利潤 |
| PF 1.5-2.0 | 合格策略 | 大多數專業交易者的PF落在這個區間 |
| PF 2.0-3.0 | 優秀策略 | 穩定的獲利機器 |
| PF > 3.0 | 極優秀或過度擬合 | 需警惕回測過擬合，實盤很少維持此水準 |

### PF 與勝率的關係

獲利因子不等於勝率。關鍵是獲利交易的「平均獲利」和虧損交易的「平均虧損」的比值：

```
Profit Factor = 勝率 × 平均獲利 / (1 - 勝率) × 平均虧損
```

三種典型策略的PF：

| 策略類型 | 勝率 | 平均獲利/平均虧損 | PF | 代表 |
|---------|------|-----------------|-----|------|
| 趨勢追蹤 | 35-45% | 2.5-3.0 | 1.5-2.0 | 海龜交易法 |
| 區間交易 | 55-65% | 1.2-1.5 | 1.5-2.0 | 均值回歸 |
| 當沖剝頭皮 | 65-75% | 0.8-1.0 | 1.5-2.5 | 高頻交易 |

**重點**：不同風格的策略可以有相同的PF，只是勝率和賺賠比的組合不同。

## 實戰應用

### 1. 策略品質篩選

PF 是最基礎的策略篩選指標：

- **PF < 1.5**：策略可能不穩定，需要改進或放棄
- **PF 1.5-2.0**：策略合格，可以考慮小部位實盤驗證
- **PF > 2.0**：策略品質良好，但仍需驗證是否過擬合

### 2. 扣除交易成本後的PF

回測PF必須扣除交易成本才是真實PF：

```
調整後PF = (獲利總額 - 交易成本 × 獲利交易次數) / (虧損總額 + 交易成本 × 虧損交易次數)
```

台股交易成本估算（買賣各一次）：
- 手續費：0.1425% × 2 = 0.285%（網路下單折數）
- 證交稅：0.1%（一般股）/ 0.2%（當沖）
- 單次來回成本：約 0.385%（一般）/ 0.485%（當沖）

高頻策略（年交易200次以上）的交易成本可能吃掉PF 0.2-0.5。

### 3. PF 與最大連虧的搭配判讀

PF 只看整體，不見得能反映局部風險：

| PF | 最大連虧 | 判讀 |
|----|---------|------|
| 2.0 | 5筆以內 | 優秀，策略穩定 |
| 2.0 | 10筆以上 | PF好看但連虧風險高，資金曲線可能劇烈震盪 |
| 1.5 | 5筆以內 | PF普通但連虧可控，心理壓力較小 |
| 1.5 | 10筆以上 | PF和連虧都不優，策略需重新設計 |

### 4. 分段PF判斷策略穩定性

將回測期間分成前、中、後三段，分別計算PF：

- **三段PF都 > 1.5**：策略穩定
- **前段PF > 2.0 後段 PF < 1.0**：策略可能過擬合或市場體制改變
- **PF波動劇烈**：策略在不同市況表現差異大，需要體制過濾器

### 5. PF 與 Sharpe/Calmar 的比較

| 指標 | 衡量什麼 | 優點 | 缺點 |
|------|---------|------|------|
| Profit Factor | 總獲利vs總虧損 | 直覺易懂 | 不考慮時間和波動度 |
| Sharpe Ratio | 超額報酬/標準差 | 考慮波動度 | 不區分上下行波動 |
| Calmar Ratio | 年化報酬/MDD | 考慮極端風險 | 依賴單一事件（MDD） |

**建議**：PF 作為快速篩選，Sharpe 和 Calmar 作為深入評估。

## 注意事項

### 1. PF 不考慮時間序列

PF 把所有交易加總計算，不區分獲利和虧損的先後順序。一個PF=2.0的策略，如果連虧10筆後才大賺1筆，資金曲線可能先腰斬再翻倍——心理上很難堅持。

### 2. 極端獲利扭曲PF

一筆超級獲利交易（如2020年3月放空COVID低點）可能讓PF虛高：
- **去除最大獲利交易**後重算PF，如果從3.0降到1.2，代表策略大部分時候其實很普通
- **去除最大虧損交易**後重算PF，如果從1.8升到4.0，代表一次意外虧損拉低了整體表現
- **建議**：同時看調整前後的PF，差距太大代表策略不穩定

### 3. 小樣本PF不可靠

- 10筆交易的PF=3.0 → 可能只是運氣
- 100筆交易的PF=2.0 → 才有統計意義
- **最低建議**：至少30筆交易才計算PF，100筆以上較可靠

### 4. PF 不等於期望值

PF 告訴你「賺的是賠的幾倍」，但沒告訴你「平均每筆交易賺多少」：

```
期望值 = (勝率 × 平均獲利) - ((1-勝率) × 平均虧損)
```

PF=2.0 但期望值只有0.1%的策略，手續費就會吃掉利潤。**PF和期望值必須一起看**。

### 5. 回測PF與實盤PF的落差

回測PF通常比實盤PF高20-50%，原因：
- **滑價**：回測用收盤價，實盤有滑價成本
- **執行偏差**：下單時機、部分成交
- **流動性**：回測假設無限流動性
- **心理因素**：實際交易時的心理壓力影響執行

**經驗法則**：回測PF打7折是合理的實盤PF預期。
