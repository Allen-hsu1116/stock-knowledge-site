# 停利方法 Stop Profit Methods

> 會買是徒弟，會賣是師傅——停利比停損更難，因為貪婪比恐懼更難控制

## 核心概念

停利（Take Profit / Stop Profit）是在達到預設獲利目標時出場的機制。停損保護下檔，停利鎖定上檔。很多人會設停損但不設停利，導致「紙上富貴」——帳面獲利最終回吐。

### 停利與停損的對稱性

| | 停損 | 停利 |
|---|---|---|
| 目的 | 限制虧損 | 鎖定利潤 |
| 心理難度 | 不認賠（不願執行） | 不願賣（貪婪干擾） |
| 設定邏輯 | 前低、支撐、ATR | 前高、壓力、目標價 |
| 移動方向 | 只往上移 | 不往下移 |

## 主要停利方法

### 一、固定目標停利

設定進場時的獲利目標百分比或目標價：

- **常見比率**：波段 10~20%、當沖 2~5%
- **目標價計算**：用型態測量、斐波那契擴展、壓力位
- **優點**：明確可執行
- **缺點**：可能賣在半山腰

**實戰建議**：分批停利比一次全賣更好（詳見 [[分批停利策略Partial-Exit-Strategy|分批停利策略]]）

### 二、風險報酬比停利

根據 [[風險報酬比|風險報酬比]] 設定停利目標：

- **最低標準**：風險報酬比至少 1:2
- **1:3 以上**：高品質交易機會
- **計算方式**：停利目標 = 進場價 +（進場價 − 停損價）× N

**範例**：
- 買進 100 元，停損 95 元（風險 5 元）
- 1:2 停利 → 目標 110 元（獲利 10 元）
- 1:3 停利 → 目標 115 元（獲利 15 元）

### 三、移動停利 (Trailing Stop)

停利線跟著股價上漲而往上移動，跌破才出場：

- **百分比移動停利**：從最高點回跌超過 X%就出場
- **ATR 移動停利**：收盤價 − N×ATR
- **均線移動停利**：跌破移動均線出場

詳見 [[移動停利停損Trailing-Stop|移動停利停損]]

### 四、分批停利

不一次全賣，分 2~3 批出場：

- **三分之一法**：1/3 在目標一賣、1/3 在目標二賣、1/3 移動停利
- **2+1 法**：2/3 在第一目標出場（鎖定大部分利潤），1/3 用移動停利追逐大行情
- **優點**：兼顧確定性和行情延續的可能性

詳見 [[分批停利策略Partial-Exit-Strategy|分批停利策略]]

### 五、理由消失停利

買進理由已充分反映或消失時出場：

- 基本面改善已反映 → 本益比合理時出場
- 技術面突破已達目標 → 測量滿足點出場
- 籌碼面法人轉賣 → 跟著出場

詳見 [[理由消失停損法Reason-Based-Exit|理由消失停損/停利法]]

### 六、時間停利

在設定時間內未達目標就走人：

- 買進後 5 個交易日未漲 → 出場
- 財報行情前一天進場 → 財報公佈後隔天出場
- 適合事件驅動型交易

## 停利常見錯誤

### 1. 不設停利目標

只設停損不設停利，獲利時不知道何時出場 → 最後回吐所有利潤

**解法**：進場時同時設定停損和停利目標

### 2. 停利設太近

- 目標只設 3% → 手續費+滑價吃掉利潤
- **解法**：停利至少要大於停損距離的 2 倍（風險報酬比 1:2 以上）

### 3. 貪婪修改停利目標

- 到了停利目標捨不得賣 → 往上修目標 → 最後回跌連原來的利潤都沒了
- **解法**：分批停利，至少先賣一半鎖定利潤

### 4. 忽略壓力位

- 停利目標設在壓力位上方 → 在壓力位就被打回
- **解法**：停利目標要考慮壓力位，設在壓力位下方或突破後設新目標

### 5. 賺小賠大

- 停利只設 3%，停損設 8% → 勝率要超過 73% 才能獲利
- **解法**：風險報酬比至少 1:2，最好 1:3

## 不同交易風格的停利設定

| 交易風格 | 建議停利方法 | 利潤目標 | 說明 |
|---------|------------|---------|------|
| 當沖 | 固定目標 | 1~3% | 當天進出，確定獲利就走 |
| 短線波段 | 分批停利 | 5~15% | 先鎖定一半，另一半追 |
| 中線波段 | 移動停利 | 15~30% | 讓利潤奔跑 |
| 長期投資 | 理由消失 | 不設上限 | 基本面不變就續抱 |

## 停利與 [[風險報酬比|風險報酬比]] 的數學

期望值公式：
```
期望值 = (勝率 × 平均獲利) − (敗率 × 平均虧損)
```

| 風險報酬比 | 需要勝率才能損益兩平 |
|-----------|-------------------|
| 1:1 | 50% |
| 1:2 | 33.3% |
| 1:3 | 25% |
| 1:4 | 20% |

**關鍵洞察**：停利距離決定風險報酬比，風險報酬比決定你需要多少勝率。停利設得好，即使勝率不到 50% 也能長期獲利。
