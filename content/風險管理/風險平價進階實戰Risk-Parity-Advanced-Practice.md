# 風險平價進階實戰 Risk Parity Advanced Practice

> 風險平價不是「平均分配風險」這麼簡單——ERC數學、槓桿管理、相關性崩潰與利率敏感度四大實戰課題決定了它是神器還是地雷

## 核心概念

### 傳統60/40的致命缺陷

傳統60/40組合（60%股票40%債券）看似分散，但風險分配極度不均：
- 股票波動率約15-20%，債券波動率約3-5%
- 股票貢獻了組合**90%以上**的風險
- 本質上是在「賭股票方向」，債券只是裝飾

風險平價的核心思想：**不分配資金，分配風險**——讓每個資產對組合整體波動率的貢獻相等。

### 等風險貢獻（ERC）的數學

對N個資產的組合，權重向量w，共變異數矩陣Σ：

組合波動率：σ(w) = √(w'Σw)

由Euler齊次函數定理可分解為各資產的風險貢獻：

```
σ(w) = Σᵢ σᵢ(w)
其中 σᵢ(w) = wᵢ · (Σw)ᵢ / √(w'Σw)
```

等風險貢獻條件：σᵢ(w) = σⱼ(w) for all i,j，即 σᵢ(w) = σ(w)/N

### 三種求解方法

1. **凸優化**：最小化 Σᵢ [σᵢ(w) - σ(w)/N]²，收斂性有保證
2. **定點迭代**：wᵢ = σ(w)² / [N · (Σw)ᵢ]，循環更新至收斂
3. **循環坐標下降法（CCD）**：逐一更新每個權重，收斂速度快，開源實作可用Python/R

### 全天候策略（All Weather）

Ray Dalio的Bridgewater在1996年推出第一個風險平價基金：
- 四象限各25%風險預算（成長/通膨/成長放緩/通膨放緩）
- 資產配置：股票30% + 長債55% + 中短債15% + 原物料7.5% + 黃金7.5%
- 關鍵：低波動資產（債券）需要加槓桿才能達到等風險貢獻

## 實戰應用

### 1. 散戶簡化版風險平價

不使用槓桿的散戶版本：
- 股票30% + 債券50% + 黃金10% + 現金10%
- 每季再平衡回目標比例
- 核心精神：讓債券的風險貢獻接近股票

### 2. 槓桿版風險平價

機構版用槓桿放大低波動資產的報酬：
- 債券部位加2-3倍槓桿
- 目標：讓組合整體報酬率接近純股票，但風險更低
- Sharpe Ratio理論上高於60/40

### 3. 搭配景氣循環微調

根據[[基本面分析/經濟週期與資產配置策略Economic-Cycle-and-Asset-Allocation|美林投資時鐘]]微調：
- 成長加速期：加碼股票、減碼債券
- 通膨上升期：加碼原物料、減碼長債
- 成長放緩期：加碼債券、減碼股票
- 通膨放緩期：加碼股票、減碼原物料

### 4. 再平衡紀律

風險平價需要持續再平衡維持等風險貢獻：
- 價格上漲的資產波動率可能上升 → 減碼
- 價格下跌的資產波動率可能上升 → 也可能減碼
- 關鍵：再平衡看的是「風險貢獻」偏離程度，不是「資金比例」偏離

## 注意事項

### 1. COVID-19的教訓——相關性崩潰
2020年Q1疫情爆發時，風險平價基金大幅虧損。原因：股債相關性從負轉正，所有資產同時下跌。風險平價依賴資產間低相關性，但[[風險管理/相關性崩潰Correlation-Breakdown|相關性崩潰]]在危機時幾乎必然發生。這是風險平價最根本的結構性弱點。

### 2. 利率上升期的脆弱性
風險平價大量配置債券（通常50%+），利率上升時債券價格下跌。2022年升息周期中，多檔風險平價基金創歷史最大虧損。問題：槓桿放大了債券部位的利率敏感度。

### 3. 槓桿是雙面刃
槓桿讓低波動資產達到等風險貢獻，但也：
- 放大融資成本侵蝕報酬
- 在流動性危機時被迫去槓桿（賣在最低點）
- 讓組合對利率變動更敏感

### 4. 共變異數矩陣估計不穩定
ERC依賴共變異數矩陣Σ的估計，但：
- 樣本期間不同，Σ差異很大
- 危機前後相關性結構劇變
- 建議用[[風險管理/階層式風險平價HRP-Hierarchical-Risk-Parity|階層式風險平價（HRP）]]降低對Σ的依賴

### 5. 2008 vs 2020的弔詭
2008年金融海嘯時風險平價表現優異（AQR僅跌18-19% vs Vanguard Balanced跌22%），但2020年COVID卻大幅落後。差異：2008是信用危機（債券上漲避險），2020是流動性危機（所有資產同跌）。風險平價在「有避險資產可躲」的危機中有效，在「無處可逃」的危機中失效。

### 6. 不要把風險平價當聖杯
風險平價是一種資產配置方法，不是萬能策略：
- 牛市中落後純股票（1990年代）
- 需要長期持有才能展現優勢
- 適合機構投資者（資金大、可承受槓桿），散戶簡化版即可
