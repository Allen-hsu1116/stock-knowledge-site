# 風險儀表板與每日風控檢查 Risk Dashboard

> 飛機駕駛不憑感覺飛行，而是看儀表板——你的交易也需要一組即時風險指標，否則你就是「蒙眼飛行」

## 核心概念

風險儀表板（Risk Dashboard）是將帳戶的關鍵風險指標可視化的監控系統。就像飛機的駕駛艙儀表板，交易者需要即時掌握帳戶的健康狀態，而不是憑感覺判斷「今天虧多了」或「最近好像還好」。

**為什麼需要儀表板？**

人腦對數字的直覺判斷極不可靠。連虧 3 天覺得完蛋了，其實只佔帳戶 2%；覺得「最近賺不錯」，其實 MDD 已經超過 20%。儀表板用數字取代感覺，用客觀取代主觀。

## 儀表板核心指標

### 第一層：帳戶級別（每天必看）

| 指標 | 計算方式 | 警戒值 | 危險值 |
|------|----------|--------|--------|
| 帳戶淨值 | 總資產市值 | - | 低於初始資金 |
| 今日損益 | 當日實現+未實現損益 | < -1% 帳戶 | < -2% 帳戶 |
| 本月損益 | 當月累計損益 | < -3% | < -6%（觸發 Elder 6% 法則） |
| MDD | 從最高點到最低點的最大回撤 | > -15% | > -25% |
| 未實現損益 | 所有持仓浮動損益總和 | < -3% | < -5% |

### 第二層：部位級別（持倉時必看）

| 指標 | 計算方式 | 警戒值 | 危險值 |
|------|----------|--------|--------|
| 單一最大部位佔比 | 最大持倉市值 / 帳戶淨值 | > 20% | > 30% |
| 前三大部位佔比 | 前三名佔比加總 | > 40% | > 60% |
| 單筆最大浮虧 | 個股未實現虧損 / 帳戶 | > -1.5% | > -2%（觸發 2% 法則） |
| 部位數量 | 當前持倉檔數 | > 8 | > 12 |

### 第三層：風控規則合規（每週檢查）

| 規則 | 檢查項目 | 通過條件 |
|------|----------|----------|
| 2% 法則 | 單筆風險 ≤ 2% 帳戶 | ✅/❌ |
| 6% 法則 | 本月累虧 ≤ 6% 帳戶 | ✅/❌ |
| 分散投資 | 單一部位 ≤ 20% | ✅/❌ |
| 停損設定 | 每筆持倉已設停損 | ✅/❌ |
| 相關性 | 前三大部位相關係數 < 0.7 | ✅/❌ |

## 實戰應用：每日風控 SOP

### 盤前檢查（8:00-8:30）

1. 查看隔夜國際市場變動對持倉的影響
2. 確認所有持倉停損單是否仍有效
3. 今日有無需特殊處理的事件（除權息、法說會、財報）
4. 帳戶本月損益是否接近 6% 警戒線

### 盤中監控（9:00-13:30）

1. 單筆浮虧觸及 2% 時立即檢視停損是否執行
2. 未實現損益總和超過帳戶 3% 時降低新倉部位
3. 盤中不加碼超過原計畫的部位大小

### 盤後檢查（13:30-14:30）

1. 更新帳戶淨值與 MDD
2. 記錄今日交易能量值（1-10）
3. 計算本週累計損益與 6% 法則餘裕
4. 確認所有持倉停損設定是否需調整
5. 有無觸發任何警戒或危險值

### 每週檢查（週五盤後）

1. 計算本週風控規則合規率（目標 > 90%）
2. 最大單筆虧損 vs 預期虧損（停損是否有效）
3. 帳戶波動率是否異常變化
4. 持倉相關性矩陣更新
5. 交易能量值趨勢（是否逐漸下降 → 倦怠預警）

## 儀表板建置方式

### 低成本方案（試算表）

用 Google Sheets 或 Excel 建立儀表板：
- 手動輸入每日收盤帳戶淨值
- 公式計算 MDD、本月損益、部位佔比
- 設定條件格式：超過警戒值變黃色、超過危險值變紅色

### 中階方案（TradingView + 試算表）

- TradingView 即時看持倉損益
- 試算表記錄每日風控檢查數據
- 用 Telegram Bot 推播警戒通知

### 高階方案（自動化）

- XQ 或 Python 串接券商 API 自動抓取持倉資料
- 即時計算所有風控指標
- 異常自動推播 Line/Telegram 通知
- 每日/週自動產生風控報告

## 風險儀表板日誌模板

```markdown

## 風控日誌 YYYY-MM-DD

**帳戶淨值**：NT$ XXX,XXX
**今日損益**：+X.X% / -X.X%
**本月損益**：+X.X% / -X.X%
**MDD**：-X.X%
**持倉數**：X 檔
**最大部位**：OOO (XX%)
**單筆最大浮虧**：OOO (-X.X%)

**警戒觸發**：無 / ⚠️ XXX
**風控合規**：✅ 2%法則 / ✅ 6%法則 / ✅ 分散 / ✅ 停損 / ✅ 相關性
**交易能量值**：X/10
**備註**：自由記錄
```

## 實戰應用

實戰使用時需搭配進出場規則、部位控制與市場情境確認，不可單靠單一概念硬上。

## 注意事項

1. **儀表板不是裝飾品**：建了不看等於沒建，每天至少花 5 分鐘掃過核心指標
2. **警戒值必須有行動對應**：看到紅燈不知道該怎麼辦，儀表板就失去意義
3. **不要過度複雜化**：初期用 5 個核心指標就夠了，多了反而不看
4. **MDD 是落後指標**：等到 MDD 觸發通常已經來不及，重點是「本月損益」和「未實現損益」的前瞻監控
5. **主觀感覺不可靠**：覺得「最近還好」≠ 數字真的還好，相信儀表板
6. **定期校準警戒值**：隨帳戶規模變化調整絕對金額，但百分比閾值保持一致
