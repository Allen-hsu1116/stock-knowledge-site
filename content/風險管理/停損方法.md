# 停損方法 Stop Loss Methods

> 停損不是認輸，是活著等下一次機會——沒有停損的交易等於開車不繫安全帶

## 核心概念

停損（Stop Loss）是在進場時就設定好出場價格的風險控制機制，當股價觸及停損價時，不問理由立即出場。停損的目的是**限制單筆虧損在可承受範圍內**，保護資金讓你有下次進場的能力。

### 停損的核心原則

1. **進場前就設好**——不是「等著看」再決定停損點
2. **停損價不往下移**——可以往上移動（移動停利），絕不往下移
3. **停損是保險不是預測**——設停損不是因為覺得會跌到那裡，而是因為萬一跌到那裡你承受不起
4. **停損後不馬上回補**——尊重自己的判斷，給市場冷卻時間

## 主要停損方法

### 一、固定百分比停損

最簡單直接的方法，設定一個固定虧損百分比：

- **常見設定**：5%~8% 停損
- **優點**：簡單明確，容易執行
- **缺點**：不考慮個股波動特性
- **適用場景**：新手入門、短線交易

**範例**：
- 買進價格 100 元，停損 7% → 停損價 93 元
- 買進價格 50 元，停損 5% → 停損價 47.5 元

### 二、技術面停損

根據技術分析的支撐壓力設定停損點，比固定百分比更有邏輯基礎：

1. **支撐線停損**：跌破支撐線（或支撐線下方 1~2%）出場
2. **均線停損**：跌破重要均線（10MA、20MA、60MA）出場
3. **前低停損**：跌破近期最低點出場
4. **型態停損**：跌破型態頸線出場
5. **跳空缺口停損**：跌破缺口下緣出場

**技術面停損的優勢**：
- 停損理由明確（支撐被打穿 = 原本看多的邏輯已被否定）
- 可以根據個股波動特性彈性調整
- 避免在正常波動中被洗出場

### 三、ATR 停損

以 [[技術分析/ATR平均真實波幅-Average-True-Range|ATR]] 為基礎的動態停損，根據市場波動調整停損距離：

- **計算方式**：停損價 = 買進價 − N × ATR
- **常見設定**：2ATR 或 3ATR 停損
- **優點**：波動大自動放寬、波動小自動收窄
- **缺點**：需要即時計算ATR

**範例**：
- 買進價 100 元，ATR(14) = 2.5 元
- 2ATR 停損 → 停損價 = 100 − 5 = 95 元
- 3ATR 停損 → 停損價 = 100 − 7.5 = 92.5 元

### 四、移動停損（Trailing Stop）

停損價跟著股價上漲而往上移動，鎖定利潤同時讓獲利奔跑：

- **固定百分比移動停損**：股價上漲時，停損價跟著上移，但跌幅超過觸發比例就出場
- **ATR 移動停損**：以收盤價 − N×ATR 為移動停損線
- **高點回跌百分比**：從最高點回跌超過X%就出場

詳見 [[風險管理/移動停利停損Trailing-Stop]]

### 五、理由消失停損

買進理由被市場否定時立即出場，不限於價格觸及：

- 均線黃金交叉買進 → **死亡交叉出場**
- 突破頸線買進 → **跌破頸線出場**
- 財報公佈前進場 → **財報不如預期出場**
- 法人連續買超買進 → **法人轉賣出場**

詳見 [[操作策略/理由消失停損法Reason-Based-Exit]]

### 六、時間停損

在設定時間內沒有如預期發動就走人：

- 買進後 N 個交易日未突破 → 出場
- 財報公佈前 N 天進場 → 財報公佈後若無反應出場
- 適合事件驅動型交易

### 七、Chandelier Exit 吊燈出場

以近期最高點為基準，往下掛 ATR 距離作為停損：

- 停損價 = 近期最高價 − N × ATR
- N 通常取 3
- 優點：跟隨趨勢自動調整，不會在盤整中停損

詳見 [[操作策略/Chandelier-Exit吊燈出場指標]]

## [[風險管理/部位控制2%法則Position-Sizing-2-Percent-Rule|2%法則]] 與停損的搭配

2%法則是說**單筆最大虧損不超過總資金的2%**，這決定了你的部位大小：

```
最大虧損金額 = 總資金 × 2%
買入股數 = 最大虧損金額 ÷ (買進價 − 停損價)
```

**範例**：
- 總資金 100 萬
- 最大虧損 = 100 萬 × 2% = 2 萬
- 買進價 50 元，停損價 47 元（6%停損）
- 可買股數 = 20,000 ÷ 3 = 6,666 股
- 實際投入 = 6,600 股 × 50 = 33 萬（佔總資金 33%）

**重點**：不是「買多少」決定停損，是停損距離決定「買多少」。

## 停損常見陷阱

### 1. 停損設太緊

- ATR很小的股票設3%停損 → 正常波動就觸發
- **解法**：至少用 2ATR 或前低停損

### 2. 停損往下移

- 「再等等看」→ 虧損擴大 → 認賠時已經虧了一大截
- **解法**：停損只往上移，絕不往下移

### 3. 停損後馬上回補

- 觸發停損後股價反彈 → FOMO 回補 → 又被洗
- **解法**：停損後至少冷卻1~2個交易日

### 4. 關前停損（停損設在整數關卡）

- 停損設在 50 元整數 → 主力專門打 50 元掃停損
- **解法**：停損設在整數關卡下方 1~2% ，例如 48.5 而非 50

### 5. 不設停損等於賭博

- 「我不設停損因為我是長期投資」→ 鴻海 300 元套到現在
- **解法**：長期投資也需要停損，只是停損距離可以較寬

## 不同交易風格的停損設定

| 交易風格 | 建議停損方法 | 停損距離 | 說明 |
|---------|------------|---------|------|
| 當沖 | 固定百分比 | 1~2% | 日內波動小，停損必須緊 |
| 短線波段 | ATR停損 | 2~3 ATR | 根據波動調整 |
| 中線波段 | 技術面停損 | 5~10% | 前低或均線 |
| 長線投資 | 理由消失停損 | 15~25% | 基本面惡化才出場 |
