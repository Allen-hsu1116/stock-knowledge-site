# Omega比率 Omega Ratio

> 把整個報酬分佈拆成「好的一半」和「壞的一半」，用機率加權比值衡量策略品質——比夏普和索提諾更全面的風險調整報酬指標，不需要假設報酬常態分佈。

## 核心概念

**Omega 比率**由 Con Keating 和 William F. Shadwick 在2002年提出，是對 [[風險調整報酬指標夏普比率與索提諾比率|夏普比率]] 和索提諾比率的升級。核心思想是：**不要只看報酬的均值和標準差，而是看整個報酬分佈相對於目標報酬率的表現**。

### 為什麼需要 Omega

傳統風險調整報酬指標的問題：

- **夏普比率**：用標準差衡量風險，但上漲的波動也被當成「壞的」風險，且假設報酬常態分佈
- **索提諾比率**：只看下行標準差，但仍假設下行風險可用標準差描述，忽略分佈形狀
- **兩者都用均值和離散度來摘要分佈**，但真實報酬分佈往往有偏態、肥尾、多峰

**Omega 比率直接使用整個報酬分佈**，不做任何分佈假設，不需要假設常態分佈，不需要假設對稱。它把所有報酬數據相對於目標報酬分成「超過目標」和「低於目標」兩群，然後比較這兩群的累積機率。

## 計算公式

### 定義

給定目標報酬率 θ（threshold，通常設為無風險利率或0），Omega 比率為：

$$\Omega(\theta) = \frac{\int_{\theta}^{\infty} [1 - F(r)] \, dr}{\int_{-\infty}^{\theta} F(r) \, dr}$$

其中：
- F(r) = 報酬率 r 的累積分佈函數（CDF）
- 分子 = 報酬超過目標 θ 的「期望超額」面積（收益潛力）
- 分母 = 報酬低於目標 θ 的「期望不足」面積（損失風險）

### 離散版本（實務計算用）

$$\Omega(\theta) = \frac{\frac{1}{N}\sum_{i=1}^{N} \max(r_i - \theta, 0)}{\frac{1}{N}\sum_{i=1}^{N} \max(\theta - r_i, 0)}$$

就是：
- **分子**：所有超過目標的報酬的平均超額部分
- **分母**：所有低於目標的報酬的平均不足部分

### 直覺解讀

- **Omega = 1**：收益潛力 = 損失風險，策略不賺不賠
- **Omega > 1**：收益潛力 > 損失風險，策略有正期望值
- **Omega < 1**：收益潛力 < 損失風險，策略有負期望值
- **Omega 越大越好**

### 計算範例

假設某策略過去10個月報酬率（目標θ=0）：

- +3%, +5%, +2%, -1%, +4%, -2%, +6%, +1%, -3%, +2%

**分子（超過0的部分平均）** = (3+5+2+4+6+1+2) / 10 = 2.3%
**分母（低於0的部分平均）** = (1+2+3) / 10 = 0.6%

$$\Omega(0) = \frac{2.3}{0.6} \approx 3.83$$

Omega = 3.83 表示每承受1單位損失風險，可獲得3.83單位的收益潛力。

## Omega 與其他指標比較

- **夏普比率**：用均值-目標 / 標準差 → 只看兩個摘要統計量
- **索提諾比率**：用均值-目標 / 下行標準差 → 改善了但仍只用摘要統計量
- **Omega 比率**：用整個分佈的積分 → 捕捉偏態、肥尾等所有分佈特徵

### 關鍵差異

| 比較項目 | 夏普比率 | 索提諾比率 | Omega 比率 |
|---------|---------|-----------|-----------|
| 分佈假設 | 常態分佈 | 半常態 | **無假設** |
| 風險衡量 | 總標準差 | 下行標準差 | 分佈全貌 |
| 偏態捕捉 | 無 | 部分 | **完整** |
| 肥尾捕捉 | 無 | 部分 | **完整** |
| 計算複雜度 | 低 | 中 | 高 |

### 與 Sortino 的數學關係

當報酬分佈對稱且目標 = 均值時，Omega 和 Sortino 會給出相似的排名。但當分佈有顯著偏態時（如選擇權賣方策略，小賺多次大虧偶爾），Omega 能更準確反映策略真實品質。

## 實戰應用

### 1. 策略選擇與排序

當比較多個策略時，Omega 比率提供不依賴分佈假設的排序：

- 策略A：年化報酬20%，夏普1.5，Omega 2.8
- 策略B：年化報酬15%，夏普1.2，Omega 3.5

傳統指標會選A，但 Omega 顯示B的風險調整後更優（因為B的分佈可能右偏，大賺次數多）。

### 2. 選擇權策略評估

選擇權賣方策略（如 [[跨式Straddle與勒式Strangle|跨式賣出]]、[[鐵蝴蝶Iron-Butterfly|鐵蝴蝶]]）的報酬分佈嚴重左偏——高機率小賺、低機率大虧。夏普和索提諾可能低估風險，Omega 能更真實反映。

### 3. 不同目標報酬的 Omega 曲線

**Omega 曲線**：畫出不同 θ 值下的 Omega 比率

- θ = 0 → 基本金額保護
- θ = 無風險利率 → 與夏普比較
- θ = 期望報酬 → 與 Sortino 比較
- θ = VaR 95% → 極端損失情境下的策略品質

曲線越陡 → 策略對目標變化越敏感（分佈越集中）
曲線越平 → 策略對目標變化越不敏感（分佈越分散）

### 4. 投資組合最佳化

用 Omega 比率取代夏普比率作為最佳化目標函數，可以避免常態分佈假設的限制，適用於包含選擇權、不動產等非傳統資產的投資組合。

## 台股實戰應用

### 個股選擇

用月報酬計算 Omega 比率篩選個股：
- θ = 0（不虧錢）
- 計算過去24個月報酬的 Omega
- Omega > 2 的股票加入觀察名單
- 搭配 [[CANSLIM選股法|CANSLIM]] 基本面篩選交叉確認

### 策略績效評估

在 [[回測績效評估完整體系Backtest-Performance-Evaluation|回測績效評估]] 中，Omega 是五大核心指標之一：

- **Sharpe Ratio**：總波動風險調整報酬
- **Sortino Ratio**：下行風險調整報酬
- **[[Calmar-Ratio年化報酬MDD|Calmar Ratio]]**：最大回撤風險調整報酬
- **Omega Ratio**：全分佈風險調整報酬
- **[[獲利因子Profit-Factor|Profit Factor]]**：毛利/毛損比

## Omega 的限制

1. **計算複雜**：需要完整報酬序列而非摘要統計量，計算量比夏普/索提諾大
2. **樣本依賴**：小樣本下 Omega 估計不穩定，建議至少36個月數據
3. **目標選擇敏感**：不同 θ 值會產生不同排名，需明確說明目標設定
4. **缺乏直覺**：不像 Sharpe 或 Calmar 有「每單位風險賺多少」的直觀解讀
5. **不區分路徑**：Omega 基於分佈而非時間序列，不考慮回撤的路徑風險（[[MDD最大回撤進階實戰各資產歷史回撤與管理方法|MDD]] 和 [[CDaR條件回撤風險Conditional-Drawdown-at-Risk|CDaR]] 補充）
