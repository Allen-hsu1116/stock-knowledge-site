# Amihud非流動性指標 Amihud Illiquidity Measure

> 用「價格變動量÷成交量」量化非流動性——Yakov Amihud在2002年提出的流動性代理指標，學術界最廣泛使用的非流動性衡量工具。

## 核心概念

**流動性**是「不影響價格就能大量交易的能力」。流動性好的股票，大單進出不會造成價格劇烈波動；流動性差的股票，同樣大單會造成顯著價格衝擊。

**Amihud非流動性指標**（ILLIQ）的核心邏輯是：**如果某資產在低成交量下就出現大幅價格變動，代表它非流動性高**。反向思考——如果高成交量但價格幾乎不動，代表流動性極佳。

### 為什麼需要這個指標

傳統流動性衡量工具都有局限：
- **買賣價差（Bid-Ask Spread）**：只反映報價層面的流動性，不反映成交後的價格衝擊
- **成交量**：高成交不代表流動性好（可能是大單造成價格大幅移動）
- **週轉率**：不考慮價格影響
- **Kyle's Lambda**：需要高頻數據和回歸分析，一般投資人難以計算

Amihud指標只需日線數據（收盤價+成交量），計算簡單且被學術界廣泛驗證。

## 計算公式

### 基本公式

$$ILLIQ_{i,t} = \frac{|r_{i,t}|}{DollarVolume_{i,t}}$$

其中：
- $|r_{i,t}|$ = 第i支股票第t日的報酬率絕對值
- $DollarVolume_{i,t}$ = 第t日的成交金額（成交量×收盤價）

**直覺解讀**：每1元成交金額造成多少比例的價格變動。數值越大代表非流動性越高。

### 平均版本（常用）

通常取N日平均：

$$ILLIQ_i = \frac{1}{N} \sum_{t=1}^{N} \frac{|r_{i,t}|}{DollarVolume_{i,t}}$$

常用N=21（一個月交易日）或N=252（一年）。

### 對數版本

為避免極端值和方便回歸分析，常取對數：

$$\log(ILLIQ) = \frac{1}{N} \sum_{t=1}^{N} \log\left(\frac{|r_{i,t}|}{DollarVolume_{i,t}}\right)$$

### 計算範例

假設某冷門股三天的數據：

**Day 1**：報酬率+2%，成交金額5000萬 → ILLIQ = 0.02 / 50,000,000 = 4.0 × 10⁻¹⁰
**Day 2**：報酬率-1.5%，成交金額3000萬 → ILLIQ = 0.015 / 30,000,000 = 5.0 × 10⁻¹⁰
**Day 3**：報酬率+3%，成交金額8000萬 → ILLIQ = 0.03 / 80,000,000 = 3.75 × 10⁻¹⁰

3日平均ILLIQ = (4.0 + 5.0 + 3.75) / 3 × 10⁻¹⁰ ≈ **4.25 × 10⁻¹⁰**

對比台積電同樣3天：
**Day 1**：報酬率+0.5%，成交金額800億 → ILLIQ = 0.005 / 80,000,000,000 = 6.25 × 10⁻¹⁴

→ 台積電的非流動性比冷門股低約**1000倍**。

## 實戰應用

### 1. 非流動性溢價（Illiquidity Premium）

Amihud在2002年的論文發現：**非流動性高的股票長期報酬率較高**。這是「非流動性溢價」——投資者要求更高的報酬來補償流動性風險。

- 美股市場：非流動性最高十分位 vs 最低十分位的年化報酬差距約7-8%
- 台股應用：小型冷門股的長期超額報酬部分來自非流動性溢價
- **投資啟示**：如果你願意且能夠持有非流動性資產，可以賺取流動性溢價

### 2. 部位規模控制

Amihud指標直接回答「我能買多少？」

- **高ILLIQ股票**：小單就會造成大價格衝擊 → 部位必須很小
- **低ILLIQ股票**：大單進出價格影響小 → 可以建立較大部位
- **實務公式**：最大部位 ≈ 日均成交金額 × (可接受價格衝擊 ÷ ILLIQ)

### 3. 流動性擇時

市場整體Amihud指標可以作為系統性流動性指標：

- **ILLIQ上升**：市場流動性惡化，風險偏高 → 降低部位
- **ILLIQ下降**：市場流動性改善 → 可以增加部位
- 2008金融危機、2020COVID崩盤期間ILLIQ都暴增

### 4. 配對交易的流動性篩選

做[[配對交易進階實戰|配對交易]]時，兩支股票的ILLIQ應該相近：
- 如果A股票ILLIQ很低、B股票ILLIQ很高，建倉平倉時B股票的滑價會遠大於A
- ILLIQ比值 > 5 的配對不適合做配對交易

### 5. 與其他流動性指標交叉驗證

- **+ 買賣價差**：Amihud衡量成交後衝擊，價差衡量報價成本，兩者互補
- **+ 週轉率**：低週轉率+高ILLIQ = 嚴重非流動性
- **+ [[市場微結構與流動性定價Market-Microstructure-and-Liquidity-Pricing|Amihud非流動性指標已在此頁提及]]**

## 台股實戰框架

### 篩選流程

1. **計算21日ILLIQ**：用每日報酬率絕對值÷成交金額
2. **百分位數排序**：把全市場ILLIQ排序，分5組
3. **最高20%（ILLIQ最高）**：非流動性極高，適合長期價值投資人
4. **最低20%（ILLIQ最低）**：流動性極佳，適合短線交易與大資金

### 與流動性風險管理整合

- [[流動性風險Liquidity-Risk|流動性風險]]基礎：部位不超過日成交量1%
- Amihud精確化：部位不超過「可接受價格衝擊 ÷ ILLIQ × 日均成交金額」
- [[流動性幻覺Liquidity-Illusion|流動性幻覺]]：平時ILLIQ低不代表危機時也低
- [[流動性風險量化衡量與流動性調整VaR-Liquidity-Adjusted-VaR|L-VaR]]：Amihud是L-VaR的核心輸入

### 常見誤區

**誤區1：ILLIQ越低越好**
→ 非流動性溢價說明高ILLIQ股票長期報酬更高。低ILLIQ適合交易，高ILLIQ適合投資（如果你能忍受流動性風險）。

**誤區2：只看ILLIQ就夠了**
→ Amihud是日線指標，不反映盤中流動性變化。盤中流動性可能突然蒸發（閃崩），需搭配高頻指標如VPIN。

**誤區3：ILLIQ是常數**
→ ILLIQ隨時間大幅變化，危機時所有股票ILLIQ同時暴增。需追蹤ILLIQ的變化趨勢而非單點值。

## Amihud指標的局限

- **價格波動≠流動性**：報酬率大可能是因為新聞事件而非流動性差。ILLIQ把所有價格波動都歸因於流動性，會高估非流動性
- **零成交量日問題**：沒有交易的日子ILLIQ無法計算（分母為零），需特殊處理
- **漲跌停日失真**：台股漲跌停鎖死時成交極少但報酬率極大，ILLIQ會異常飆高
- **只看日線**：日內流動性變化完全被忽略

## 學術背景

- **Yakov Amihud**：紐約大學Stern商學院教授，流動性研究權威
- **2002年論文**："Illiquidity and Stock Returns: Cross-Section and Time-Series Effects"
- **發現**：非流動性是橫截面報酬的顯著解釋因子，獨立於規模、價值、動量因子
- **後續研究**：Amihud指標被用於40+國家的市場研究，驗證非流動性溢價的普適性
