# 動態部位管理 Dynamic Position Sizing

> 不是固定2%走天下——根據市場波動度、策略勝率和帳戶狀態動態調整部位大小，讓風險永遠在控制之中。

## 核心概念

### 為什麼需要動態部位管理

固定比例部位管理（如2%法則）的問題：
- **高波動時倉位太大**：市場波動加大，2%的停損距離不變但實際風險增加
- **低波動時倉位太小**：市場平靜，2%停損距離可以放大部位但沒放大
- **帳戶損益未反映**：連虧後應減碼但固定比例不會自動減碼

**動態部位管理的核心邏輯**：市場給你多少風險預算，你就承擔多少風險。

### 三大動態調整維度

**維度一：波動度調整（Volatility-Based Sizing）**

根據標的波動度決定部位大小：
```
部位大小 = 帳戶風險預算 / (ATR × 合約乘數)
```

- ATR大（高波動）→ 部位縮小
- ATR小（低波動）→ 部位放大
- **結果**：不同波動度的股票承擔相同的金額風險

**維度二：勝率調整（Win Rate-Based Sizing）**

根據策略近期勝率動態調整：
- 連虧3次以上 → 部位減半或暫停交易
- 連贏 → 維持正常部位，不急加碼
- 勝率低於歷史平均2個標準差 → 減碼至50%

公式（Kelly變形）：
```
f = p - (1-p)/(b)
```
其中 p = 勝率，b = 賺賠比

Half Kelly建議：用Kelly公式計算結果的一半作為部位上限。

**維度三：帳戶狀態調整（Equity Curve-Based Sizing）**

根據帳戶淨值曲線狀態調整：
- 帳戶創新高 → 正常部位
- 帳戶從高點回撤5% → 部位減至75%
- 帳戶從高點回撤10% → 部位減至50%
- 帳戶從高點回撤15% → 暫停交易，僅觀察

### 四種動態部位管理模型

**模型一：ATR部位模型**
```
股數 = (帳戶淨值 × 風險%) / (進場價 - 停損價)
停損距離 = 2 × ATR(14)
```
- 優點：自動適應不同股票的波動特性
- 缺點：需要即時ATR數據
- 最適合：波段交易、多標的組合

**模型二：Kelly部位模型**
```
f* = (bp - q) / b
```
其中 b = 賺賠比，p = 勝率，q = 1-p

實戰使用 Half Kelly：
```
部位比例 = f* / 2
```
- 優點：數學最優解
- 缺點：過度依賴歷史勝率和賺賠比估計
- 最適合：有足夠歷史數據的系統化策略

**模型三：帳戶曲線部位模型**
```
部位%= 基礎部位% × 調整係數

調整係數：
帳戶創新高 → 1.0
回撤0-5%   → 1.0
回撤5-10%  → 0.75
回撤10-15% → 0.50
回撤15%+   → 0（暫停）
```
- 優點：自動在虧損期減碼，保護帳戶
- 缺點：可能錯過回檔後的反彈
- 最適合：想要穩定資金曲線的交易者

**模型四：波動率目標模型（Volatility Targeting）**
```
目標波動率 = 15%（年化）
部位 = 目標波動率 / 標的實際波動率
```
- 標的波動率30% → 部位 = 15/30 = 50%
- 標的波動率15% → 部位 = 15/15 = 100%
- 標的波動率10% → 部位 = 15/10 = 150%（需要槓桿）

- 優點：讓投資組合的整體波動率穩定
- 缺點：高波動標的會被大幅減碼
- 最適合：追求穩定報酬的投資組合

## 實戰應用

### 動態部位管理SOP五步驟

**Step 1：設定基礎風險預算**
- 單筆最大風險：帳戶淨值的1-2%
- 帳戶最大回撤容忍：10-20%
- 每日最大虧損：帳戶淨值的3-5%

**Step 2：計算標的波動度**
- 使用ATR(14)或歷史波動率(20日)
- 波動度 = MAX(ATR, 20日歷史波動率×進場價)
- 取較大值保守估計風險

**Step 3：計算基礎部位**
```
基礎部位 = (帳戶淨值 × 1%) / (ATR × 合約乘數)
```

**Step 4：根據三維度調整**
- 波動度調整：高波動減碼、低波動加碼
- 勝率調整：連虧減碼、連贏維持
- 帳戶調整：回撤減碼、創新高正常

**Step 5：設定調整上限**
- 單一標的不超過總資金的10%
- 總曝險不超過總資金的30-50%
- 槓桿倍數不超過2倍

### 台股實戰範例

**範例：台積電(2330)波段交易**
- 帳戶淨值：100萬
- 單筆風險：1% = 10,000元
- 台積電ATR(14)：15元（股價900元）
- 停損距離：2×ATR = 30元
- 基礎部位 = 10,000 / 30 = 333股 ≈ 3張
- 部位金額 = 3 × 900 = 270,000元（佔帳戶27%）

**帳戶回撤調整**：
- 如果帳戶從高點回撤8%
- 調整係數 = 0.75
- 部位調整 = 3 × 0.75 = 2.25 → 減碼至2張

**波動度變化調整**：
- 如果ATR從15元擴大到25元（波動增加67%）
- 停損距離 = 2 × 25 = 50元
- 新部位 = 10,000 / 50 = 200股 ≈ 2張
- 原本3張降為2張

### 不同策略的部位模型選擇

| 策略類型 | 推薦模型 | 原因 |
|---------|---------|------|
| 日沖交易 | Kelly模型 | 勝率數據充足，可精確計算 |
| 波段交易 | ATR模型 | 波動度差異大，需要適應 |
| 趨勢追蹤 | 波動率目標 | 波動變化大，需要穩定化 |
| 價值投資 | 帳戶曲線 | 進出場頻率低，看重帳戶保護 |
| 多策略組合 | 混合模型 | 各策略特性不同 |

## 注意事項

### 四大陷阱

**陷阱一：過度最佳化部位公式**
- 歷史最優部位≠未來最優部位
- Kelly公式給出的部位經常太大
- 建議使用Half Kelly或Quarter Kelly

**陷阱二：忽略交易成本**
- 手續費、滑價、稅金
- 頻繁調整部位會侵蝕利潤
- 設定最小調整門檻（如±10%才調整）

**陷阱三：多標的相關性風險**
- 5個部位各2%風險≠10%總風險
- 高相關標的實際風險是疊加的
- 相關性>0.7的標的視為同一風險源

**陷阱四：情緒干擾動態調整**
- 連虧時不敢減碼（已經虧了不想認）
- 連贏時過度加碼（覺得自己無敵了）
- 動態部位管理必須100%機械化執行

### 動態vs靜態部位管理比較

| 特性 | 靜態（固定2%） | 動態 |
|------|-------------|------|
| 簡單度 | ★★★★★ | ★★★ |
| 適應性 | ★★ | ★★★★★ |
| 風險控制 | ★★★ | ★★★★★ |
| 報酬穩定性 | ★★★ | ★★★★ |
| 長期存活率 | ★★★ | ★★★★★ |
| 執行難度 | ★★ | ★★★★ |

**建議**：新手從靜態2%法則開始，建立紀律後再進階到動態模型。

### 與其他風險管理工具的整合

動態部位管理不是單獨使用的，它應該與其他工具整合：
- **停損**：進場前確定停損點，再反推部位
- **移動停損**：部位大小隨移動停損調整
- **帳戶曲線**：帳戶回撤到一定程度時全系統減碼
- **相關性矩陣**：多標的組合的整體風險預算
