# 一致性風險測度 Coherent Risk Measures

> 風險測度的四大公理——單調性、次可加性、正齊次性、平移不變性——VaR 不合格、CVaR 才合格的數學原因。

## 核心概念

一致性風險測度（Coherent Risk Measure）是 Artzner、Delbaen、Eber、Heath（1999）提出的理論框架，用四條公理判斷一個風險測度是否「合理」。如果一個風險測度同時滿足這四條，就稱為「一致的」風險測度。

### 四大公理

**1. 常態化（Normalized）**：ϱ(0) = 0
不持有任何資產，風險為零。廢話，但是起點。

**2. 單調性（Monotonicity）**：如果 Z₁ ≤ Z₂（幾乎必然），則 ϱ(Z₁) ≥ ϱ(Z₂)
報酬越好的組合，風險越低。邏輯上：如果你未來一定賺比較多，那你的風險就應該比較小。

**3. 次可加性（Sub-additivity）**：ϱ(Z₁ + Z₂) ≤ ϱ(Z₁) + ϱ(Z₂)
兩個組合合在一起，風險不會比各自風險加總更大。這就是**分散投資有效**的數學表達。合在一起的風險可能更小（因為相關性 < 1），但絕不會更大。

**4. 正齊次性（Positive Homogeneity）**：ϱ(αZ) = αϱ(Z)（α ≥ 0）
部位放大 n 倍，風險也放大 n 倍。槓桿線性放大風險。

**平移不變性（Translation Invariance）**：ϱ(Z + A) = ϱ(Z) - a
加入確定報酬 a（例如無風險利率），風險等量下降。如果 a = ϱ(Z)，則 ϱ(Z + A) = 0，也就是存夠資本就零風險。

### 凸風險測度（Convex Risk Measure）

後來 Föllmer & Schied（2002）放寬了次可加性和正齊次性，用「凸性」取代：
ϱ(λZ₁ + (1-λ)Z₂) ≤ λϱ(Z₁) + (1-λ)ϱ(Z₂)

凸風險測度比一致性風險測度更寬鬆，但保留了「分散有益」的核心精神。正齊次性在現實中不一定成立（大部位的市場衝擊成本非線性），凸性更貼近現實。

## VaR 為什麼不合格

**[[VaR風險值Value-at-Risk|VaR]] 不是一致性風險測度**，因為它違反了次可加性。

經典反例：兩檔零息債券，各自有 4% 違約機率，回收率 30%。
- 單獨持有任一檔：95% VaR = 0（因為 4% < 5%，VaR 不計入尾部）
- 同時持有各 50%：95% VaR = 35%（因為至少一檔違約的機率 = 1 - 0.96² = 7.84% > 5%）

VaR(50%+50%) = 35% > 0 + 0 = VaR(50%) + VaR(50%)，**次可加性被違反**。

這意味著 VaR 可能「懲罰分散投資」——分散後風險反而看起來更大。這在監管上是有問題的，因為 Basel 框架用 VaR 做資本要求，可能導致「分散反而要更多資本」的荒謬結果。

VaR 在橢圓分配（常態分配）且組合價值是線性函數時才是一致的，但現實中報酬分配有肥尾，VaR 就不合格。

## CVaR 為什麼合格

**[[CVaR條件風險價值Conditional-Value-at-Risk|CVaR]]（Expected Shortfall）是一致性風險測度**。CVaR 看的是超過 VaR 閾值之後的平均損失，而非單一點的百分位數，所以不會有 VaR 那種「尾部突然跳一下就違反次可加性」的問題。

CVaR 的數學性質：連續分配下 CVaR 必定是一致的；離散分配下在某些極端情況下仍可能違反次可加性，但可以用修正版本解決。

## 其他一致性風險測度

- **Tail Value at Risk（TVaR）**：尾部條件期望值，一致性
- **Entropic VaR**：基於熵概念的風險測度，一致性
- **[[光譜風險測度Spectral-Risk-Measure|光譜風險測度]]**：用非遞增權重函數加權所有分位數，必定是一致性的（Acerbi, 2002）
- **Wang Transform**：用扭曲函數轉換分配，某些情況下一致性

## 實戰應用

**風險指標選擇**：用 VaR 做風控會有「分散看起來更危險」的盲區。實務上：
- 銀行監管：Basel III 已從 VaR 轉向 Expected Shortfall（FRTB 框架）
- 內部風控：如果還在用 VaR，至少同時報告 CVaR 做對照
- 策略評估：回測中用 CVaR 而非 VaR 做最大虧損估算，避免低估尾部風險

**分散投資驗證**：用一致性風險測度可以數學驗證「分散有效」。如果兩個策略的 CVaR 加總 > 合併後 CVaR，分散就有效；如果用 VaR 可能算出反向結果。

## 注意事項

- **正齊次性的現實偏差**：理論上部位放大 n 倍風險放大 n 倍，但實際上大部位有市場衝擊、流動性惡化等非線性效應。凸風險測度更貼近這個現實
- **VaR 不是完全沒用**：VaR 在常態分配假設下是一致的，且溝通容易（「95% 信心不會超過 X」），但必須知道它的缺陷
- **一致性不等於正確**：一致性是數學上的「合理」，不代表能準確預測未來風險。模型風險和分配假設仍是問題
