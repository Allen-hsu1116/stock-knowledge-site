# 外資資金匯入匯出與大盤多空判讀

> 外資資金流向是台股最根本的領先指標——有錢才能買，匯入先於買超、匯出先於賣超

## 核心概念

外資資金匯入匯出是觀察台股多空的第一道防線。外資是台股最大買超力量，累計匯入金額與加權指數高度正相關（相關係數0.85-0.92）。資金流向比買賣超更根本，因為「有錢才能買」。

### 三大數據來源

- **證交所**：每月公布外資匯入淨額、匯出淨額、累計匯入淨額
- **央行**：每週公布外資投資國內證券資金進出統計
- **金管會**：即時統計外資累計匯入金額

### 關鍵數據解讀

- **匯入淨額**：當期匯入減匯出，正數代表外資淨匯入
- **累計匯入淨額**：歷年總累積，衡量外資長期進出趨勢
- **匯入率**：匯入淨額佔累計匯入淨額的比例

## 實戰應用

### 四種資金流向型態

1. **持續匯入型**：連續數月淨匯入，大盤通常多頭。最強多頭訊號
2. **持續匯出型**：連續數月淨匯出，大盤面臨壓力。2008金融海嘯、2022升息周期皆出現
3. **匯入減緩型**：仍淨匯入但金額縮小，大盤可能轉弱的早期訊號
4. **匯出減緩型**：仍淨匯出但金額縮小，大盤可能反彈的早期訊號

### 資金流向 vs 買賣超：三種背離情境

- **資金進但沒買**（匯入 + 賣超或小買超）：錢進來了在觀望，進場前兆
- **資金出但沒賣**（匯出 + 小賣超或買超）：資金調度，不一定是看空
- **資金出且大賣**（匯出 + 大賣超）：最危險組合，全面撤離

### 外資匯出入與匯率關係

1. 外資匯入 → 台幣升值（美元換台幣買股）
2. 外資匯出 → 台幣貶值（台幣換美元匯出）
3. 台幣升值預期 → 吸引外資匯入（匯兌收益+資本利得雙重誘因）
4. 台幣貶值預期 → 促使外資匯出（匯兌損失侵蝕資本利得）

### 匯入加速期選股策略

1. 外資持股比例偏低的績優股（加碼空間大）
2. 外資連續買超的個股（方向明確）
3. 大市值權值股（外資偏好流動性好的標的）

### 匯出加速期防禦策略

1. 減持外資高持股個股
2. 轉向內資主導的中小型股
3. 觀察外資賣超但股價不跌的個股（內資接手）

## 注意事項

- **資金數據有時間差**：證交所數據落後1-2週，實務上用買賽超日資料即時追蹤
- **匯入≠買超**：資金可能暫時停泊在銀行帳戶不會立刻買股
- **被動型vs主動型外資**：ETF追蹤指數的被動買賽不反映主觀看法
- **資金調度≠實質進出**：不同外資間的資金調度不代表多空方向
- **匯出不一定看空**：可能是獲利了結、匯率避險或資金重新配置
