# 集保股權分散多層級判讀 中實戶大戶散戶進階分析

> 千張大戶只是冰山一角，中實戶是主力的洗盤對象、中大戶是最靈敏的先行指標、散戶是進出场的反向訊號——多層級交叉判讀才能看懂籌碼真正的流向

## 核心概念

集保股權分散表是台股最重要的籌碼面工具之一，但多數投資人只看千張大戶的增減，忽略了其他層級蘊含的豐富訊息。不同持股層級代表不同類型的投資人，他們的增減互動構成了籌碼流動的完整畫像。

理解多層級判讀的核心邏輯：**籌碼從下往上流動=集中（偏多），從上往下流動=分散（偏空）**。

### 集保持股層級定義與特徵

| 層級 | 持股張數 | 代表身分 | 判讀意義 |
|------|----------|----------|----------|
| 散戶 | 1-5張 | 小額投資人 | 反向指標，人數越多越危險 |
| 中散戶 | 5-10張 | 有紀律的散戶 | 容易被洗出場 |
| 中實戶 | 10-50張 | 中型主力/投資人 | 主力洗盤的重點對象 |
| 大實戶 | 50-100張 | 接近法人規模的投資人 | 方向性參考 |
| 中大戶 | 100-400張 | 大型主力 | 進出影響股價流動性 |
| 大戶 | 400-1000張 | 大型主力/小法人 | 最靈敏的先行指標 |
| 千張大戶 | >1000張 | 超大戶/法人 | 趨勢確認者 |

### 各層級的判讀重點

**千張大戶（>1000張）— 趨勢確認者**

千張大戶的增減是趨勢確認的最重要指標，但反應較慢（因為進出量體大，需要時間完成）。
- 增加：大資金進場，通常需要較長時間布局，股價中長期看多
- 減少：大資金退場，趨勢可能反轉
- 黃金區間40%-70%：低於30%籌碼太散容易亂跌，高於80%流動性不足難以拉抬

**400-1000張中大戶 — 最靈敏的先行指標**

這個層級是所有層級中最早反應的，因為中大戶進出比千張大戶快，又能代表明確的資金方向。
- 增加：有資金正在加碼但尚未到千張規模，通常是千張大戶增加的前兆
- 減少：中大戶開始調節，可能領先千張大戶1-2週出現減少
- **實戰用法**：如果中大戶連續2週增加+千張大戶尚未增加，是提前進場訊號

**10-50張中實戶 — 主力洗盤的重點對象**

中實戶是主力在吸籌和出貨過程中都要處理的對象。吸籌時要把他們洗出去，出貨時要讓他們接手。
- 中實戶增加+大戶減少=籌碼分散（大戶出貨給中實戶），偏空
- 中實戶減少+大戶增加=籌碼集中（中實戶被洗出、大戶接手），偏多
- 中實戶穩定+大戶穩定=籌碼安定，股價可能盤整

**1-5張散戶 — 最有效的反向指標**

散戶人數變化與股價呈反向關係，這是經過歷史驗證的規律：
- 散戶人數增加=籌碼分散=股價高檔風險增加
- 散戶人數減少=籌碼集中=股價低檔機會浮現
- 散戶持股比>50%+大戶減少=最危險的組合
- 散戶持股比<30%+大戶增加=最安全的組合

## 實戰應用

### 跨層級互動判讀的三種模式

**模式一：籌碼集中（偏多訊號）**

籌碼從下往上流動：
1. 散戶減少 → 中實戶減少 → 大戶增加
2. 代表大戶正在吸籌，散戶和中實戶被洗出
3. 過程中股價可能盤整或小幅下跌（主力壓低吸貨）
4. **進場時機**：中大戶層級率先增加+千張大戶尚未增加時

**模式二：籌碼分散（偏空訊號）**

籌碼從上往下流動：
1. 大戶減少 → 中實戶增加 → 散戶增加
2. 代表大戶正在出貨，籌碼分散到散戶手中
3. 過程中股價可能還在上漲（主力邊拉邊出）
4. **出場時機**：千張大戶連續2週減少+散戶人數增加

**模式三：籌碼換手（中性偏多）**

同一層級內的內部流動：
1. 舊大戶減少+新大戶增加（不同分點進出）
2. 中實戶數量穩定
3. 股價回檔幅度有限，代表有新主力接手
4. **判斷方法**：看分點進出是否出現新的買方分點

### 多層級選股條件

選股時同時檢視多個層級，提高勝率：

1. 千張大戶持股比例在40%-70%區間
2. 近4週千張大戶持股比例增加≥3%
3. 400-1000張層級近2週增加>5%（先行指標）
4. 散戶（1-5張）近4週人數減少
5. 中實戶穩定或小幅減少（被主力洗出）
6. 股價在月線之上或接近月線（技術面配合）

### 內部大戶理論交叉應用

集保股權分散表大戶增減扣除三大法人，就能推算非法人大戶的動向：
- 單週爆買佔股本2%以上=進場訊號
- 持續買超5%以上=確認訊號
- 搭配多層級分析，如果非法人大戶增加集中在400-1000張層級，代表新資金正在建倉

### 不同股性的層級差異

**大型權值股（如台積電）**：
- 401-1000張層級最重要（法人主力在這區間）
- 千張大戶變動緩慢，因為持股規模太大
- 1-400張層級變化對股價影響有限

**中小型股**：
- 10-50張中實戶變化最關鍵（主力資金規模相對小）
- 千張大戶持股超過60%可能流動性不足
- 1-5張散戶比例>50%是高危險信號

## 注意事項

### 五大限制

1. **資料落後**：集保股權分散表每週五更新，數據落後1-2週，短線操作參考價值有限
2. **法人混入**：三大法人持股也在大戶層級中，要看真正的「個人大戶」需扣除法人持股
3. **除權息影響**：除權息後張數改變、層級可能跳動，比較前後需還原基準
4. **分拆帳戶**：有時大戶把持股拆到多個帳戶，讓大戶層級看起來減少但實際上沒出貨
5. **ETF被動持有**：ETF大量持有的個股，大戶層級會被動增加，不代表有主力進場

### 三個常見錯誤

1. **只看千張大戶**：忽略了更靈敏的中大戶和中實戶變化
2. **把層級變化當絕對訊號**：單一層級變化不足以判斷方向，必須跨層級交叉驗證
3. **忽略扣除法人**：法人持股佔大戶層級的比例越高，單看大戶增減的誤差越大
