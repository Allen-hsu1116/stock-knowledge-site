# 套息交易 Carry Trade

> 借低利率貨幣買高利率資產，賺利差的同時承擔匯率風險——全球最古老的套利策略之一。

## 核心概念

套息交易（Carry Trade）是外匯市場最經典的策略：借入低利率貨幣（融資貨幣），投資於高利率貨幣或資產（目標貨幣），賺取兩者之間的利率差。

**基本機制：**
- 在日本以 0.1% 利率借入日圓
- 換匯成澳幣存入澳洲銀行賺 4.5% 利率
- 利差 4.4% 就是「Carry」（息差收益）
- 只要匯率不大幅波動，每年穩賺 4.4%

## 兩大類型

### 傳統外匯套息交易（FX Carry Trade）
- **融資貨幣**（低利率）：日圓（JPY）、瑞郎（CHF）、歐元（EUR）
- **目標貨幣**（高利率）：澳幣（AUD）、紐幣（NZD）、墨西哥披索（MXN）、土耳其里拉（TRY）
- 收益 = 利差 - 換匯成本 - 資金成本
- 槓桿通常 10-50 倍

### 跨資產套息交易
- **債券套息**：借低利率國家公債、買高利率國家公債
- **信用套息**：賣低利率主權債 CDS、買高利率公司債 CDS
- **股票套息**：借低利率融資買高股息股票（台股散戶最常做的變體）
- **加密貨幣套息**：借穩定幣買高收益率 DeFi 協議

## 為什麼套息交易「有效」？

### 學術基礎：Uncovered Interest Rate Parity 失效
- 學術理論 UIP 預測：高利率貨幣應該貶值抵消利差收益
- 實證發現：高利率貨幣長期不貶值甚至升值（Forward Premium Puzzle）
- 這意味著利差收益未被匯率變動抵消 → 套息交易長期獲利

### 行為基礎：風險偏好
- 套息交易本質上是在「賣保險」——賣出波動率保護
- 全球風險偏好高時，資金從避險貨幣流向風險貨幣
- 投資者願意承擔匯率風險換取利差收益

## 套息交易的致命風險

### 「刀尖上起舞」的收益結構
- **常態**：每月穩定賺取利差，勝率極高（月度正報酬機率 60-70%）
- **危機**：匯率反向劇烈波動，一個月虧掉數年累積的利差收益
- 收益結構：**賣出看跌選擇權**的報酬型態（高勝率、小賺、尾部大虧）

### 日圓套息交易的崩盤案例

**2008 金融危機：**
- 日圓套息交易規模估計 1 兆美元
- 金融危機爆發 → 全球去槓桿 → 日圓急升 20-30%
- 賣出澳幣買回日圓還債 → 日圓進一步升值 → 火災拍賣連鎖效應
- 套息交易者數年累積的利差收益在一個月內歸零

**2024-2025 日圓升值事件：**
- 日本央行升息 + 美國降息預期 → 日圓急升
- 全球套息交易平倉潮 → 美股、台股同步重挫
- 台股與日圓的負相關性在危機時急劇上升

### 三大風險來源
1. **匯率風險**：目標貨幣貶值或融資貨幣升值，利差收益被匯損吃掉
2. **利率風險**：融資貨幣升息或目標貨幣降息，利差縮小或消失
3. **流動性風險**：危機時無法平倉，被迫承受更大匯率損失

## 與台股的關聯

### 台股是隱形的套息交易受益者
- 全球套息交易資金流向高利率、高成長市場
- 台股在 2025-2026 年的 AI 超級週期中吸引了大量外資
- 外資借低利率貨幣（日圓、美元）買台股 = 變相套息交易
- 當日圓升值 → 外資被迫平倉 → 台股遭到拋售

### 台股散戶的「本土版套息交易」
- 融資買高殖利率股票 = 借 2-3% 利率的錢買 5-6% 殖利率的股票
- 利差 2-3% 看似穩定，但股價下跌 10% 就虧掉 3-5 年的利差
- 本質上就是微型套息交易，風險結構完全相同

- **日圓匯率**：USD/JPY 走勢是台股外資流向的前瞻指標
- **美日利差**：Fed vs BoJ 利率差異是套息交易規模的核心驅動力
- **VIX 恐慌指數**：VIX 飆升 = 全球去槓桿 = 套息交易平倉訊號

## 套息交易與跨市場分析的整合

套息交易是理解跨市場聯動的核心框架：

- **債券 → 外匯 → 股票 → 商品**的傳導鏈
- 當全球利率環境變化 → 套息交易重新定價 → 資金跨市場流動
- 美林投資時鐘的四階段輪動本質上就是利率環境變化驅動的套息交易再配置
- 詳見 [[操作策略/跨市場分析Intermarket-Analysis|跨市場分析]]

### 實戰觀察框架
1. 看**美日利差**趨勢 → 判斷套息交易是否擴張或收縮
2. 看**日圓走勢** → 日圓升值 = 平倉壓力 = 台股外資賣壓
3. 看**VIX** → VIX > 30 套息交易平倉機率急劇上升
4. 看**信用利差** → 信用利差擴大 = 風險偏好下降 = 套息交易撤退
- 詳見 [[風險管理/信用利差Credit-Spread|信用利差]]

## 風險管理：套息交易的生存法則

1. **部位控制**：套息交易的尾部風險無法消除，部位不超過總資金 20%
2. **動態停損**：設定匯率停損線（如目標貨幣貶值 5% 即平倉），不要硬扛
3. **分散貨幣**：不要只做單一貨幣對，分散到 3-5 組不同貨幣對
4. **VIB（Volatility-Based Intervention）**：VIX 超過 25 自動減碼 50%
5. **不過度槓桿**：雖然專業基金用 10-50 倍槓桿，散戶建議不超過 3 倍

## 歷史數據

- 2000-2007 日圓套息交易年化報酬約 5-8%（未加槓桿）
- 2008 年單年虧損 -30%~-50%（取決於貨幣對和槓桿）
- 2010-2019 低利率時代利差壓縮，套息交易報酬降至 2-4%
- 2022-2026 全球利率分化加劇，套息交易捲土重來
