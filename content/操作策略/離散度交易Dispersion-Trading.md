# 離散度交易 Dispersion Trading

> 指數的隱含波動率長期高於成分股的隱含波動率——離散度交易做空這個結構性溢價，賣指數方差買成分股方差

## 核心概念

離散度交易（Dispersion Trading）是相對價值策略的經典，利用**指數隱含波動率**與**成分股隱含波動率加權平均**之間的結構性價差：

- **做空指數方差**：賣出指數的方差交換或賣出指數選擇權跨式
- **做多成分股方差**：買入成分股的方差交換或買入個股選擇權跨式
- 損益 = 成分股方差加權平均 − 指數方差（近似，還有相關性與權重調整）

### 為什麼有價差

指數的方差公式：

```
σ²_index = Σ wᵢ² σᵢ² + Σᵢ≠ⱼ wᵢ wⱼ σᵢ σⱼ ρᵢⱼ
```

其中 wᵢ 是權重、σᵢ 是成分股波動率、ρᵢⱼ 是兩兩相關係數。

關鍵發現：**市場長期高估成分股間的相關係數**。當相關性低於隱含水準，指數實際波動率會低於成分股加權波動率。原因：

- 避險需求：機構買指數選擇權避險，推高指數IV
- 流動性溢價：指數選擇權流動性好，賣方要風險溢價
- 相關性幻覺：市場假設危機時所有股票一起跌，但平時相關性低
- 模型錯誤：用歷史相關性預測未來會高估

相關頁面 [[相關性風險Correlation-Risk]]、[[相關性崩潰Correlation-Breakdown]]。

### 離散度（Dispersion）的定義

離散度 = 成分股加權平均波動率 − 指數波動率

- 離散度高 → 成分股表現分歧、相關性低
- 離散度低 → 成分股齊漲齊跌、相關性高

歷史規律：危機時離散度壓縮（所有股票一起跌，相關性→1），平時離散度擴大。

## 策略實作

### 結構

經典離散度交易：

```
賣出 指數方差Swap（做空指數方差）
買入 各成分股方差Swap（做多成分股方差，按權重）
淨部位 = 做多離散度 = 做空相關性
```

選擇權版本：

```
賣出 指數 ATM straddle
買入 各成分股 ATM straddle（按權重）
```

### 部位規模

部位要做成**相關性中性**或**Vega中性**：

- 相關性中性：讓指數方差的Vega等於成分股方差組合的Vega
- 實際操作時需要動態調整，因為權重隨股價變化

### 動態調整

離散度交易的痛苦點：**成分股權重會隨股價變化**。

- 某成分股大漲，權重上升，部位需要再平衡
- 不調整會產生 unintended beta 曝險
- 再平衡頻率太高會被手續費吃掉

### 到期日選擇

- 短期（1-3月）：離散度波動大，但調整成本高
- 中期（3-6月）：最常見，平衡調整成本與獲利
- 長期（6-12月）：相關性回歸效應強，但流動性差

## 獲利來源

### 1. 結構性相關性溢價

市場長期高估相關性。平時成分股表現分歧，指數波動率 < 成分股加權波動率，離散度交易穩定獲利。

### 2. 賣方Theta收割

賣指數選擇權收Theta，買成分股選擇權付Theta。因為指數IV長期偏高，淨Theta通常為正。

### 3. Vega曲線套利

不同到期日的隱含相關性曲線有套利空間，相關頁面 [[波動率期限結構與曲面演化Volatility-Term-Structure-and-Surface-Evolution]]。

## 風險

### 相關性跳升風險

最大敵人：**危機時所有股票相關性跳升到1**。

- 2008 金融危機、2020 COVID：離散度壓縮，離散度交易大虧
- 這是**尾部風險**，平時不會出現，出現時殺傷極大
- 相關頁面 [[相關性崩潰Correlation-Breakdown]]、[[黑天鵝事件與尾部風險基礎Black-Swan-and-Tail-Risk-Fundamentals]]

### 跳空與Gamma

離散度交易的 Gamma 結構複雜——指數的 Gamma 與成分股的 Gamma 不對稱：

- 指數大跌時指數 Gamma 暴增（賣方虧損加速）
- 成分股不一定同步跌，分散效果打折
- 相關頁面 [[選擇權Convexity凸性與非對稱收益Option-Convexity]]

### 流動性風險

成分股選擇權流動性遠差於指數：

- 進場容易出場難
- 平倉時成分股選擇權 bid-ask 價差擴大
- 相關頁面 [[流動性風險Liquidity-Risk]]、[[滑價與交易執行風險]]

### 模型風險

離散度交易需要相關性預測，而相關性是出了名的難預測：

- 歷史相關性不穩定
- 極端情境下的相關性難以用常態分佈建模
- 相關頁面 [[模型風險Model Risk]]、[[Copula連接函數與尾部相依性Copula-and-Tail-Dependence]]

## 變體

### 1. Reverse Dispersion

反向離散度——買指數方差賣成分股方差。在相關性極度壓縮時進場，賭相關性反彈。歷史上反向離散度交易勝率低，因為結構性溢價長期偏向賣指數。

### 2. Single-Sector Dispersion

只針對某產業指數做離散度——例如只做空半導體指數方差、做多台積電聯電等。產業內相關性更高，溢價較小但風險也較集中。

### 3. Correlation Swap

直接交易相關性的衍生品——賣出指數相關係數 Swap，買入成分股間相關係數組合。比離散度交易更純粹但流動性極差。

## 台股適用性

台股離散度交易的挑戰：

- 台指選 TXO 流動性佳，但個股選擇權流動性參差
- 權重股（台積電、鴻海）的選擇權較活絡，中小型股選擇權幾乎沒流動性
- 可以做 **部分離散度**——只針對前 10 大權值股，犧牲分散度換流動性
- 台灣 50 ETF（0050）選擇權不存在，無法直接做空 0050 方差
- 替代：做空台指選 TXO + 買入權值股個股選擇權

## 總結

離散度交易是機構級的相對價值策略，利用市場對相關性的長期高估。核心價值：

- **結構性溢價**：市場長期高估相關性
- **市場中性**：不賭漲跌賭相關性
- **穩定現金流**：平時離散度穩定擴大

但實戰必須正視：

- **尾部風險巨大**：危機時相關性崩潰到1，策略大虧
- **流動性陷阱**：個股選擇權難出場
- **動態調整成本**：權重變化要再平衡
- **模型依賴**：相關性預測是出了名的難

適合：機構、大資金、有完整選擇權市場的環境。散戶在台股幾乎做不了完整版本，但理解邏輯有助於判讀法人對相關性的操作意圖。

## 注意事項

### 生存者偏差

成分股會變動——如果用今天的台灣 50 成分股回測過去，會有生存者偏差。相關頁面 [[生存者偏差Survivorship-Bias]]。正確做法是用歷史成分股清單，每年調整。

### 相關性不穩定

相關性在不同市場環境差異巨大：

- 用單一歷史平均相關性回測會高估策略穩定性
- 應該用滾動相關性矩陣或情景分析
- 相關頁面 [[情境分析與壓力測試框架Scenario-Analysis-Framework]]
