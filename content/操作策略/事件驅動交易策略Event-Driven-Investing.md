# 事件驅動交易策略 Event-Driven Investing

> 事件驅動不是看到新聞就衝，而是先定義催化劑、預期差、時間窗口與失敗條件，再用事件前後的價格錯位換取報酬。

## 核心概念

事件驅動交易（Event-Driven Investing）把重大事件當成價格重估的催化劑，例如併購、分拆、重整、財報、法說會、政策、訴訟或產業供需變化。核心邏輯不是「事件發生一定漲跌」，而是市場原本的預期與事件結果之間出現落差，價格需要重新定價。

事件驅動可拆成四個要素：

1. **事件本身**：是否足以改變現金流、估值、供需或籌碼結構。
2. **市場預期**：價格是否已經反映好消息或壞消息。
3. **時間窗口**：事件前布局、事件公布當下反應、事件後延續，三種交易完全不同。
4. **風險邊界**：事件若落空、延後或被市場反向解讀，必須有撤退規則。

白話講，事件是火柴，價格錯位才是汽油。沒有錯位，只剩大家一起看新聞自嗨，最後通常是追在煙火最高點。

## 實戰應用

### 1. 建立事件清單

台股可追蹤的事件包含：月營收、季報、法說會、除權息、股東會、併購、增減資、庫藏股、MSCI/ETF成分調整、政策補助、關稅與產業法規。每個事件先標記「公布日期、預期方向、可能受惠/受害標的、關鍵數字」。

### 2. 用預期差決定方向

事件公布後不要只看表面好壞，要看相對預期：

- 好消息但股價不漲：可能早已反映，甚至利多出盡。
- 壞消息但股價不跌：可能市場預期更爛，反而是底部訊號。
- 數字超預期且放量突破：可列入右側追蹤清單。
- 數字低於預期且跌破支撐：先避開，別用信仰硬接。

### 3. 三段式操作

1. **事件前**：只適合小部位試單，因為結果未定，重點是風險報酬比。
2. **事件當下**：觀察第一根大量K棒方向、收盤位置與法人籌碼，避免被開盤情緒騙。
3. **事件後**：若價格和籌碼同向延續，才是較穩的右側進場點；若只跳一天就熄火，事件強度不足。

### 4. 失敗條件寫死

事件交易最怕把短線催化劑凹成長期信仰。若原本買進理由是「法說會上修展望」，結果公司沒有上修，或上修後股價放量收黑，理由就消失，該出場就出場。

## 注意事項

- 事件越熱門，越可能已反映在價格中；新聞很多不等於還有肉，可能只剩骨頭給散戶啃。
- 事件結果有「方向對但市場不買單」的風險，所以必須看價格反應，不要只看自己解讀。
- 併購、訴訟、政策審查等事件有時間延後與不確定性，槓桿部位容易被時間成本磨死。
- 台股小型股事件題材容易被主力操作，需搭配分點、成交量與流動性確認。
- 事件驅動不是免停損策略，催化劑落空時比一般交易更該快砍。
