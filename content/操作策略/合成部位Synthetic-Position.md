# 合成部位 Synthetic Position

> 用選擇權組合複製出標的資產的損益結構，不直接持有標的就能獲得相同的方向性曝險。

## 核心概念

合成部位（Synthetic Position）是選擇權交易中最精妙的技術之一——透過 Put-Call Parity（買賣權平價關係）的數學等式，用選擇權組合完美複製出持有標的資產的損益型態。

**Put-Call Parity 基礎等式：**
```
C − P = S − K × e^(−rT)
```
其中 C=Call價格、P=Put價格、S=標的價格、K=履約價、r=無風險利率、T=到期時間

這個等式告訴我們：**買Call賣Put = 買股票借錢**，兩者損益結構完全相同。

## 四種基本合成部位

### 1. 合成多頭（Synthetic Long Stock）
- **組合**：買Call + 賣Put（相同履約價、相同到期日）
- **效果**：複製持有100股標的的多頭損益
- **損益**：股價上漲獲利無上限、股價下跌虧損無下限
- **優勢**：資金效率高，只需選擇權保證金而非全額股款
- **劣勢**：賣出Put需要保證金、到期日限制、Gamma/Vega曝險

### 2. 合成空頭（Synthetic Short Stock）
- **組合**：買Put + 賣Call（相同履約價、相同到期日）
- **效果**：複製放空100股標的的空頭損益
- **損益**：股價下跌獲利有限（最多到零）、股價上漲虧損無上限
- **優勢**：不需融券、無券源問題、無強制回補壓力
- **劣勢**：賣出Call風險無限、保證金要求高、到期日限制

### 3. 合成多頭Put（Synthetic Long Put）
- **組合**：放空標的 + 買Call
- **效果**：複製買進Put的保險型損益
- **應用**：當Put流動性差或定價過貴時，用合成方式替代

### 4. 合成多頭Call（Synthetic Long Call）
- **組合**：買進標的 + 買Put
- **效果**：複製買進Call的損益結構（即保護性賣權 Protective Put）
- **應用**：本質上就是 [[風險管理/保護性賣權與Collar避險策略Protective-Put-and-Collar|Protective Put]]

## 為什麼要用合成部位？

### 資金效率
- 直接持有100股台積電（1000股×1000元）需要100萬本金
- 合成多頭只需賣Put的保證金（約15-30萬）+ 買Call的權利金
- 槓桿效果放大但不增加方向性風險

### 市場不完美時的套利
- 當 Put-Call Parity 偏離時，合成部位與實際部位之間出現價差
- 買低估的一方、賣高估的一方 = 無風險套利（Box Spread 的基礎）
- 詳見 [[操作策略/盒式價差Box-Spread|盒式價差 Box Spread]]

### 繞過交易限制
- 台股融券有券源限制、平盤下不能放空
- 合成空頭（買Put賣Call）可繞過這些限制
- 除權息旺季融券強制回補，合成空頭不需回補

### 調整現有部位
- 持有股票想轉空 → 不需賣股票，加賣Call買Put即可變成合成空頭
- 空頭想轉多 → 不需回補空單，調整選擇權部位即可
- 降低交易成本（免去現貨買賣的手續費與滑價）

## 合成部位 vs 實際部位：關鍵差異

- **到期日風險**：合成部位有到期日，實際部位沒有。到期前必須決定展延或平倉
- **Greeks 差異**：合成部位的 Delta≈100（接近實際部位），但 Gamma/Vega/Theta 不為零，存在額外的波動率與時間風險
- **股利權利**：合成多頭不享受股利（除息時 Put 價格已反映），實際持有多頭可領息
- **投票權**：合成部位無股東投票權
- **保證金追繳風險**：賣出端（賣Put或賣Call）有保證金追繳風險，實際持有多頭無此風險

## 實戰應用

### 實戰應用場景
### 場景一：低成本建立大型多頭部位
- 看好某檔股票但資金不足 → 買ATM Call + 賣ATM Put = 合成多頭
- 以約1/3~1/5的資金獲得相同方向性曝險
- ⚠️ 賣Put的保證金風險必須納入風控

### 場景二：除權息旺季的放空替代
- 台股6-8月融券強制回補，無法放空
- 改用合成空頭（買Put賣Call）維持空頭部位
- 但需注意賣Call的無限風險，建議搭配價差結構控制風險

### 場景三：Put-Call Parity 套利
- 當 C − P ≠ S − PV(K) 時存在套利空間
- 買便宜的一方、賣貴的一方，到期時收斂獲利
- 散戶很難捕捉（手續費+滑價吃掉利潤），機構主要受益

### 場景四：Reversal/Conversion
- **Reversal**：賣空標的 + 買Call + 賣Put = 做多合成部位（賺Put-Call Parity偏離）
- **Conversion**：買進標的 + 賣Call + 買Put = 做空合成部位
- 這是做市商最常用的部位調整工具

## 台股實戰注意事項

- **流動性**：台指選流動性佳，個股選擇權流動性差，合成部位滑價成本可能很高
- **手續費**：買賣兩腿選擇權的手續費可能比直接買賣股票還貴
- **保證金**：賣出端保證金與期貨保證金體系不同，需確認券商計算方式
- **除權息調整**：合成部位在除權息時的調整比直接持股複雜，履約價會被調整但時間價值可能損失
- **最佳標的**：台指選（TXO）流動性最好，最適合合成部位操作；個股選擇權建議只用大型權值股

## 風險管理

1. **賣出端無限風險**：合成多頭的賣Put、合成空頭的賣Call都有無限風險，必須嚴格控制部位大小
2. **Gamma 風險**：接近到期日Gamma暴增，標的小幅波動就會讓Delta大幅偏離100
3. **Vega 風險**：隱含波動率變化會影響合成部位與實際部位的偏離程度
4. **保證金追繳**：賣出端可能因標的劇烈波動觸發保證金追繳
5. **展延成本**：每個月或每季展延的權利金損耗是隱形成本
