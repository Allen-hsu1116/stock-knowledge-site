# 效率前緣與馬可維茲現代投資組合理論 Efficient Frontier and Markowitz MPT

> 不要把所有雞蛋放在同一個籃子裡——馬可維茲用數學證明了這句老話，並畫出了一條「效率前緣」告訴你怎麼放

## 核心概念

現代投資組合理論（Modern Portfolio Theory, MPT）是Harry Markowitz在1952年提出的數學框架，用來組建在給定風險水準下最大化預期報酬的投資組合。它將「分散投資」從直覺升級為嚴格的數學理論——一個資產的風險和報酬不應單獨評估，而應看它對整個投資組合風險和報酬的貢獻。

Markowitz因此獲得1990年諾貝爾經濟學獎。MPT的核心洞見是：只要資產間不是完全正相關（ρ < 1），組合的標準差永遠小於個別資產標準差的加權平均——這就是分散投資的「免費午餐」。

### 數學模型

**投資組合預期報酬**：

```
E(Rp) = Σ wi × E(Ri)
```

**投資組合變異數（風險）**：

- **兩資產**：σp² = wA²σA² + wB²σB² + 2wAwBσAσBρAB
- **N資產**：σp² = wTΣw（矩陣形式，Σ為共變異數矩陣）

**相關性對分散效果的影響**：

- **ρ = 1（完全正相關）**：σp = Σwiσi，無分散效果，風險就是個別波動度的加權平均
- **ρ = 0（零相關）**：隨資產數增加，組合變異數趨近於零
- **0 < ρ < 1（部分相關）**：有分散效果，組合標準差小於個別標準差加權平均
- **ρ < 0（負相關）**：分散效果最強，可大幅降低組合風險

## 效率前緣（Efficient Frontier）

### 無風險資產的情況

在「報酬-風險」空間中，所有可能投資組合形成一個區域，其左邊界是一條雙曲線，稱為「馬可維茲子彈」（Markowitz Bullet）。雙曲線的上半部就是效率前緣——在給定風險下提供最高預期報酬的組合集合。

- **效率前緣上的組合**：最佳風險-報酬權衡
- **效率前緣下方的組合**：次優，相同風險下報酬更低
- **全域最小變異數組合（GMVP）**：雙曲線頂點，所有風險組合中風險最低的

> 相關頁面：[[操作策略/最小變異數投資組合Minimum-Variance-Portfolio]] — GMVP的進階實戰

### 引入無風險資產

引入無風險資產後，效率前緣從雙曲線變成一條直線——資本配置線（Capital Allocation Line, CAL）：

```
E(Rc) = Rf + (σc / σp) × [E(Rp) - Rf]
```

- CAL與馬可維茲子彈的切點就是**切線組合（Tangency Portfolio）**，即最高夏普比率的風險組合
- 切線組合以下：借出組合（部分投資無風險資產）
- 切線組合以上：借入組合（槓桿投資切線組合）

### 兩基金分離定理

Markowitz的一個重要結論：效率前緣上的任何組合都可以用效率前緣上任意兩個不同組合的線性組合來構建。引入無風險資產後簡化為一基金定理——投資人只需無風險資產和一個切線組合即可達成任何風險-報酬目標。

## 效率前緣的計算

### 最佳化問題

給定風險容忍度q ≥ 0，最小化：

```
min wTΣw - q × RTw
```

條件：Σwi = 1（權重總和為1，可為負即放空）

- **q = 0**：全域最小變異數組合
- **q → ∞**：最大報酬組合（風險也最大）

### 替代形式

給定目標報酬μ，最小化變異數：

```
min wTΣw
```

條件：RTw = μ 且 Σwi = 1

用Lagrange乘數法求解，得到線性方程組。

### Markowitz的臨界線演算法

Markowitz開發了臨界線演算法（Critical Line Algorithm），可處理額外線性約束、資產上下限等限制條件，並證明在半正定共變異數矩陣下有效。

## 實戰應用

### 1. 資產配置的理論基礎

效率前緣是資產配置的數學基礎——決定股票、債券、現金、商品等大類資產的配置比例。不同相關性的資產組合可以推高效率前緣，在相同風險下獲得更高報酬。

### 2. 台股資產配置實務

- **股債組合**：台股加權指數與台灣公債相關性低，組合可顯著降低風險
- **產業分散**：電子股、金融股、傳產股的相關性<1，跨產業分散有效
- **台股+美股**：台股與S&P 500相關性約0.6-0.7，跨市場分散有助降低風險
- **0050+0056**：市值型與高股息型ETF組合，不同因子曝險
- **加入非相關資產**：黃金、REITs等與股市相關性低的資產可推高效率前緣

### 3. 與CAPM的關係

CAPM是建立在MPT之上的均衡定價模型。MPT描述個別投資人的最佳行為，CAPM在此基礎上推導出市場均衡時資產的必要報酬率。所有投資人持有相同的切線組合（即市場組合），這就是CAPM的市場組合。

> 相關頁面：[[基本面分析/CAPM資本資產定價模型Capital-Asset-Pricing-Model]] — MPT的均衡定價延伸

### 4. Black-Litterman模型

Black-Litterman模型在MPT的基礎上加入投資人觀點，解決了Markowitz模型對輸入參數過度敏感的問題。

> 相關頁面：[[操作策略/Black-Litterman模型結合觀點與市場均衡Black-Litterman-Model]] — MPT的改良版

## MPT的局限與批評

### 1. 假設與現實的落差

- **常態分佈假設**：MPT用變異數衡量風險，隱含報酬服從常態分佈。但實際上股市報酬有肥尾（fat tails）和偏態，1987年黑色星期一單日跌22%在常態分佈下幾乎不可能
- **歷史數據預測未來**：用歷史報酬和共變異數估計未來，但市場結構會變化
- **無交易成本與稅**：實際交易有手續費、稅、滑點
- **資產可無限分割**：實際上股票最小單位是1張（1000股）

### 2. 變異數作為風險衡量的問題

- **對稱性**：變異數把大漲和大跌都算「風險」，但投資人只怕大跌不怕大漲
- **損失趨避**：行為財務學證明投資人對損失的痛苦遠大於同等獲利的快樂
- **下行風險**：Sortino比率用下行偏差取代標準差更符合投資人直覺

> 相關頁面：[[風險管理/風險調整報酬指標夏普比率與索提諾比率]] — 用下行風險取代變異數的改良指標

### 3. 模型不穩定性

Markowitz模型對輸入參數極度敏感——微小改變預期報酬估計可能導致完全不同的最適權重。這在高度相關的資產群中尤其嚴重。

### 4. Taleb的批評

Nassim Taleb在《黑天鵝》中批評MPT建立在常態分佈假設上，移除高斯假設後MPT就變成「熱空氣」——無法處理極端事件和肥尾分佈。

> 相關頁面：[[風險管理/投資組合理論與分散投資的局限Portfolio-Theory-and-Diversification-Limits]] — MPT局限的完整分析

### 5. 行為財務學的挑戰

MPT假設投資人完全理性，但行為財務學證明投資人受心理帳戶、框架效應、過度自信等偏差影響，實際行為與MPT的最適組合大相逕庭。

> 相關頁面：[[風險管理/行為財務學總論Behavioral-Finance-Overview]] — MPT理性假設的系統性挑戰

## MPT的延伸

- **後現代投資組合理論（PMPT）**：用非常態分佈、不對稱、肥尾的風險衡量取代變異數
- **Black-Litterman模型**：在MPT最佳化中加入投資人觀點
- **風險平價策略**：按風險貢獻而非資金比例分配權重
- **階層式風險平價（HRP）**：用機器學習聚類取代共變異數矩陣反矩陣
- **不變投資組合**：利用物理學不變性質，用相關矩陣平方根反矩陣取代反矩陣

> 相關頁面：[[風險管理/風險平價策略Risk-Parity]] — 按風險而非資金分配的資產配置策略

## 散戶實戰要點

1. **分散不是隨便買**：相關性低的資產組合才有分散效果，買10檔電子股不如買5檔不同產業
2. **效率前緣是理論不是實務**：實際無法精確計算效率前緣，但概念有助於理解風險-報酬權衡
3. **30-40檔足夠分散**：再多邊際效益遞減，且追蹤成本上升
4. **加入低相關資產**：債券、黃金、REITs等與股市相關性低的資產可推高效率前緣
5. **定期再平衡**：資產價格變動會改變權重，定期再平衡維持目標配置
6. **不要過度依賴歷史數據**：共變異數矩陣會變，用歷史數據算出的最適組合未必適用未來
