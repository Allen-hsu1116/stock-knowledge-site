# 可轉債套利 Convertible Bond Arbitrage

> 可轉債是債券與選擇權的混合體——可轉債套利利用定價偏差，做多便宜可轉債同時放空標的股票對沖，賺債券價值與嵌入選擇權的雙重錯價

## 核心概念

可轉債（Convertible Bond，CB）是持有人可按約定比例轉換為發行公司普通股的債券。它本質上是「債券 + 認股選擇權」的組合：

- **債券價值（Bond Floor）**：純粹債券的現值，提供下檔保護
- **轉換價值（Conversion Value）**：立即轉股的價值 = 轉換比率 × 股價
- **嵌入選擇權**：持有人有權但無義務轉換，本質是 Call Option

可轉債的市價 = max(債券價值, 轉換價值) + 嵌入選擇權的時間價值

相關基礎頁面 [[可轉債操作策略]]。

### 套利邏輯

可轉債套利的核心：**可轉債的嵌入選擇權經常被市場低估**。

- 發行時轉換價格通常設定在當時股價的 110-130%，溢價發行
- 市場把可轉債當「債券」定價，忽略嵌入選擇權的時間價值
- 套利者買入便宜可轉債 + 放空對應股數 = delta-neutral 部位
- 等可轉債的選擇權價值回升，平倉獲利

## 策略結構

### 經典 Convertible Arbitrage

```
買入 可轉債
放空 標的股票（按轉換比率計算的 delta 股數）
淨部位 = delta-neutral，不賭漲跌，賭可轉債定價錯誤修正
```

放空股票的目的：

- 對沖可轉債的 delta 曝險（不賭漲跌）
- 股價上漲時，可轉債賺、空單虧，但可轉債漲更多（凸性）
- 股價下跌時，可轉債跌、空單賺，但有債券價值保護

### Delta 動態調整

可轉債的 delta 隨股價變化：

- 股價 << 轉換價：delta 接近 0，像純債券
- 股價 ≈ 轉換價：delta 約 0.5
- 股價 >> 轉換價：delta 接近 1，像股票

套利者必須動態調整空單數量維持 delta-neutral。相關頁面 [[Delta中性對沖與避險比率實戰Delta-Neutral-Hedging]]、[[選擇權Greeks希臘字母]]。

### Gamma 收割

可轉債有正 Gamma——股價漲可轉債 delta 上升、股價跌 delta 下降。動態調整空單時：

- 股價漲 → delta 上升 → 補空單（高價補）
- 股價跌 → delta 下降 → 空單回補（低價買回）

Gamma Scalping 類似 [[Gamma-Scalping實戰策略Gamma-Scalping-Strategy]]，從波動中收割。

## 收益來源

### 1. 嵌入選擇權折價

主要利潤——可轉債的選擇權部分被低估，隨時間市場會修正。買入時的折價空間就是潛在利潤。

### 2. 票息收入

可轉債有票面利率（通常低於純債券），套利者持續領息。

### 3. 放空股息與借券收入

放空股票會收到股息（公司配息時放空者要補息，但若有借券市場可賺借券費）。相關頁面 [[借券賣出進階判讀與外資做空路徑分析Short-Selling-Advanced-Analysis]]。

### 4. Gamma Scalping

如上所述，動態調整空單從波動中獲利。

## 風險

### 1. 信用風險

可轉債是公司債——發行公司違約，可轉債可能歸零。相關頁面 [[信用風險Credit-Risk]]、[[信用評等與公司債違約風險判讀Credit-Rating-and-Default-Risk]]、[[Altman-Z-Score破產預測模型]]。

### 2. 股價暴跌

可轉債套利放空股票對沖，但：

- 股價暴跌時空單獲利
- 可轉債跌到債券價值附近（仍有下檔）
- 但如果公司同步違約，可轉債跟股票一起崩

### 3. 強制轉換 / 贖回

許多可轉債有**強制贖回條款（Call Provision）**——當股價超過轉換價某百分比（通常 130-150%）連續 N 天，發行公司可以強制贖回。套利者被迫在不利時機平倉。

### 4. 流動性風險

可轉債流動性通常差，bid-ask 價差大。相關頁面 [[流動性風險Liquidity-Risk]]、[[滑價與交易執行風險]]。

### 5. 放空成本

放空股票需要借券，熱門放空標的借券費可能很高。相關頁面 [[借券費率與缺券風險判讀]]、[[融券放空策略與軋空判讀實戰Short-Selling-Strategy-and-Short-Squeeze]]。

### 6. Gamma 為負的情境

當可轉債深度價內（股價遠高於轉換價），delta 接近 1，Gamma 接近 0，動態調整空單的 Gamma Scalping 收益消失。策略變成純債券套利，收益降低。

### 7. 融資成本

套利者通常用融資買可轉債（槓桿 2-5 倍），融資成本侵蝕利潤。相關頁面 [[財務槓桿風險管理Leverage-Risk-Management]]。

## 變體策略

### 1. Cash-and-Carry Arbitrage

純粹套利版本——當可轉債明顯低估：

```
買入 可轉債
放空 股票
持有到期或至折價收斂
```

低風險但機會少。

### 2. Distressed Convertible

買入接近違約或股價崩跌的可轉債（稱為「墮落天使」），賭公司不會違約、可轉債會反彈。高風險高報酬，相關頁面 [[信用循環與明斯基時刻Credit-Cycle-and-Minsky-Moment]]。

### 3. Convertible Underwriting

新可轉債發行時認購並同時放空股票，賺髮行折價。流動性套利。

### 4. Dual-Hedge

加買 Put 避險信用風險——買可轉債 + 放空股票 + 買公司債 CDS。降低信用風險但成本提高。

## 實戰考量

### 定價模型

可轉債定價需要三套模型整合：

- **債券定價**：DCF 算債券價值，相關頁面 [[現金流量折現法DCF估值]]
- **選擇權定價**：Black-Scholes 或樹狀模型算嵌入選擇權，相關頁面 [[Black-Scholes定價模型]]
- **信用風險定價**：用信用利差或結構模型算違約風險，相關頁面 [[信用評等與公司債違約風險判讀Credit-Rating-and-Default-Risk]]

### 模型風險

可轉債定價複雜，模型誤差大：

- 強制贖回條款難建模
- 轉換價重設條款複雜
- 信用風險與股價相關
- 相關頁面 [[模型風險Model Risk]]

### 再融資風險

套利者用槓桿，市場流動性緊縮時可能被追繳保證金。相關頁面 [[保證金追繳與融資斷頭Margin-Call-and-Forced-Liquidation]]。

### 長期資本管理 LTCM 教訓

LTCM 1998 年崩盤時持有大量可轉債套利部位。俄羅斯違約引發流動性危機，可轉債與放空股票的收斂變成擴大，最終被迫平倉。相關頁面 [[對沖風險三大內生風險與失敗案例]]。

## 台股適用性

台股可轉債市場相對成熟，常見的可轉債：

- 上市公司發行的可轉換公司債（CB）
- 附認股權公司債（WB）
- 海外可轉債（ECB）

台股可轉債套利的特點：

- **借券成本高**：台股放空股票需要借券，熱門標的借券費可能 5-20%
- **強制贖回常見**：台股公司常用強制贖回降低融資成本，套利者要密切監控
- **流動性集中**：只有大型股的可轉債流動性好
- **股息處理**：放空股票遇除息要補息（5-10元稅負），侵蝕利潤
- 相關頁面 [[除權息三大操作策略Ex-Dividend-Three-Strategies]]、[[除權息稅務與二代健保節稅策略Ex-Dividend-Tax-and-NHI]]

## 總結

可轉債套利是固定收益市場的經典策略，利用可轉債定價複雜度帶來的錯價。核心價值：

- **結構性錯價**：嵌入選擇權長期被低估
- **多維度獲利**：選擇權折價 + 票息 + Gamma + 借券收入
- **下檔保護**：債券價值提供底部

但實戰必須正視：

- **信用風險**：公司違約可轉債歸零
- **強制贖回**：公司可以單方面終止
- **流動性陷阱**：可轉債難平倉
- **槓桿風險**：套利者用融資放大風險
- **LTCM 教訓**：收斂策略危機時反而擴大

適合：機構、大資金、有借券管道與信用分析能力的投資人。散戶在台股可以做簡化版本，但要注意借券成本、強制贖回與流動性陷阱。
