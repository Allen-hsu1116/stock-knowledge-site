# 市場中性策略 Market Neutral Strategy

> 透過做多和做空對沖掉市場系統性風險，只賺選股的 alpha——不管大盤漲跌都能賺錢的理想，但「完全中性」在實務中幾乎不可能達成

## 核心概念

市場中性（Market Neutral）策略是指透過對沖完全消除某種市場風險的投資策略。一個投資組合要被稱為市場中性，必須與被避險的風險來源**零相關**。

### 市場中性的本質

- **不是不做方向**：而是做多有 alpha 的、做空沒 alpha 的，對沖掉 beta
- **賺的是相對價值**：A 比 B 好就做多 A 做空 B，不管大盤漲跌
- **理想 vs 現實**：真正的零相關幾乎不可能，看起來中性的組合在市場條件變化時可能出現意外相關——這叫做**基差風險（Basis Risk）**

### Equity Market Neutral（股票市場中性）

這是避險基金的經典策略：
1. **Long/Short 架構**：同時持有多頭和空頭部位
2. **產業中和**：多空部位在相同或相關產業，降低產業風險暴露
3. **Beta 中性**：組合的 beta 接近零，大盤漲跌對損益影響極小
4. **本質是選股能力的較量**：賭的是多頭部位會跑账空頭部位，不管產業漲跌

### 與其他策略的比較

- **配對交易**：市場中性的一種，但只交易兩檔
- **統計套利**：市場中性的升級版，交易數百檔
- **一般 Long/Short**：不一定 Beta 中性，保留部分系統性風險
- **Delta 中性**：選擇權市場的中性策略，用 Greeks 衡量

## 實戰應用

### 股票市場中性的建構步驟

1. **選股**：用量化模型給每檔股票評分（基本面+技術面+動能等）
2. **分組**：高分組做多、低分組做空
3. **產業匹配**：多空部位在相同產業權重相同，消除產業因子
4. **Beta 調整**：調整多空部位的資金比例使組合 Beta = 0
5. **風險模型**：用 MSCI/Barra 等模型限制因子暴露
6. **持續再平衡**：隨股價變化，定期調整維持中性

### 台股市場中性操作

**做多端**：
- 基本面有轉機、法人買超的股票
- 投信鎖碼趨勢確立的股票
- 市值適中、流動性充足的標的

**做空端**：
- 同產業中投信正在棄守的股票
- 與做多標的歷史相關性高的股票
- 用股票期貨或指數期貨替代融券降低成本

**損益情境**（買 A + 放空 B 為例）：
- 兩檔都漲 3% → 多空相抵 ≈ 0
- 大盤跌 10%，兩檔都跌 10% → 只虧交易成本
- A 漲 10%、B 跌 10% → 價差擴大 20%，大賺

### 市場中性策略種類

| 策略 | 避險對象 | 工具 |
|------|---------|------|
| 股票市場中性 | 市場 Beta | Long/Short 股票 |
| Delta 中性 | 標的價格變動 | 選擇權 + 標的 |
| 配對交易 | 配對內系統風險 | 兩檔相關股票 |
| 可轉債套利 | 標的股票價格 | 可轉債 + 放空股票 |
| 固定收益套利 | 利率風險 | 做多做空債券 |
| 波動率套利 | 波動率變化 | 選擇權組合 |

## 注意事項

### 四大風險

1. **基差風險**：看似中性的組合在極端市場條件下可能出現意外相關性，對沖失效
2. **Beta 估計誤差**：Beta 是歷史值，未來可能完全不同。CAPM 模型本身的有效性也是假設
3. **均值漂移**：均值回歸策略假設均值不變，但均值會變（稱為 drift），漂移時策略失效
4. **流動性風險**：做空端需要借券或期貨，流動性不足時無法維持中性

### 實務限制

- **完全中性是理想**：實際上只能「接近中性」，一定有殘餘風險暴露
- **交易成本侵蝕**：多空雙邊交易，成本是單邊的兩倍
- **台股做空限制**：平盤以下不得放空、借券成本不固定、處置股交易限制
- **資金效率低**：需要保證金和擔保品，資金利用率不如單邊操作
- **低波動 ≠ 低風險**：平時波動低，但極端事件時可能同時崩潰

### 2008 金融危機的教訓

市場中性策略在正常時期表現穩定，但在 2007-2008 年金融危機期間，許多看似中性的策略同時失效。原因：
- 流動性枯竭導致無法維持部位
- 相關性結構在危機中崩潰，原本不相關的資產突然高度相關
- 被迫平倉引發連鎖效應
