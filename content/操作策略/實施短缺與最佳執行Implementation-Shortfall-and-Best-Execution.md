# 實施短缺與最佳執行 Implementation Shortfall & Best Execution

> 從「決定買賣」到「真正成交」之間的每一分錢都在流失——實施短缺量化這段距離的成本，最佳執行追求讓流失最小化

## 核心概念

實施短缺（Implementation Shortfall，簡稱IS）是衡量交易執行品質的核心指標，定義為**決策價格與最終執行價格之間的差額**（含手續費、稅金等所有成本）。又稱為「滑價」（Slippage）。

這個概念把交易拆成兩個階段：
1. **決策階段**：基金經理或投資人決定買賣某檔股票的時刻
2. **執行階段**：訂單實際送到市場並成交的過程

兩個階段之間的價格變化、市場衝擊、手續費等，統稱為實施短缺。機構交易的核心任務之一就是最小化實施短缺。

### 決策價格（Decision Price）

決策價格是觸發交易決定的那個價格，最常見有兩種：

- **收盤價（Close Price）**：基金經理的視角。他根據今天的收盤價和所有歷史數據做出決定，明天進場。決策價格就是今天的收盤價
- **到達價（Arrival Price）**：券商的視角。券商收到訂單時不知道基金經理為什麼決定交易，只能假設「現在的價格就是觸發決定的價格」。到達價通常用最後成交價或買賣均價（mid price）

兩種決策價格的選擇會影響IS的計算結果，基金經理傾向用收盤價（讓自己看起來執行得更好），券商傾向用到達價（讓自己負責的區間更小）。

## 成本拆解

實施短缺可拆解為三個組成部分：

### 1. 延遲成本（Delay Cost）

訂單未在投資決策產生的那一刻就送到市場，這段延遲期間的價格變化就是延遲成本。

- 基金經理收盤後決定買進 → 隔天早上9點才下單 → 隔天開盤跳空上漲 → 延遲成本就是跳空幅度
- 延遲越久，價格隨機漂移的風險越大

### 2. 執行成本（Execution Cost）

完成交易過程中產生的成本，包含：

- **市場衝擊成本**：你的訂單本身推動了價格（買進推高、賣出壓低）
- **市場風險成本**：執行期間價格的隨機波動
- **手續費與稅金**：券商佣金、交易稅等固定成本
- **買賣價差**：買價和賣價之間的缺口，你買在Ask賣在Bid，價差就是成本

> 相關頁面：[[技術分析/Kyle-Lambda與價格衝擊模型Price-Impact-Model]] — Kyle's Lambda量化每單位交易量推動價格的程度，是市場衝擊成本的數學基礎

### 3. 機會成本（Opportunity Cost）

部分或全部的計畫訂單未能成交的成本。原因包括：

- 價格往不利方向移動，設了限價但沒成交
- 流動性不足，掛單量遠超過市場可消化量
- 時間用完但訂單未執行完畢

機會成本是最容易被忽略但往往最大的成本——你本來想買1000張，結果只買到300張，剩下的700張漲了10%，那10%就是機會成本。

### 成本拆解公式

```
IS = (執行價格 - 決策價格) × 成交股數 + 手續費 + 稅金 + 未成交部分的機會成本
  = 延遲成本 + 執行成本 + 機會成本
```

## 最佳執行（Best Execution）

最佳執行不是「拿到最好的價格」（那是不可能的，因為你永 不知道未來價格），而是**在交易決策已知的前提下，系統性地最小化實施短缺**。

### 三大執行演算法

機構用演算法把大單拆小單，平衡市場衝擊與時間風險：

- **VWAP（成交量加權均價）**：按市場成交量分佈分配訂單，追蹤當日均價。適合流動性好的股票
- **TWAP（時間加權均價）**：把訂單均勻分布在時間軸上，不考慮成交量。適合不想被市場看出意圖的場合
- **IS（實施短缺演算法）**：直接以最小化IS為目標，在前段時間加速執行（降低機會成本和延遲成本），同時控制市場衝擊。適合對執行品質要求最高的大單

> 相關頁面：[[操作策略/執行演算法VWAP-TWAP-Execution-Algorithm]]、[[操作策略/VWAP執行演算法與機構交易策略VWAP-Execution-Algorithms]]

### 執行策略的時間取捨

```
快速執行 ←→ 慢速執行
  ↓              ↓
市場衝擊大      市場風險大
時間風險小      時間風險小
機會成本低      機會成本高
```

- **急著買完** → 市場衝擊大（你的買單推高價格），但不怕價格跑掉
- **慢慢買** → 市場衝擊小，但價格可能在你慢慢買的時候就漲上去了

IS演算法的核心就是在這個取捨中找到最佳平衡點——通常在前段執行更快（因為延遲成本和機會成本在此時最高），後段放慢（避免衝擊累積）。

### Almgren-Chriss最佳執行模型

Almgren和Chriss（2000）提出的模型是最佳執行的經典框架：

- 同時考慮**永久衝擊**（你買完後價格回不去的部分）和**暫時衝擊**（買的當下推高但隨後恢復的部分）
- 在給定風險厭惡程度下，計算出最優的執行軌跡（每一期買多少）
- 最優解是在「市場衝擊」和「時間風險」之間的帕累托前沿上選擇

## 實戰應用

### 1. 交易成本分析（TCA）

機構投資人用IS框架做交易成本分析（Transaction Cost Analysis），評估：

- 哪個券商執行得更好
- 哪個交易場所（交易所、暗池）流動性更好
- 哪種演算法適合哪種訂單
- 交易員的執行績效

> 相關頁面：[[籌碼面分析/暗池交易與大戶足跡Dark-Pool-Trading-and-Institutional-Footprint]]

### 2. 散戶的IS意識

散戶雖然不用IS演算法，但IS概念同樣重要：

- **市價單vs限價單**：市價單的IS = 買賣價差 + 滑價；限價單的IS = 可能的機會成本（沒成交）
- **大單分批下**：一次下50張和分10次每次5張，市場衝擊天差地別——尤其流動性差的小型股
- **避開流動性低谷**：午休時段、尾盤前後流動性差，IS會暴增
- **台股最小摩擦**：0.1425%手續費（券商折扣後更低）+ 0.3%交易稅（賣出時）是固定成本，但滑價是變動成本，可以控制

### 3. 買賣時機與IS

- **財報公告前後**：流動性可能驟降、價差擴大，IS暴增
- **除權息日**：開盤跳空參考價已調整，限價單容易掛錯價
- **外資大單進出時**：你跟著外資的方向走，外資的VWAP執行會推動價格，你的IS會受影響

> 相關頁面：[[操作策略/財報公告交易策略Earnings-Announcement-Trading]]、[[操作策略/事件驅動交易策略Event-Driven-Investing]]

### 4. 從盤中足跡識別機構IS執行

散戶可以從盤中行為反推機構的IS執行：

- **開盤前30分鐘量能集中** → 機構IS演算法前段加速執行
- **盤中規律小單持續進出** → VWAP或TWAP分批執行中
- **尾盤突然爆量** → 機構在收盤前完成剩餘訂單（降低機會成本）

> 相關頁面：[[技術分析/VWAP偏差與機構執行足跡VWAP-Deviation-Institutional-Footprint]]

## IS vs VWAP vs TWAP 三種基準比較

- **IS基準**：以決策價格為基準，衡量全部成本（延遲+執行+機會）。最全面但計算複雜，適合績效評估
- **VWAP基準**：以當日成交量加權均價為基準，衡量相對市場均價的表現。最常用但只看當日，忽略決策到開盤的延遲成本
- **TWAP基準**：以時間均勻分布的均價為基準。最簡單但完全不考慮成交量分佈，容易被市場看出意圖

實務上，機構會同時用多種基準交叉驗證執行品質。

## 散戶實戰要點

1. **你的滑價就是你的IS**：市價單買在盤口高點、限價單沒成交錯過行情，都是實施短缺
2. **大型股用市價、小型股用限價**：流動性好的大型股滑價小，市價單IS低；流動性差的小型股用市價單會被坑
3. **分批下單降低衝擊**：超過日均量1%的單都應該分批，否則你就是自己的市場衝擊
4. **避開流動性低谷**：12:30-13:00午休前後、13:30前最後30分鐘是流動性最差的時段
5. **懂IS就能讀懂機構足跡**：盤中看到規律小單單向流出，可能是機構在執行IS或VWAP，跟著走或反向操作都是策略
