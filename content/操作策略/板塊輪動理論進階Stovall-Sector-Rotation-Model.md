# 板塊輪動理論進階 Sam Stovall Sector Rotation Model

> 經濟週期的四個季節各有贏家——Sam Stovall 的板塊輪動模型把景氣循環與產業表現的對應關係量化，讓你不再只靠「感覺」猜輪動方向

## 核心概念

Sam Stovall 的板塊輪動理論（Sector Rotation Model）是 CFRA 首席投資策略師 Sam Stovall 在其著作《Sector Investing》中系統化的理論框架。它建立在美林投資時鐘的基礎上，進一步細化每個經濟週期階段哪些板塊表現最好、為什麼好、何時開始輪動。

**核心論點**：股市是經濟的領先指標，會提前 6-9 個月反映經濟拐點。板塊輪動不是隨機的，而是市場參與者提前對經濟階段變化的定價行為。

### 與美林投資時鐘的差異

- **美林投資時鐘**：以 GDP + CPI 兩維度分四象限，每個象限對應一種資產類別
- **Stovall 板塊輪動**：在美林時鐘基礎上，進一步拆解每個象限內「哪些產業板塊」勝出，提供更細的選股方向
- 兩者互補：美林時鐘定資產配置方向，Stovall 定產業配置方向

## 四階段板塊輪動模型

### 第一階段：復甦期（Recovery）

**經濟特徵**：GDP 從谷底回升、CPI 仍低、利率仍在低檔、央行維持寬鬆

**表現最佳板塊**：
- **科技**：企業資本支出開始恢復，IT 投資先行
- **非必需消費**：消費信心回升，可選消費品需求率先反彈
- **工業**：製造業訂單回暖，庫存回補啟動
- **原材料（中期）**：需求預期帶動原物料價格觸底

**為什麼這些板塊先漲**：
- 科技和工業是經濟的領先指標，市場定價領先實際數據 6-9 個月
- 非必需消費對利率和就業敏感，寬鬆環境下率先受益
- 這些板塊的 Beta > 1，在市場從底部反彈時漲幅最大

### 第二階段：繁榮期（Boom/Expansion）

**經濟特徵**：GDP 增速最快、CPI 開始上升、央行可能開始收緊

**表現最佳板塊**：
- **原材料**：需求最旺、庫存最低、漲價能力最強
- **能源**：經濟過熱帶動能源需求
- **工業（持續）**：產能利用率最高
- **非必需消費（尾聲）**：就市場好的時候消費者花最多

**為什麼板塊開始切換**：
- 經濟從「恢復期」進入「過熱期」，資本支出週期高峰
- 原物料從「預期驅動」變成「現貨驅動」，價格加速
- 科技開始面臨「高基期」壓力，估值不再便宜

### 第三階段：滯脹期（Stagflation）

**經濟特徵**：GDP 增速放緩、CPI 仍高、央行被迫升息或維持高利率

**表現最佳板塊**：
- **能源**：通膨推高油價，能源股是通膨受益者
- **必需消費**：不管經濟多差人都要吃飯，防禦性最強
- **醫療保健**：需求不隨景氣變化，穩定現金流
- **公用事業**：低 Beta + 高股息，利率雖高但盈餘穩定

**為什麼市場開始防禦**：
- 企業盈餘增長放緩，高 Beta 板塊率先被拋售
- 通膨侵蝕利潤率，定價權強的必需品公司受益
- 能源是少數在通膨中「產品漲價>成本上升」的板塊

### 第四階段：衰退期（Recession）

**經濟特徵**：GDP 負成長、CPI 開始下降、央行開始降息

**表現最佳板塊**：
- **公用事業**：降息最大受益者（利率敏感 + 穩定股息）
- **必需消費（持續）**：防守型配置
- **醫療保健（持續）**：人口老齡化結構性需求
- **金融（尾聲）**：降息改善淨利差，但壞帳風險仍在

**為什麼開始預埋復甦種子**：
- 央行降息 → 市場預期經濟復甦 → 科技和非必需消費開始悄悄建倉
- 衰退期末段實際上是科技股最佳買點（領先市場 6-9 個月）
- 板塊輪動在此階段開始從防禦型轉向成長型

## 輪動時間軸

### 股市領先經濟多久？

Stovall 的核心觀察：**股市板塊輪動領先經濟指標拐點約 6-9 個月**。

- 科技股觸底 → 經濟衰退結束前 6-9 個月
- 原材料股高峰 → 經濟過熱頂峰前 3-6 個月
- 公用事業股觸底 → 經濟復甦前 3-6 個月
- 能源股高峰 → 通膨頂峰前 0-3 個月

### 輪動速度因市場結構而異

- **牛市輪動快**：資金積極尋找新標的，每個板塊停留 3-6 個月
- **熊市輪動慢**：資金集中防禦，防禦板塊可能主導 12-18 個月
- **震盪市輪動極快**：資金在不同板塊間高速切換，每個板塊可能只主導 2-4 週

## 量化輪動指標

### 一、相對強度比率（Relative Strength Ratio）

```
RS Ratio = 板塊指數 / 大盤指數
```

- RS Ratio 上升 → 板塊跑贏大盤，資金流入
- RS Ratio 下降 → 板塊跑輸大盤，資金流出
- RS Ratio 突破長期下降趨勢線 → 板塊輪動開始

### 二、RS Momentum（相對強度動量）

用板塊 RS Ratio 的變化率衡量輪動速度：

- RS Momentum > 0 且加速 → 輪動剛開始，可追進
- RS Momentum > 0 但減速 → 輪動接近尾聲，注意出場
- RS Momentum < 0 且加速 → 板塊加速被棄，避免

### 三、板塊 RSI 矩陣

追蹤 11 個板塊的 14 日 RSI：
- RSI > 70 + RS Ratio 在高位 → 板塊過熱，輪動可能即將開始
- RSI < 30 + RS Ratio 在低位 → 板塊可能即將啟動
- 當領先板塊 RSI 從 70+ 回落同時落後板塊 RSI 從 30 以下回升 → 輪動訊號

### 四、資金流向（Fund Flow）追蹤

- 板塊 ETF 資金淨流入/流出是輪動最直接的證據
- 單週淨流入 > 板塊規模 2% → 資金明顯湧入
- 連續 3 週淨流出 → 資金持續撤離

## 台股板塊輪動實戰

### 台股 11 大板塊對應

台股的產業分類與美股 GICS 11 板塊有對應但不完全相同：

- **科技** → 半導體、電子零組件、電腦及週邊、通信網路
- **非必需消費** → 觀光、貿易百貨
- **必需消費** → 食品
- **工業** → 電機機械、汽車
- **原材料** → 塑膠、化學、鋼鐵、水泥
- **能源** → 油電燃氣
- **金融** → 金融保險
- **醫療** → 生技醫療
- **公用事業** → 電器電纜（部分）
- **通信** → 通信網路
- **房地產** → 建築營造

### 台股輪動的獨特性

1. **半導體主導**：半導體佔台股市值超過 40%，科技板塊輪動幾乎等於大盤走勢
2. **AI 結構性題材**：AI 供應鏈打破傳統週期邏輯，半導體持續主導超過 18 個月
3. **金融輪動滯後**：台股金融股輪動通常滯後美股 2-3 個月
4. **季底作帳效應**：投信季底拉抬持股，形成制度性輪動

### 台股板塊輪動觀察重點

- **半導體 vs 金融 vs 傳產的三角輪動**：半導體休息時金融和傳產接棒
- **被動元件 vs 主動元件**：子板塊內部的輪動比大板塊輪動更頻繁
- **外資動向是輪動的引擎**：外資買超集中在哪些板塊 = 輪動方向

## 注意事項

### 🚨 經濟週期並非完美的四階段
- 現實中的經濟週期經常跳過某些階段（如 2020 COVID 從衰退直接跳到復甦）
- 滯脹期可能極短或不明顯
- 不要機械式套用四階段，要看實際數據判斷

### 🚨 結構性變化打破週期邏輯
- AI 超級週期讓科技板塊持續主導超過 2 年，傳統輪動邏輯失效
- 被動 ETF 資金機械性流入大市值股，扭曲了板塊輪動
- 環境能源轉型讓傳統能源板塊的週期行為改變

### 🚨 領先時間不穩定
- 「領先 6-9 個月」是統計平均值，個別週期可能領先 3 個月或 12 個月
- 在 QE/QT 等非常規政策下，領先關係可能失靈
- 不要用固定時間窗口等轉折

### 🚨 台股適用性受限
- 台股以半導體為核心的結構與美股多元板塊結構不同
- 金融股在台股的週期行為與美股不同（台灣金融與房地產關聯弱）
- 原材料板塊在台股市值小、影響力弱

### 🚨 不要追輪動
- 輪動確認時往往已漲一段，追入可能買在輪動尾聲
- 建議用 RS Ratio 趨勢突破作為進場點，而不是漲幅排名
- 輪動速度加快時（每 2-3 週切換）代表進入震盪市，追輪動必虧
