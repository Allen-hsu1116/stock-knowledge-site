# Black-Litterman 模型：結合投資者觀點與市場均衡

> Fischer Black 與 Robert Litterman 1990 年在 Goldman Sachs 開發的資產配置模型，解決 Markowitz 均值-方差優化在實務上「預期報酬率難以估計」的核心痛點。

## 核心概念

Markowitz 的現代投資組合理論（MPT）理論上很完美——給我預期報酬率和協方差矩陣，我給你最有效的組合。但實務上：

- **協方差矩陣**可以從歷史數據相對準確地估計
- **預期報酬率**幾乎不可能準確估計——歷史平均報酬率的信噪比極低，微小估計誤差會被優化器放大成極端權重

這就是所謂的「誤差放大效應」（error maximization）：你對某資產預期報酬率高估 1%，優化器可能給它分配 80% 的權重。結果不是「最優組合」而是「最錯組合」。

## Black-Litterman 的解法

### 第一步：從市場均衡出發

不要求投資者輸入預期報酬率，而是反向推導：

**市場本身的市值權重就是均衡預期報酬率的隱含結果。**

用市場市值權重（如全球股市中美股 60%、日股 6% 等）反推出隱含的均衡報酬率：

```
Π = δ × Σ × w_mkt
```

- **Π**：隱含均衡報酬率向量
- **δ**：風險趨避係數
- **Σ**：協方差矩陣
- **w_mkt**：市場市值權重

這就像 CAPM 的延伸——市場已經告訴你每個資產的「公允」預期報酬，不需要你自己猜。

### 第二步：加入投資者觀點

投資者不需要對所有資產提出預測，只需表達「我有什麼不同的看法」：

- **絕對觀點**：「台股未來一年報酬率 15%」
- **相對觀點**：「半導體類股表現優於金融類股 5%」

每個觀點附帶一個信心水準——你有多確定這個觀點是對的。

### 第三步：貝氏融合

用貝氏統計將市場均衡先驗（prior）與投資者觀點（views）融合：

```
E[R] = [(τΣ)⁻¹ + P'Ω⁻¹P]⁻¹ × [(τΣ)⁻¹Π + P'Ω⁻¹Q]
```

- **τ**：標量縮放因子（通常 0.025-0.05），控制均衡報酬的不確定性
- **P**：觀點矩陣（每行代表一個觀點，每列對應一個資產）
- **Q**：觀點向量（每個觀點的預期報酬值）
- **Ω**：觀點的信心矩陣（對角矩陣，每個觀點的變異數）

結果是一個後驗預期報酬率——市場均衡與投資者觀點的加權平均，權重取決於各自的不確定性。

### 第四步：最優化

用後驗報酬率跑 Markowitz 均值-方差優化，得到最終資產配置。

## 觀點矩陣 P 的構建範例

假設有 4 個資產：[台股, 美股, 日股, 債券]

**觀點 1**：台股報酬率 12%（絕對觀點，信心 60%）
- P = [1, 0, 0, 0]
- Q = 12%

**觀點 2**：美股優於日股 4%（相對觀點，信心 40%）
- P = [0, 1, -1, 0]
- Q = 4%

**觀點 3**：債券報酬率 3%（絕對觀點，信心 80%）
- P = [0, 0, 0, 1]
- Q = 3%

## 與 Markowitz 的關鍵差異

**Markowitz**：
- 投資者必須輸入所有資產的預期報酬率
- 微小誤差導致極端權重
- 結果對輸入極度敏感（脆弱）

**Black-Litterman**：
- 從市場均衡出發，只表達「不同於市場的看法」
- 沒有觀點的資產自動回到市場均衡權重
- 觀點越不確定，對最終配置的影響越小（穩健）

## 信心水準設定方法

### 方法一：歷史變異數法
用觀點資產的歷史變異數作為 Ω 的對角元素：
```
Ω = diag(τ × P × Σ × P')
```

### 方法二：Idzorek 百分比法
直接設定每個觀點的信心百分比（0%-100%），然後反推 Ω：
- 100% 信心：完全採用觀點，忽略市場均衡
- 0% 信心：完全採用市場均衡，忽略觀點
- 50% 信心：觀點和市場均衡各半

### 方法三：固定比例法
設 Ω = τ × diag(P × Σ × P')，簡單但較粗糙。

## 台股實戰應用場景

### 場景一：核心-衛星策略的權重優化
- **核心部位**：0050 或市值型 ETF，權重接近市場均衡
- **衛星部位**：對特定產業或個股有觀點時，用 BL 模型調整權重
- 沒有觀點的標的自動維持均衡配置，避免過度自信

### 場景二：多資產配置
- 資產：台股 50、美股指數、 investment級債券、商品
- 從市值權重推導均衡報酬
- 加入「台股 AI 供應鏈受惠，預期超額報酬 5%」的觀點
- 模型自動調整台股權重向上，其他資產微調

### 場景三：產業輪動
- 對七個產業類股設定均衡權重
- 表達「半導體優於金融 3%」「傳產落後電子 5%」等相對觀點
- 置信度反映景氣指標的可靠度

## 優點

- **穩健性**：不確定的觀點自動降權，避免極端配置
- **直覺性**：只需表達「跟市場哪裡不同」，不用猜全部
- **可擴展**：觀點數量不限，可以只有 1 個也可以有 N 個
- **與均值-方差優化無縫接軌**：輸出直接餵給 Markowski 優化器

## 實戰應用

**1. 定義資產宇宙**
- 選擇要配置的資產類別（如台股、美股、債券、商品）
- 收集各資產的歷史報酬率計算協方差矩陣 Σ

**2. 計算市場均衡**
- 取得各資產的市值權重 w_mkt
- 設定風險趨避係數 δ（通常從歷史數據反推）
- 計算隱含均衡報酬率 Π = δΣw_mkt

**3. 表達觀點**
- 列出你與市場不同的看法（1-N 個觀點）
- 每個觀點設定信心水準（可參考 Idzorek 的方法：用百分比表示信心，如 50% 信心）
- 構建 P 矩陣和 Q 向量

**4. 融合計算**
- 設定 τ 值（通常 0.025）
- 構建 Ω 信心矩陣
- 計算後驗報酬率 E[R]

**5. 優化配置**
- 用 E[R] 和 Σ 跑均值-方差優化
- 加入限制條件（如不允許放空、單一資產上限等）
- 得到最終權重

## 注意事項

- **τ 值設定主觀**：不同 τ 會產生不同結果，缺乏共識
- **Ω 信心矩陣設定困難**：如何量化「我有多確定」是最大實務挑戰
- **協方差矩陣估計**：仍依賴歷史數據，市場結構變化時可能失效
- **只適合機構等級**：對散戶來說，市場市值權重難以取得且計算複雜
- **常態分配假設**：極端事件下可能失靈

> 💡 **核心要點**：Black-Litterman 不是取代 Markowitz，而是在 Markowitz 的基礎上加了一層貝氏濾網——讓你不確定的觀點自動降權，讓確定的觀點有效放大，最終產出比「硬猜預期報酬率」更穩健的資產配置。對於想做多資產配置的台股投資者，它提供了一個從「我覺得台股會漲」到「台股權重應該調高多少」的數學化橋樑。
