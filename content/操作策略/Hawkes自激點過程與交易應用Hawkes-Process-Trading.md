# Hawkes 自激點過程與交易應用

> 一筆大單成交後，後面跟著更多大單——事件不是獨立的，而是會「自我激發」。Alan Hawkes 1971年提出的自激點過程，從地震學到高頻交易都在用。

## 核心概念

**Hawkes 過程**（Hawkes Process）是一種**自激點過程**（Self-exciting Point Process），由 Alan G. Hawkes 於1971年提出。核心特徵：**一個事件的發生會提高後續事件發生的機率**。

這與傳統的卜瓦松過程（Poisson Process）不同——卜瓦松過程假設事件獨立發生，事件之間沒有互相影響。Hawkes 過程更貼近現實：地震後有餘震、一筆大單後有跟單、一則新聞後有更多討論。

## 數學框架

### 強度函數

Hawkes 過程的條件強度函數：

**λ(t) = μ(t) + Σ ϕ(t - tᵢ)**

其中：
- **μ(t)**：基礎強度（背景事件率，exogenous）
- **ϕ(t - tᵢ)**：激發函數，第 i 個事件在時間 t 的殘留激發效應（endogenous）
- **tᵢ**：第 i 個事件的發生時間

每發生一個事件，強度函數就跳升一次，然後隨時間衰減。

### 激發函數 ϕ

最常見的形式是**指數衰減**：

**ϕ(τ) = α·e^(-β·τ)**

- **α**：激發強度（jump size），事件發生後強度跳升多少
- **β**：衰減速率（decay rate），激發效應多快消失

### 分支比

**η = ∫₀^∞ ϕ(t) dt = α/β**

分支比代表每個事件平均「生下」多少後代事件：
- **η < 1**：過程穩定（stationary），後代數量有限
- **η = 1**：臨界狀態
- **η > 1**：爆炸性增長，事件無限衍生

### 多變量 Hawkes 過程

多個事件類型互相激發：

**λᵢ(t) = μᵢ(t) + Σⱼ Σ ϕᵢⱼ(t - tʲₖ)**

- **ϕᵢⱼ**：類型 j 的事件對類型 i 的激發效應
- 可以是一個市場的事件發另一個市場的事件（跨市場溢出）

## 在金融市場的應用

### 1. 高頻交易中的事件聚類

金融市場的成交時間絕非隨機——大單成交後往往引發更多交易：
- 一筆大額買單成交 → 價格跳動 → 觸發更多買單
- 一筆大額賣單成交 → 價格下跌 → 觸發停損賣單

Hawkes 過程可以量化這種「事件聚類」的強度和持續時間。

### 2. 限價單簿動態建模

- 限價單的掛單和撤單服從自激過程
- 一筆大單吃掉多檔後，新掛單的速度會加快（造市商補單）
- 用 Hawkes 模型預測短期掛單流量，優化做市策略

### 3. 价格跳動建模

- 价格跳動（price jumps）不是獨立的，而是服從自激過程
- 一次大跳動後，短期內有更多跳動的機率顯著上升
- 可用來設計波動率交易策略：跳動聚類 = 波動率聚集

### 4. 系統性風險傳染

- 用多變量 Hawkes 過程建模跨市場、跨資產的事件傳染
- 例如：美股閃崩 → 台股期貨跳空 → 台股現貨賣壓
- 分支比 η 衡量傳染強度，η 越高系統性風險越大

### 5. 新聞與社群媒體事件

- 一則重大消息發布後，相關討論和新聞自激增長
- 用 Hawkes 過程預測消息面的擴散速度和持續時間
- 配合 [[籌碼面分析/恐懼貪婪指標與市場情緒量化Fear-and-Greed-Index|情緒指標]] 使用

## 實戰應用框架

### 事件定義

在台股交易中，可定義的「事件」包括：
- 單筆成交超過 N 張的大單
- 价格跳動超過 M 檔的跳動
- 內盤/外盤成交量突破閾值
- 法人買賣超公告

### 參數估計

- 用最大概似估計（MLE）估計 μ、α、β
- 分支比 η = α/β 是核心監控指標
- η 上升 = 市場自我激發增強，趨勢或恐慌正在形成

### 交易訊號

1. **η 突然上升**：事件聚類加劇，可能是趨勢啟動或消息面發酵
2. **η 持續低檔**：市場平靜，適合均值回歸策略
3. **跨市場 η 差異**：一個市場自激但另一個未跟隨，可能有套利空間

## 與其他模型的關係

- **vs [[操作策略/高頻交易與做市策略High-Frequency-Trading-and-Market-Making|做市模型]]**：Avellaneda-Stoikov 做市模型假設到達率固定，Hawkes 放寬為自激到達
- **vs [[風險管理/GARCH模型與波動率預測GARCH-Model-and-Volatility-Forecasting|GARCH]]**：GARCH 建模波動率聚集，Hawkes 建模事件聚集，兩者從不同角度描述同一現象
- **vs [[技術分析/訂單流失衡OFI-Order-Flow-Imbalance|OFI]]**：OFI 衡量買賣力量失衡的靜態快照，Hawkes 描述失衡的動態演化

## 限制與注意事項

1. **參數估計計算量大**：MLE 需要對所有歷史事件配對計算，高頻數據下計算成本高
2. **模型假設事件可標記精確時間**：實務上成交記錄的時間精度受限
3. **非平穩性**：市場狀態變化時 μ 和 ϕ 可能改變，需要滾動估計
4. **台股數據限制**：逐筆成交數據需要 Level 2 行情，一般投資人不易取得
5. **過度擬合風險**：多變量模型參數多，容易過度擬合歷史數據
