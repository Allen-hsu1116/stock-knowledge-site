# 最小變異數投資組合 Minimum Variance Portfolio

> 不猜報酬率、不靠預測，只靠共變異數矩陣算出波動最低的權重組合——Markowitz 框架中最穩健的「無觀點」策略，在因子衰退和預測失靈時反而最可靠

## 核心概念

最小變異數投資組合（Minimum Variance Portfolio, MVP）是 Markowitz 均值-方差優化框架中的一個特殊解。在有效前沿上，MVP 是最左邊的點——**所有可能投資組合中波動率（標準差）最低的組合**。

MVP 的核心哲學：**不對預期報酬率做任何假設**，只最佳化風險。這聽起來消極，但在實務上反而是最大優勢——因為預期報酬率的估計是投資組合優化中最不穩定的部分，MVP 完全跳過了這個問題。

### 為什麼 MVP 重要？

Markowitz 均值-方差優化的實務痛點是**預期報酬率極難準確估計**。輸入微小變化就會導致權重大幅波動（被稱為「誤差最大化」問題）。MVP 只需要共變異數矩陣，不需要預期報酬率，因此：

1. **輸入更少**：不需要估計預期報酬率（最不穩定的輸入）
2. **更穩健**：共變異數矩陣雖然也不完美，但比報酬率預測穩定得多
3. **樣本外表現更好**：學術研究反覆證實 MVP 在樣本外績效優於等權重和市值加權

## 數學公式

### 目標函數

```
最小化：σ²p = w' Σ w

限制條件：
  w' 1 = 1    （權重總和為 1）
  w ≥ 0       （不允許放空，可選）
```

其中：
- **w** = 權重向量（n×1）
- **Σ** = 共變異數矩陣（n×n）
- **σ²p** = 投資組合變異數

### 封閉解（無放空限制）

如果允許放空（w 可為負），MVP 有簡潔的封閉解：

```
w = Σ⁻¹ 1 / (1' Σ⁻¹ 1)
```

分子是共變異數矩陣逆矩陣的每列之和，分母是總和的倒數（用於正規化讓權重加總為 1）。

### 不允許放空（更實務）

台股不能放空個股建投資組合（融券有限制），所以實務上需要用**二次規劃（Quadratic Programming）**求解：

```
最小化 w' Σ w
限制條件：Σwi = 1, wi ≥ 0
```

這需要數值優化演算法（如 SMO、內點法），Excel 的 Solver 或 Python 的 `scipy.optimize` 都能做。

## 實戰建構步驟

### Step 1：選擇資產池

- 台股應用：選 10-20 檔不同產業的龍頭股（如台積電、鴻海、國泰金、中華電、統一等）
- 跨資產：股票 + 債券 + 商品 + REITs，分散性更好
- 注意：資產數量不宜太多（共變異數矩陯的估計誤差隨 n² 增長）

### Step 2：估計共變異數矩陣

- **樣本共變異數**：用過去 60 個月（5年）的月報酬計算，最簡單但估計誤差大
- **收縮估計（Shrinkage）**：Ledoit-Wolf 方法，將樣本共變異數向單因子模型收縮，顯著降低估計誤差
- **因子模型**：用 Fama-French 因子或產業因子的共變異數結構，雜訊更少

### Step 3：求解最佳權重

```python
from scipy.optimize import minimize
import numpy as np

def min_variance_portfolio(cov_matrix):
    n = len(cov_matrix)
    # 目標函數：組合變異數
    def portfolio_variance(w):
        return w @ cov_matrix @ w
    # 限制條件
    constraints = {'type': 'eq', 'fun': lambda w: np.sum(w) - 1}
    bounds = [(0, 1) for _ in range(n)]  # 不允許放空
    x0 = np.array([1/n] * n)  # 初始猜測：等權重
    result = minimize(portfolio_variance, x0, method='SLSQP',
                      constraints=constraints, bounds=bounds)
    return result.x
```

### Step 4：再平衡頻率

- **季度再平衡**：最常見，平衡追蹤誤差和交易成本
- **半年再平衡**：交易成本低，適合台股（手續費 0.1425%）
- **觸發式再平衡**：偏離目標權重超過 20% 才再平衡

## MVP 的實證表現

### 學術研究亮點

1. **Clarke, de Silva & Thorley (2011)**：美股市場，MVP 年化夏普比率比市值加權高 0.15-0.25
2. **DeMiguel, Garlappi & Uppal (2009)**：樣本外測試，MVP 在多數情境下打敗等權重策略
3. **台股應用**：用台灣 50 指數成分股建構 MVP，年化波動率比市值加權低 3-5%

### MVP 為什麼有效？

**低 Beta 效應**：MVP 天然偏離高 Beta 股票（因為高 Beta 股票貢獻更多變異數），而低 Beta 異象是學術上最穩健的因子之一。

**分散化紅利**：MVP 不會過度集中於單一股票（市值加權的致命弱點），天然達成分散。

**反集中化**：市值加權在台積電佔大盤 40% 的台股市場極度集中，MVP 可以把權重分散到低相關性的防禦型股票。

## MVP vs 其他配置策略

### MVP vs 市值加權
- 市值加權：簡單，免再平衡，但集中度風險高（台積電佔 40%）
- MVP：分散，低波動，但需要再平衡和交易成本

### MVP vs 等權重
- 等權重：簡單透明，但忽略了資產間的相關性
- MVP：考慮相關性結構，理論上更優，但估計誤差可能抵消優勢

### MVP vs [[風險平價Risk-Parity|風險平價]]
- 風險平價：每個資產貢獻相同風險，平衡度更好
- MVP：最小化總變異數，某些資產可能權重極低或為零

### MVP vs [[Black-Litterman模型結合觀點與市場均衡Black-Litterman-Model|Black-Litterman]]
- BL 模型：加入投資者觀點到市場均衡，需要預期報酬率
- MVP：完全不需要預期報酬率，是 BL 模型的「無觀點」特例

### MVP vs [[階層式風險平價HRP-Hierarchical-Risk-Parity|HRP]]
- HRP：用階層聚類重組共變異數矩陣，更穩健但更複雜
- MVP：數學簡潔，但對共變異數矩陣的估計誤差敏感

## 台股實戰注意事項

1. **集中度問題**：台股市值加權極度集中於台積電（佔比 35-40%），MVP 可以有效降低集中度風險，將權重分散到金融、電信、傳產

2. **流動性考量**：MVP 可能給低流動性股票較高權重（因為低流動性通常意味著低波動），需加入流動性限制（如最低成交量門檻）

3. **產業均衡**：純 MVP 可能過度配置防禦型產業（金融、電信），錯過科技股成長。可加入產業權重上限

4. **交易成本**：台股手續費 0.1425%（打折後約 0.1%），再平衡頻率不宜太頻繁。季度再平衡 + 觸發式調整是最佳平衡

5. **稅務考量**：台股證交稅賣出 0.3%，再平衡時賣出端成本較高，適合半年或年度再平衡

## 常見誤區

1. **「低波動 = 低報酬」**：錯。低 Beta 異象告訴我們，低波動股票長期報酬率不輸高波動股票，MVP 不一定犧牲報酬

2. **「MVP 永遠最好」**：錯。MVP 在多頭市場可能落後市值加權（因為 MVP 低配了高 Beta 的領漲股）。它是防禦型策略，適合震盪市和熊市

3. **「共變異數矩陣很穩定」**：錯。相關性在危機中會暴增（[[相關性崩潰Correlation-Breakdown|相關性崩潰]]），MVP 在常態下的分散效果在極端事件時可能失效

4. **「樣本越大越好」**：不一定。太長的樣本期包含了已經不適用的歷史結構，60 個月通常是較好的平衡點

## 總結

最小變異數投資組合是 Markowitz 框架中最實用的策略之一，因為它跳過了最難估計的預期報酬率。在台股這種集中度極高的市場，MVP 提供了一個天然的分散化工具。實戰上，MVP 最適合作為核心配置（[[核心衛星投資策略Core-Satellite-Strategy|核心-衛星策略]]的核心部位），用低波動的分散組合打底，再用衛星部位追求超額報酬。
