# 凱利公式 Kelly Criterion 最佳下注比例

> **一句話：** 凱利公式用數學告訴你「有多少把握下多少注」——勝率60%、賠率1:1 的賭局，最佳下注比例是總資金的20%，多下是自殺，少下是浪費。

## 核心概念

**凱利公式（Kelly Criterion）** 是 John Larry Kelly Jr. 於 1956 年在貝爾實驗室提出的數學公式，用來計算在重複博弈中，每次應該投入總資金的多少比例，才能讓**長期幾何成長率最大化**。

簡單說，它回答一個核心問題：**「這一筆交易，我該壓多少？」**

## 賭博版公式（二元結果）

最基礎的凱利公式，適用於「全贏或全輸」的賭局：

```
f* = (p × b - q) / b = p - (1-p)/b
```

**參數說明：**
- **f\*** = 最佳下注比例（占總資金的百分比）
- **p** = 獲勝機率
- **q** = 失敗機率（= 1 - p）
- **b** = 賠率（贏的時候淨賺多少倍下注金額）

**範例：** 60% 勝率、1:1 賠率（贏了賺一倍下注額）

```
f* = (0.6 × 1 - 0.4) / 1 = 0.2 → 下注 20% 的總資金
```

## 投資版公式（部分損失）

投資不像賭博會全輸，股價跌 10% 只損失 10% 而非 100%。投資版凱利公式：

```
f* = p/l - q/g
```

**參數說明：**
- **p** = 上漲機率
- **q** = 下跌機率（= 1 - p）
- **g** = 上漲時的漲幅比例（如 +10% → g = 0.1）
- **l** = 下跌時的跌幅比例（如 -10% → l = 0.1）

**範例：** 70% 機率漲 15%，30% 機率跌 10%

```
f* = 0.7/0.1 - 0.3/0.15 = 7 - 2 = 5 → 凱利比例 500%？！
```

凱利比例超過 100% 代表理論上應該用槓桿，但實務上極度危險，因為你對 p、g、l 的估計一定有誤差。

## 股市版公式（連續報酬）

對於股價服從幾何布朗運動的連續模型，凱利公式簡化為：

```
f* = (μ - r) / σ²
```

**參數說明：**
- **f\*** = 最佳投入比例
- **μ** = 標的預期報酬率
- **r** = 無風險利率
- **σ²** = 標的報酬率變異數

**範例：** S&P 500 預期報酬 8%，無風險利率 2%，年化波動率 16%（σ² = 0.0256）

```
f* = (0.08 - 0.02) / 0.0256 = 2.34 → 凱利比例 234%
```

Thorp 估計美股市場的凱利比例約 117%，即理論上應該用 1.17 倍槓桿。但這是基於假設的參數估計，實際操作極度不建議接近這個比例。

## 為什麼不用 Full Kelly？

凱利公式在理論上完美，在實務上致命：

**1. 參數估計不確定性**

凱利公式的輸入（p、g、l 或 μ、σ）都是估計值。如果你估計勝率 60% 但實際只有 50%，Full Kelly 會讓你下注 20% 但實際期望值為零——等於用 20% 的部位在賭運氣。

**2. 極端回撤**

Full Kelly 的最大回撤可以達到 99.9% 雖然機率極低但路徑上的波動大到心理難以承受。歷史上很多使用 Full Kelly 的交易者不是因為策略錯而是因為回撤期間受不了出場。

**3. 模型假設過於理想**

凱利假設每次賭局獨立同分佈、已知精確機率、可以無限分割下注——這些在金融市場全不成立。

## Fractional Kelly（分數凱利）

實務上幾乎所有人使用**分數凱利**，即只投入凱利公式建議比例的一部分：

- **Half Kelly（50%）：** 最常見的折衷方案，大幅降低波動和回撤，長期成長率只降低約 25%
- **Quarter Kelly（25%）：** 極度保守，適合高不確定性環境或新手
- **1/N Kelly：** 有 N 個部位時每個部位用 1/N 的凱利比例，自然分散

**Half Kelly 的數學優勢：**

- 長期成長率約為 Full Kelly 的 75%（只損失 25%）
- 最大回撤約只有 Full Kelly 的一半
- 波動率降低約 50%

## 多資產凱利

對於多資產組合，凱利公式變成矩陣形式：

```
f* = Σ⁻¹ × (μ - r)
```

- **f\*** = 最佳權重向量
- **Σ⁻¹** = 報酬率協方差矩陣的逆矩陣
- **(μ - r)** = 超額報酬向量

這跟 Markowitz 均值-方差優化的結果一致，但凱利版本的目標是最大化幾何成長率而非均值-方差效用。

## 凱利公式的行為實驗

Wikipedia 記載了一個經典實驗：受試者拿到 $25，可以對一個 60% 勝率的硬幣下注 30 分鐘。凱利公式建議每次下注 20%，理論上 300 次後可以長到 $10,505。

**實際結果：**
- 28% 的人破產
- 平均最終只有 $91
- 只有 21% 達到上限 $250
- 18 人把全部資金壓在單次投擲上

這個實驗證明：**即使知道最佳比例，絕大多數人的行為都會偏離理性**。凱利公式的難處不在算數學，在於執行紀律。

## 凱利公式的批評

- **Samuelson 批評：** 保羅·薩繆爾森指出凱利的「時間分散」與「資產分散」不同，長期最大化幾何成長率不等於最大化個人的效用函數
- **尾部風險：** 凱利假設報酬分佈對稱，但股市有顯著的左尾風險（崩盤），實際凱利比例應更低
- **參數敏感：** μ 和 σ 的微小變化會導致 f* 劇烈變化，garbage in garbage out

## 總結

凱利公式不是讓你算出「應該壓多少」的魔術公式，而是一個**思考框架**：

1. 它提醒你每筆交易都有最佳下注比例，不是「感覺」來的
2. 它讓你量化自己的「edge」——如果你算不出 p 和 g/l，你根本沒有 edge
3. 它告訴你分數凱利（Half Kelly）是實務上最合理的折衷
4. 它證明超過凱利比例下注長期必定比凱利差（不是少賺而是會虧）

記住：凱利公式的核心精神是「有優勢時適度下注，沒優勢時不下注」，不是讓你算出一個數字然後 all in。

## 實戰應用
### 1. 單一交易部位控制

假設你有一筆交易：
- 歷史回測勝率 55%
- 賺的時候平均 +8%，虧的時候平均 -5%
- 帳戶總資金 100 萬

```
凱利比例 = 0.55/0.05 - 0.45/0.08 = 11 - 5.625 = 5.375
Half Kelly = 5.375 × 0.5 = 2.69 → 269%
```

這顯然太高了，代表你的回測參數過於樂觀或樣本不足。實務上應該用更保守的 Quarter Kelly 或直接設上限（如單筆不超過 10%）。

### 2. 凱利公式驗證策略可行性

如果凱利公式算出來是**負數**，代表這個策略期望值為負，根本不該交易：

```
f* < 0 → 不要交易這個策略
f* ≈ 0 → 邊際策略，不值得冒險
f* > 0 → 有正期望值，可以用 Fractional Kelly 控制部位
```

### 3. 結合固定比例風險控制

凱利公式可以跟 [[部位控制2%法則Position-Sizing-2-Percent-Rule|2% 法則]] 結合：

- 先用凱利公式算出理論最佳比例
- 再用 2% 法則設上限（單筆虧損不超過總資金 2%）
- 取兩者的較小值作為實際下注比例

### 4. 凱利比例作為信心溫度計

凱利比例越高代表你對這筆交易的「edge」越有信心。可以建立分級制度：

- **凱利比例 < 5%：** 低信心，用 1-2% 部位測水溫
- **凱利比例 5-15%：** 中信心，用 3-5% 部位
- **凱利比例 > 15%：** 高信心，用 5-10% 部位（但永遠不超過 10%）
