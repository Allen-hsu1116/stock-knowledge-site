# 因子擇時進階實戰 Factor Timing Advanced

> 知道價值因子長期有效不難，難的是知道「現在」該押價值還是押動能。因子擇時被稱為量化投資的聖杯，也是最多人翻車的地方。

## 核心概念

**因子擇時**（Factor Timing）是指在不同市場環境下動態調整各因子的權重，試圖在價值、動能、品質、低波動等因子之間切換以獲取超額報酬。

這與**因子輪動**（Factor Rotation）不同：輪動是被動追隨因子間的相對強弱，擇時是主動預測因子未來表現。

### 為什麼因子擇時如此困難？

1. **因子報酬高度波動**：價值因子一年可以跑贏大盤 20%，下一年可以跑輸 20%
2. **因子週期長**：價值因子可以連續 5-7 年失效，考驗投資人耐心
3. **因子相關性不穩定**：危機時所有因子相關性趨向 1，分散效果消失
4. **樣本數太少**：一個完整的因子週期可能 10-15 年，回測樣本嚴重不足
5. **過度擬合風險**：用太多總經指標預測因子，容易曲線套入歷史數據

## 五大因子與其週期特徵

### 價值因子（Value）
- **適用環境**：經濟復甦初期、通膨上升、利率正常化
- **失效環境**：低利率環境、成長股泡沫、市場追逐題材
- **歷史教訓**：2018-2021 年價值因子連續四年跑輸大盤，2022 年才大爆發

### 動能因子（Momentum）
- **適用環境**：趨勢明確的市場、政策方向清晰
- **失效環境**：市場轉折點、[[風險管理/動量崩潰Momentum-Crash|動量崩潰]]
- **歷史教訓**：2009年3月動量因子單月跌 50%，因市場從空頭急轉多頭

### 品質因子（Quality）
- **適用環境**：市場修正期、熊市、不確定性高的環境
- **失效環境**：極端牛市、投機情緒高漲
- **特徵**：品質因子是唯一在空頭市場也不太虧錢的因子，見 [[基本面分析/品質因子選股進階Quality-Factor-Advanced|品質因子進階]]

### 低波動因子（Low Volatility）
- **適用環境**：震盪市、熊市
- **失效環境**：強勢牛市（低波動股漲幅落後）
- **注意**：低波動因子有「防禦」特質但不是「攻擊」工具

### 规模因子（Size）
- **適用環境**：經濟擴張期、小型股盈利成長加速
- **失效環境**：避險情緒升高、資金流向大型股
- **近年趨勢**：規模因子在美股效果遞減，在台股小型股效果仍存

## 因子擇時的三大方法論

### 方法一：總經指標法

用總體經濟指標判斷目前適合哪個因子：

**景氣循環四階段對應**（參考 [[操作策略/美林投資時鐘景氣循環四階段|美林投資時鐘]]）：
- **復甦期**（利率低 + 成長加速）→ 動能 + 規模
- **過熱期**（利率升 + 成長高）→ 價值 + 品質
- **停滯期**（利率高 + 成長降）→ 低波動 + 品質
- **衰退期**（利率降 + 成長低）→ 低波動 + 品質

**實戰指標**：
- **殖利率曲線**：陡峭 → 價值，平坦/倒掛 → 品質 + 低波動
- **信用利差**：收窄 → 動能 + 價值，擴大 → 品質 + 低波動
- **ISM/PMI**：上升 → 動能 + 規模，下降 → 品質 + 低波動

### 方法二：因子估值法

用因子本身的「估值」判斷是否便宜：

- **價值因子的估值**：價值股的 P/B 相對成長股的 P/B 比率，歷史極端低點 = 價值因子便宜
- **動能因子的估值**：動能股的估值溢價，過高 = 動能擁擠
- **品質因子的估值**：品質股的估值溢價，過高 = 品質擁擠

**核心邏輯**：因子本身也有周期，便宜的因子未來報酬更高。

### 方法三：因子動能法

用因子自己的動能來擇時——哪個因子近 3-6 個月表現好就加碼：

- **優點**：不需要預測，單純追隨趨勢
- **缺點**：在因子轉折點會慢半拍，可能買在高點賣在低點
- **改良**：用 1 個月和 12 個月動能的組合，降低噪音

## AQR 的研究結論

AQR Capital（Cliff Asness 的公司）的研究指出：

1. **因子擇時很難跑贏固定權重的多因子組合**
2. **因子估值法是唯一有證據支持的擇時方法**，但效果邊際不大
3. **投資人最大的錯誤是在因子失效時放棄**，而不是擇時失敗
4. **推薦做法**：固定權重多因子組合 + 用因子估值做微調（±10-20%）

## 實戰應用

### 實戰操作框架
### Step 1：建立因子基準權重

根據風險容忍度和投資期限設定基準：
- 保守型：品質 40% + 低波動 30% + 價值 20% + 動能 10%
- 均衡型：價值 30% + 品質 25% + 動能 25% + 低波動 20%
- 積極型：動能 35% + 價值 30% + 品質 20% + 規模 15%

### Step 2：用因子估值做微調

- 計算各因子的估值百分位（相對歷史）
- 估值在歷史 20% 以下 → 加碼 10-20%
- 估值在歷史 80% 以上 → 減碼 10-20%
- 不要做超過 ±20% 的調整（擇時誤差比不擇時更大）

### Step 3：用總經環境做方向確認

- 殖利率曲線 + 信用利差 + PMI 三指標共振時才做較大調整
- 只有一個指標訊號時維持基準權重

### Step 4：紀律執行

- **不要在因子失效時放棄**：價值因子連續 3 年跑輸大盤是正常的
- **不要追熱門因子**：2021 年追動能、2022 年追價值、2023 年追 AI，每個都慢半拍
- **定期再平衡**：每季或每半年再平衡一次，避免單一因子權重失控

## 台股因子擇時的特殊考量

1. **台股產業集中度高**：台積電權重過大，純因子策略效果被權值股稀釋
2. **籌碼面影響大**：外資期貨空單、融資餘額等籌碼因素可能壓過因子效果
3. **除權息季節性**：6-9月除權息旺季影響價值因子表現，見 [[操作策略/台股除權息旺季季節性套利策略Taiwan-Ex-Dividend-Season-Arbitrage|除權息策略]]
4. **法人行為**：投信做夢、外資套利，法人行為可能扭曲因子報酬

## 注意事項

### 常見陷阱
1. **過度自信**：以為能精準判斷因子轉折，結果每次都慢一拍
2. **確認偏誤**：只看支持自己判斷的指標，忽略反面證據
3. **短期主義**：因子效果以年為單位衡量，用月度績效判斷因子有效性是錯的
4. **忽略交易成本**：頻繁調整因子權重產生的交易成本可能吃掉擇時收益
5. **因子擁擠**：當大家都用同一個因子擇時模型時，模型本身會失效
